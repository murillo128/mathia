# Experimental entry point

The first executable Mathia research work is the **pre-RL conceptual signal study** described in:

- `docs/FIRST_MATHEMATICAL_WORLD.md`
- `docs/PRE_RL_SIGNAL_STUDY.md`

The immediate objective is to implement exact finite-arithmetic generators/verifiers and measure whether frozen conceptual contexts causally improve held-out mathematical interventions.

Do **not** add RL training, Lean integration, a large synthetic corpus, or a fixed dataset schema until this study shows a discriminative signal worth training on.
