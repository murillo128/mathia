# Prime-lattice research lines

This file records current mathematical questions for the Prime Lattice line. It is a mutable synthesis, not a task queue or history.

## Add analytic or target-relative structure beyond the native almost-periodic quotients

**Linked intuition:** `MI-044-finite-prime-wold-classification-does-not-globalize-atomically`.

PL-383--PL-385 show that ambient strong/selfadjoint closure and the unweighted norm algebra forget too much: the former recovers the continuous shift geometry, while the latter preserves the discrete positive semigroup only as a universal free commutative/polydisk algebra. PL-386 provides an important positive boundary: once the selfadjoint energy data are retained, norm-closed structure can recover the ordered numerical frequency weights. Numerical `log p` geometry is therefore not intrinsically lost; it has to be carried as distinguished structure.

PL-387--PL-389 test the corresponding almost-periodic index route. The standard Coburn--Douglas/Wiener--Hopf index reads additive frequency energy, but the native vertical zeta symbol is AP-invertible with zero index for `Re(s)>1` and leaves the bounded uniform-AP algebra throughout `1/2<Re(s)<1` because zeta values there are unbounded and approach zero densely. Even RH would not restore AP invertibility.

PL-390 closes the obvious Besicovitch escape. The vertical zeta function does define a `B^2` mean-square almost-periodic element for every `sigma>1/2`, with frequencies `-log n` and squared norm `zeta(2sigma)`. But `B^2` is a mean-square quotient: isolated zeros can be changed on a null set without changing the element, and the space is not the pointwise Banach algebra needed by the previous invertibility/index mechanism. The `1/2` boundary is therefore a square-summability wall, not an RH-sensitive zero transition.

The live route must add structure not contained in either native quotient: a distinguished analytic representative/Jensen object, a source-forced renormalized or affiliated symbol theory, or a compression to the Nyman target that retains both numerical prime weights and pointwise analytic information. Classical Borchsenius--Jessen analytic almost-periodic zero theory is already prior art, so merely restoring Jensen/mean-motion data does not by itself constitute a new prime-lattice mechanism.

## Keep frequency recovery, symbol membership, pointwise zero data and Fredholm indexability separate

PL-386 shows that numerical weights can be recoverable in a sufficiently enriched operator pair. PL-389 shows that the natural zeta symbol can nevertheless leave the bounded symbol algebra before the critical line. PL-390 shows that weakening the topology enough to carry the symbol through the open strip can erase the isolated zero data the destination needs.

Future index proposals should therefore state simultaneously which topology carries the vertical symbol, what distinguished representative or target restores pointwise analytic information, what multiplicative/Fredholm structure remains available, and why matched generic-frequency or prime-twist controls do not reproduce the same invariant.
