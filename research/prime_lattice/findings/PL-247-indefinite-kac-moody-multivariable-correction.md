# PL-247 — Indefinite Kac–Moody correction factors give canonical multivariable imaginary coupling, but lose affine positivity

## Claim

`PL-245` showed that Weyl-invariant imaginary-root freedom in affine type is confined to the one-dimensional null-root direction, while `PL-246` showed in the explicit `\widetilde A_1` multiple-Dirichlet-series model that an additional source-forced selector still chooses only a scalar Pochhammer factor and that the zero-bearing function-field block is centered using Weil purity as input. A theorem-level representation-theoretic control sharpens the boundary of that conclusion.

Muthiah–Puskás–Whitehead define the canonical correction factor `m` attached to an arbitrary Kac–Moody root system in the `p`-adic Kac–Moody spherical/Whittaker framework. It is a Weyl-invariant formal power-series unit supported on the positive imaginary cone and has the unique product expansion

`m = product_(lambda in Q_im^+) product_(n>=0) (1-t^n e^lambda)^(-m(lambda,n))`.

In **every affine type**, `Q_im^+` is generated by the single minimal imaginary root `delta`, so `m` is a one-variable series in `e^delta`; their uniform affine formula makes this explicit for all affine types. In **indefinite type**, by contrast, `Q_im^+` is a saturated graded cone of full rank, and their Theorem 7.5 proves that the polynomial `m_lambda(t)=sum_n m(lambda,n)t^n` is nonzero exactly when `lambda` is a root. Thus the standard Kac–Moody correction factor itself contains nonzero factors along multiple independent imaginary-root directions: indefinite type is the first intrinsic Kac–Moody regime in which this correction is genuinely multivariable rather than merely a higher-rank presentation of one null-root scalar.

The same source supplies an immediate RH-facing obstruction. In affine type the normalized polynomials

`chi_lambda(t) = m_lambda(t)/(1-t)^2`

have positive coefficients. Beyond affine type this positivity fails in general; in rank-two hyperbolic type an alternating-sign pattern is only conjectural, and the authors state that even that pattern fails beyond rank two. Hence the first canonical regime that supplies genuinely multivariable imaginary coupling simultaneously loses the elementary coefficient-positivity structure available in affine type.

**Evidence/status:** `LITERATURE+EXACT-DERIVED + PRIOR-ART-REDIRECT + NEGATIVE-BOUNDARY + NO-NOVELTY-CLAIM`. The Kac–Moody correction factor, the affine one-variable statement, the full-rank indefinite imaginary cone, the product formula, the nonvanishing criterion, and the loss of affine coefficient positivity are published prior art. The line-level consequence is the routing statement: increasing affine rank cannot make the standard Kac–Moody correction factor nonseparable, whereas indefinite type supplies canonical multivariable support but not an automatic positivity mechanism. No claim is made that this formal correction factor is itself a Riemann-zeta continuation or that it solves the source-selection problem for number-field multiple Dirichlet series.

## The exact affine/indefinite boundary

Let `Q` be the root lattice, `Q^+` the positive root cone, and `Q_im^+` the cone generated by positive imaginary roots. Muthiah–Puskás–Whitehead define `m` intrinsically from the real-root denominator by relative inversion on `Q_im^+`; their Theorem 3.12 states that `m` and `m^(-1)` are Weyl-invariant power-series units supported on this cone.

The geometry of the support cone changes qualitatively with Kac–Moody type. In finite type the imaginary subspace is zero-dimensional. In affine type the positive imaginary cone is one-dimensional and generated by the minimal imaginary root `delta`. In indefinite type, using the standard Kac results they cite, the positive imaginary roots generate a saturated graded cone of **full rank** in `Q`.

This is stronger than merely saying that an indefinite root system has many roots. The correction factor is supported precisely on the canonical Weyl-invariant imaginary cone, so the dimension jump occurs in the support of the object that corrects the spherical/Whittaker formula itself rather than in an auxiliary choice of coordinates.

## Why all affine ranks remain scalar

For an affine Kac–Moody root system every imaginary root has the form `eta=k delta`. Muthiah–Puskás–Whitehead define an explicit factor `m_eta` for each such root and prove uniformly across all affine types

`m = product_(eta in Phi_im^+) m_eta`.

Each `m_eta` depends on its root-lattice variable only through `e^eta=(e^delta)^k`. Consequently no matter how large the affine Dynkin rank is, the entire standard correction factor lives in the one-variable ring generated by `e^delta`.

This closes a specific possible escape left after `PL-246`: **higher affine rank by itself does not make the canonical Kac–Moody correction factor multivariable**. It does not close additional non-Weyl/local-global selector relations of the kind Popa–Walsh find in `\widetilde A_1`; those are extra structure and must be audited separately rather than identified with `m`.

## Why indefinite type is genuinely multivariable

For arbitrary Kac–Moody type the correction factor has a unique product over `Q_im^+`. Write

`m_lambda(t)=sum_(n>=0) m(lambda,n)t^n`.

Theorem 7.5 proves

`m_lambda(t) != 0  <=>  lambda is a root`

for `lambda in Q_im^+`. In indefinite type, the positive imaginary roots generate a full-rank cone. Therefore there are positive imaginary roots in linearly independent directions and the corresponding `m_lambda` are nonzero. The product defining `m` consequently contains intrinsic factors in several independent monomial directions `e^lambda`; it cannot be reduced to the affine form `C(e^delta)` for a single null-root coordinate.

This provides a useful matched control for the current line. A canonical, source-derived, non-one-dimensional correction object **does exist** once one leaves affine type. Thus the obstruction in `PL-245` should not be generalized to “Kac–Moody symmetry always scalarizes the imaginary sector.” Its exact scope is affine type.

## The positivity tradeoff

The same product admits a coefficient package that is unusually clean in affine type. The authors prove that for every imaginary root `lambda`, `m_lambda(t)` is divisible by `(1-t)^2`, and define

`chi_lambda(t)=m_lambda(t)/(1-t)^2`.

In affine type `chi_lambda(t)` has positive coefficients with an explicit finite-root interpretation. The source then states that **beyond affine type these polynomials no longer have positive coefficients**. For rank-two hyperbolic systems they conjecture an alternating-sign pattern from computation; beyond rank two they explicitly say that this pattern does not hold either.

For the RH program this is an important falsification control. Moving to indefinite type succeeds at the narrow task of obtaining a canonical multivariable imaginary correction, but the move does not simultaneously provide the kind of positive quadratic form, positive kernel, or monotone coefficient structure that could plausibly force zero localization. Any such positivity would have to be a subtler invariant than coefficientwise positivity of the normalized correction factors.

## Relation to the prime-exponent lattice

The Kac–Moody root lattice is **not** the prime-exponent lattice `N_0^(P)`, and no canonical identification of its simple-root directions with rational primes is supplied by this theory. Mapping prime coordinates to simple-root variables by hand would therefore be exactly the kind of arbitrary re-encoding excluded by the `prime_lattice` mandate.

What the result supplies is a structural control on a proposed mechanism: if a future arithmetic construction maps rational-prime data into a Kac–Moody correction/selector object, then affine rank alone cannot create the required nonseparable imaginary interaction. Indefinite type has enough intrinsic support dimension, but a valid bridge must still explain why the rational primes select that root system and how the same object couples to the ordinary Riemann divisor.

Nor does the formal product above justify analytic continuation of `zeta(s)`. Muthiah–Puskás–Whitehead work with root-lattice power series and Kac–Moody correction factors. The statement here is a representation-theoretic support/positivity boundary, not a passage from an Euler product in `Re(s)>1` into the Riemann critical strip.

## Adversarial controls

**Multivariable support is not yet a zeta mechanism.** Full-rank `Q_im^+` proves that the correction factor has genuinely multiple root-lattice directions. It does not provide a number-field Dirichlet series whose Riemann-zeta factor shares those variables, much less a theorem forcing its zeros to a symmetry line.

**The affine result closes only the standard correction factor.** The one-variable theorem concerns the canonical Macdonald/Gindikin–Karpelevich/spherical/Whittaker correction `m`. Extra functional equations or local-global selectors can impose additional conditions not contained in Weyl invariance; `PL-246` is an explicit example. No claim is made that all higher-affine multiple Dirichlet series scalarize.

**Loss of coefficient positivity is not a theorem that all indefinite positivity is impossible.** The source rules out the simple affine positivity of `chi_lambda`. Operator positivity, signed pairings, Hodge-theoretic positivity, or a different normalized object could still exist and would need independent proof.

**The rank-two hyperbolic sign pattern is conjectural.** It is retained only as a boundary marker from the source, not used as evidence for an RH mechanism.

**No ordinary-zeta continuation is inferred.** The root-lattice formal series and its product are not being analytically identified with `zeta`. Any future specialization must establish its convergence/continuation and arithmetic meaning independently.

## Prior-art and novelty audit

The decisive source is Dinakar Muthiah, Anna Puskás, and Ian Whitehead, “Correction factors for Kac–Moody groups and `t`-deformed root multiplicities,” *Mathematische Zeitschrift* **296** (2020), 127–145, DOI `10.1007/s00209-019-02419-1`, arXiv `1806.05209`.

Their Section 2 identifies the affine imaginary subspace as one-dimensional and the indefinite positive imaginary cone as full-rank. Section 3 proves that the correction factor is Weyl-invariant and supported on `Q_im^+`. Theorem 4.2 gives the uniform all-affine product formula, Theorem 7.5 gives `m_lambda(t) != 0` exactly on roots, and Theorem 7.6 together with the discussion around `chi_lambda` records the affine divisibility/positivity and its failure beyond affine type.

The source itself emphasizes that the affine formula is equivalent to the Macdonald constant-term theorem and is established prior art. The existence of multivariable indefinite correction factors is likewise not claimed as a Mathia discovery. The durable delta here is the **exact routing boundary relative to `PL-245`–`PL-246`**: standard higher-affine correction factors cannot provide new multivariable coupling; indefinite type can, but the simplest positivity feature is lost exactly when that dimensional escape appears.

A current audit against the 2026 Popa–Walsh decomposition of Weyl-group multiple Dirichlet series for symmetrizable Kac–Moody root systems does not alter this boundary. Their affine `\widetilde A_1` extra functional equation is genuinely additional selector structure, while beyond affine they describe the imaginary-root orbit structure as substantially more complicated. Nothing found in that audit turns the indefinite correction factor into a number-field Riemann-zero localization principle.

## Research implication

The representation-theoretic branch should stop treating “higher affine rank” as a plausible way to make the **standard** imaginary correction nonseparable. If this branch is pursued further, the mathematically distinct targets are now:

- indefinite Kac–Moody / hyperbolic imaginary-root corrections, where canonical multivariable coupling actually exists;
- extra non-Weyl/local-global selector relations in higher affine or indefinite multiple Dirichlet series, which are not the standard correction factor;
- pre-scalarization geometric objects, such as Hodge/perverse-sheaf data, only if they supply a source-derived arithmetic map and an independently proved positivity or purity mechanism.

For RH relevance, dimensional richness is only Gate 1. A surviving mechanism still has to couple the exact rational-prime norm data to the same zero-sensitive divisor and supply a sign, self-adjointness, purity, or positivity principle that is not imported from a function-field analogue.
