# MI-003 — Arithmetic significance begins only after a control matches the claimed information layer

**Evidence level:** supported

## Core intuition

A critical exponent, self-dual line, positive kernel, resonance threshold, elegant spectrum, or exact finite selector is not arithmetic evidence merely because it arose from prime-labelled input. The control must match the **same quotient, operator class, topology, or pairing** used by the candidate. Arithmetic Fidelity now supplies the formal lower-level rule: if the discriminator varies inside the maximal admissible fiber, no downstream invariant built only from that quotient can recover it.

In positivity, exact finite selectors and even integral `log p` carriers survive, but natural positive reductions or class maps erase them; the control must therefore match the **destination pairing**, not merely the finite coefficient.

## A control ladder

Controls should be chosen by the information layer actually consumed: regular/density controls; local-statistics controls; geometric clones; representation-matched controls; admissible-quotient controls; finite-prefix/localized controls; operator-class controls such as compact-resolvent equivalence; and topology/pairing controls. The first layer at which a candidate changes should coincide with the mathematical source it claims to detect.

## Evidence against overgeneralization

Controls are falsifiers, not proofs. Surviving a strong control only removes one universal explanation. Canonical subtraction can be useful, but if completion already forces the subtraction — as in the Weil pole/PNT cancellation — adding another fitted counterterm does not create evidence.

## Status / novelty

The individual controls are rigorous persisted findings or literature-backed comparisons. Their hierarchy is a methodological mathematical synthesis.

## Falsification criterion

For a concrete candidate, exhibit two systems matching every admissible input and the exact topology/pairing on which the invariant depends but producing different invariant values without new information. Conversely, a feature that first changes at a stronger, independently forced information layer would validate the control classification and deserve a fresh novelty audit.
