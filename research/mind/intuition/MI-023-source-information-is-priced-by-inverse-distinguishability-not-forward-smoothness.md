# MI-023 — Source information is priced by the declared acquisition primitive and its inverse/capacity/reliability geometry

**Evidence level:** supported cross-line synthesis from [FD-167](../../farey_discrepancy/findings/FD-167-full-field-l2-inversion-has-uniform-square-root-prefix-conditioning.md), [FD-168](../../farey_discrepancy/findings/FD-168-prefix-mobius-rows-give-coordinate-minimal-stable-partial-farey-sampling.md), [FD-169](../../farey_discrepancy/findings/FD-169-unrestricted-mixed-measurements-collapse-to-target-rank.md), [FD-170](../../farey_discrepancy/findings/FD-170-midpoint-horizon-path-is-a-dirichlet-invertible-temporal-sensor.md), [FD-171](../../farey_discrepancy/findings/FD-171-midpoint-temporal-sensing-has-zero-exact-redundancy.md), [MC-342](../../mobius_cancellation/findings/MC-342-forward-source-regularity-does-not-price-analog-capacity.md), [MC-343](../../mobius_cancellation/findings/MC-343-gaussian-noise-transcript-capacity.md), [MC-344](../../mobius_cancellation/findings/MC-344-bit-flip-source-readout-capacity.md), [MC-345](../../mobius_cancellation/findings/MC-345-adaptive-source-query-feedback-capacity.md), [MC-346](../../mobius_cancellation/findings/MC-346-adaptive-raw-bit-reliability-overhead.md), [MC-347](../../mobius_cancellation/findings/MC-347-variable-fidelity-source-query-divergence-budget.md), [NB-176](../../nyman_beurling/findings/NB-176-euler-weighted-fourier-fingerprints-certify-source-complexity.md), [NB-177](../../nyman_beurling/findings/NB-177-square-summable-euler-spectrum-caps-canonical-complexity-certificate.md), [NB-178](../../nyman_beurling/findings/NB-178-coordinatewise-phase-codes-recover-linear-source-complexity-certificates.md), [NB-179](../../nyman_beurling/findings/NB-179-poisson-separated-dipoles-realize-maximal-coordinatewise-phase-codes-without-arithmetic.md), and [NB-180](../../nyman_beurling/findings/NB-180-prime-power-euler-frequency-support-still-admits-geometric-fourier-codes.md). No common transform theorem is claimed.

Farey Discrepancy, Möbius Cancellation and Nyman--Beurling expose complementary ways raw information counting can fail. The common question is not how many coordinates a representation has, but what **acquisition or dual-access primitive** is allowed, which source fibres it identifies, how the operator itself varies across observations, which amplitudes/conditioning are part of the source channel, and at what inverse/capacity/reliability scale those distinctions remain usable.

FD-167 gives a positive inverse theorem and FD-168 shows the same conditioning survives severe sparsification inside a fixed raw Fourier basis. FD-169 shows why that count is meaningful only because the acquisition family was fixed: with arbitrary target-aware linear measurements, the inverse can be moved into the sensor and the minimum output dimension collapses to target rank.

FD-170 adds a second warning. A single spatial coordinate is not one scalar degree of information if it is observed through a different horizon operator each time. Consecutive midpoint values have increments equal to a Dirichlet convolution with the odd-indicator, and Möbius inversion on odd divisors reconstructs every formal source coefficient. FD-171 proves that this temporal family has **zero exact row redundancy** over the unrestricted normalized formal source class: omitting any one horizon leaves an explicit permanent null direction, and on a finite prefix a selected horizon set `S` has exactly rank `|S|`. Operator variation must therefore be charged not just because it can add information, but because each changing row may be independently indispensable.

MC-342 gives the opposite pathology: a scalar transcript can carry essentially `R` source bits while bounded range and benign forward regularity hide the cost in exponentially small inverse separation. MC-343 converts that hidden precision into an SNR bill. MC-344--MC-345 show that once the primitive is fixed to memoryless noisy coordinate queries, each actual access contributes at most channel capacity even under feedback and adaptive stopping.

MC-346 separates capacity from reliability at fixed BSC quality. If final raw-coordinate error `bar p` must vanish, pairwise change-of-measure forces `Omega_q(R log(1/bar p))` expected accesses. MC-347 then removes query count as the invariant when measurement fidelity can vary. For adaptive raw-coordinate experiments the conserved reliability currency is accumulated directional discrimination divergence `mathfrak D`; vanishing error forces `mathfrak D=Omega(R log(1/bar p))`. A protocol may trade many weak measurements for a few strong ones, but it cannot remove the required pairwise evidence.

NB-176--NB-180 show the same declaration problem on the dual side. The canonical Euler feature map is source-native and jointly Hilbert-contracting, but its square-summed spectrum can be compact enough to under-certify source complexity. Coordinatewise scalar contractions enlarge the witness class and can recover a linear certificate, while NB-179 constructs the same maximal response from source-free Poisson-width dipole packing. NB-180 sharpens the matched control: even restricting probes to genuine prime-power Euler frequencies does not restore selectivity if each frequency is independently normalized. One prime-power tower already gives an exact Fourier code; the actual Euler amplitudes suppress the same response exponentially. **Frequency support without source amplitude/conditioning is only a label restriction, not source fidelity.**

These examples isolate one reusable accounting rule. Before assigning an information cost, state the admissible source class, the acquisition/dual family, every changing operator or horizon, the target quotient, the source amplitudes and allowed renormalization, the observation norm or noise model, the downstream error tolerance and the matched-control geometry. Then prove a resource that survives those declarations: inverse modulus, stable singular values, independent row rank, capacity per admitted access, accumulated discrimination divergence, or charged dual response that cannot be reproduced by generic packing under the same source weights.

Forward smoothness, raw feature count, positive noise, nominal spatial dimension, adaptivity, frequency membership and “canonical” probe labels are secondary descriptors. Sparse coordinates can be enough when the inverse is uniformly conditioned; one spatial coordinate can be complete when the operator changes through a rich hierarchy; those temporal rows can nevertheless be individually irredundant; unrestricted mixtures can make count tautological; feedback cannot create free memoryless capacity; variable fidelity converts query count into discrimination cost; one jointly weighted witness can become compact; and an independently normalized coordinatewise witness can erase exactly the source-amplitude conditioning that made the original channel difficult.

**Boundary.** The cited results concern different finite-source/Farey/Nyman models and do not supply a universal acquisition theorem or canonical noise/dual norm. FD-171's null directions need not preserve Möbius multiplicativity/squarefree structure; MC-347 covers raw-coordinate rather than arbitrary coded experiments; NB-180 uses a prime-power tower and an explicit width sequence. This synthesis is an audit rule: information budgets become mathematical only after the full acquisition, amplitude and resolution geometry is fixed rather than optimized away.
