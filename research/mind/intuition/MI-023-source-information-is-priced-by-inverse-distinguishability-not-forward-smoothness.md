# MI-023 — Source information is priced by the declared source class, acquisition topology and inverse/capacity geometry

**Evidence level:** supported cross-line synthesis from [FD-167](../../farey_discrepancy/findings/FD-167-full-field-l2-inversion-has-uniform-square-root-prefix-conditioning.md) through [FD-172](../../farey_discrepancy/findings/FD-172-dyadic-midpoint-sensing-rigidifies-bounded-squarefree-multiplicative-sources.md), [MC-342](../../mobius_cancellation/findings/MC-342-forward-source-regularity-does-not-price-analog-capacity.md) through [MC-347](../../mobius_cancellation/findings/MC-347-variable-fidelity-source-query-divergence-budget.md), and [NB-176](../../nyman_beurling/findings/NB-176-euler-weighted-fourier-fingerprints-certify-source-complexity.md) through [NB-181](../../nyman_beurling/findings/NB-181-bounded-hilbert-acquisition-cannot-recover-hadamard-scale-euler-codes.md). No common transform theorem is claimed.

Farey Discrepancy, Möbius Cancellation and Nyman--Beurling expose complementary ways raw information counting can fail. The common question is not how many coordinates a representation has, but what **source class and acquisition/dual primitive** are declared, which source fibres they distinguish, how the operator varies across observations, which amplitudes and conditioning are part of the source channel, whether the natural source functional belongs to the admitted dual space, and at what inverse/capacity/reliability scale those distinctions remain usable.

FD-167 gives a positive inverse theorem and FD-168 shows the same conditioning survives severe sparsification inside a fixed raw Fourier basis. FD-169 shows why that count is meaningful only because the acquisition family was fixed: with arbitrary target-aware linear measurements, the inverse can be moved into the sensor and the minimum output dimension collapses to target rank.

FD-170 adds a second warning. A single spatial coordinate is not one scalar degree of information if it is observed through a different horizon operator each time. Consecutive midpoint values have increments equal to a Dirichlet convolution with the odd-indicator, and Möbius inversion on odd divisors reconstructs every formal source coefficient. FD-171 proves that this temporal family has **zero exact row redundancy** over the unrestricted normalized formal source class: omitting any one horizon leaves an explicit permanent null direction, and on a finite prefix a selected horizon set `S` has exactly rank `|S|`.

FD-172 shows that even this exact rank statement is source-class relative. Restrict to squarefree-supported multiplicative sources with `-1<=a(p)<=1`. In the transformed coordinate `F=u*a`, all relevant odd coefficients become nonnegative products `prod_(p|m)(1+a(p))`. Dyadic midpoint errors decompose into nonnegative annular masses, so cancellation of a prime defect is impossible: exact agreement at `H=2^m` forces the Möbius target, and small dyadic errors bound every prime defect. The ambient temporal rows are irredundant for arbitrary recovery but exponentially sparse rows suffice for **one-target rigidity inside the nonlinear arithmetic cone**.

MC-342 gives the opposite pathology: a scalar transcript can carry essentially `R` source bits while bounded range and benign forward regularity hide the cost in exponentially small inverse separation. MC-343 converts that hidden precision into an SNR bill. MC-344--MC-345 show that once the primitive is fixed to memoryless noisy coordinate queries, each actual access contributes at most channel capacity even under feedback and adaptive stopping. MC-346--MC-347 then identify the reliability currency: vanishing coordinate error requires `Omega(R log(1/bar p))` pairwise evidence, represented by query count at fixed quality or accumulated directional discrimination divergence when fidelity varies.

NB-176--NB-180 show the same declaration problem on the dual side. The canonical Euler feature map is source-native and jointly Hilbert-contracting, but its square-summed spectrum can under-certify source complexity. Coordinatewise scalar contractions can recover a linear certificate, yet generic Poisson-width packing reproduces the same Hadamard response. Restricting to genuine Euler frequencies still fails when each weak channel is independently normalized: one prime-power tower gives an exact Fourier code, while the true Euler amplitudes suppress it exponentially.

NB-181 adds a different boundary. If those true amplitudes are retained in the natural feature Hilbert space, any `N x N` Hadamard-scale response forces the RMS Hilbert acquisition norm to grow like `sqrt N`; bounded Hilbert dual access cannot recover the code. The actual scalar Euler readout escapes because its phase vector is not `ell^2` at all. Its finite value comes from stronger weighted Dirichlet summability. Thus “source-faithful” must specify the **topology of the acquisition space**, not only the labels and amplitudes of its coordinates.

These examples isolate one reusable accounting rule. Before assigning an information cost, state the admissible source class, whether the task is arbitrary recovery or one-target testing, the acquisition/dual family and its topology, every changing operator or horizon, the target quotient, source amplitudes and allowed renormalization, observation norm/noise model, downstream error tolerance and matched-control geometry. Then prove a resource that survives those declarations: an inverse modulus, source-class-relative kernel bound, stable singular values, independent row rank, channel capacity, accumulated discrimination divergence, or charged dual response that the matched control cannot reproduce under the same source weights and functional class.

Forward smoothness, raw feature count, positive noise, nominal spatial dimension, adaptivity, frequency membership and “canonical” probe labels are secondary descriptors. Sparse coordinates can be enough when the source cone removes ambient null directions; one spatial coordinate can be complete when the operator changes through a rich hierarchy; those rows can still be individually irredundant in the ambient linear class; unrestricted mixtures can make count tautological; variable fidelity converts query count into discrimination cost; independently normalized coordinates can erase source-amplitude conditioning; and a bounded Hilbert witness can exclude the very non-Hilbert functional through which the physical source is read.

**Boundary.** The cited results concern different Farey, finite-source and Nyman models and do not supply a universal acquisition theorem or canonical noise/dual norm. FD-172 proves Möbius target-rigidity only in its bounded squarefree multiplicative class, not pairwise injectivity. MC-347 covers raw-coordinate rather than arbitrary coded experiments. NB-181 is a bounded-Hilbert result and leaves weighted Dirichlet/non-Hilbert acquisition open. This synthesis is an audit rule: information budgets become mathematical only after the source fibre and full acquisition topology are fixed rather than optimized away.
