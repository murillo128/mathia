# MI-020 — Incommensurability removes collisions, but the residual fibre may stay target-mixed or collapse to decoding

**Evidence level:** supported cross-line synthesis from exact results [AF-375](../../arithmetic_fidelity/findings/AF-375-sampling-difference-subgroup-classifies-separable-determinant-gauges.md), [AF-376](../../arithmetic_fidelity/findings/AF-376-uniform-separation-defeats-e-polya-frequency-determination.md), and [PC-318](../../prime_circle/findings/PC-318-irrational-radial-rays-are-tensor-decoders-and-barnes-zeta-packets.md).

Two current constructions use the same algebraic move—make sampling/frequency scales incommensurate so a known collision family disappears—but land at opposite bad endpoints for compression.

In Arithmetic Fidelity, `H_E=<E-E>` controls the continuous separable multiplicative gauge of sampled Toeplitz minors. An irrational second lattice phase makes `H_E` dense and kills every nonconstant periodic separable factor modulo exponential tilt. AF-376 then shows that this does **not** make the observation determining on Ganzburg's broad class `L`: the actual two-phase row set remains uniformly discrete, so compact-support kernels narrower than its minimum spacing satisfy every sampled determinant inequality while failing global Pólya-frequency structure. Collision/gauge removal leaves a non-separable target-mixed fibre.

In Prime Circle, irrational radial slopes remove residue-frequency collisions so completely that the trace becomes a decoder. A Vandermonde inversion recovers the full residue tensor, canonical normalization recovers the source packets, and the Mellin image is a Barnes double-zeta packet. Here collision removal does not leave a useful compressed quotient; it collapses toward source reconstruction.

The shared principle is therefore not “irrationality adds arithmetic richness.” It is:

**incommensurability destroys a specified alias class; the mathematical value is determined only by the fibre that remains.**

That residual fibre can still be target-mixed for a different geometric reason, as AF-376 proves, or it can become essentially a source decoder, as PC-318 proves. A useful intermediate representation requires the harder third case: target-pure for the declared discriminator without reconstructing the source and with a usable destination modulus.

This is not a universal theorem about irrational sampling. It is a reusable audit forced by the two exact constructions: after removing collisions, classify both the algebra generated by the observations and the actual observation geometry/source class before interpreting the change as fidelity progress.
