# MI-021 — Representation enrichment only buys leverage where source-specific coupling actually lives

**Evidence level:** supported cross-line synthesis of exact/current results [AF-377](../../arithmetic_fidelity/findings/AF-377-bounded-support-interaction-components-hide-finite-order-aliases.md), [AF-378](../../arithmetic_fidelity/findings/AF-378-order-reparameterization-preserves-sampling-fibres-but-not-translation-geometry.md), [AF-379](../../arithmetic_fidelity/findings/AF-379-vanishing-row-mesh-determines-continuous-translation-total-positivity.md), [FD-155](../../farey_discrepancy/findings/FD-155-thinning-finite-prime-avoidance-frame-has-double-exponential-parent-load-cost.md), [MC-329](../../mobius_cancellation/findings/MC-329-fixed-common-modulus-bias-energy-has-a-quartic-horizon.md), [MC-330](../../mobius_cancellation/findings/MC-330-signed-bias-postprocessing-cannot-amplify-quartic-horizon.md), [WI-317](../../weil_inertia/findings/WI-317-finite-localization-portfolios-cannot-contract-scalar-defect.md), [WI-318](../../weil_inertia/findings/WI-318-bounded-h1-adaptive-localizers-cannot-contract-scalar-defect.md), [WP-329](../../weil_positivity/findings/WP-329-deterministic-amalgamated-lifts-make-operator-valued-free-divisibility-universal-before-scalarization.md), [WP-330](../../weil_positivity/findings/WP-330-nondeterministic-amalgamated-noise-remains-universal-when-scalarization-annihilates-the-fluctuation-ideal.md), and [WP-331](../../weil_positivity/findings/WP-331-faithful-scalarization-collapses-source-preserving-centered-enrichment.md). The mechanisms are different; only the information-placement and resource-accounting principle is shared.

Several current branches exhibit the same structural distinction: a construction can become richer by nominal dimension, arity, category, coordinate geometry, moment/order, noise content, portfolio size or source coordinates while the source-sensitive interaction still factors through a smaller object, is killed by the destination map, or is purchased at a hidden resource cost. Added degrees of freedom become genuine leverage only when they change the effective source coupling **before** the destination-relevant compression and survive to the final observable with a controlled bill.

Arithmetic Fidelity now gives both sides of this distinction exactly. AF-377 shows that sampled total positivity of every nominal determinant order can factor through uniformly bounded blocks when the intrinsic support-scale interaction graph has bounded components. AF-378 shows that a nonlinear order reparameterization can make displayed rows look denser without changing any sampled determinant or false-positive fibre when the kernel is transported faithfully. AF-379 then gives the positive criterion: for continuous translation kernels, dense normalized finite row patterns modulo common translation make the sampled inequalities genuinely determining. Vanishing tail mesh forces that closure, so `E={log p}` is already determining by PNT. This is real leverage because the added row configurations approximate every target configuration; but precisely for that reason the final positivity certificate has no residual prime specificity. The arithmetic resource must lie in how the sampled inequalities are produced.

Farey Discrepancy gives a cost version. FD-154 can make finite-`L^q` ancestry coercive with a fixed finite-prime coordinate face, and adding more avoided-prime coordinates reduces the anchored source mass. FD-155 shows that this apparent source saving is not free in the direct frame: achieving anchor mass at most `alpha` requires `exp(alpha^(-1+o(1)))` coordinates/depth, while the best parent load within that family grows like `exp(exp(alpha^(-1+o(1))))`. More coordinates do alter the source fibre, but they do not constitute cheap leverage unless the architecture's conditioning/load is priced at the same time.

Möbius Cancellation gives the compression-order version. MC-329 compresses the complete reciprocal endpoint character family into one nonnegative bias-energy statistic and reaches the quartic source floor. MC-330 shows that arbitrary signed linear combinations, off-diagonal quadratic kernels and endpoint-matched low-rank projectors applied **after** that compression have no operator-normalized advantage over the original energy; the endpoint already saturates the generic Hilbert-space bound. If signed/joint information is useful, it must enter before the `ell^2` collapse through a source-natural structured transform/correlation estimate, through higher-order data not controlled by the same energy, or through a changed representation.

Weil Inertia gives the portfolio-complexity version. WI-317 showed that finitely many exact source localizations cannot contract a scalar defect when every localized term receives only the same scalar premise. WI-318 removes portfolio infinity and adaptivity as generic escapes for unit-window families with bounded total `H^1`: uniform Riemann--Lebesgue decay plus a family-independent first-prime autocorrelation gap yields one recurrence sequence defeating the entire family. Cardinality is not the resource; an escape that reuses only scalar feedback must at least become spectrally noncompact, with unbounded frequency second moment, or import genuinely new localized/non-scalar information.

Weil Positivity gives the readout version and now closes both obvious sides. WP-329 can store all arithmetic specificity in a scalar state below a universal deterministic operator-valued law. WP-330 can add genuine covariance while hiding it in a scalarization-null ideal. WP-331 shows that making the same readout faithful does not repair this while preserving the exact scalar source law: conditional variance and complete positivity force the centered operator-valued law to collapse back to the deterministic base. The relevant resource is therefore not merely mixed data existing upstream or even being positively visible; it is source-dependent mixed data coupled to a response interface that is not simultaneously constrained to preserve the unchanged scalar law of its conditional mean.

The reusable audit is: **locate the smallest object in which source-specific coupling remains before each factorization/compression/readout, price the resources needed to expose it, and verify that the destination actually consumes it.** Count complexity there, not in the ambient representation. A proposed enrichment is useful when new coordinates create a determining closure, a new source-conditioned correlation, a genuinely stronger local invariant, or another destination-visible coupling whose cost is controlled. It is not useful merely because it increases nominal arity, coordinate count, portfolio cardinality, operator-valued noise, signs or postprocessing after the informative structure has already been erased or externalized.

**Boundary.** This is not a theorem transferring AF pattern closure to Farey ancestry, character sums, Weil localization or operator-valued probability. Each mechanism and quantitative cost is line-specific. The shared conclusion is an audit principle about effective information placement, timing and visibility: nominal richness is not a resource until a source-specific coupling across the added degrees of freedom is proved, its cost is accounted for, and the destination uses it before a generic compression makes it universal, invisible or already saturated.
