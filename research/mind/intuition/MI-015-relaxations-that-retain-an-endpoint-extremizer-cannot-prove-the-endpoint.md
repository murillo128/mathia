# MI-015 — A relaxation is exhausted until its surviving extremizer pays in the exact destination currency

**Evidence level:** supported cross-line synthesis from MC-276--MC-277, PF-333--PF-334, WI-282--WI-283, FD-119--FD-122, NB-118--NB-121, and VIS-217--VIS-220. This is a diagnostic about the current relaxed classes, not a universal impossibility theorem.

A proposed simplification is exhausted when its admissible class still contains an exact or asymptotic extremizer at the forbidden budget **in the norm or loss actually used by the endpoint**. No sharper estimate using only the retained hypotheses can then create the missing gap. The number of exact constraints is not the relevant measure: what matters is the cost of imposing them near the extremizer in the destination currency, and whether apparently new constraints are even independent.

Möbius Cancellation makes the destination-functional test explicit. Imposing the correct blind-point value and minimizing `L^2` classification error gives exactly the Christoffel kernel, with a loss that subtracts the blind mass itself. MC-277 shows that the original scalar representation still has exact blind/nonblind margin; the relaxation is exhausted because its aggregation discards the endpoint atom, not because the representation lacks information.

Weil Inertia supplies a support-topology extremizer test. Complete prime-power screening plus nonnegativity allows the length-`log 2` packing optimizer; qualitative full span and source-specific support domination can be added with vanishing-mass repairs. A strict decrement must therefore force quantitative amplitude or operator balance that excludes those near-extremizers rather than adding more qualitative support facts.

Farey Discrepancy now shows how an exhausted marginal relaxation can acquire a genuine but still nonpointwise cost. FD-119--FD-120 preserve critical near-saturation under strong single-horizon constraints. FD-121 adds an expensive dyadic same-source relation, and FD-122 extends that cost to every fixed squarefree dilation: sufficiently cheap endpoints in a finite prime cube form a Sperner antichain. The marginal extremizers are no longer jointly feasible on a squarefree network. But the pointwise endpoint is still open because the cost can be redistributed among horizons and the constants deteriorate as the network grows.

Nyman--Beurling gives the opposite cross-scale control. NB-118--NB-120 show that an increasing number of exact Nyman equations still leaves perfect target capture at `Theta(1/R)`. NB-121 then proves that adding a fixed finite nested cutoff ladder is algebraically redundant: the simultaneous feasible set is exactly the maximal-cutoff/maximal-section feasible set. The common-source wording does not make the extremizer more expensive because the purported new constraints are projections of one existing constraint. A useful continuation must add actual zero-power structure, a faster section regime, or genuinely non-nested/widening information.

Prime Flute adds the necessary norm check. In operator norm, PF-333 shows the generic positive relative-square-root class already has logarithmic sensitivity, so positivity alone cannot produce a dimension-free `S_infinity` theorem. PF-334 proves the same map is dimension-free in Hilbert--Schmidt norm, which is the currency the downstream theorem consumes. A bad extremizer in the wrong norm is irrelevant; exhaustion must be demonstrated in the destination norm.

Visual Exploration gives a certificate-family ceiling stronger than a failed search for saturation. VIS-217--VIS-218 show that normalized magnetic relaxation cannot reach Haar-RMS scale. VIS-219 shows the simple-cycle packing LP would have to leave only `O(sqrt(R))` residual. VIS-220 proves this is impossible for that certificate: every simple support graph leaves at least `7B/9`, so the normalized residual grows like `sqrt(N_eff)`. More cycles or a better optimizer cannot repair a ceiling intrinsic to the reward/capacity relaxation. The exact fixed-modulus torus optimum remains open because failure of a certificate does not lower-bound the object it relaxes.

The decisive workflow is therefore concrete: identify the relaxed class; compute or approximate its endpoint extremizers; test them in the exact destination functional; then add one source-native relation and first ask whether it actually shrinks the feasible set. If the extremizer still saturates—or the new relation is algebraically redundant—more constraints of the same type cannot help. If a new relation creates only a componentwise/network gap, test switching and redistribution before treating the destination endpoint as controlled. If a certificate has a universal ceiling above the required scale, leave that certificate family rather than optimizing it further.

**Boundary.** The mechanisms differ: target subtraction, support-topology saturation, horizon-dependent repair, squarefree switching, nested-projection redundancy, inverse-section tail repair, norm dependence and certificate ceilings. FD-122 does not show pointwise Farey coercivity; NB-121 does not model actual zero packets; VIS-220 does not lower-bound the exact torus optimum. The diagnostic applies only to the specific relaxed class and destination currency that have been audited.
