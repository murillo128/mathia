# MI-015 — A relaxation is exhausted when its extremizer still saturates the endpoint in the relevant currency

**Evidence level:** supported cross-line synthesis from [MC-276](../../mobius_cancellation/findings/MC-276-distributional-witness-normalization-christoffel-collapse.md), [MC-277](../../mobius_cancellation/findings/MC-277-christoffel-endpoint-margin-conditioning.md), [PF-333](../../prime_flute/findings/PF-333-relative-square-root-sensitivity-remains-logarithmic-even-for-positive-insertions.md), [PF-334](../../prime_flute/findings/PF-334-hilbert-schmidt-relative-square-root-control-escapes-logarithmic-dimension-loss.md), and [WI-282](../../weil_inertia/findings/WI-282-complete-prime-screening-and-full-span-do-not-lower-the-log2-packing-budget.md)--[WI-283](../../weil_inertia/findings/WI-283-support-domination-does-not-lower-screened-packing-supremum.md). This is a diagnostic about the current relaxed classes, not a universal impossibility theorem.

A proposed simplification is exhausted when the relaxed admissible class still contains an exact or asymptotic extremizer at the forbidden budget **in the norm or loss actually used by the endpoint**. No sharper estimate using only the retained hypotheses can then create the missing gap.

Möbius Cancellation makes the destination-functional test explicit. Imposing the correct blind-point value and minimizing L2 classification error gives exactly the Christoffel kernel, with a loss that subtracts the blind mass itself. MC-277 then shows that the underlying row representation was not the problem: the original Christoffel scalar still separates blind from nonblind rows with exact margin `delta~2m/k`. The relaxed L2 objective is exhausted because it discards the very atom the endpoint asks about; replacing the representation is unnecessary unless the new observable changes the aggregation/provenance currency.

Weil Inertia now supplies a stronger extremizer test. Complete prime-power screening plus nonnegativity allows the length-`log 2` packing optimizer; qualitative full span can be added with vanishing-mass satellites. WI-283 proves that even the source-specific prime-translation support domination forced by actual Suzuki null modes can be added without lowering the supremum: a maximal distance-avoiding support can be made dominating, and arbitrarily small `L^2` mass can realize that support topology while converging back to the same `K_pack` endpoint. Thus **support topology itself is an exhausted relaxation currency**. A strict decrement must force quantitative amplitude or operator balance that excludes those near-extremizers.

Prime Flute adds the necessary norm check. In operator norm, PF-333 shows the generic positive relative-square-root class already has `asymp log r` sensitivity, so positivity alone cannot produce a dimension-free `S_infinity` theorem. But PF-334 proves that the same map is dimension-free in Hilbert--Schmidt norm, which is the currency PF-318 actually consumes. The operator-norm relaxation is exhausted, yet that does **not** obstruct the weaker endpoint. One must first verify that the bad extremizer lives in the destination norm being used.

The decisive workflow is therefore concrete: identify the relaxed class; compute or approximate its endpoint extremizers; check them in the exact destination functional; and ask which source-native hypothesis excludes them **quantitatively**. If the extremizer still saturates the correct budget, adding constraints that can be realized by vanishing mass, deleted target terms or stronger irrelevant norms cannot help. Reintroduce signed phase, amplitude lower bounds, the exact null equation, geometric localization or another source constraint that the endpoint can actually measure.

**Boundary.** The mechanisms are different: target subtraction, row aggregation, support-topology saturation and norm-dependent matrix sensitivity. The synthesis does not imply that every relaxation is useless or that the named source-specific refinements will succeed. The diagnostic applies only after an extremizer has been shown to survive in the exact endpoint currency.
