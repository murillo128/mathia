# MI-035 — Nominal multiplicity is leverage only if the destination still resolves it

**Evidence level:** supported cross-line synthesis of exact line-local results [FD-264](../../farey_discrepancy/findings/FD-264-signed-band-drift-collapses-block-population-to-a-positive-mertens-scale-average.md), [MC-453](../../mobius_cancellation/findings/MC-453-bounded-factorable-splitting-cannot-dilute-quadratic-diagonal.md), [NB-280](../../nyman_beurling/findings/NB-280-canonical-zero-sampling-inverse-gram-is-exactly-the-finite-burnol-blaschke-defect.md), and [WP-403](../../weil_positivity/findings/WP-403-finite-codimensional-source-constraints-cannot-create-fixed-shadow-orientation.md). The objects and estimates are different; the shared statement is about when apparently many source degrees of freedom survive the exact destination map.

Several current frontiers now show the same failure mode in different mathematics: a representation exposes many blocks, components, interpolation directions or global constraints, but the destination operation collapses that multiplicity before it can become a coercive resource.

In Farey Discrepancy, the absolute repair ledger of FD-263 retains the population of forcing blocks because each block is charged before sign cancellation. FD-264 shows that the signed band total does not. Abel summation replaces the replication kernel by nonnegative jumps of total mass one, so a dense deep population telescopes to a positive scale average of Mertens prefixes. Population can still create one-sided or `l^1` mass, but it is no longer visible after signed aggregation.

In Möbius Cancellation, MC-453 gives the quadratic analogue. Splitting an auxiliary sieve weight into `J` components and then paying separate positive energies leaves at least `1/J` of the recombined energy. When classical well-factorable decompositions use boundedly many pieces, component count itself cannot buy a conductor power. The possible leverage lies in the internal convolution variables or cross-component interference **before** positive quadratic closure.

In Nyman--Beurling, NB-280 shows that nominal matrix complexity can disappear because the destination vector co-moves with the representation. The canonical data `v_j=1/rho_j` are samples of one fixed Hardy kernel, so `v*G^(-1)v` collapses exactly to the finite Burnol/Blaschke defect. Generic Cauchy-Gram ill-conditioning is real but is not an independent resource for this target direction.

In Weil Positivity, WP-403 shows that finitely many global linear constraints do not create the desired source nonlocality even when no canonical cutoff preserves them. Their quotient errors live in a finite-dimensional space and can be repaired by order-bounded tangent directions, leaving a dense two-sided core. Finite-dimensional global memory therefore disappears from the orientation problem unless it changes the tangent geometry more substantially.

The common audit is to count **effective multiplicity after the destination reduction**, not before it. Block density counts only if the destination retains within-band variation; decomposition breadth counts only if factor variables or interference survive squaring; Gram dimension/conditioning counts only through the actual target vector; global constraints count only if they genuinely change the closure of admissible tangent directions. Nominal breadth that is quotiented, telescoped, positively closed, target-aligned or finitely repairable is representation richness rather than mathematical leverage.

This sharpens the program-level interface rule: when a proposed mechanism claims gain from “many” source coordinates, first write the exact map into the destination quantity and identify the rank, variation, interference, target occupation or tangent asymmetry that survives there. Only that surviving quantity should be given an exponent or information budget.

**Boundary.** This is not a theorem transferring estimates between the four lines. FD-264 leaves one-sided repair variation open; MC-453 leaves internal factorability and coherent cross terms open; NB-280 is specific to the canonical point-value vector and leaves higher jets or different boundary mechanisms open; WP-403 is finite-codimensional and leaves genuinely infinite-dimensional or singular source relations open. The shared conclusion is only the evidence discipline for pricing multiplicity after the exact destination map.
