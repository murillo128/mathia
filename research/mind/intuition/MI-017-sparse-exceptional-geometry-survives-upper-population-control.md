# MI-017 — Thin channels matter only after pullback to the destination-visible source family

**Evidence level:** supported cross-line synthesis from current exact results including NB-147--NB-168, FD-147--FD-160, RE-145/RE-151--RE-158, PL-321--PL-323 and [MC-385](../../mobius_cancellation/findings/MC-385-fixed-power-exceptional-moduli-cannot-feed-rank-linear-source-frame.md). The mathematical objects and scales remain line-specific.

A recurring obstruction is quantitatively clearer: **small ambient population is not small destination influence**, but neither is syntactic sparsity automatically a surviving resource. A target may concentrate decisive mass on a thin shell, deep ancestry layer, signed lobe, exceptional height or structured source family that generic population controls underweight. The relevant questions are how much leverage the destination assigns to that set, whether it survives the natural closure/completion, and how an ambient exceptional set intersects the exact source image.

Robin Extremal exposes a moment hierarchy: matching terminal count or first-order source mass need not control the internally placed channel that carries destination leverage. Farey Discrepancy supplies a closure test: sparse divisor supports can regain full cut pressure after the natural divisor closure is taken. Nyman--Beurling adds a family-quantifier test: a phase rescue can survive on isolated target heights while failing on a positive-density translated family. These examples already show that thinness must be measured after the destination's own closure and quantifier are fixed.

MC-385 adds an exact source-incidence version. The endpoint rows are indexed by an additive source group `W`, so bad pair correlations are determined by a set of difference modes. If `H=|W|`, rank forcing gives `lambda_max(G)>=H/R`, while a bad-difference set of size `E` and good correlation bound `epsilon` gives `lambda_max(G)<=1+E+H epsilon`. The relevant exception budget is therefore `E=o(H/R)`, not a small **ambient fraction** of all conductors.

This distinction makes a standard almost-all theorem potentially irrelevant even when its exceptional proportion is tiny. An ambient bound `E(P)<<P^theta` does not prevent the structured source-conductor image from lying almost entirely inside that exceptional set; by cardinality alone it reaches only a much smaller source exponent. Conversely, a large ambient exceptional set can be harmless if its intersection or induced degree on the source frame is small.

The reusable diagnostic is destination-weighted, closure-aware, quantifier-aware and now **source-pullback-aware**. Identify the exact set/mode/shell/depth/sign component the target consumes; compute its leverage; apply the natural closure; state the required family quantifier; and pull any exceptional-population theorem back through the exact source map before calling the exceptional set sparse for the problem at hand.

**Boundary.** The examples use unrelated measures, operators, graph depths and arithmetic families. No common exponent or density conclusion transfers between them. MC-385 in particular is a certificate barrier, not evidence that the actual ambient exceptional set concentrates on the source family. The synthesis is the requirement to measure thinness in the destination's own source coordinates rather than in a larger ambient population chosen for theorem convenience.
