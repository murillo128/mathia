# MI-009 — Nonlocal reconstruction matters only when the analytic object is selected independently of the target carrier

**Evidence level:** supported by the Weil-positivity carrier/category/sign/compression results through WP-274; this is not a statement about every arithmetic completion.

WP-267--WP-270 separate source coherence, hostability, and category descent. The canonical pole-completed carrier is tempered if and only if RH, so ordinary analytic cleanup is already target-strength. WP-271--WP-272 then show that finite-order conditional positivity and continuous scalar filtering cannot repair the sign while retaining the Mangoldt atoms.

WP-273 identifies the next gate. A positive compression of the canonical positive-minus-positive carrier is exactly a contraction from the arithmetic sample component to the pole continuum. For function-generated ranges this is a sampling/reconstruction inequality. Localizable continuous spaces fail because one can cut off inside an atom-free interval; a surviving range must therefore be globally nonlocal.

WP-274 shows that this necessary nonlocality is not sufficient. The pole weight normalizes the arithmetic samples to the positive Herglotz measure `sigma_Lambda` with masses `Lambda(n)/(n+1)`. Classical Herglotz--Clark theory can reconstruct an inner function from that measure and a model space on which the pole-completed form is identically zero. The construction is mathematically valid but universal: essentially any Poisson-finite singular positive-minus-positive carrier can be fed into the same inverse representation theorem.

The explanatory direction is therefore decisive. If the target measure defines the inner function and the resulting Clark space returns the target measure as its sampling law, positivity is a representation tautology. A Riemann-facing mechanism needs the nonlocal object—inner function, canonical system, de Branges Hamiltonian, matrix coupling, boundary law, or equivalent—to arise from **independent source geometry before the desired carrier is installed as spectral data**.

The compatibility ledger is now: **hostability, category descent, local sign, arithmetic retention, nonlocal reconstruction, and independent model selection are separate gates.** Nonlocal analytic structure can evade the local-cutoff obstruction yet still contain zero source-specific information if it was reverse-engineered from the desired samples.

**Boundary.** WP-274 does not rule out model-space, de Branges, canonical-system, singular-boundary, or noncommutative routes. It rules out using inverse realization of the target carrier itself as evidence for a Weil sign mechanism. The full Gamma/polar completion remains an additional obligation.
