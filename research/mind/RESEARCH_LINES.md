## Global discriminator: a useful source resource must scale and survive composition

The newest evidence strengthens [MI-013](intuition/MI-013-closing-the-bulk-often-leaves-a-thin-source-specific-endpoint.md). AF-347 shows raw locality can die under downstream smoothing; FD-128 shows infinite but sparse arithmetic rank can remain cheap; MC-298 shows bounded interaction order misses parity; NB-127 shows exact multibase identifiability can be globally unstable; PC-297 shows nonnormality can collapse to a universal square-zero class; RE-129 merges spacing and phase into one precise zero requirement; VIS-225 closes a static relaxation by a coarse binary certificate; WI-294 shows retaining the actual sign constraint can eliminate an escape created by spectral relaxation; WP-307 closes all positive affine recentering.

These are not one theorem. They impose a common accounting rule: after identifying a source coordinate, ask not only whether it exists but **at what order/density/resolution it is visible, whether each intervening map preserves it, and whether the endpoint charges it with a uniform margin**. If any of those links is only plausible, the transfer belongs in a clue rather than a global mathematical claim.
