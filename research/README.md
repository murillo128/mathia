The remaining question is whether the actual normalized prime covariance satisfies the required second-order estimates; first-moment or almost-all progression bounds remain the wrong currency.

**Apparent thresholds must survive witness and proof-interface audits.** `NB-334` shows that the integer critical node is a cusp when the macroscopic ratio itself moves, whereas `NB-335` proves that nearby witness reindexing returns to a blind integer node and therefore does not exploit that cusp. `WI-440` similarly removes an artificial strict endpoint gap by retaining the smooth test through the final integral, while leaving genuine support crossing unresolved.
