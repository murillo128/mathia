## Cross-line structure

The first strong convergence is between **joint source selection and stable transport**. `AF-280` shows that several complete but separately retained acquisition channels can share a mixed interaction kernel even when their phase labels look informative. `WP-262` shows the complementary failure after acquisition: exact source weights, boundedness, closability, positivity, and nonzero cross-prime entries still leave an enormous programmable family of mixed geometries. Together they sharpen the global question from “can we couple primes?” to “what source identity selects this particular joint kernel, and in what topology can it be transported?” Global Mind's multiplicative/bispectral comparison remains useful here, but no cross-line theorem yet identifies the Weil kernel with that model.

A second convergence is **localization before averaging**. `FD-058` avoids a false sparse-endpoint penalty by letting maximality choose a nearby real ambient window. `MC-230` avoids a false demand for global cross-cell anti-alignment by resolving the shell into a subpower exact-cell alphabet. `WI-250` avoids an exponentially expensive all-odd source bound by conditioning on the forced first zero mode and importing positivity from smaller windows. These are not one theorem, but they share a precise methodological boundary: the source selects a much smaller geometry than the ambient norm sees. Progress now requires a quantitative estimate on that selected geometry, not a stronger generic average.

A third convergence concerns **local fidelity versus accumulated evolution**. `PF-297`--`PF-298` show that two natural local transfer pieces are asymptotically conservative, so any useful loss must be accumulated or created by the physical global reassembly. `RE-059` shows that an entire continuum inside one CA threshold cell carries only a frozen finite source state, so new information enters only when cells change. `PL-279` shows that an individual Weil prime-power threshold turns on quadratically softly, pushing the source mechanism toward coherent motion across many activations. These lines now agree on what *not* to overinterpret: one local cell, seam, or threshold event is too weak; the unresolved arithmetic content lies in how many genuine source events compose.

Nyman and Visual Exploration provide complementary endpoint calibrations. `NB-058` turns an apparently diffuse multichannel tail problem into an exact finite-time localization question inside the arithmetic defect space; a positive theorem still has to construct those defects from zeta. `VIS-175` instead proves that an entire natural additive square-summable prime-phase representation already has the matched Haar law. One line has found the exact source-dependent subspace it must populate; the other has proved that a broad representation class contains no source discriminator at all.

The existing clue set remains sufficient. Prime Flute's source-weighted return-potential clue is `accepted` and now incorporates `PF-297`--`PF-298`; Weil Inertia's first-mode cutoff-flux clue is already validated by `WI-250`; Nyman's early-cell adjoint-dual clue is now `accepted` after `NB-058`; Visual Exploration's prime-phase clue is accepted in the narrower post-`VIS-175` form. No new Master clue is created because the new analogies do not supply an exact shared object, normalization, and conclusion beyond questions already owned by their destination lines.
