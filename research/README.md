## Cross-line structure

The strongest reusable lesson is still methodological rather than a common RH mechanism: **the information has to survive the exact operation and norm used by the endgame**. Prime Flute illustrates this twice. One-sided seam order is enough after the diagonal inverse-corridor block is exposed, but PF-244 shows that the same order is not enough for separated Poisson smoothing because the seam square root can rearrange spectral mass first. Xi gives the complementary conditioning warning: exact invertibility and even very deep local jets can remain exponentially insensitive to the transition. Nyman-Beurling makes the same distinction between perfect Gram preservation and decaying target alignment, while Farey shows that an exact norm bridge can still be only a classical re-expression unless it yields a cheaper estimate.

A second recurring boundary is **source selection versus programmable destination geometry**. Weil Positivity now has both sides of that problem explicitly: the critical Bost-Connes Gram is source-forced, but compact repair fails and arbitrary coinvariant quotients can program either sign. Prime Lattice supplies a related warning that finite arithmetic labels do not automatically preserve enough infinite-prime structure for a normal equilibrium. These are not a common no-go theorem; they say that any successful noncommutative route must state which relation or quotient is canonically selected before asking whether it has the desired sign.

A third boundary is **finite samples versus coherent continuum information**. Weil Inertia can screen every fixed finite reciprocal packet with `O(1)` added off-line pairs, while Visual Exploration has learned that the null law of a finite window changes when repeated-index collisions or windowing are altered. In both cases, simply adding channels is not the relevant resource. What matters is whether a growing/continuum measurement survives its source normalization and matched controls. This analogy does not yet cross the clue threshold: Weil Inertia already has a dedicated continuum-residual clue, and Visual has its own source-faithful finite-window gate.

No additional Master clue is created in this snapshot. The three recent Master-routed tests already cover the live constructive alternatives with enough specificity: odd-dilated positive annihilators for Analytic Frontier, fixed-seam separated Poisson smoothing for Prime Flute (now accepted and narrowed by `PF-243/244`), and the continuum residual of sparse reciprocal screens for Weil Inertia. Creating another clue from the same observations would duplicate active work rather than route new cross-line information.
