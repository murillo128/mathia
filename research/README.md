## Cross-line structure

### 1. Fixed-size closure is repeatedly giving way to a growth-law problem

Farey and Nyman now have unusually clean versions of the same strategic boundary without sharing an operator. `FD-096` supplies entry states and arbitrary **fixed** predecessor depth, but not depth growing with scale. `NB-095` supplies additive repair for every **fixed finite** distinct zero set, but not a zero family whose cardinality or confluence grows. `VIS-207` similarly expands a fixed-scale crowding theorem into a nontrivial growing-width corridor and leaves only the transition to larger scales. In each case the next theorem is about uniformity in a growing parameter; repeating another fixed-size closure would not move the endpoint.

### 2. Optimal use of retained information is different from new arithmetic information

`MC-268` and `WI-277` sharpen this distinction from opposite sides. The Christoffel detector is optimal for the blind endpoint at a fixed polynomial-degree budget, but it is explicitly only a better combination of the Krawtchouk data already present in `MC-267`; arithmetic control of its expectation is still missing. `WI-277`, by contrast, gains from requiring **one supported cut-energy profile** to satisfy several shift constraints simultaneously: separate sharp extremizers are incompatible, so joint target geometry itself creates a stronger reserve. Neither result licenses a generic claim that a richer representation is new source information. The relevant question is whether the exact destination consumes the retained coordinates jointly in a way that cannot be reproduced by an information-neutral reparameterization.

### 3. Target-independent success can still be a matched control

`WP-285` is the clearest current warning. Once the RH-favorable residual has been scalarized into an absolutely summable almost-periodic field, ordinary positive Cesaro averaging is zero-independent and still removes every nonzero mode. `AF-318` supplies a different version: an ambient singular family can satisfy the strongest elementary character-rank condition without showing that the prime orbit ever reaches it. `PL-296` adds an operator-domain warning: an attractive explicit inverse can produce the wrong boundary exponent when it silently switches from whole-space to restricted Dirichlet functional calculus. Together these results strengthen, rather than replace, the existing fidelity/transport/realization separation: provenance, admissible source incidence, and the exact destination category must be audited independently.

### 4. Source sensitivity matters only if it survives the destination

Prime Flute and Robin now provide concrete tests. `PF-324` proves that adjacent prime-gap ordering survives into the recentered **input boundary geometry**, but no current theorem says that the completed intrinsic angle retains it. `RE-098` shows that the source-specific CA deformation first becomes relevant in the shifted phase kernel, not in the already-sufficient resonant zero energy. Both lines therefore have a precise destination-aware next step: propagate the source parameter through the operation that the final theorem actually consumes instead of treating its upstream presence as progress by itself.
