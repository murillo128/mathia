## Cross-line structure

**Quotienting a nuisance direction can reveal the real instability without reducing it.** `AF-295` shows that removing the global scalar gauge leaves exactly the same eta zero-count collapse as projective angular distance. `MC-244`--`MC-245` show that Fourier-mode multiplicity collapses to one affine source cell and that dimension reduction gives no power gain unless the blind sector vanishes completely. `NB-072` similarly separates the outer part that controls conditioning from the inner part that alone carries the stable tail. These are different operators, so no theorem is transferred between them, but they strongly discourage using quotient dimension or ambient conditioning as a proxy for endpoint control.

**Capacity and recurrence are replacing existence as the decisive currency.** Farey now has protected source blocks rather than isolated records, but still lacks global density. Robin has a one-sided ledger whose reset requires polynomial first-layer support births, but still lacks an impossibility theorem for paying that bill. Nyman has an exact global defect architecture, but the actual arithmetic source still needs to be shown transverse to it. The relevant question is increasingly not whether a favorable event exists but whether the source can sustain enough of the required structure over the same global trajectory consumed by the endpoint.

**Physical observation maps can reverse the interpretation of an ambient obstruction.** Prime Flute's full constant sector reaches a divergent screened backreaction, yet the explicit screening relaxation is physical-low and is strongly suppressed by the first fixed high-frequency entrance. Visual's rectangular cross-scale logarithm disappears under a source-independent endpoint-zero taper, and the complete tapered quadratic off-diagonal then vanishes. A representation-level obstruction or visual residual should therefore be promoted only after the actual source/observation/reassembly map is included.

**Positive sign cannot be manufactured by a smooth scalar postprocessing of the critical Weil carrier.** Weil Positivity now rules out both finite-dimensional moment quotients and continuous scalar filtering while retaining the arithmetic atoms. This is complementary to, not transferable from, Weil Inertia and Prime Lattice: those lines still have source-specific first-crossing/form routes because they modify the variational geometry before a final scalar spectral sign is read.

The existing proposed `CLUE-global-cross-line-fidelity-realization-separation` already captures the distinction between source fidelity, target transport, destination realization, and assembly. The new evidence strengthens that separation but still does not supply one exact common source family, operator, normalization, and target map across these lines, so no new Master clue is justified.
