## Cross-line structure

**A smaller admissible state space helps only when the restriction is source-derived before the target is queried.** `AF-300` proves this exactly for complex-affine coefficient families: source restriction buys its genuine intrinsic dimension and nothing beyond it. `PL-288` then shows that even spectacular finite-dimensional state localization can be useless when the target margin is much smaller than the square-root tail error. `PF-313` makes the same accounting principle operational at a different interface: inverse amplification is benign only if the actual physical source vanishes at the Schur-defect scale. These are not transferable operators, but they all separate a real source theorem from an ambient representation trick.

**Aggregation is now protected against fixed-power dilution in several lines, so the remaining question is where the protected mass lands.** `FD-078` prevents any fixed polynomial loss in energy-weighted nonsquarefree occupation. `NB-077` prevents integer branching from erasing a coarse cross-cut prediction charge. `RE-080` forces the single Robin transport measure into an intermediate power-scale front on long threshold fans. None of these statements supplies the final target category automatically: Farey still lacks fixed positive occupation, Nyman still lacks mesoscopic localization, and Robin still lacks a source impossibility theorem for the required moving front.

**Algebraic and spectral refinements are useful only when weighted by the part of the source that actually carries energy.** `MC-250` converts support into a torsion-rank tradeoff, but leaves low-order high-rank quotients. `VIS-194` converts the global worst prime-ratio gap into an energy-weighted inverse-spacing average, but leaves its arithmetic size unproved. Both have crossed from crude worst-case geometry to a source-weighted residual quantity; the next theorem must control that residual rather than improve another unweighted proxy.

**Nonlocal representation is not enough if it is reconstructed from the target carrier itself.** `WP-274` is an important matched control for any future model-space/de Branges proposal: Clark theory can manufacture an exact null positive compression from the normalized Mangoldt sampling measure without RH. Therefore the evidentiary content lies in deriving the analytic space independently and only afterwards matching its sampling law to the Weil carrier. This is the nonlocal analogue of the source-before-target rule already visible in Arithmetic Fidelity and Prime Flute.

**Certification remains separate from mathematical plausibility.** `WI-261` strengthens `WI-260`: even the nominally exact `proofctl` path judges a surrogate matrix and contains an exact interval miss. The positive numerical picture may still be correct, but no downstream first-prime argument may treat `lambda_(7/20)>0` as certified until an independent exact enclosure closes this gate.

The existing proposed `CLUE-global-cross-line-fidelity-realization-separation` already captures the distinction between source fidelity, target transport, destination realization, and assembly. No new Master clue is justified: the new correspondences above are structural accounting principles rather than exact transfers preserving one source family, operator, normalization, and target map.
