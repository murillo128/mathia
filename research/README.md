## Cross-line structure

These are shared proof disciplines, not a theorem identifying the three representations.

**Local correctness is weaker than global integrability, while exact integrability can already be identifying.** `FD-313` shows that sublinear contiguous factor inventories need not coerce a cumulative path, and `FD-314` shows that every denominator edge in a reassembly can be genuine while the stitched triples violate the integer Farey-index law. `FD-315` proves that enforcing that index law pointwise together with Farey-triangle admissibility is already rigid: from `(1,Q)` it forces the BCZ successor and reconstructs the denominator word. The live Farey quotient must therefore deliberately coarsen or sparsify index/ancestry information and then prove that the retained quotient still controls the Franel target.

**Prime Lattice's finite-dimensional geometry is no longer the principal uncertainty.** `PL-443` quotients the target's diagonal gauge and turns the Reynolds point into one explicit member of an optimizable stationary shrinkage family. The `PL-421` character reconciliation makes the information loss especially explicit: the `PL-415` virtual supertrace is one quadratic-form shadow of the inverse covariance, and `PL-424` gives matched controls with identical character variances and the same positive supertrace but opposite cone verdicts. Scalar character budgets therefore cannot certify the matrix floor. The remaining question is whether the actual normalized prime covariance satisfies the required second-order estimates; first-moment or almost-all progression bounds remain the wrong currency.

**Apparent thresholds must survive witness and proof-interface audits.** `NB-334` shows that the integer critical node is a cusp when the macroscopic ratio itself moves, whereas `NB-335` proves that nearby witness reindexing returns to a blind integer node and therefore does not exploit that cusp. `WI-440` similarly removes an artificial strict endpoint gap by retaining the smooth test through the final integral, while leaving genuine support crossing unresolved. In both cases the useful next theorem must change the information reaching the destination, not merely perturb a coordinate that the current channel or proof interface already annihilates.
