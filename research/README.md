## Cross-line structure

### 1. The endpoint currency must be checked after the final quotient and normalization

`PF-329` is the clearest correction: the quantity that looked obstructive before final normalization is not the quantity consumed by the angle endpoint; the relevant object is a leakage fraction against completed total energy. `AF-323` makes the same point from the source side: a strong fixed-support conditioning theorem says nothing uniform once the support itself is allowed to move, because varying prime supports fill the finite phase target arbitrarily well. The withdrawal of `VIS-210` is the corresponding epistemic guardrail: an attractive aggregate simplification must be removed once its exact support reduction is not certified. These are all cases where a mathematically richer intermediate representation is insufficient unless it survives the actual destination map.

### 2. Componentwise coercivity now repeatedly stops at a switching or compatibility law

`FD-101` prevents exact source-preserving descent inside sufficiently small non-head shells, but an adaptive proof can still switch packets or tolerate source drift. `NB-100` says bad conditioning is not pairwise crowding but a specific local tangency, so the missing resource is a zeta-specific compatibility among several zeros. `RE-103` leaves only a binary local endpoint choice, yet local finiteness alone cannot prevent an infinite global selected-state path. This is exactly the global pattern captured by `MI-014`: local/componentwise coercivity becomes useful only after a quantitative switching, continuation, or compatibility cost is proved.

### 3. Source-aware simplification is useful only when it keeps the exceptional state distinguishable

`MC-273` is a useful positive example with a sharp limitation. Once a nonblind target supplies one negative witness, the whole cumulative Christoffel ball collapses algebraically to one homogeneous shell; however, blindness is precisely the case in which no such witness exists, and the endpoint separation is only of diagonal-energy size. The simplification therefore does not eliminate the exceptional state; it identifies the resolution an arithmetic theorem must achieve while retaining the adaptive witness condition. Similar caution already governs Weil Positivity and Prime Circle: universal positive/scalar completion can simplify the operator while discarding the source distinction needed by the target.

### 4. The strongest live routes now expose an exact terminal observable rather than a stronger proxy

Prime Flute asks for the normalized physical angle/leakage fraction after the true pant destination. Visual, after withdrawing `VIS-210`, asks directly for off-diagonal Frobenius mass of the certified `VIS-209` anchor Gram rather than a nonexistent diagonal cone. Prime Lattice has separated the universal `H^{1/2}` benchmark from the unproved arithmetic source-amplitude law. Robin asks for a switching law between already-classified local endpoint states. In each case the next useful theorem is cheaper and more falsifiable than another generic regularity, moment, or representation theorem.
