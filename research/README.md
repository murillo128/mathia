# Cross-line structure

The dominant distinction is now **fixed-complexity truth versus endpoint-scale source complexity**. Arithmetic Fidelity supplies a source that is unquestionably zero-sensitive but whose sign complexity grows too quickly for a fixed-order certificate. Farey supplies the opposite control: a fixed amount of genuine arithmetic endpoint data is so cheap in the native quadratic geometry that it cannot move the critical equality ray by a relative amount. Nyman sits between them: exact source orthogonality is powerful enough to force strong target capture into a precisely quantified near-kernel, but that still leaves a source-specific impossibility theorem to prove. These examples argue against both shortcuts — neither “the source is arithmetic” nor “we imposed some exact arithmetic constraints” is enough without pricing the complexity at the endpoint scale.

A second common pattern is **source-forcedness versus programmability**. `WP-302` makes that distinction exact for moving kernels: homogeneous finite-dimensional dynamics are too rigid, while arbitrary dynamics are too programmable. `RE-120` gives a parallel warning in a different language: under spectral isolation, arbitrarily many fixed algebraic corrections add no new CA coordinate because they are all deterministic filters of the same edge profile. `PL-308` similarly removes finite-`s` regularity as an independent degree of freedom; what remains is the singular zero-order limit and arithmetic sign. Richer representation is useful only if the source forces a new degree of freedom that the destination actually retains.

A third pattern is that the first unresolved scales are increasingly explicit. Prime Circle has reached the true square-root profile boundary, Visual has closed the normalized magnetic relaxation throughout the strictly subcritical regime, Weil Inertia has separated abundant lower safe windows from rare upper screening deserts, and Analytic Frontier has calibrated physical activation at `A asymp ell^2`. The highest-value next steps are therefore source theorems or incidence/transport results **at those first unresolved interfaces**, not another refinement below a matched-control boundary.

The existing global fidelity/realization clue together with `MI-008`, `MI-012`, `MI-013`, `MI-015`, and `MI-016` already organize these distinctions: exact recovery versus stable transport, information versus destination sensitivity, thin source-specific endpoints, endpoint extremizers retained by relaxations, and relational information after gauge quotient. The new findings sharpen those principles quantitatively but do not yet establish a new reusable cross-line theorem, so no new Master clue is justified.
