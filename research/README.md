## Cross-line structure

The first common constraint is now **stable resolving capacity with both a lower and an upper bill**. Farey pushes the lower bill from merely growing/sub-root-rank observation to an order-rank requirement: `o(r_T)` source-independent prime-coordinate constraints can still be blind. Prime Circle and `FD-142` supply the opposite warning that very low-dimensional exact data can already identify the source if arbitrary precision or ill-conditioned decoding is allowed. Arithmetic Fidelity adds a second stability axis: even after relative inversion is cheap, the absolute endpoint-bearing signal may already have been exponentially attenuated. A useful observer therefore needs a target-bearing separation margin, an absolute signal floor, controlled inversion constants, and a quantitative argument that this capacity remains below source reconstruction.

The second common constraint is **arithmetic source realization rather than analytic or ambient realizability**. `NB-143` is the cleanest zero-side example: broad zeta-like analytic axioms plus the exact functional equation still allow the dangerous packet. `MC-315` is the finite-geometric analogue: the arithmetic endpoint requirement can be phrased as a standard projective-cap problem, but solving the ambient cap problem one way or the other is distinct from deciding whether actual Legendre-labeled source columns realize it. The next strong results should state explicitly which feature belongs to the actual arithmetic source and cannot be reproduced by the matched ambient object.

A third constraint is **local escape geometry after generic losses are removed**. Robin no longer pays the artificial rightmost-transfer factor, yet `RE-144` exhibits the surviving one-sided cooperative cluster. Weil Inertia no longer asks whether odd primes contribute enough raw mass; `WI-241` identifies discrepancy after PNT cancellation as the relevant repayment channel. Möbius no longer asks for a first-order redundancy law; `MC-314--MC-315` move the generic frontier to a second-order diagonal incidence problem. These are substantially sharper than requests for “more regularity” or “more cancellation”: each identifies the exact object a source theorem has to charge.

Several representation families have reached clean exhaustion points without implying impossibility of the parent program. `WP-317` removes bounded finite scalar multipoles but leaves unbounded collective/operator geometry; `MC-315` removes general first incidence averaging but leaves sharp diagonal finite geometry and arithmetic incidence; `NB-143` removes xi-type analytic realization as a discriminator but leaves arithmetic source laws; `VIS-238` removes Poisson count variance but leaves a fixed-count geometric residual test; and `AF-361` removes relative conditioning alone as a recovery certificate but leaves source-native cross-scale observables. These are carrier or proof-resource boundaries, not global impossibility results.

No new Master clue is justified. The actionable questions are already owned by their destination lines or absorbed into current local Mind state, and the new cross-line synthesis does not expose a distinct transfer claim requiring bounded foreign-source access. No merge, split, or new-line proposal is warranted.
