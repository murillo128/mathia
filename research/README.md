## Cross-line structure

The clearest new cross-line transfer is **Prime Lattice -> Weil Positivity inside Bost--Connes**. Weil Positivity had a legitimate reason to ask whether unbounded or infinite-prime objects escape the finite-mass bounded-KMS obstruction; Prime Lattice now proves that four particularly natural versions do not provide a discriminator. Mere affiliation lives in the full `B(H)`, scalar-renormalized corner vectors have no nonzero GNS tail, lcm conditioning either collapses fixed probes or reproduces the starting state under blow-up, and coprimality conditioning lands on the classical unit boundary. This is why the new local clue asks Weil Positivity for an additional source-forced relation rather than another category enlargement. The transfer is a falsification gate, not evidence that Bost--Connes cannot contribute through a different relation.

A second pattern is the distinction between **sublinear/local information and a genuinely global aggregate**. Xi makes this exact: any sublinear set of proper harmonic heat histories can be blind, while the terminal mode can see the first complementary Vieta shell. Visual supplies an information-theoretic analogue rather than the same mathematics: local Markov type fixes all short-span third-order correlations, power spectra can remain homometric, and a minimally nonlocal third-order correlation can recover chronology. These results support changing information category only when an exact witness proves that the new carrier contains something the old quotient erased; they do not identify a shared RH mechanism.

Arithmetic Fidelity and Möbius Cancellation now give a useful stability contrast. In Arithmetic Fidelity, exact injectivity becomes uniform finite observation once the source class is precompact. In Möbius, standard oriented linear commutator readouts can be exactly invertible but only by reconstructing Mertens itself. Exact recovery is therefore neither automatically useful nor automatically useless: the unresolved question is whether the source supplies a quantitatively cheaper, stable intermediate class after the full destination quotient.

No further cross-line connection currently clears the clue threshold. The Prime-Flute, Weil-Inertia, Analytic-Frontier, Xi and Visual decisive tests are already owned locally or by existing accepted clues; duplicating them would add routing noise rather than mathematical leverage.
