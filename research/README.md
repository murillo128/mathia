## Cross-line structure

### 1. Exact repair increasingly moves the endpoint from representation to incidence, conditioning, or destination response

`AF-320`, `NB-097`, and `PF-327` are three clean examples of a useful but limited closure. Arithmetic Fidelity repairs the singular finite representation but leaves whether the source orbit hits the singular fiber and how close it can approach the deeper forbidden stratum. Nyman removes determinant crowding, pivot collapse, and every isolated two-state conditioning failure but leaves genuinely collective shear and later finite-window/target costs. Prime Flute preserves both the packet and its critical energy through the exact seam coordinate, but the completed `L/H` angle can still erase it downstream. In each case the representation/interface question has been answered strongly enough that reopening it would attack the wrong mathematical currency.

### 2. Uniformization can lose exactly the amount of information needed at the endpoint

`MC-270`, `WI-279`, and `WP-287` locate three different versions of this loss. Möbius shows that replacing the one flat source vector by arbitrary coefficients costs exactly the blind-atom budget: the best possible operator norm reaches the threshold but cannot cross it. Weil Inertia shows that restoring Hilbert orientation improves the cut reserve, yet any argument whose numerator still depends only on the same scalar `lambda_a` profile remains trapped by the `WI-278` countermodel. Weil Positivity shows that arbitrary nonlinear profile post-processing creates no new linear Weil distribution: distribution linearity forces the rule back into the linear factor class on the attainable data manifold. The common diagnostic is to identify the first relaxation that becomes universal and ask whether its information loss is already of the same scale as the desired contradiction.

### 3. Bulk closure is leaving thin tails whose mathematical type is different from the bulk estimate

`FD-098`, `RE-100`, and `VIS-208` sharpen this pattern. Farey's best current uniform source regularity extends an all-head retreat logarithmically but cannot make it macroscopic, so the residual is a branch/scale law rather than another short-interval estimate of the same kind. Robin's critical line and most of the strip no longer require fourth moments; the residual is only a high-`beta` tail where density is much thinner. Visual's positive noncancelling determinant band is controlled after the actual sinc weighting; the residual begins at the one-cancellation geometry or at the gap between Cesaro-typical and uniform starts. Strengthening the closed bulk machinery without addressing these changed currencies is unlikely to move the endpoint.

### 4. Matched transport now reaches whole destination objects, not just scalar proxies

`PC-281` is the strongest example: once the phase profile is uniformly regular, the Li-grid control transports the entire normalized singular-value vector of the finite section, including spectral edges and every uniformly Lipschitz functional of the ordered spectrum. That raises the matched-control standard for Prime Circle from reproducing a few scalar moments to reproducing the full regular destination object. `PF-327` provides the complementary positive lesson: a source-realized witness should not be credited until it survives the actual destination normalization and completion. Together they reinforce the global rule that retained source dependence is meaningful only after the precise quotient, transport regularity, and target metric have all been charged.
