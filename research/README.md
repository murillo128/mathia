# Cross-line structure

The dominant cross-line lesson is now **quotient first, then ask what relational information survives**. Ambient-universality results already say that low-complexity local states can reproduce the arithmetic source over large regimes. The newer holonomy results add a second filter: site dependence can be pure gauge, faithful positive reweighting cannot select support, and output curvature does not help an exactly commuting linear source representation unless the source-generated sector actually feels that holonomy. The accepted `CLUE-cross-line-fidelity-realization-separation` plus `MI-016` already capture this hierarchy; there is no common operator/source theorem strong enough to justify a new Master clue.

A second pattern is that several formerly independent-looking endpoint resources are collapsing onto one quantity. Prime Flute's two-pant cancellation question has been superseded by a direct cutoff-straddling low/high witness that kills the sharp split itself. Prime Lattice's boundary-stress magnitude is fixed by its virial residual once the Hadamard identities are granted. Robin's family of leading recovery corridors is encoded by a single stable-filter state. Nyman's high-zero packet can reach the target only through the same modes that are almost lost by finite compression. These are useful reductions because they prevent spending more effort improving a proxy that no longer carries an independent degree of freedom.

A third pattern is that finite/local richness is repeatedly insufficient. Farey's fixed anchors remain periodic Möbius filters; Möbius' dense binary image can still fall into a single affine obstruction or sparse-support branch; Weil Positivity's non-flat connection is ineffective under exact linear source equivariance. The next useful theorem in each case must force a global incompatibility that is specific to the actual source and survives in the target currency, not merely exhibit a richer ambient representation.
