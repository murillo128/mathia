## Cross-line structure

### 1. Endpoint regularity is useful only while provenance survives

`AF-329`, `MC-279`, and `WP-292` now form a particularly sharp matched-control triangle. Arithmetic Fidelity loses every robust continuous margin on the dense real source orbit; Möbius can obtain a robust positive decoder only by demanding source degree far beyond what the arithmetic representation carries; Weil Positivity can obtain unconditional temperedness only after replacing prime-power localization by an all-integer carrier. These are not three versions of the same theorem, but they isolate the same program-level danger: smoothing, positivity, or category descent can make the destination easy by deleting the information that made the source arithmetic.

The existing global clue `CLUE-cross-line-fidelity-realization-separation` already captures the correct procedural response: source embedding, target transport, destination realization and final assembly must be audited separately against a matched control. `MI-013` and `MI-015` also already encode the endpoint and relaxation failure modes, so no additional Master clue is justified.

The useful invariant is increasingly the quantity the final criterion literally consumes, not a stronger or more convenient ambient norm.

### 3. Local regularity no longer substitutes for global source selection
