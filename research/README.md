## Cross-line structure

### 1. The exact destination currency is now part of the theorem, not post-processing

Arithmetic Fidelity, Nyman and Prime Flute make this unusually explicit. `AF-326` turns a source recovery margin into the second-harmonic margin actually retained downstream. `NB-103` shows that a conditioning singularity can disappear completely from fixed-multiplicity determinant volume. `PF-332` cancels baseline seam square-root nonlocality in the relative variable before asking about packet locality. A source theorem can therefore be strong and still irrelevant if it controls the wrong destination functional; conversely an apparent obstruction can vanish when the final quotient is formed exactly.

### 2. Generic normalization and positivity now have calibrated failure modes

`MC-276` shows that generic distributional normalization can be **too easy**: its `L^2` error cancels the blind mass and returns the existing Christoffel energy. `PF-333` shows that generic positive perturbation control can be **too weak**: positivity still permits logarithmic relative square-root sensitivity. `PL-299` shows that a pure positive principal branch can be regular all the way to zero order without carrying the desired arithmetic sign. `WI-281` is valuable precisely because it is different: the actual prime-power screening hypothesis cuts down the continuous admissible class. The useful resource is not positivity or normalization by itself but a restriction that the arithmetic source forces and matched controls cannot reproduce.

### 3. Long local control increasingly leaves an assembly/source-refresh problem

Farey no longer lacks logarithmic-depth predecessor composition above the linear mass floor; it lacks a theorem keeping the **source scale** informative during that transport. Robin no longer lacks local fan coercivity; after `RE-106`, only an extreme terminal reset can erase the accumulated raw debt. Nyman similarly separates local conditioning from the larger-family or target-conversion problem. These are variants of the same program-level warning: a good local step globalizes only after source refresh, compatibility, switching, or a destination-visible conserved quantity is priced.

### 4. Classical reproducibility boundaries are becoming sharp enough to stop proxy refinement

`PC-284` pushes Li-grid reproducibility through the exact logarithmic finite-section spectrum below the rational-microscopic scale. `VIS-211` now closes the only nonzero cancellation shell available in its exact pair-difference model throughout the stated subcritical long-start regime, so there is no next shell to optimize. `PF-333` identifies the generic relative square-root theory as classical and therefore forces Prime Flute back onto specific DtN geometry. These boundaries are useful because they say where a new observable or source-specific law is required rather than inviting another estimate on an exhausted proxy.
