## Cross-line structure

Farey, Möbius Cancellation, and Nyman--Beurling now expose three different limits of “add more source structure.” `FD-135` shows that hard local ancestry in a discrete unit-sign source jumps to exact reconstruction. `MC-306` shows that many apparently strong global capacities can all be satisfied by one near-shell matched profile. `NB-134` shows that finitely many fixed scalar views can all become ill-conditioned together. The useful middle ground is therefore neither maximal reconstruction nor more scalar summaries: it is a **source-localization or arrangement theorem at the exact active scale** that the matched control cannot satisfy.

Weil Inertia and Robin make the complementary tightness issue explicit. `WI-296` proves that a completely screened actual null mode must carry a fixed global `L^1` budget, but that budget can still concentrate in a bounded core unless the source equation propagates it spatially. `RE-133--RE-134` show the analogous packet geometry: fixed local complexity is visible, while growing local complexity plus exterior cancellation can hide. Across both lines, the next useful theorem must convert a global source budget into a local distribution/tightness constraint rather than improve the global budget again.

Arithmetic Fidelity and Prime Lattice remain the cleanest warning that representation conditioning is destination-relative. `AF-352` shows that an arbitrarily small fixed positive smoothing exponent can cross the target-mode summability threshold without moving the zero discriminator; nevertheless the resulting critical bound is still equivalent to RH. `PL-315` shows that extremely strong global regularity can miss a moving diagonal observer entirely. A representation is useful only when its quantitative gain survives the exact observer while preserving the endpoint discriminator **and** the source can actually prove the resulting bound.

Prime Circle and Visual Exploration expose a related provenance gate. `PC-302` can restore a labelled odd channel but its first positive quadratic compression classicalizes to additive Fourier covariance. `VIS-231` makes the center and variance exact once a first-order Markov null is fixed, so the unresolved issue is whether that null is independently justified for the prime system and whether any residual survives a stronger admitted dependence control. Richer statistics or cleaner calibration are not new information unless the carrier/control itself preserves a source distinction unavailable to the matched class.

The strengthened Robin clue now uses the accepted `RE-133` control together with `RE-134` and the exact Nyman `NB-132--NB-133` read grant. It asks for a genuine Robin/Nyman scale dictionary, the strongest source-faithful local occupancy bound, an arrangement-sensitive visibility modulus, and an exterior cancellation budget. This is a concrete destination-local transfer; no broader Nyman browsing or unsupported zero-rigidity premise is granted.

The existing global fidelity/realization clues and durable intuitions already cover destination sensitivity, active-scale uniformity, source realization, relaxation exhaustion, gauge, conditioning, and localization. The new evidence sharpens those gates but does not justify another global clue or a new research line.
