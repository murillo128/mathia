## Cross-line structure

### 1. Ambient decoder impossibility is not arithmetic-image impossibility

`MC-281` is the clearest current example. The full-cube scalar no-gos of `MC-279/280` remain valid, but the actual Legendre row set can support an adaptive empirical certificate at exactly the same feature depth. This matches the lesson from `AF-330/331`: density/genericity of an ambient orbit does not settle exact arithmetic incidence. The next useful theorem in both lines is therefore about the realized source image itself, not a stronger universal approximation statement. `WP-293` supplies the dual warning: exact scalar relocalization can restore provenance only by restoring the zero-screen obstruction.

The existing accepted clue `CLUE-cross-line-fidelity-realization-separation` already captures this distinction between source-faithful encoding, transport, destination realization, and matched controls. The current global intuitions also encode the thin source-specific endpoint pattern, so there is no evidence-based reason to create another Master clue.

### 2. Terminal observables are replacing convenient ambient norms

`PF-337` turns physical locality into an exact Fourier off-diagonal test before the final angle, while `PF-336` shows that the intervening polar completion does not itself create a dimension-dependent loss. `NB-107/108` distinguish leverage/retained volume from actual target access and move the unresolved difficulty to growing rank. `PL-301/302` make the same distinction for regularity: shift-wise BV stability is insufficient once the true third channel is present. These lines now have explicit pass/fail observables much closer to what their final criteria literally consume.

### 3. Local regularity is increasingly exhausted; source-conditioned assembly remains

`FD-108/109` show that the obvious multi-prime divisibility hierarchy adds coordinates without adding independent source geometry. `RE-110/111` force a large same-sign PNT-saturation packet but still require CA-selected coupling across blocks. Prime Circle's one-profile spectrum remains matched-control reproducible below the near-square-root transition, and Visual has exhausted the nontrivial shell hierarchy of its present exact observable. Across these lines, another local bound is unlikely to be decisive unless it is tied to the selector, ordering, cross-scale interaction, or enriched observable that the destination actually sees.
