## Cross-line structure

Arithmetic Fidelity, Nyman--Beurling, and Prime Circle now make a useful three-way distinction. `AF-350` proves that a **lossy** terminal quotient can still be perfectly adequate when it retains the exact analytic discriminator required by the endpoint. `NB-131` proves that an **exact** finite-prefix representation can still be noncoercive for the target mass. `PC-301` identifies an irreversible carrier quotient that removes orientation before any later statistic can exploit source dependence. “Information preserved” is therefore not a scalar property: one must identify the minimal target discriminator, the stage at which it is quotiented, and whether the surviving topology controls that discriminator quantitatively.

Farey, Robin, and Visual expose three different baseline failures at an active scale. `FD-132` defeats pointwise convergence in every fixed coordinate because the defect migrates through a growing prime/rank boundary. `RE-132` defeats arbitrarily strong one-level global counting because the obstruction is a local reciprocal pair geometry. `VIS-228` defeats positive extensive collision excess because the simplest stochastic occupancy null already produces it. Uniform quantifiers, local geometry, and matched stochastic baselines are independent resources; replacing one by more strength in another does not close the endpoint.

Möbius Cancellation and Weil Positivity show that reorganizing a problem into a more sophisticated classical object does not automatically buy the theorem range needed. `MC-303` exactly couples the selected quadratic modes through a multiquadratic field, but the same source inflation makes generic Chebotarev too expensive at the shell scale. `WP-310` shows that the classical infinity Schur compression is not even in the admissible function class of the critical Mangoldt source. In both cases the surviving continuation must exploit structure specific to the source/problem, not merely invoke a stronger black-box representation theorem.

Weil Inertia and Prime Lattice provide the more constructive counterpoint. `WI-295` extracts an exact source-compatible support threshold and a quantitative amplitude tariff from the true sign constraint instead of minimizing over a larger artificial class. `PL-313--PL-314` identify an exact rank-one endpoint channel and the moving-scale regularity needed for that channel to be stable. These are useful models for a viable reduction: preserve the extremizer class actually used by the endpoint, identify the scalar or geometry the theorem really samples, and then price precisely the source condition still missing.

The existing global fidelity/realization clue, the observable-specific gate clue, and `MI-008`, `MI-009`, `MI-012--MI-016` already cover stable transport, destination sensitivity, active-scale uniformity, endpoint-faithful relaxation, and source-forced geometry. The present evidence sharpens those principles rather than exposing a distinct cross-line conjecture that warrants another Master clue.
