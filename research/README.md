## Cross-line structure

The first strong convergence is between **acquisition complexity and target orientation**. Arithmetic Fidelity shows that local Euler depth can be finite while global prime breadth remains infinite; finite exact scalar samples still leave far-prime fibers. Analytic Frontier provides an explicit geometric complexity threshold below which a dangerous endpoint defect remains invisible. Farey shows that even strong global almost-all information can miss adaptively selected source locations. Nyman then shows the complementary failure mode: useful information may already be present in a compressed representation while its normalized direction relative to the target remains uncontrolled. These are different mathematical statements, but together they rule out treating “more information” as an unqualified resource; the information has to arrive in the coordinate and complexity class consumed by the endgame.

A second convergence concerns norm control versus signed/source-selected coordinates. Möbius Cancellation now has the cleanest quantitative example: the per-character GRH-strength theorem would close the shell, but both exceptional-sector counting and generic large-sieve energy discard the signed selected residue and fail by a fixed-power margin. Weil Inertia reaches the same methodological boundary from a different operator: the positive archimedean reserve is known sharply, while phase-blind control of the prime symbol is too expensive; only the source's orientation against the first odd zero-mode candidate matters. Visual Exploration supplies a calibrated null for the growing-complexity version of this issue, so a future statistical discriminator must beat a dimension-dependent square-root/Gaussian baseline rather than merely evade fixed-order Haar tests.

A third convergence concerns **noncompact/global completion**. Prime Flute proves that the known local fixed-axis response is regular enough that a precompact fixed-window mechanism cannot sustain the heavy angle; any obstruction must escape through genuinely global or nonuniform geometry. Prime Lattice shows that a canonical noncompact completion can radically change Morse-index category, but that repair is generic for every finite source replacement and leaves the RH-sensitive information in a finite low/mesoscopic sector. Weil Positivity likewise shows that sophisticated Fock representations can preserve much prime structure while missing the exact Weil weights and pairing. The useful common lesson is therefore limited but durable: source identity, eventual spectral positivity, and critical-looking normalization are not substitutes for a source-forced global ordering relation.

The existing cross-line clues remain sufficient. The Bombieri-to-Weil-Inertia clue owns sparse zero-side persistence, the Maaß--Selberg-to-Weil-Positivity clue owns preservation of the target sign in a genuinely global positive construction, and Prime Flute's accepted clue owns the normalized-response compactness test. No new Master clue is created. In particular, `PL-278` and the Weil-Inertia finite-radius program now look structurally related, but there is still no exact normalization-preserving map between the completed Galerkin/compact-resolvent operator and the localized odd first-crossing operator; a formal handoff would overstate the evidence.
