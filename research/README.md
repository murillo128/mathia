## Cross-line structure

The common positive target is narrower: identify the actual source-accessed subspace, topology, or threshold family and prove the required estimate there. This strengthens the existing proposed fidelity/transport/realization clue but does not yet give an exact operator transfer between lines.

**Persistent or abundant local structure can still vanish under global normalization.** Farey packets can survive forever pointwise and still be diluted by later frontier energy. Nyman's arithmetic branching forces long-range absolute covariance, yet signed elimination remains open. Robin has a genuinely one-sided local ledger, but still needs enough global capacity. Visual can contain exact resonant pairs while the normalized aggregate contribution vanishes. The next useful theorem in each line must quantify non-escape in the same currency consumed by its endpoint.

**Algebraic obstruction size and cancellation are different resources.** Möbius now shows this explicitly: growing support does not imply growing rank, and annihilator control would still not yield the required signed amplitude. Prime Circle has the complementary warning: exact quotient/character algebra is valid, but a source-specific numerical witness can fail independently. Structural identities should therefore be retained while empirical or source-specific conclusions are quarantined when challenged.

**The strongest live routes are becoming source-assembly tests rather than representation searches.** Analytic Frontier asks whether the real prime-minus-rough source can continue through a sharp adversarial aperture. Prime Flute asks whether the physical `P/H` source/reassembly sees or cancels a now-explicit divergent scalar backreaction. Weil Inertia asks whether one first mode can satisfy the source-selected medium-radius constraints across multiple prime-power thresholds. These remain the three `continue` lines because each has a falsifiable next theorem tied to the source and endpoint rather than another generic representation refinement.
