# MI-053 — Vertical Euler phase resolves a shell, while shell index is priced by Diophantine recurrence

**Evidence level:** exact synthesis from [RE-193](../../findings/RE-193-dyadic-laplace-compression-makes-euler-stable-dimension-logarithmic.md), [RE-199](../../findings/RE-199-full-real-euler-collapse-persists-through-sub-quarter-linear-depth.md), [RE-200](../../findings/RE-200-vertical-euler-phase-supports-linear-stable-dimension-on-one-prime-shell.md), [RE-201](../../findings/RE-201-commensurate-vertical-euler-frames-admit-remote-shell-aliases-at-selector-debt-scale.md), and [RE-202](../../findings/RE-202-diophantine-rank-prices-noncommensurate-vertical-euler-aliases.md). The Laplace/Fourier, aliasing and simultaneous-approximation mechanisms are classical; the Mathia content is their exact realization by ordinary-prime Euler atoms at selector scale under KV source fidelity.

The same logarithmic prime coordinate behaves very differently along real and imaginary spectral directions. After selector-shell normalization, positive-real Euler sampling sees essentially `e^(-ux)`, so Laplace damping makes separated source locations redundant at finite precision. RE-193 quantifies the resulting low stable rank, while RE-196--RE-199 exploit the same geometry to make the complete positive real ray exponentially almost blind along honest matched controls carrying a Robin-scale transient.

Vertical motion replaces damping by phase. RE-200 places ordinary primes near an equally spaced logarithmic grid on one fixed multiplicative shell and samples dual frequencies. The exact Euler response is a diagonally weighted DFT plus a vanishing perturbation, so `K` prime atoms retain `K` uniformly conditioned Euclidean directions up to height `O(K)`. This proves genuine representation capacity inside one logarithmic fundamental domain.

RE-201 identifies the missing global coordinate for the commensurate grid. Logarithmic position is observed only modulo the DFT period, so multiplying a source location by `Lambda=e^(mW)` leaves every first-harmonic phase unchanged. The reciprocal-amplitude loss can be repaired by about `Lambda` ordinary remote primes. With honest `{0,1,2}` multiplicities and the same KV source envelope, this creates a selector-scale packet whose debt is present between shells while every sampled exact Euler value is `o(d_Q)` after remote repair.

RE-202 shows that exact commensurability was not the essential weakness. If all sampled heights lie in a rank-`r` integer frequency module with coefficient radius `K`, simultaneous Diophantine approximation gives a common approximate logarithmic period at cost roughly `(K A)^r`, where `A->infinity` is the requested inverse phase error. Comparing that recurrence cost with the KV-safe log-distance

`L_KV(Q)=(log Q)^(5/3)(loglog Q)^(1/3)`

shows that selector-scale ordinary-prime aliases still exist whenever `K^r=o(L_KV(Q))`. In particular, two irrationally related arithmetic panels remain noncoercive throughout `K=o((log Q)^(5/6)(loglog Q)^(1/6))`. Even a fully jittered finite panel cannot universally escape: any `M=o(loglog Q)` heights of size `O(M)` have a common recurrence early enough to realize the same source-level alias.

Thus **vertical Fourier rank is local support information, while global shell-index resolution has a separate Diophantine budget**. Replacing one arithmetic grid by two incommensurate grids increases the repair distance but does not by itself create source coercivity. What matters is the spectral generator rank, coefficient radius, required phase precision and the largest logarithmic repair displacement still affordable by the source class.

The next complex-sampling question is no longer merely whether a panel is noncommensurate. It is whether one can design a finite height set with no common almost-period throughout the KV-affordable displacement range and, after that single-translation failure mode is removed, whether several remote shells with integer prime populations can still synthesize the same observation vector. Those are distinct gates: anti-recurrence of one translated shell does not yet imply global source rigidity.

**Boundary.** RE-202 does not invalidate RE-200 and does not prove that every large irregular panel is noncoercive. Its structured alias requires `K^r=o(L_KV(Q))`, while the universal arbitrary-panel statement only covers `M=o(loglog Q)`. The construction remains a selector-scale source-noncoercivity result, not a complete Robin countermodel, and it does not rule out a genuinely anti-aliasing high-rank vertical design beyond those regimes.
