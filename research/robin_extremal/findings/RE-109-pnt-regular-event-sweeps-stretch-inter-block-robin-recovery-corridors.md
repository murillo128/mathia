# RE-109 — PNT-regular event sweeps stretch inter-block Robin recovery corridors

**Status:** `EXACT-DERIVED + PNT-EVENT-SWEEP + MASS-TRANSPORT + INTER-BLOCK-RECOVERY + STRETCHED-SUBPOWER-SPACING + FALSE-RH-CONSEQUENCE + MATCHED-CONTROL + PRIOR-ART-AUDITED`.

`RE-108` proves that a positive quantitative Robin state cannot return to the nonpositive regime before a normalization corridor of length `Y^(1-b) log Y`, with `Y=log C`. Its matched control shows that this scale is sharp if one uses only monotonicity of `rho(C)=sigma(C)/C` and the positive witness height. That control deliberately forgets, however, that the numerator and the physical CA size are generated by the **same prime-layer event sweep**.

Restoring that source constraint adds a stretched-subpower price. Let

\[
\Phi(x)=\sum_{\eta_{p,j}\le x}\log p
\tag{1}
\]

be the full CA event staircase. For some absolute `a>0`, put

\[
\mathcal E(x)=
\exp\!\left[-a(\log x)^{3/5}(\log\log x)^{-1/5}\right].
\tag{2}
\]

Then

\[
\boxed{\Phi(x)=x+O\!\left(x\mathcal E(x)\right).}
\tag{3}
\]

More importantly, every event atom of mass `log p` can be coupled to the physical logarithmic-mass interval that it creates, and (3) keeps that entire interval within `O(Y E(Y))` of its event coordinate on a corridor of scale `Y`.

Let `C<D` be CA states and write

\[
Y=\log C,\qquad V=\log D,
\qquad h(N)=\log G(N)-\gamma.
\tag{4}
\]

If `h(C)>0` and `h(D)<=0`, then either `V>2Y`, or

\[
\boxed{
V-Y\gg
\frac{h(C)Y\log Y}{\mathcal E(Y)}.
}
\tag{5}
\]

For the quantitative false-RH witnesses of `RE-038`--`RE-040`, where `h(C_b)\gg_JY_b^{-b}` for each fixed `b` in a compact threshold interval `J`, the large-corridor alternative is automatically stronger than (5). Hence

\[
\boxed{
V_{\mathcal B}-Y_b
\gg_J
\frac{Y_b^{1-b}\log Y_b}{\mathcal E(Y_b)}.
}
\tag{6}
\]

Thus the normalization corridor of `RE-108` acquires an arithmetic factor

\[
\mathcal E(Y)^{-1}
=
\exp\!\left[a(\log Y)^{3/5}(\log\log Y)^{-1/5}\right].
\tag{7}
\]

The frozen-numerator control of `RE-108` is therefore no longer source-admissible after imposing the unconditional PNT regularity of the actual event sweep.

## 1. The full event staircase has PNT-scale discrepancy

Split

\[
\Phi(x)=\Phi_1(x)+\Phi_{\ge2}(x).
\tag{8}
\]

`RE-069` gives the exact first-layer identity

\[
\Phi_1(x)=\vartheta(x)-B_1(x),
\qquad
B_1(x)=\sum_p(\log p)\mathbf 1_{[p,\eta_{p,1})}(x).
\tag{9}
\]

`RE-004` gives `p<=eta_(p,1)<p+1`. Thus a nonzero first-layer pulse at `x` can only come from a prime in `(x-1,x]`, so

\[
\boxed{B_1(x)\ll\log x.}
\tag{10}
\]

For higher layers, `RE-004` proves

\[
M_{\ge2}(x)
:=\#\{(p,j):j\ge2,\eta_{p,j}\le x\}
=O\!\left(\sqrt{x\log x}\right),
\tag{11}
\]

and the same event-location inequality gives

\[
p^j\log p\le x\log x.
\tag{12}
\]

For `j>=2` this implies `log p\ll log x`. Therefore the **weighted** higher-layer mass satisfies

\[
\boxed{
\Phi_{\ge2}(x)
\ll\sqrt{x}(\log x)^{3/2}.
}
\tag{13}
\]

Combining (9)--(13),

\[
\boxed{
\Phi(x)=\vartheta(x)
+O\!\left(\sqrt{x}(\log x)^{3/2}\right).
}
\tag{14}
\]

The unconditional Korobov--Vinogradov PNT error already anchored in `SOURCES.md` gives, after decreasing the positive constant if necessary,

\[
\vartheta(x)-x
=O\!\left(x\mathcal E(x)\right).
\tag{15}
\]

The square-root error in (14) is asymptotically smaller, proving (3). In particular, after another harmless decrease of `a`, uniformly on every fixed multiplicative neighborhood of `Y`, for example `Y/2<=x<=4Y`,

\[
\boxed{
|\Phi(x)-x|\ll Y\mathcal E(Y).
}
\tag{16}
\]

No new zero-density theorem is used here: the only analytic input is the unconditional PNT error already present in the line.

## 2. Event atoms are coupled to physical logarithmic mass

Consider the prime-layer events crossed in passing from `C` to `D`. Group simultaneous events at one coordinate if necessary. For an event group `e`, let `eta_e` be its event coordinate and `m_e` its total `log p` mass. The CA threshold equation gives the exact numerator increment

\[
\Delta_e\log\rho=g(\eta_e)m_e,
\qquad
g(x)=\frac1{x\log x}.
\tag{17}
\]

The same event increases the physical logarithmic state size by exactly `m_e`. Therefore

\[
\boxed{
V-Y=\sum_em_e,
\qquad
\log\rho(D)-\log\rho(C)
=\sum_em_eg(\eta_e).
}
\tag{18}
\]

The Robin normalization changes by

\[
\log\log V-\log\log Y
=\int_Y^Vg(s)\,ds.
\tag{19}
\]

Hence

\[
\boxed{
h(C)-h(D)
=\int_Y^Vg(s)\,ds
-\sum_em_eg(\eta_e).
}
\tag{20}
\]

Attach to event group `e` the physical-mass interval

\[
I_e=
\bigl(\Phi(\eta_e^-),\Phi(\eta_e)\bigr],
\tag{21}
\]

or the corresponding subinterval if `C` or `D` lies inside a simultaneous tie. The intervals are consecutive, have length `m_e`, and partition `(Y,V]`. Ties cause no problem: all tied atoms have the same `eta_e`, and an intermediate CA state merely subdivides the same physical jump.

Assume first that `V<=2Y`. Since `Phi(x)/x->1`, every crossed event coordinate lies in a fixed multiplicative neighborhood of `Y` for all sufficiently large `Y`; `[Y/2,4Y]` is enough. Applying (16) to the left and right limits in (21), every `s in I_e` satisfies

\[
\boxed{|s-\eta_e|\ll Y\mathcal E(Y).}
\tag{22}
\]

This is the source constraint absent from `RE-108`: not just the corridor endpoints, but the entire physical mass created by each event stays close to the coordinate at which that same event contributes its numerator gain.

## 3. Robin recovery is a quadrature error

Because the intervals `I_e` partition `(Y,V]`, equation (20) becomes exactly

\[
h(C)-h(D)
=
\sum_e\int_{I_e}
\bigl(g(s)-g(\eta_e)\bigr)\,ds.
\tag{23}
\]

On `[Y/2,4Y]`,

\[
|g'(x)|\asymp\frac1{Y^2\log Y}.
\tag{24}
\]

Combining (22)--(24),

\[
\boxed{
|h(C)-h(D)|
\ll
\frac{(V-Y)\mathcal E(Y)}{Y\log Y}.
}
\tag{25}
\]

If `h(C)>0` and `h(D)<=0`, then `h(C)<=h(C)-h(D)`, and (25) yields (5) in the branch `V<=2Y`.

There is no circularity in the event localization. If a crossed event coordinate were outside every fixed multiple of `Y`, then its post-jump cumulative mass `Phi(eta)` would also be outside `[Y,2Y]` because `Phi(eta)/eta->1`, contradicting that the event belongs to the transition from `C` to `D`. The coarse `o(x)` statement localizes first; then the quantitative estimate (16) applies.

For arbitrary positive heights the theorem is deliberately a dichotomy, because the right side of (5) can exceed `Y` while the branch `V>2Y` only gives a corridor of order `Y`. For the false-RH amplitudes used below this issue disappears: for every fixed `b>0`,

\[
\frac{Y^{-b}\log Y}{\mathcal E(Y)}\longrightarrow0.
\tag{26}
\]

## 4. False RH blocks acquire a stretched-subpower recovery price

If `R<=1`, use `log(1+R)>=R/2`; if `R>1`, the fixed lower bound `log 2` is stronger than (29).

## 5. Adversarial checks and matched sharpness

Simultaneous events do not weaken the argument. A tie combines several `log p` atoms at one coordinate; the combined physical interval still lies between `Phi(eta^-)` and `Phi(eta)`, and both endpoints obey (16). Subdividing that jump at an intermediate tied CA state preserves (22)--(23).

Higher layers are included rather than discarded. Their total weighted mass is controlled only to the square-root scale in (13), but this is already negligible compared with the unconditional PNT envelope. No first-layer normal form, prime-gap assumption, bounded fan complexity, or layer-depth restriction enters (25)--(31).

There is also a matched synthetic control for the information class used here. On a local interval, take a monotone atomic staircase whose cumulative mass stays at displacement `delta` of order `Y E(Y)` from the identity, and arrange each event atom at coordinate `eta` to create physical mass near `eta-delta`. Then

\[
\int\bigl(g(s)-g(\eta(s))\bigr)\,ds
\asymp
(V-Y)\frac{\delta}{Y^2\log Y}
\asymp
(V-Y)\frac{\mathcal E(Y)}{Y\log Y}.
\tag{33}
\]

Thus a height drop of order `Y^(-b)` naturally requires the scale in (6). This synthetic staircase is not claimed to come from primes or from a genuine CA sequence; it shows only that the factor `1/E(Y)` cannot be improved from a uniform sup-norm event-sweep discrepancy alone.

This identifies precisely why the matched control of `RE-108` ceases to be relevant after adding source information. Freezing `rho` is sharp when numerator monotonicity is the whole information class, but it is incompatible with the coupled event-source identities (17)--(18) across a corridor carrying positive physical logarithmic mass. Once the same PNT-regular atoms must generate both quantities, the quadrature defect (25) becomes the recovery currency.

No novelty is claimed for the Korobov--Vinogradov PNT error, the Alaoglu--Erdos CA threshold structure, or the prime-layer event measure/workload representation. I did not locate a result coupling the **full asymptotic event-sweep discrepancy** to the physical logarithmic-mass intervals of its jumps to obtain an inter-block Robin-recovery spacing law. The durable Mathia delta is the coupling (21)--(25) and its false-RH consequence (30)--(32), not any underlying PNT or CA theorem. No new external theorem is load-bearing, so `SOURCES.md` requires no change.

The research frontier becomes more specific. `RE-108` showed that normalization alone leaves a corridor longer than the internal Chebyshev transport forced by `RE-107`; `RE-109` shows that the actual prime source cannot use that corridor arbitrarily efficiently. It must spend an additional stretched-subpower factor before a quantitative positive state can return to the threshold.

That is still not a contradiction. The next useful theorem must beat the **global sup-norm PNT envelope by using selection**: for example, show that CA-selected recovery intervals cannot maintain the extremal sign and magnitude needed to saturate (25), or couple the Chebyshev and reciprocal-Mertens coordinates across those selected intervals. Merely sharpening the same unconditional PNT error would only modify the stretched-subpower factor; a qualitatively stronger step must use source phase conditioned on the Robin selector.
