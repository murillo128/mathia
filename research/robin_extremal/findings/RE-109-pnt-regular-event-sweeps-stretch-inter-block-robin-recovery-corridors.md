# RE-109 — PNT-regular event sweeps stretch inter-block Robin recovery corridors

**Status:** `EXACT-DERIVED + PNT-EVENT-SWEEP + MASS-TRANSPORT + INTER-BLOCK-RECOVERY + STRETCHED-SUBPOWER-SPACING + FALSE-RH-CONSEQUENCE + MATCHED-CONTROL + PRIOR-ART-AUDITED`.

`RE-108` proves that a positive quantitative Robin state cannot return to the nonpositive regime before a normalization corridor of length `Y^(1-b) log Y`, with `Y=log C`. Its matched control also shows that this power law is sharp if one uses only monotonicity of `rho(C)=sigma(C)/C` and the positive witness height. That control deliberately forgets, however, that the numerator is generated by the same prime-layer event sweep whose cumulative mass selects the CA states.

Restoring that source constraint gives an additional factor. The full CA event staircase

\[
\Phi(x)=\sum_{\eta_{p,j}\le x}\log p
\tag{1}
\]

tracks the identity map with the unconditional prime-number-theorem error

\[
\boxed{
\Phi(x)=x+O\!\left(x\mathcal E(x)\right),
\qquad
\mathcal E(x)
:=\exp\!\left[-a
(\log x)^{3/5}(\log\log x)^{-1/5}
\right]
}
\tag{2}
\]

for some absolute `a>0`. The important consequence is not merely that the event axis and the physical logarithmic-size axis are asymptotic. Every individual event atom of mass `log p` can be coupled to the physical-mass interval that it creates, and (2) keeps **the entire interval** within `O(Y E(Y))` of the event coordinate on a corridor of scale `Y`.

This converts Robin-height recovery into a quadrature-error problem. Let `C<D` be CA states,

\[
Y:=\log C,
\qquad
V:=\log D,
\qquad
h(N):=\log G(N)-\gamma,
\tag{3}
\]

and suppose

\[
h(C)>0,
\qquad
h(D)\le0.
\tag{4}
\]

Then either `V>2Y`, or

\[
\boxed{
V-Y
\gg
\frac{h(C)\,Y\log Y}{\mathcal E(Y)}.
}
\tag{5}
\]

The implicit constant is absolute after fixing a sufficiently small admissible PNT constant in `E`. For the quantitative false-RH witnesses of `RE-038`--`RE-040`, where for every fixed `b in J` one has `h(C_b) \gg_J Y_b^{-b}`, the large-corridor alternative is automatically stronger than (5), because `Y^{-b} log Y/E(Y)=o(1)`. Hence

\[
\boxed{
V_{\mathcal B}-Y_b
\gg_J
Y_b^{1-b}\log Y_b\,
\exp\!\left[a
(\log Y_b)^{3/5}(\log\log Y_b)^{-1/5}
\right].
}
\tag{6}
\]

Thus the normalization corridor of `RE-108` acquires a genuine arithmetic **stretched-subpower price**. The old frozen-numerator control is no longer source-admissible once the PNT regularity of the actual prime-layer event sweep is imposed.

## 1. The full event staircase has PNT-scale discrepancy

Split the event staircase into first and higher layers,

\[
\Phi(x)=\Phi_1(x)+\Phi_{\ge2}(x).
\tag{7}
\]

`RE-069` gives the exact first-layer identity

\[
\Phi_1(x)=\vartheta(x)-B_1(x),
\qquad
B_1(x)=\sum_p(\log p)\mathbf 1_{[p,\eta_{p,1})}(x).
\tag{8}
\]

Moreover `RE-004` gives `p<=eta_(p,1)<p+1`. Therefore, for a fixed sufficiently large `x`, a nonzero pulse in (8) must come from a prime in `(x-1,x]`. There are only `O(1)` such integer candidates, and hence

\[
\boxed{B_1(x)\ll\log x.}
\tag{9}
\]

For the higher layers, `RE-004` proves

\[
M_{\ge2}(x)
:=\#\{(p,j):j\ge2,\eta_{p,j}\le x\}
=O\!\left(\sqrt{x\log x}\right).
\tag{10}
\]

The same event-location inequality used there gives

\[
p^j\log p\le x\log x.
\tag{11}
\]

For `j>=2` this implies `log p\ll log x`, so the **weighted** higher-layer mass obeys

\[
\boxed{
\Phi_{\ge2}(x)
\ll
\sqrt{x}(\log x)^{3/2}.
}
\tag{12}
\]

Consequently

\[
\Phi(x)
=artheta(x)
+O\!\left(\sqrt{x}(\log x)^{3/2}\right).
\tag{13}
\]

The unconditional Korobov--Vinogradov prime-number-theorem error already anchored in `SOURCES.md` gives, after reducing the positive constant if necessary,

\[
\vartheta(x)-x
=O\!\left(x\mathcal E(x)\right).
\tag{14}
\]

The error in (12) is asymptotically smaller than the right side of (14), proving (2). No zero-density estimate beyond the standard unconditional PNT input is being imported here.

A local form will be used below. For every sufficiently large `Y`, uniformly for `x` in any fixed multiplicative neighborhood of `Y`, for example `Y/2<=x<=4Y`,

\[
\boxed{
|\Phi(x)-x|
\ll
Y\mathcal E(Y).
}
\tag{15}
\]

One can ensure (15) with the same displayed shape simply by replacing `a` by a smaller positive absolute constant.

## 2. Event atoms are coupled to physical logarithmic mass

Consider all prime-layer events crossed in passing from the CA state `C` to the later CA state `D`. Group simultaneous events at one coordinate if necessary. For an event group `e`, write

\[
\eta_e:=\text{its event coordinate},
\qquad
m_e:=\text{its total }\log p\text{ mass}.
\tag{16}
\]

The CA threshold equation gives an exact numerator increment

\[
\Delta_e\log\rho
=g(\eta_e)m_e,
\qquad
g(x):=\frac1{x\log x}.
\tag{17}
\]

The same event adds exactly `m_e` to `log C`. Thus

\[
\boxed{
V-Y=\sum_e m_e,
\qquad
\log\rho(D)-\log\rho(C)
=\sum_e m_e g(\eta_e).
}
\tag{18}
\]

The normalization contributes

\[
\log\log V-\log\log Y
=\int_Y^Vg(s)\,ds.
\tag{19}
\]

Subtracting the numerator gain from the normalization gain gives the exact height identity

\[
\boxed{
h(C)-h(D)
=
\int_Y^Vg(s)\,ds
-
\sum_e m_e g(\eta_e).
}
\tag{20}
\]

Now attach to each event group its physical-mass interval

\[
I_e
:=
\bigl(\Phi(\eta_e^-),\Phi(\eta_e)\bigr],
\tag{21}
\]

or the corresponding subinterval if `C` or `D` lies inside a simultaneous tie. These intervals are consecutive, disjoint up to endpoints, have length `m_e`, and partition `(Y,V]`. This remains true under ties because all tied atoms have the same `eta_e`; any intermediate CA state simply cuts the total jump into subintervals at the same coordinate.

Suppose first that `V<=2Y`. Equation (2) implies `Phi(x)/x->1`, so every event contributing to (18) lies, for all sufficiently large `Y`, in a fixed multiplicative neighborhood of `Y`; one may take `[Y/2,4Y]`. Applying (15) to the two endpoints of (21) gives, for every `s in I_e`,

\[
\boxed{
|s-\eta_e|
\ll
Y\mathcal E(Y).
}
\tag{22}
\]

This is the key source constraint. It is stronger than comparing only the beginning and end of a corridor: the whole physical mass created by each event stays close to the coordinate at which that event contributes its Robin numerator gain.

## 3. Robin recovery is a quadrature error

Because the intervals `I_e` partition `(Y,V]`, equation (20) can be rewritten exactly as

\[
 h(C)-h(D)
=
\sum_e\int_{I_e}
\bigl(g(s)-g(\eta_e)\bigr)\,ds.
\tag{23}
\]

On `[Y/2,4Y]`,

\[
|g'(x)|
\asymp
\frac1{Y^2\log Y}.
\tag{24}
\]

Combining (22)--(24),

\[
\begin{aligned}
|h(C)-h(D)|
&\ll
\sum_e |I_e|
\frac{Y\mathcal E(Y)}{Y^2\log Y}\\
&=
\boxed{
O\!\left(
\frac{(V-Y)\mathcal E(Y)}{Y\log Y}
\right).
}
\end{aligned}
\tag{25}
\]

If `h(C)>0` and `h(D)<=0`, then `h(C)<=h(C)-h(D)`. In the short-corridor branch `V<=2Y`, equation (25) therefore implies (5).

There is no circularity from using the PNT discrepancy at the event coordinates. If an event crossed between `C` and `D` had coordinate `eta` far outside a fixed multiple of `Y`, its post-jump mass `Phi(eta)` would also be far outside `[Y,2Y]`, contradicting `Phi(eta)/eta->1`. This first coarse localization uses only the `o(x)` consequence of (2); after that, the quantitative local estimate (15) applies.

The statement is intentionally a dichotomy for arbitrary positive heights: if `V>2Y`, the physical corridor is already of order `Y`, while the right side of (5) could exceed `Y` for an artificially large `h(C)`. In the false-RH quantitative regime of interest this caveat disappears, because for every fixed `b>0`,

\[
\frac{Y^{-b}\log Y}{\mathcal E(Y)}\longrightarrow0.
\tag{26}
\]

## 4. False RH blocks acquire a stretched-subpower recovery price

Assume RH is false and retain the common-threshold fan notation of `RE-038`--`RE-040` and `RE-108`,

\[
J=[b_0,b_1]\Subset(1-\Theta,1/2).
\tag{27}

For every selected state `C_b` in one of the quantitative blocks,

\[
R_{C_b}
:=\frac{G(C_b)}{e^\gamma}-1
\ge c_0Y_b^{-b}.
\tag{28}
\]

Since `h(C_b)=log(1+R_(C_b))`, equation (28) implies, for all sufficiently large blocks,

\[
\boxed{h(C_b)\gg_JY_b^{-b}.}
\tag{29}
\]

Indeed, if `R<=1` use `log(1+R)>=R/2`; if `R>1`, the fixed lower bound `log 2` is even stronger than (29).

Let `D_B` be the first later CA state with nonpositive Robin height and set `V_B=log D_B`. If `V_B<=2Y_b`, equations (5) and (29) give (6). If `V_B>2Y_b`, then `V_B-Y_b>Y_b`; equation (26) shows that this is again stronger than (6). Thus (6) is unconditional within the false-RH hypothesis and uniform over each fixed compact `J`.

Equation (31) is still only `X^(1-b0+o(1))` on the exponent scale. It does not contradict the existence of infinitely many false-RH witness blocks. Its value is that the previously source-free corridor now has a quantified arithmetic cost which cannot be reproduced by the normalization-only matched control.

## 5. Adversarial checks and matched sharpness

The argument is insensitive to simultaneous CA events. A tie merely combines several `log p` atoms at one `eta`; the physical interval of the combined jump still lies between `Phi(eta^-)` and `Phi(eta)`, and both endpoints satisfy the same discrepancy bound. If one chooses an intermediate tied CA state, subdividing that interval does not alter (22) or (23).

Higher layers are also fully included rather than discarded. Their total weighted mass is controlled only to the square-root scale in (12), but this is enough because the unconditional PNT error is much larger asymptotically. No first-layer normal form, prime-gap hypothesis, bounded fan complexity, or restriction on layer depth enters (25)--(31).

There is a matching synthetic control for the **information class used here**. On a local interval, replace the actual event staircase by a monotone atomic staircase whose cumulative mass remains at displacement about `delta=Y E(Y)` from the identity and arrange its event atom at coordinate `eta` to create physical mass near `eta-delta`. Then

\[
\int\bigl(g(s)-g(\eta(s))\bigr)\,ds
\asymp
(V-Y)\frac{\delta}{Y^2\log Y}
\asymp
(V-Y)\frac{\mathcal E(Y)}{Y\log Y}.
\tag{33}
\]

Thus a height drop of order `Y^(-b)` naturally requires the scale in (6). This synthetic staircase is not asserted to come from primes or from a genuine CA sequence; it shows only that the factor `1/E(Y)` cannot be improved from a uniform sup-norm event-sweep discrepancy alone.

This also diagnoses the matched control of `RE-108`. Freezing `rho` was sharp when numerator monotonicity was the entire information class, but it is not compatible with the full event-source relation (17)--(18) over a corridor carrying positive logarithmic mass. Once the numerator increments and physical state increments are required to come from the same PNT-regular event sweep, the quadrature defect (25) is the relevant recovery currency.

## 6. Prior-art boundary and research consequence

No novelty is claimed for the Korobov--Vinogradov prime-number-theorem error, for the Alaoglu--Erdos CA threshold structure, or for the prime-layer event measure/workload representation. Those inputs are already anchored in `SOURCES.md`; in particular the line already records the current PNT tail input and Mantovanelli's recent prime-layer workload as the closest representation-level prior art.

A directed current search of the recent Robin/CA literature again found the Mantovanelli event-sweep work and its finite certified companion, which explicitly treats its finite certificates as illustrations rather than premises for an asymptotic theorem, together with Zimov's analysis of the least CA exception through individual consecutive prime/semiprime quotients. I did not locate a result coupling the **full asymptotic event-sweep discrepancy** to the physical logarithmic mass intervals of its jumps in order to derive an inter-block Robin-recovery spacing law. The durable Mathia delta is therefore the coupling (21)--(25) and its false-RH consequence (30)--(32), not any of the underlying PNT or CA facts. No new external theorem is load-bearing, so `SOURCES.md` requires no change.

The research frontier moves in a useful way. `RE-108` showed that normalization alone leaves a corridor longer than the internal Chebyshev transport forced by `RE-107`; `RE-109` shows that the actual prime source cannot use that corridor arbitrarily efficiently. It must spend an additional stretched-subpower factor before a quantitative positive state can return to the threshold.

That still falls short of a contradiction. The next useful theorem must improve on the **global sup-norm PNT envelope** by exploiting selection: for example, show that CA-selected recovery intervals cannot keep the event staircase at the extremal sign and magnitude needed to saturate (25), or couple the Chebyshev and reciprocal-Mertens coordinates across these selected intervals. Merely sharpening the same unconditional PNT error would only change the stretched-subpower factor; a qualitatively stronger step has to use source phase conditioned on the Robin selector.
