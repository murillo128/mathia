# RE-086 — higher-layer support boundaries force anchored base-prime-gap resonances

**Status:** `EXACT-DERIVED + SINGULAR-CROSS-LAYER-SELECTION + ANCHORED-BASE-PRIME-GAPS + FIXED-LAYER-ASYMPTOTIC + TIED-BOUNDARY-RESONANCE + COUNTEREXAMPLE-NARROWING + PRIOR-ART-BOUNDED`. `RE-083`--`RE-085` show that long mixed adaptive fans are asymptotically first-layer in every bounded physical-mass observable: endpoint data reconstruct the complete first-layer birth geometry, while the higher-layer share of normalized logarithmic event mass tends to zero. The remaining live channel is therefore singular rather than mass-averaged. One natural singular mechanism is that a rare higher-layer event becomes an actual support boundary of an exposed threshold cell. This finding shows that such a boundary cannot occur freely: **its generating base prime must itself sit at the edge of an ordinary prime gap large enough to carry the same threshold cell after inverse-layer transport.**

Assume RH is false, let

\[
\Theta:=\sup_{\zeta(\rho)=0}\Re\rho>\frac12,
\]

fix

\[
J=[b_0,b_1]\Subset(1-\Theta,1/2),
\]

and work on a sufficiently late common positive CA block from `RE-040`. Let `C` be an exposed state with positive-width threshold cell `I_C`, write

\[
Y:=\log C,
\qquad
h:=\log G(C)-\gamma>0,
\qquad
a:=1-e^{-h},
\]

and let

\[
\xi_-<\xi_+
\]

be the adjacent genuine CA event coordinates supporting `C`. Its selector image

\[
S_C:=Z_C(I_C^\circ)
\]

lies in `(\xi_-,\xi_+)`. For a fixed layer `j>=1`, let `\eta_j(x)` denote the increasing real event map of `RE-054`, and set

\[
Q_{C,j}:=\eta_j^{-1}(S_C).
\]

Suppose one support boundary is generated by the layer-`j` event of an ordinary prime `p`:

\[
\xi_+=\eta_j(p)
\qquad\text{or}\qquad
\xi_-=\eta_j(p).
\tag{1}
\]

Let `p^-<p<p^+` be the neighboring ordinary primes and define the **chamber-facing base gap**

\[
\mathcal G_C(p,j):=
\begin{cases}
 p-p^-,&\xi_+=\eta_j(p),\\
 p^+-p,&\xi_-=\eta_j(p).
\end{cases}
\tag{2}
\]

Then the full inverse support chamber is prime-free in layer `j`, and because one of its endpoints is exactly `p`,

\[
\boxed{
\mathcal G_C(p,j)
\ge
\left|\eta_j^{-1}\bigl((\xi_-,\xi_+)\bigr)\right|
\ge |Q_{C,j}|.
}
\tag{3}
\]

For every fixed `j`, `RE-054` and the event asymptotics imply uniformly along the late fan

\[
\boxed{
|Q_{C,j}|
=
(1+o_J(1))\,a\,|I_C|\,p\log p.
}
\tag{4}
\]

Consequently every fixed-layer support-boundary event obeys the **layer-independent normalized gap law**

\[
\boxed{
\frac{\mathcal G_C(p,j)}{p\log p}
\ge
(1-o_J(1))\,a\,|I_C|.
}
\tag{5}
\]

The cancellation of the layer index in (4)--(5) is the main point. Although the base prime of a depth-`j` event lies at scale `p\asymp(jY)^{1/j}`, inverse-layer expansion exactly compensates the power compression: the amount of threshold width that the event can support is measured by the same normalized ordinary-gap currency `G/(p log p)` at every fixed layer.

Using the false-RH amplitude floor from `RE-040`,

\[
a\gg_J Y^{-b_1},
\]

and `Y=(1+o_J(1))p^j/j`, equation (5) gives the explicit fixed-layer consequence

\[
\boxed{
\mathcal G_C(p,j)
\gg_{J,j}
|I_C|\,p^{1-jb_1}\log p.
}
\tag{6}
\]

Equivalently,

\[
\boxed{
|I_C|
\ll_{J,j}
\frac{\mathcal G_C(p,j)}{p^{1-jb_1}\log p}.
}
\tag{7}
\]

If a tied support boundary contains two fixed-layer events `(p,j)` and `(q,k)`, then both chamber-facing gaps are forced simultaneously and at power-related scales:

\[
\frac{p^j}{j}\sim\frac{q^k}{k}\sim Y,
\tag{8}
\]

\[
\boxed{
\min\!\left(
\frac{\mathcal G_C(p,j)}{p\log p},
\frac{\mathcal G_C(q,k)}{q\log q}
\right)
\ge
(1-o_J(1))a|I_C|.
}
\tag{9}
\]

Thus a semiprime/tied exceptional boundary is not merely a rare CA event. It is a **synchronized prime-gap resonance at each of its generating base primes**, with a common normalized lower threshold determined by the exposed cell itself.

## 1. A boundary event anchors the inverse-layer prime-free chamber at its own base prime

The support interval `(\xi_-,\xi_+)` contains no genuine CA event by definition. Fix a layer `j` and use the strictly increasing real event map `\eta_j`. Its inverse image

\[
\widetilde Q_{C,j}:=
\eta_j^{-1}\bigl((\xi_-,\xi_+)\bigr)
\tag{10}
\]

contains no ordinary prime: if a prime `r` belonged to its interior, then the genuine layer-`j` event `\eta_j(r)` would lie strictly between the adjacent support events, a contradiction.

Now suppose first that the outgoing boundary is `\xi_+=\eta_j(p)`. Monotonicity gives

\[
\widetilde Q_{C,j}=(u,p)
\]

for some real `u<p`. Since the interval is prime-free, the previous prime satisfies `p^-\le u`. Hence

\[
p-p^-\ge p-u=|\widetilde Q_{C,j}|.
\tag{11}
\]

Because `S_C\subset(\xi_-,\xi_+)`, its inverse image satisfies

\[
Q_{C,j}\subset\widetilde Q_{C,j},
\]

which proves (3) on the outgoing side. If instead `\xi_-=\eta_j(p)`, then

\[
\widetilde Q_{C,j}=(p,v)
\]

is prime-free, so `p^+\ge v` and

\[
p^+-p\ge v-p=|\widetilde Q_{C,j}|\ge|Q_{C,j}|.
\tag{12}
\]

This is the extra information absent from a generic inverse-layer prime-free interval. `RE-054` proves that a cell creates a prime-free interval near the inverse scale; condition (1) pins that interval to the **specific prime whose power event is causing the singular support boundary**.

Ties cause no ambiguity. If several prime-layer events share the same support coordinate, apply (10)--(12) separately to each increasing map `\eta_j`. Every participating base prime is an endpoint of its own inverse prime-free chamber.

## 2. In fixed depth the layer constants cancel exactly at leading order

`RE-054` gives, for every fixed `j`,

\[
|Q_{C,j}|
=
\left(j^{-(j-1)/j}+o_J(1)\right)
 a|I_C|Y^{1/j}\log Y.
\tag{13}
\]

It also gives the event-map expansion

\[
\eta_j(x)
=
\frac{x^j}{j}
\left(1+O_j\!\left(\frac1{\log x}\right)\right).
\tag{14}
\]

The selected support chamber lies at the selector scale. `RE-040` gives `Z/Y->1` uniformly on the compact fan, while the ambient first-layer prime mesh used in `RE-051` keeps both adjacent support coordinates at `Y+o(Y)`. Therefore condition (1) and (14) imply

\[
Y
=
\frac{p^j}{j}(1+o_J(1)).
\tag{15}
\]

Hence

\[
Y^{1/j}
=
\frac{p}{j^{1/j}}(1+o_J(1)),
\qquad
\log Y
=j\log p+O_j(\log\log p).
\tag{16}
\]

Substituting (16) into (13), the two powers of `j` multiply to `1/j`, which is then cancelled by the factor `j` in `log Y`:

\[
\begin{aligned}
|Q_{C,j}|
&=
(1+o_J(1))
 j^{-(j-1)/j}a|I_C|
 \frac{p}{j^{1/j}}
 j\log p\\
&=
(1+o_J(1))a|I_C|p\log p.
\end{aligned}
\tag{17}
\]

Equations (3) and (17) prove (4)--(5). The result is therefore not a new prime-gap estimate imported from outside the CA problem. It is a geometric exchange law: **one unit of normalized threshold capacity costs the same relative base-prime gap at every fixed CA layer.**

## 3. Tied exceptional boundaries require simultaneous multi-scale gap endpoints

Suppose a support coordinate carries two distinct events

\[
\xi_+=\eta_j(p)=\eta_k(q),
\qquad
(p,j)\ne(q,k),
\tag{18}
\]

with fixed `j,k`. Applying (15) to both events gives (8). Applying (5) to both gives (9). The same statement holds at the incoming boundary, with next-prime rather than previous-prime gaps.

This is a genuinely singular cross-layer condition. `RE-085` says that the total logarithmic mass of higher-layer events is asymptotically invisible in long-fan normalized observables. Equations (8)--(9) show why a rare higher-layer event can nevertheless matter if it is selected as a support boundary: its influence is not proportional to its mass. It requires the event coordinate to land precisely where **each base prime participating in the boundary already has enough one-sided ordinary-gap capacity to support the exposed threshold interval.**

The tied case is especially rigid because the required gaps live at different arithmetic scales but share one threshold-capacity parameter `a|I_C|`. A first-layer/higher-layer tie gives one anchored gap near the physical scale `Y` and another at `Y^{1/j}`; a higher/higher tie gives two smaller power-related scales. This synchronization is absent from bounded physical-mass moments and therefore survives exactly in the kind of singular channel left open by `RE-085`.

## 4. Relation to the previous gap-capacity laws

Equation (7) does not improve the best known exponent if one immediately discards the anchoring. For example, if one inserts a generic pointwise gap bound

\[
\mathcal G_C(p,j)\ll p^\theta,
\]

then

\[
|I_C|
\ll_{J,j}
\frac{p^{\theta-1+jb_1}}{\log p}
\asymp
\frac{Y^{b_1-(1-\theta)/j}}{\log Y},
\tag{19}
\]

which is the fixed-layer exponent already identified in `RE-054`. In particular, the first layer remains strongest for the coarse fan-complexity splice of `RE-051`.

The new information is **conditional location**, not a better generic gap exponent. `RE-052` says every cell consumes same-scale prime-free capacity; `RE-054` pulls the same cell back to a prime-free interval in every fixed layer. `RE-086` adds the selection-sensitive fact that when a higher-layer event is actually used as a support boundary, the pulled-back interval must terminate at the event's own generating prime. The singular event is therefore coupled to the exact neighboring gap of its base prime rather than merely to the existence of some gap near the inverse scale.

This distinction is precisely what the post-`RE-085` frontier needs. Ambient higher-layer density, total higher-layer mass, and arbitrary fixed-order event statistics have already been shown too weak. A theorem excluding the remaining boundary channel must now rule out, or sufficiently limit, these **anchored gap/event coincidences** on the rightmost-maximizer fan.

## 5. Stress tests and exact boundary of the claim

This is not a proof that exceptional support boundaries are rare enough to contradict false RH. Ordinary prime gaps can be large, and the selected fan could in principle concentrate on the base primes whose neighboring gaps satisfy (5). `RE-004`'s zero ambient density of higher-layer events cannot be converted into a selected-density statement without an additional argument.

The asymptotic normalization (4)--(9) is stated for fixed layer depth. If `j=j(Y)` diverges, the exact anchored prime-free containment (3) still holds, but the fixed-`j` event-map expansion used to cancel the layer constants is not uniform in arbitrary growing depth. Deep-layer escape therefore remains separate and must not be folded into (5) without a uniform inverse-event theorem.

The result also applies only when the higher-layer event is an **actual adjacent support boundary** of the selected state. A higher-layer event crossed inside a skipped physical span, or one whose presence changes a nonlocal rightmost-maximizer comparison without becoming `\xi_-` or `\xi_+`, is not covered. Those are distinct singular channels and remain open.

Finally, no probabilistic independence between gaps at the scales in (8) is assumed. Equation (9) is a deterministic necessary condition. Treating simultaneous large gaps as statistically independent would add an unsupported hypothesis and is explicitly outside the claim.
