# VIS-170 — growing-support collision bulk has a universal first-order Gaussian fluctuation

## Claim

Keep the anchored held-out-prime Haar control and notation of `VIS-169`. Let

`U_j = sin^2(pi X_j)`,

`A_d = d^(-1) sum_(j=1)^d U_j`,

`N = |sin(pi Y)|`,

and

`C_d = N / sqrt(d A_d)`.

Thus `VIS-169` writes the bulk-normalized collision score as

`Z_d = sqrt(d) C_d = N / sqrt(A_d)`

and proves `Z_d -> sqrt(2) N` almost surely.

The first fluctuation around that random arcsine bulk limit is also universal. Since

`E[U_j]=1/2`, `Var(U_j)=1/8`,

the central limit theorem and delta method give

`sqrt(d) (A_d^(-1/2) - sqrt(2)) => Normal(0,1/4)`.

Because `N` is independent of the retained coordinates for every `d`, jointly

`sqrt(d) (Z_d - sqrt(2) N) => N G`,

where `G ~ Normal(0,1/4)` is independent of `N`. Equivalently, conditional on `N=n`, the limiting fluctuation is Gaussian with variance `n^2/4`.

The unconditional limit is a centered Gaussian scale mixture with characteristic function

`phi(t) = exp(-t^2/16) I_0(t^2/16)`,

where `I_0` is the modified Bessel function of the first kind.

There is an even simpler relative coordinate. Away from the Haar-null set `N=0`, define

`T_d = sqrt(d) ( Z_d/(sqrt(2) N) - 1 )`

`    = sqrt(d) ( 1/sqrt(2 A_d) - 1 )`.

Then

`T_d => Normal(0,1/8)`.

Thus after the `sqrt(d)` bulk normalization from `VIS-169`, the next ordinary support effect is an `O(d^(-1/2))` universal Gaussian denominator fluctuation. A visual or numerical separation that only sees this first-order width is still reproduced by the matched held-out-prime Haar null.

**Evidence/status:** `CLASSICAL-CLT+DELTA-METHOD SPECIALIZATION + HIGH-DIMENSIONAL-MATCHED-NULL + NEGATIVE CONTROL + NO-NOVELTY-CLAIM`.

This is a Haar-population asymptotic. It is not a growing-dimensional deterministic prime-log equidistribution theorem, a Berry--Esseen bound, an extreme-value result, a zeta-facing separation, or an RH consequence.

## 1. Mean and variance of one retained coordinate

For Haar-uniform `X_j` on `T`,

`U_j = sin^2(pi X_j)`

has

`E[U_j] = int_0^1 sin^2(pi x) dx = 1/2`

and

`E[U_j^2] = int_0^1 sin^4(pi x) dx = 3/8`.

Therefore

`Var(U_j)=3/8-1/4=1/8`.

The variables are independent and bounded, so the ordinary i.i.d. central limit theorem yields

`sqrt(d)(A_d-1/2) => H`,

with `H ~ Normal(0,1/8)`.

## 2. Delta method for the bulk collision denominator

Let

`g(a)=a^(-1/2)`.

At `a=1/2`,

`g(1/2)=sqrt(2)`,

`g'(1/2)=-sqrt(2)`.

The delta method therefore gives

`sqrt(d)(g(A_d)-sqrt(2)) => -sqrt(2) H`.

Since `Var(H)=1/8`, the limiting variance is

`2 * (1/8) = 1/4`.

Hence

`sqrt(d)(A_d^(-1/2)-sqrt(2)) => G`,

where `G ~ Normal(0,1/4)`.

This fluctuation is entirely generated by the retained Haar coordinates. No arithmetic property of the held-out frequency enters it.

## 3. Multiplication by the independent numerator gives a Gaussian scale mixture

For every `d`, the held-out numerator

`N=|sin(pi Y)|`

is independent of `A_d`. Therefore the pair

`(N, sqrt(d)(A_d^(-1/2)-sqrt(2)))`

converges jointly to `(N,G)` with independent components. Multiplying the second coordinate by the first gives

`sqrt(d)(Z_d-sqrt(2)N)`
` = N sqrt(d)(A_d^(-1/2)-sqrt(2))`
` => N G`.

Conditionally on `N=n`, this is `Normal(0,n^2/4)`. Unconditionally it is not Gaussian because the scale remains random.

Its characteristic function is explicit. Conditional Gaussianity gives

`E[exp(i t N G) | N] = exp(-t^2 N^2/8)`.

Since `N^2=sin^2(pi Y)`, putting `a=t^2/8` gives

`phi(t)=int_0^1 exp(-a sin^2(pi y)) dy`.

Using `sin^2(theta)=(1-cos(2 theta))/2` and the standard integral definition of `I_0`,

`phi(t)=exp(-a/2) I_0(a/2)`
`      =exp(-t^2/16) I_0(t^2/16)`.

This gives a closed matched-null law for the first vertical thickness of the support-normalized collision cloud around the random limit curve `sqrt(2)N`.

## 4. Relative normalization removes the random numerator scale

The absolute fluctuation inherits the random factor `N`. If the numerator coordinate is available in the matched control, divide it out before comparing widths.

Define

`h(a)=1/sqrt(2a)`.

Then `h(1/2)=1` and `h'(1/2)=-1`. A second delta-method application gives

`sqrt(d)(h(A_d)-1) => Normal(0,1/8)`.

But, whenever `N>0`,

`h(A_d)=Z_d/(sqrt(2)N)`.

Thus

`T_d=sqrt(d)(Z_d/(sqrt(2)N)-1) => Normal(0,1/8)`.

The exceptional set `N=0` has Haar measure zero and may be assigned any value. The relative fluctuation coordinate is therefore a pure retained-support null: it removes both the deterministic `sqrt(d)` contraction and the random arcsine numerator scale.

## 5. Consequence for support-varying visual tests

`VIS-169` shows that raw bulk collision scores shrink like `d^(-1/2)` and that `sqrt(d) C_d` converges to the arcsine-derived law `sqrt(2)N`. The present result adds the first finite-support width around that limit.

A support-varying plot can therefore display three nested generic effects without containing source information:

- raw contraction of `C_d` at scale `d^(-1/2)`;
- a non-Gaussian arcsine bulk profile after multiplying by `sqrt(d)`;
- an additional `d^(-1/2)` Gaussian denominator fluctuation around that profile.

For matched held-out-prime controls, a first-order bulk residual should therefore be expressed in the relative coordinate `T_d`, or compared against the equivalent Gaussian scale-mixture law for the absolute residual, before interpreting a changing width as arithmetic structure.

A genuine source-sensitive signal may still live in higher-order corrections, non-Gaussian deterministic discrepancy, tail geometry, or a zeta-facing observable not reducible to this held-out-prime quotient. Those are separate questions. The present theorem only removes the ordinary first-order support fluctuation as a positive discriminator.

## 6. Prior art and novelty boundary

The probabilistic ingredients are classical. The i.i.d. central limit theorem applies directly to the bounded variables `U_j`, and the delta method transfers that Gaussian fluctuation through the smooth maps `a -> a^(-1/2)` and `a -> (2a)^(-1/2)` near `a=1/2`.

A standard reference for the delta method and its relation to asymptotic normality is A. W. van der Vaart, **Asymptotic Statistics**, Cambridge University Press, 1998, Chapter 3, DOI `10.1017/CBO9780511802256`.

The Bessel characteristic-function identity above is an elementary rewriting of the defining angular integral for `I_0`. No new central limit theorem, delta-method theorem, or special-function identity is claimed.

The Mathia-specific content is the specialization to the collision geometry already isolated in `VIS-164`--`VIS-169`, which supplies an explicit first-order finite-support null for future visual comparisons.

## 7. Boundaries and falsification

The result assumes independent Haar retained coordinates and an independent held-out numerator coordinate. It does not justify replacing those variables by a deterministic prime-log orbit when the support dimension grows with the sample window. That remains a changing-dimensional discrepancy problem.

The theorem concerns ordinary `sqrt(d)` fluctuations of the bulk. It does not control large deviations of `A_d`, the rare near-zero denominator region, high collision moments, maxima over deterministic samples, or the small-ball regime of `VIS-168`.

It also gives only weak convergence. A finite-`d` testing rule that needs explicit approximation error requires a Berry--Esseen or other quantitative delta-method bound and must account for the singular map away from the high-probability neighborhood of `A_d=1/2`.

Falsify the result by showing that `E[U_j]`, `Var(U_j)`, the stated independence, or either delta-method derivative is wrong. Any such failure would break the displayed limit law directly.
