# VIS-029 — the unit-fraction fan is only the first fixed-`nx` Farey endpoint layer

## Claim

Let

`0=x_0<x_1<...<x_N=1`

be the Farey sequence of order `n`, with `N=sum_(q<=n) phi(q)` gaps, and for fixed `y>=1` let

`R_n(y) = #{x_k : 0 < x_k <= y/n}`.

For every fixed `Y>1`, uniformly for `1<=y<=Y`,

`R_n(y)/n -> K(y)`

where

`K(y) = sum_(a>=1) [phi(a)/a] (1-a/y)_+`
`     = sum_(a<=y) phi(a) (1/a-1/y)`.

Consequently the endpoint-scaled local discrepancy

`H_n(y) = y - n R_n(y)/N`

converges uniformly on `1<=y<=Y` to

`H(y) = y - (pi^2/3) K(y)`,

because `N/n^2 -> 3/pi^2`. At an actual Farey point `x_k=y/n`, this is exactly

`H_n(y)=n(x_k-k/N)=nD_k`.

On each interval `m<y<m+1`, with

`A_m=sum_(a<=m) phi(a)/a`,
`B_m=sum_(a<=m) phi(a)`,

the limit is the explicit smooth arc

`H(y)=y-(pi^2/3)(A_m-B_m/y)`.

The arcs join continuously at integers but their derivatives change there. The endpoint geometry is therefore a deterministic layered totient profile: the unit-fraction fan isolated in `VIS-028` is exactly the first layer `1<=y<=2`, while numerators `2,3,...` add further layers at every fixed `nx` scale.

For a fixed reflected endpoint window `x<=Y/n` and `x>=1-Y/n`, let `E_(n,Y)` be the contribution of those ranks to `sum_k D_k^2`. Then

`n E_(n,Y) -> C(Y) := 2 integral_(1)^Y H(y)^2 dK(y)`.

Equivalently, on each `m<y<m+1`, `dK(y)=B_m y^-2 dy`, so `C(Y)` is an explicit finite sum of elementary integrals. At `Y=2` this reduces exactly to the endpoint-fan constant from `VIS-028`,

`C(2)=0.3602210103...`.

For larger fixed windows the deterministic endpoint energy is strictly larger; for example

`C(3)=0.3997755699...`,
`C(4)=0.4182530470...`,
`C(6)=0.4355970378...`,
`C(10)=0.4484270716...`.

The same geometry also preserves the `r=Theta(n)` Dirichlet spectral scale. If `h(u)=H(K^{-1}(u))` for `0<=u<=K(Y)` and `r=floor(xn)`, then the reflected even Dirichlet coefficient satisfies, for fixed `x>0`,

`n d_(2r)^(Y) -> 2 sqrt(2/c) integral_0^(K(Y)) h(u) sin(2 pi x u/c) du`,

with `c=3/pi^2`. Thus subtracting only the `Y=2` unit-fraction fan cannot remove the deterministic endpoint mechanism that creates an `r/n` modal scale: the remaining fixed-`nx` layers produce the same scale.

**Evidence/status:** `CLASSICAL FAREY RANK STRUCTURE + EXACT-DERIVED ASYMPTOTIC CONTROL + FINITE NUMERICAL VALIDATION + NEGATIVE CONTROL`.

No new Farey rank theorem, strengthened Franel–Landau criterion, or RH implication is claimed.

## Fixed-`nx` rank asymptotic

A reduced fraction `a/q` lies in `(0,y/n]` exactly when

`a n <= y q`, `q<=n`, `(a,q)=1`.

For fixed `Y` and `y<=Y`, this forces `a<=Y`, so only finitely many numerators occur. For a fixed numerator `a`,

`a/q <= y/n`

is equivalent to

`an/y <= q <= n`.

The number of integers `q` in this interval coprime to `a` is

`n (phi(a)/a) (1-a/y)_+ + O_Y(1)`,

uniformly for `1<=y<=Y`; this is the elementary fixed-modulus coprime-counting estimate obtained by splitting integers into residue classes modulo `a`.

Summing over the finitely many possible numerators gives

`R_n(y)=n K(y)+O_Y(1)`.

The formula makes the layer structure explicit. For `1<y<2`, only `a=1` contributes and

`K(y)=1-1/y`.

For `2<y<3`, the numerator-two family joins; for `3<y<4`, numerator three joins; and so on. The breakpoint at each integer is not a rendering choice but the exact moment at which another fixed numerator becomes admissible in the shrinking endpoint window.

Since

`N=(3/pi^2)n^2+O(n log n)`,

we have uniformly on bounded `y`

`n R_n(y)/N = (pi^2/3) K(y) + o(1)`,

which proves the stated limit for `H_n`.

## The unit-fraction fan is the `1<=y<=2` restriction

On the first layer,

`K(y)=1-1/y`

and therefore

`H(y)=y-(pi^2/3)(1-1/y)`.

Put

`y=1/(1-u)`, `0<=u<=1/2`.

Then

`H(y)=1/(1-u)-(pi^2/3)u`,

which is exactly the continuum profile `f(u)` in `VIS-028`. The earlier deterministic fan is therefore not an isolated endpoint phenomenon. It is the first chart of a longer fixed-`nx` profile generated by bounded numerators.

This matters for interpretation. Removing only the fractions

`1/n,1/(n-1),...,1/ceil(n/2)`

removes the `a=1` chart but leaves the numerator-two chart beginning immediately beyond `2/n`, then the numerator-three chart beyond `3/n`, and so forth. Every fixed finite collection of these layers occupies `Theta(n)` Farey ranks because `R_n(Y)~nK(Y)`.

## Endpoint energy asymptotic

For the left endpoint, parameterize Farey ranks in `x<=Y/n` by `y=nx`. From

`R_n(y)/n -> K(y)`

the scaled empirical rank measure converges to the Stieltjes measure `dK(y)`. At those points

`D_k=H_n(y)/n=H(y)/n+o(1/n)`

uniformly on fixed `Y`. Therefore

`n sum_(0<x_k<=Y/n) D_k^2 -> integral_1^Y H(y)^2 dK(y)`.

Farey reflection contributes the identical right-endpoint term, giving the factor two in `C(Y)`.

On `m<y<m+1`,

`K(y)=A_m-B_m/y`

and hence

`dK(y)=B_m y^-2 dy`.

The integral is therefore elementary interval by interval. It is monotone in `Y` because it is the energy of an expanding deterministic endpoint region, and it is already larger than the `VIS-028` fan constant as soon as additional numerator layers are included.

Finite direct evaluation gives:

- `nE_(n,2) = 0.351819, 0.354443, 0.357804, 0.358688` at `n=200,400,800,1600`, approaching `C(2)=0.360221...`;
- `nE_(n,3) = 0.390209, 0.392074, 0.396782, 0.397681`, approaching `C(3)=0.399776...`;
- `nE_(n,4) = 0.407039, 0.408656, 0.414555, 0.415593`, approaching `C(4)=0.418253...`;
- `nE_(n,6) = 0.424836, 0.424123, 0.431423, 0.432297`, approaching `C(6)=0.435597...`;
- `nE_(n,10) = 0.439635, 0.436156, 0.443907, 0.444425`, approaching `C(10)=0.448427...`.

These are validation diagnostics, not fitted asymptotics.

## The `r=Theta(n)` scale survives every fixed endpoint window

The left endpoint window contains `R_n(Y)=Theta(n)` ranks inside a Farey sequence with `N=Theta(n^2)` gaps. Its discrepancy amplitude is `Theta(1/n)`. For the reflected antisymmetric endpoint profile, odd Dirichlet modes vanish as in `VIS-027`, while for `m=2r`

`d_(2r)^(Y)`
` = 2 sqrt(2/N) sum_(x_k<=Y/n) D_k sin(2 pi r k/N)`.

Set `r=floor(xn)` and `u=k/n`. The rank asymptotic gives `u->K(y)`, while the discrepancy limit gives `nD_k->H(y)`. The sum is then a Riemann–Stieltjes sum and yields

`n d_(2r)^(Y)`
` -> 2 sqrt(2/c) integral_1^Y H(y) sin(2 pi x K(y)/c) dK(y)`,

equivalent to the `h(u)` form in the claim.

Therefore the spectral scaling mechanism in `VIS-028` is not special to the unit-fraction layer. Any fixed `nx` endpoint window has spatial rank width `Theta(n)` and hence contributes on the same `r=Theta(n)` scale. A residual `r/n` collapse after subtracting only `Y=2` is still compatible with completely deterministic endpoint rank geometry.

## Finite validation and robustness

Direct finite evaluation of the exact Farey ranks over `1<=y<=10` agrees with the analytic profile. The maximum absolute error in `nD-H(y)` decreases from about `0.110` at `n=100` to `0.00697` at `n=1600`; the corresponding RMS error falls from about `0.0270` to `0.00171`. The integer breakpoints and continuation beyond `y=2` are therefore predicted analytically and converge under substantial changes of `n`, rather than being selected from a rendering.

The fixed-window energy values above likewise approach the exact interval integrals for several pre-fixed `Y`. No fitted exponent, embedding, dimensional reduction, or subjective pattern judgment enters the claim.

## Prior art and novelty assessment

The underlying Farey endpoint and rank mathematics is classical territory. Dress's 1999 discrepancy analysis identifies the endpoint scale and the exact absolute discrepancy `1/n`. Tomás's work on partial Franel sums studies endpoint neighborhoods, and García's 2024 paper on equal numerators and ranks of unit fractions provides direct prior-art context for decomposing a small Farey interval by bounded numerator.

No novelty is claimed for counting fixed-numerator fractions or for the resulting rank asymptotic as a standalone theorem. The durable Mathia contribution is the **control boundary** exposed by combining that classical structure with the current spectral experiment: the exact `Y=2` fan of `VIS-028` is not a sufficient endpoint null. A whole deterministic fixed-`nx` hierarchy survives outside it and generates the same modal scale that the visual branch was trying to interpret.

## Boundary conditions and falsification

The result is for every **fixed** endpoint scale `Y` while `n->infinity`. It does not describe windows `Y=Y(n)` growing with `n`, and it does not determine how far into the Farey bulk endpoint structure remains the dominant contribution. No limit of `C(Y)` as `Y->infinity` is asserted.

The fixed-`Y` profile does not determine the complete Farey discrepancy or its spectral measure. Interior and endpoint contributions can interfere coefficient by coefficient. The result only says that removing one endpoint layer cannot certify that a surviving `r/n` signal is an interior arithmetic invariant.

A falsification would require an error in the bounded-numerator counting, the summatory-totient normalization, the Stieltjes/Riemann passage on fixed `Y`, or the Dirichlet-mode scaling derivation. Finite tests over several `n` and several endpoint windows agree with those analytic predictions.
