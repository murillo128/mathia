# VIS-236 — ordered prime-coordinate cells make the exact first-order type degenerate

## Claim

Keep the critical coherence-cell representation inherited from `VIS-225` and `VIS-227`. Partition the prime-coordinate interval `(y/2,y]` into ordered disjoint cells

`I_1 < I_2 < ... < I_J`

of the prescribed common width (with any fixed allowed cell-origin shift), list the primes in increasing order

`p_1 < p_2 < ... < p_m`,

and let `x_t=j` when `p_t in I_j`.

Then the actual cell-label sequence is nondecreasing:

`x_1 <= x_2 <= ... <= x_m`.

If `N_j=#{t:x_t=j}` are its occupancies and `j_1<...<j_k` are the occupied cells, the sequence is therefore exactly

`j_1^(N_(j_1)) j_2^(N_(j_2)) ... j_k^(N_(j_k))`,

where the exponent denotes repetition. Consequently:

1. the lag-two return statistic of `VIS-233`,

   `T_2=sum_(t=1)^(m-2) 1_(x_t=x_(t+2))`,

   is already an occupancy functional,

   `T_2 = sum_j (N_j-2)_+`;

2. the endpoint-matched first-order transition table has

   `C_(jj)=(N_j-1)_+`

   and, between successive occupied cells only,

   `C_(j_r,j_(r+1))=1`,

   with every other off-diagonal entry zero;

3. that transition table and its endpoints admit exactly **one** compatible state sequence. In the notation of `VIS-234` and `VIS-235`,

   `W(C;x_1,x_m)=1`

   and

   `Z_(C;x_1,x_m)(q)=q^(T_2)`.

Thus the exact first-order Markov-type route proposed after `VIS-233`--`VIS-235` is conditionally degenerate for every actual prime-coordinate coherence-cell instance, at every finite `y`, every critical `lambda`, and every allowed fixed cell-origin shift. No numerical instantiation of the actual transition table is needed to discover this: the degeneracy is forced by the ordered interval representation itself.

**Evidence/status:** `EXACT-DERIVED + REPRESENTATION-SUPPORT OBSTRUCTION + CONDITIONAL-NULL DEGENERACY + NO-NOVELTY-CLAIM`.

This does not invalidate `VIS-233`--`VIS-235` as general finite-sequence/Markov-type statements. It shows that their nondegenerate conditional sample space is too broad for the specific ordered prime-coordinate cells that motivated the critical branch.

## 1. Prime-coordinate cell labels are monotone

The cells are intervals in the same real coordinate in which the primes are ordered. If `p_a<p_b`, the cell containing `p_a` cannot lie strictly to the right of the cell containing `p_b`. Hence

`a<b  =>  x_a<=x_b`.

Every occupied cell therefore appears in one contiguous block and can never be revisited after the sequence moves to a larger cell. Empty cells simply produce jumps from one occupied index to the next and do not change this conclusion.

This remains true after any fixed translation of the cell grid allowed by the representation. The shift changes the occupancies but not the monotone order of cell labels.

## 2. The lag-two statistic collapses to occupancies

For a nondecreasing sequence, if

`x_t=x_(t+2)`,

then necessarily

`x_t <= x_(t+1) <= x_(t+2)=x_t`,

so all three labels are equal. Therefore a block of `N_j` copies of cell `j` contributes exactly

`max(N_j-2,0)`

lag-two returns, and different occupied cells contribute independently. Summing the block contributions gives

`T_2=sum_j (N_j-2)_+`.

So the candidate that escaped a **generic** endpoint-matched first-order type in `VIS-233` does not escape the sigma-field generated by the occupancies of the actual ordered cell representation. In particular, any control that fixes the prime-coordinate cell occupancies has already fixed `T_2`.

## 3. The actual first-order type is a singleton

Let `j_1<...<j_k` be the occupied cells. Inside the block for `j_r`, there are exactly `N_(j_r)-1` self transitions. Leaving that block contributes one transition

`j_r -> j_(r+1)`

when `r<k`. No other transition occurs. This proves the displayed form of `C`.

Now consider any endpoint-matched realization of this same transition multiset. At state `j_r`, all nonloop outgoing transitions except the single edge to `j_(r+1)` are absent, and no later state has an edge returning to `j_r`. Hence every self-loop at `j_r` must be consumed before taking the unique forward edge: after that edge is used, the path can never return to consume a leftover loop. Induction over `r=1,...,k` forces the unique state sequence

`j_1^(N_(j_1)) ... j_k^(N_(j_k))`.

Therefore the uniform endpoint-matched type class used by `VIS-234` has cardinality one. Its PGF is a monomial, its conditional variance is zero, and the `VIS-235` deletion mean equals the observed `T_2` trivially.

This is stronger than merely finding one degenerate numerical transition table: **every table generated by this representation is degenerate for the same structural reason**.

## 4. The control must randomize geometry that can actually vary

The critical branch introduced stochastic categorical and Markov controls to avoid mistaking forced occupancy effects for arithmetic structure. Those controls remain mathematically valid abstract null models, but the ordered cell labels expose a representation mismatch if they are interpreted as preserving the actual local support of the prime-coordinate construction.

A stationary categorical Markov chain can revisit smaller or previously visited cells. The prime-coordinate label sequence cannot: it is the quantization of an increasing point process. Likewise, an unrestricted Euler-trail randomization inside a generic fixed transition type may rearrange local order in ways unavailable to the actual cell geometry; for the actual transition tables there is no such freedom anyway.

A representation-matched dependent control should therefore randomize an object that genuinely varies while preserving monotonicity, for example the cell occupancy/count process, normalized prime gaps, within-cell point locations, or another increasing-point-process description. An order-sensitive statistic can still be useful, but it must depend on information not already determined by the monotone run lengths. Merely moving from occupancy collisions to higher lag equality of the same interval labels does not create a new information channel.

## Prior art and novelty boundary

No new theorem about Markov types or ordered point processes is claimed. The monotonicity and run decomposition are elementary consequences of quantizing an increasing sequence by ordered intervals. `VIS-232`--`VIS-235` already source-audit Whittle-type conditional transition-count enumeration and conditional pattern frequencies; those general results remain correct but apply to a larger combinatorial sample space than the present geometric representation permits.

The Mathia-specific delta is the compatibility check between that general conditional null and the actual coherence cells inherited from `VIS-225`: once the representation support is imposed, the proposed `T_2` escape collapses before any prime-specific inference is attempted. No new external source is needed for this elementary representation obstruction.

## Boundaries and falsification

The finding applies to the **prime-coordinate interval cells** of the current critical coherence representation, with primes indexed in increasing prime order. It does not say that every possible phase representation has monotone labels. A genuinely periodic phase partition, a reordered prime sequence, a graph traversal, or another representation could produce revisits and a nondegenerate Markov type; such a representation would need its own scientific justification and matched controls rather than inheriting this conclusion automatically.

The result also does not show that the scalar collision statistic `S`, a gap statistic, or an occupancy-process statistic is prime-specific. It removes only the exact first-order-type / lag-two-label route in the current representation.

Falsify the claim by producing, under the `VIS-225`/`VIS-227` ordered interval construction and increasing prime order, either a decreasing cell-label step, two distinct endpoint-matched state sequences with the same resulting transition table, or a value of `T_2` different from `sum_j (N_j-2)_+`.

## Research consequence

The accepted `CLUE-prime-phase-critical-logarithmic-occupancy` should no longer spend effort instantiating the `VIS-234` conditional PGF on the actual prime-coordinate transition table: it is always a monomial. The concrete gate requested after `VIS-235` is resolved negatively without computation.

The live critical question should instead calibrate dependence on the monotone geometric object itself. The scalar collision route can remain alive under an independently specified occupancy/gap model that leaves confirmation occupancies random. A more representation-faithful successor may use the ordered occupancy process, normalized gaps, within-cell locations, or another statistic whose value is not fixed by the cell run lengths, and only then ask whether a frozen residual connects back to the signed prime-phase kernel.
