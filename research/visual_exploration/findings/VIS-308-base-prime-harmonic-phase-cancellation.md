# VIS-308 — base-prime harmonic phases still cancel at the Wang log-log boundary

## Claim

Keep Wang's exact prime-power coefficients

`a_q = (Lambda(q)/sqrt(q)) min(q/x,x/q)`

from `VIS-302`--`VIS-307`. Let `(epsilon_p)` be independent Steinhaus variables, one for each prime, and extend them completely multiplicatively on prime powers by

`f(p^k)=epsilon_p^k`.

Define

`D_x^f(t)=sum_(q=p^k) f(q) a_q q^(-it)`

and, for `I=(T,T+H]`,

`R_I^f = integral_I |D_x^f(t)|^2 dt - H sum_q a_q^2`.

Then uniformly in real `T` and `H>0`,

`E R_I^f = 0`

and

`E |R_I^f|^2 << x log^3(3x)`.

Consequently

`R_I^f = O_p(sqrt(x) log^(3/2)(3x))`,

and at the active boundary

`H asymp x log log(3x)`

one has

`R_I^f/H -> 0`

in probability.

Unlike the independent-support phase control of `VIS-307`, this ensemble preserves the exact harmonic relation among all powers of the same base prime: `f(p^k)=f(p)^k`. The additional same-prime character collisions contribute only

`O(log^4(3x)/x)`

to the second moment. Thus **base-prime multiplicative phase coherence by itself still does not sustain an `H`-scale signed remainder** at `H asymp x log log x`.

**Evidence/status:** `EXACT-DERIVED + COMPLETELY-MULTIPLICATIVE STEINHAUS CONTROL + EXACT-SUPPORT SIGNED-CANCELLATION NEGATIVE CONTROL + NO-NOVELTY-CLAIM`.

## 1. The control preserves one phase per base prime

Write a prime-power support point as `q=p^k`. The artificial phase is now

`f(q)=epsilon_p^k`,

not an independent variable for each `q`. Hence every relation among `p,p^2,p^3,...` generated by complete multiplicativity is preserved exactly.

For distinct support points `q=p^k` and `r=s^l`, put

`K_I(q,r)=integral_T^(T+H) exp(-it log(q/r)) dt`.

Then

`R_I^f`
` = sum_(q!=r) f(q) conjugate(f(r)) a_q a_r K_I(q,r)`.

If `p!=s`, independence gives zero expectation. If `p=s` but `k!=l`, then

`E epsilon_p^(k-l)=0`.

Therefore every off-diagonal term still has zero expectation and

`E R_I^f=0`.

## 2. Torus orthogonality leaves only same-base harmonic collisions

View `(epsilon_p)` as Haar coordinates on the prime torus. The character attached to an oriented pair `(p^k,s^l)` is

`epsilon_p^k conjugate(epsilon_s^l)`.

For `p!=s`, its exponent vector has two nonzero prime coordinates, `+k` at `p` and `-l` at `s`. That vector uniquely determines the oriented pair. Thus all cross-base contributions to `E|R_I^f|^2` remain diagonal exactly as in `VIS-307`.

The only new collisions occur when both support points are powers of the same prime. For `q=p^k`, `r=p^l`, the character is `epsilon_p^(k-l)`, so all pairs with the same exponent difference `d=k-l` share one character. Hence exact torus orthogonality gives

`E|R_I^f|^2`
` = S_cross + S_same`,

where

`S_cross = sum_(p!=s) sum_(k,l>=1) a_(p^k)^2 a_(s^l)^2 |K_I(p^k,s^l)|^2`

and

`S_same`
` = sum_p sum_(d!=0) | K_(p,d) sum_(l>=1; l+d>=1) a_(p^(l+d)) a_(p^l) |^2`,

with

`K_(p,d)=integral_T^(T+H) exp(-it d log p) dt`.

The cross-base term is a subset of the independent-phase second-moment energy already bounded in `VIS-307`, so

`S_cross << x log^3(3x)`.

It remains only to bound the harmonic collision term.

## 3. Same-base harmonic collisions are tiny

For every nonzero integer `d`,

`|K_(p,d)| <= 2/(|d| log p)`.

Put

`A_p = sum_(k>=1) a_(p^k)^2`.

By Cauchy--Schwarz,

`|sum_l a_(p^(l+d)) a_(p^l)| <= A_p`.

Therefore

`S_same`
` << sum_p [A_p^2/log^2 p] sum_(d!=0) 1/d^2`
` << sum_p A_p^2/log^2 p`.

Let `L=log(3x)`. For `p<=x`, split the powers at `m=floor(log x/log p)`. When `k<=m`,

`a_(p^k)^2 = (k log p)^2 p^k/x^2`,

and `k log p<=log x`, so the geometric sum gives

`sum_(k<=m) a_(p^k)^2 << L^2/x`.

For `k>=m+1`,

`a_(p^k)^2 = (k log p)^2 x^2/p^(3k)`.

The geometric tail is dominated by its first scale, and `(m+1)log p <= log x+log p <= 2 log x`; since `p^(m+1)>x`,

`sum_(k>=m+1) a_(p^k)^2 << L^2/x`.

Thus

`A_p << L^2/x` for `p<=x`.

For `p>x`, every power lies on the upper taper and

`A_p << x^2 log^2 p/p^3`.

Consequently, using only the trivial count of primes below `x` and comparison with an integer tail,

`sum_(p<=x) A_p^2/log^2 p << L^4/x`,

while

`sum_(p>x) A_p^2/log^2 p`
` << x^4 sum_(n>x) log^2 n/n^6`
` << L^2/x`.

Hence

`S_same << L^4/x`.

This is negligible compared with the cross-base bound, proving

`E|R_I^f|^2 << x L^3`.

Chebyshev then gives

`P(|R_I^f|>eta H) << x L^3/H^2`.

At `H asymp x log log(3x)`, the right side tends to zero.

## 4. What this control removes from the surviving hypothesis

`VIS-307` left open the possibility that the current boundary was carried by the harmonic phase relation among powers of one base prime. The present control preserves that relation exactly and still cancels at root-mean-square scale far below `H`.

The surviving distinction is therefore narrower. The true Wang polynomial corresponds to the highly aligned torus point in which all base-prime phases are fixed coherently rather than sampled independently. Any genuine `H`-scale obstruction must exploit **collective phase alignment across distinct base primes**, or another deterministic interaction not reproduced by a completely multiplicative Haar phase field.

This statement is weaker than a cancellation theorem for the true polynomial. Haar-typical completely multiplicative phases can have small quadratic remainder while a special deterministic torus point has a much larger value. The finding only removes same-base harmonic coherence as a sufficient explanation of the current `x log log x` boundary.

## 5. Prior art and novelty boundary

The phase model used here is the standard Steinhaus random multiplicative function: values at primes are independent uniform unit-circle variables and complete multiplicativity forces `f(p^k)=f(p)^k`. For example, K. Soundararajan and M. W. Xu, **Central limit theorems for random multiplicative functions**, *Journal d'Analyse Mathematique* 151 (2023), 343--374, DOI `10.1007/s11854-023-0331-y`, uses exactly this standard model. Weighted Steinhaus sums are also a well-developed random-multiplicative-function setting.

No general probabilistic theorem is claimed here. The durable content is the elementary torus-character calculation specialized to Wang's exact prime-power support: the only extra second-moment collisions created by complete multiplicativity are same-prime equal-difference fibers, and Wang's taper makes their total contribution negligible.

## Boundaries and falsification

The ensemble preserves exact prime-power support, exact Wang coefficient magnitudes, all support spacings, and the complete multiplicative phase relation within each base prime. It does **not** preserve deterministic phase alignment between different base primes.

The estimate is probabilistic over the artificial phase ensemble and is not uniform over all phase assignments. It therefore does not contradict the possibility that the true all-aligned coefficient phase is exceptional.

Falsify the result by exhibiting an additional torus-character collision beyond the same-base equal-difference fibers, an error in the bound for `A_p`, a same-base contribution larger than `O(log^4(3x)/x)`, or a failure of the inherited `VIS-307` cross-base energy bound.
