VIS-097 shows that this boundary is sharp in dimension three. Two three-delay paths can have identical endpoint windows and identical unordered length-four-block inventories yet differ at signature level four, because the order of two closed cycles appears through an area-area commutator. VIS-098 then supplies the critical admission gate: with pairwise distinct exact delay states, the local transition graph is a directed simple path and the exact block-preserving reassembly class is generically a singleton.

VIS-099 gives a precise replacement rather than an ad hoc approximate shuffle. After a **fixed finite quantization**, preserving the initial `m`-context and the complete transition-count table gives exactly the order-`m` Markov type class, equivalently the compatible Eulerian reassemblies of the finite context multigraph. Conditional on those counts, every homogeneous order-`m` Markov chain is uniform on that type class. For the active three-delay branch, quantized length-four counts therefore define an exact parameter-free conditional null for any statistic computed on the quantized representation.

The live source-specificity test is now concrete: pre-register the quantizer, symbol embedding, observation window, and one direction-sensitive level-four statistic; verify that the resulting third-order type class is genuinely non-singleton; then compare the source with the exact conditional-uniform type null. A separation establishes chronology beyond the admitted **quantized** four-block table, not arithmetic specificity. Returning to the original real-valued path requires a separate dequantization theorem or control, because the exact conditional guarantee stops at the quotient.
