# Weil-positivity research lines

This file holds the current mathematical lines of investigation suggested by the durable Weil-positivity intuitions. It is not a roadmap, task queue, status page, or history.

## Derive a source-native completion whose zero suppression is a consequence

**Linked intuitions:** `MI-001-positivity-needs-a-sign-producing-global-operation`, `MI-010-source-forced-critical-gram-can-have-the-wrong-weil-orientation`, `MI-011-prime-ray-marginals-do-not-determine-mixed-prime-coupling`, `MI-012-automorphic-multiplicity-does-not-prevent-global-scalarization`, `MI-013-critical-sector-transport-needs-new-global-arithmetic-structure`, `MI-014-nontrivial-zero-modes-screen-the-gamma-tangent-layer`.

WP-267--WP-280 leave a source-native pole continuum but no independent Gamma completion. WP-281--WP-283 close fixed finite-state, positive Stieltjes and fixed compact-memory linear responses. WP-284 then shows that positive growing memory can erase the favorable-RH zero screen if it is programmed from the target ordinates.

WP-285 removes even that target-programming requirement. Under the same favorable-RH control, an ordinary trailing Cesàro average suppresses the complete regularized zero field uniformly by `O(1/L)` and recovers the Gamma-center scalar for **any** deterministic zero-independent memory law `L(E)->infinity` with `E-L(E)->infinity`. The memory may grow arbitrarily slowly.

Therefore the live completion problem is no longer “find a positive, zero-independent growing-memory filter.” Those properties are still generic matched controls. Derive the operation itself from the prime/archimedean source geometry, before using the zero decomposition, and then prove that the same operation has the required sign/zero suppression/completion behavior. Other viable categories are source-forced oscillatory/noncompact responses, nonlinear mechanisms with a separate sign audit, or finite--archimedean coupling formed before scalarization.

## Treat canonical source provenance, not memory length, as the main missing theorem

WP-283's `Omega(log T)` lower bound concerns exact notch interpolation by fixed compact-memory transfers. WP-285 shows that asymptotic removal of the regularized favorable-RH zero field can be achieved with arbitrarily slowly diverging memory by a generic Bohr/Cesàro projection. Closing the `Omega(log T)` versus `O((log T)^2)` exact-notch gap is therefore no longer central to the completion question.

A future candidate must expose two logically separate theorems: first, why the zeta source selects its support/weights/evolution/coupling law; second, why zero suppression and the desired sign follow from that law. Target-independent post hoc averaging is not enough, because the same construction works for generic oscillatory spectra.
