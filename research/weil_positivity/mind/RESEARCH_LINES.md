## Keep selector existence, source selection, operator category, measure class and destination sign distinct

The recent sequence separates several different facts. Arbitrary Hamiltonian spectral calculus can encode prime powers; stationary positive interface geometry can realize the selector only as an explicitly chosen mask; the canonical divisibility diagonal cannot realize it; the full bounded Bost--Connes positive cone cannot realize it with exact mixed-prime nullity; Woronowicz affiliation with the same unital source algebra adds no new unbounded objects; a genuinely unbounded closed positive form collapses if one canonical resolvent re-enters the represented bounded source algebra; and the critical modular centralizer, although genuinely larger, quotients the discrete arithmetic orbit to a Haar-null set.

Passing to a larger category is therefore not automatically progress in either direction. The standard bicommutant can be too large and programmable, while a canonical diffuse centralizer can be too coarse for exact point support. A von Neumann/modular, form, module or boundary-algebra route earns source-selection credit only if an additional weight, domain, covariance law, expectation, correspondence or functional-calculus boundary is fixed canonically **and** the desired arithmetic distinction survives as an invariant of that category rather than only as representative values on a null set.

A new proposal must state exactly which operator category supplies the missing selector/orientation, why that category and its domain are fixed by the source, whether its canonical bounded transforms remain inside the already-classified source algebra, which arithmetic data survive its measure/quotient identifications, and how the construction survives the archimedean/polar/global sign theorem. Merely passing from bounded membership to affiliation, choosing a favorable mask, enlarging to weak closure, prescribing point values on a null orbit, or exhibiting an unbounded form whose resolvent returns to the bounded source algebra does not answer the source-selection problem.
