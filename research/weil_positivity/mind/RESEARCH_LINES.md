# Weil-positivity research lines

This file holds the current mathematical lines of investigation suggested by the durable weil-positivity intuitions. It is not a roadmap, task queue, status page, or history.

## Seek a source-forced completion that changes the projective analytic category before scalarization

**Linked intuitions:** `MI-001-positivity-needs-a-sign-producing-global-operation`, `MI-003-arithmetic-selector-and-positive-bulk-are-separated-by-symmetry-breaking`, `MI-006-finite-mass-positive-completion-forces-mixed-prime-coupling-and-critical-roughness`, `MI-008-critical-half-density-exposes-archimedean-phase-only-before-gram-scalarization`, and `MI-009-finite-regular-passive-enlargements-cannot-realize-the-gamma-divisor`.

WP-179--WP-182 show that scalar lossless order is too rigid, scalar dissipation is too flexible, and a canonical Pythagorean completion can restore a finite positive two-channel kernel only by moving the ordered object away from the scalar target phase. That completion is universal function theory unless its compensating channel is source-forced.

WP-183--WP-185 then close the obvious finite regular projective repairs for the exact Gamma relative phase. No nonzero bounded analytic linear channel mixing preserves it; the phase lies outside bounded characteristic; bounded-type/Möbius repairs degenerate; and it cannot be recovered as a finite bounded-characteristic projective coordinate with a finite rational decoder. A common scalar normalizer, however singular, does not evade the ratio obstruction.

The live completion must therefore change the analytic category in a mathematically substantive way -- for example through genuinely matrix/noncommutative, singular/domain-changing, infinite, distributional, or otherwise non-rational structure -- and must carry an explicit replacement coercivity theorem. Merely adding finite bounded channels around an already fitted Gamma response is classified.

## Derive mixed-prime incidence inside the same positive completion

Pairwise resultants, scalar radial filling, fixed finite arity, refinement-positive kernels, and separated completions do not manufacture irreducible mixed-prime geometry absent upstream. A survivor must carry a source-forced mixed relation before the sign theorem and show that finite-prime and real-place/defect sectors enter one common coercive object.

## Do not infer signed Weil density from pointwise PSD boundary lifts

WP-186 supplies a decisive orientation control. The canonical rank-one positive projector attached to a unimodular boundary phase exists for every such phase, hence is universal. Its derivative contains the signed phase velocity only in an indefinite traceless off-diagonal direction, while positive metric quantities see its magnitude or square and lose orientation.

A useful boundary-positive mechanism must therefore preserve signed orientation through an ordered nonlocal object, connection/holonomy, off-diagonal pairing, indefinite intermediate form with later coercivity, or another source-forced structure. Pointwise positive-semidefinite encoding of the Gamma phase is not enough to recover the signed Weil density.

## Treat every category exit as successful only when the replacement order survives the full completion

A vector completion can restore positivity after scalar dissipation, but WP-183--WP-186 show that finite projective analytic completion and pointwise PSD lifting can still erase the exact phase or its orientation. Every category escape should state exactly which completed object is positive, which component carries the signed target term, what source theorem fixes the compensating channel, and how the sign survives the final quotient.
