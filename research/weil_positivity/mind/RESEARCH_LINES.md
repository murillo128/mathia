# Weil-positivity research lines

This file holds the current mathematical lines of investigation suggested by the durable Weil-positivity intuitions. It is not a roadmap, task queue, status page, or history.

## Derive a source-native completion before scalar height-profile collapse

**Linked intuitions:** `MI-001-positivity-needs-a-sign-producing-global-operation`, `MI-010-source-forced-critical-gram-can-have-the-wrong-weil-orientation`, `MI-011-prime-ray-marginals-do-not-determine-mixed-prime-coupling`, `MI-012-automorphic-multiplicity-does-not-prevent-global-scalarization`, `MI-013-critical-sector-transport-needs-new-global-arithmetic-structure`, `MI-014-nontrivial-zero-modes-screen-the-gamma-tangent-layer`, `MI-015-nonlinear-postprocessing-after-scalarization-cannot-create-a-new-distribution`.

WP-267--WP-280 leave a source-native pole continuum but no independent Gamma completion. WP-281--WP-283 close fixed finite-state, positive Stieltjes and fixed compact-memory linear responses. WP-284--WP-286 show that growing positive memory, even when zero-independent and canonically chosen from Haar/Følner scale symmetry, can suppress the regularized oscillatory zero field for generic harmonic reasons rather than arithmetic ones.

WP-287 closes the apparent escape of applying arbitrary nonlinear post-processing to the positive Arthur/Maaß--Selberg scalar height profile while still claiming to recover a Weil-type distribution. The profile map `g -> (T -> Q_T(g))` is linear. If an arbitrary rule `Phi` of that profile produces a linear distribution `R(g)`, then `Phi` is automatically linear on the attainable profile space. For finitely many heights, the output is exactly a linear combination of the sampled `Q_T` values. The construction therefore falls back into the linear-height category already blocked by WP-237.

The live completion problem must introduce new structure **before or beyond scalar profile post-processing**. Candidate categories include operator-level nonlinear constructions before taking scalar traces, finite--archimedean coupling formed before scalarization, non-spherical/irreducibly coupled automorphic data, cohomological/intersection pairings, or a cone-only positive functional accompanied by an independent theorem that polarizes or identifies it with the canonical Weil form.

## Treat arithmetic provenance and target linearity as separate hard gates

Ambient scale symmetry, long memory and positivity do not establish arithmetic provenance. WP-287 adds a different obstruction: arbitrary nonlinearity does not enlarge the class of obtainable **linear** distributions once the source has already been compressed to a linear scalar profile.

A future candidate must therefore answer two questions independently. First, what source-native information survives into the construction before scalarization? Second, why does the final object have exactly the linear/polarizable structure required by Weil's criterion? A nonlinear scalar statistic can be useful analytically, but positivity of that statistic is not Weil positivity unless an additional equivalence theorem is proved.
