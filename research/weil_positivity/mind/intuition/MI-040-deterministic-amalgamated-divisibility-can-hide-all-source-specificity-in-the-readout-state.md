# MI-040 — Deterministic amalgamated divisibility can hide all source specificity in the readout state

**Evidence level:** exact synthesis from [WP-326](../../findings/WP-326-prime-power-gaps-make-mangoldt-tilts-freely-indecomposable-while-boolean-divisibility-is-universal.md), [WP-328](../../findings/WP-328-free-scalar-shadows-block-bi-free-and-c-free-source-lifts.md), and [WP-329](../../findings/WP-329-deterministic-amalgamated-lifts-make-operator-valued-free-divisibility-universal-before-scalarization.md).

Operator-valued free probability genuinely escapes the scalar-shadow obstruction because composing an amalgamated conditional expectation with a scalar state need not turn operator-valued free convolution into scalar free convolution. But that freedom is large enough to create a new universality failure: the enriched divisible object can be completely source-independent while the exact arithmetic law is stored only in the state used to read it out.

WP-329 gives the exact model. At a finite cutoff, take `B_R=C(Sigma_R)`, `A_R=B_R`, `E_R=id`, and let the coordinate `b_R(x)=x` be deterministic over `B_R`. Its `B_R`-valued law is the point law `delta_(b_R)`, and for every `m>=2` it has the trivial amalgamated free root `delta_(b_R/m)`. Scalarization by the integration state recovers the exact cutoff Mangoldt weights, but replacing that state by arbitrary probability weights leaves the operator-valued law and its infinite divisibility unchanged.

The full source has the same algebraic form with `B=C[t]`, `X=t`, and `E=id`. All higher `B`-valued free cumulants vanish; the entire source is encoded in the scalar moment state `tau_s`. The exact Mangoldt law can therefore remain scalar freely indecomposable while sitting below an operator-valued freely infinitely divisible object for a completely universal reason.

The reusable audit is stronger than checking scalar homomorphic shadows. Ask **where the source specificity lives inside the enriched construction**. If changing only an external/readout state can replace the arithmetic law while preserving the enriched positive/divisible theorem, that theorem is not an arithmetic-selective mechanism. The source must affect non-deterministic coupling data before scalarization—higher operator-valued cumulants, covariance, boundary response, mixed moments, or another invariant whose positivity is not automatic for matched controls.

**Falsification criterion.** Freeze the proposed enriched positive/divisible object and vary only the scalarization/readout state over a broad matched class. If arbitrary scalar laws can be obtained without changing the enriched theorem, the construction has moved source specificity into the readout and is nonselective. A surviving operator-valued route must prove that the arithmetic source constrains the enriched law itself and that the same constraint participates in the finite, archimedean and global sign mechanism.
