# MI-017 — Admissibility can be bought by erasing localization, but exact scalar relocalization uniquely restores the hard gate

**Evidence level:** supported by [WP-290](../../findings/WP-290-critical-mangoldt-dilation-coboundary-is-rh-equivalent-and-jordan-parts-remain-nontempered.md)--[WP-293](../../findings/WP-293-exact-source-native-relocalization-is-uniquely-mobius-and-restores-zero-screen.md), together with the positive-completion obstructions of WP-288--WP-289. No Weil-positivity proof is claimed.

For the critical Mangoldt half-density, WP-290 introduces the intrinsic dilation coboundary. Its multiplier cancels the zeta-pole tangent exactly, but the result is tempered if and only if RH and both Jordan parts remain individually non-tempered. WP-291 closes every finite iteration: finite products can annihilate the pole tangent to arbitrary finite order yet cancel no nontrivial zeta-zero pole.

WP-292 shows that unconditional category descent is possible if one changes the source carrier. Convolution with the critical counting half-density turns `-zeta'/zeta` into `-zeta'`, so the nontrivial-zero poles disappear. After two canonical dilation differences the resulting all-integer source is unconditionally tempered.

That success has an exact price: prime-power/Mangoldt localization is erased. WP-293 now shows that exact scalar source-native recovery has **no alternative inverse**. If an arithmetic half-density kernel exactly sends the smoothed logarithmic carrier back to Mangoldt, ordinary Dirichlet convolution forces the kernel to be Möbius uniquely. Its transform is `1/zeta`, so exact relocalization necessarily reinstates the reciprocal-zeta divisor, the signed source and the RH-equivalent zero screen.

The reusable conclusion is now a four-way separation. **Pole cancellation, category admissibility, arithmetic localization and recovery architecture are independent currencies.** Finite signed differences preserve localization but cannot buy unconditional admissibility; counting convolution buys admissibility by discarding localization; exact one-channel scalar arithmetic recovery is uniquely Möbius and recreates the hard gate.

The live Weil problem must therefore leave at least one assumption of the exact scalar recovery model. Plausible classes include approximate/coarse localization that is sufficient for the final Weil form without reconstructing the full Mangoldt source, multi-channel linear recovery, non-translation-invariant/boundary-conditioned operators, or a nonlinear geometric coupling with its own unconditional admissibility theorem.

**Boundary.** WP-293 is a uniqueness theorem only for exact scalar linear source-native arithmetic convolution on the log-integer semigroup. It does not rule out partial recovery, off-lattice kernels, several coupled channels, boundary-dependent operators or nonlinear geometry. Those alternatives still must prove that the retained arithmetic information is enough for exact Weil positivity rather than merely restoring category membership.
