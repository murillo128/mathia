# WP-344 — Singular character-tangent readout is a fixed boundary state in disguise

## Claim

`WP-343` leaves a genuine boundary open: an infinite-dimensional stationary operator-valued transport may admit moving or singular readouts that are not uniformly dominated by any one bounded positive functional. The simplest coherent realization of that escape is nevertheless illusory.

Let `Gamma` be an abelian group and let

\[
h:\Gamma\to\mathbb R
\tag{1}
\]

be a real homomorphism. For `t in (0,1]` define the one-parameter character

\[
\chi_t(\alpha)=e^{it h(\alpha)}
\tag{2}
\]

and the normalized character-chord transport

\[
\Psi_h(\alpha)(t)
:=\frac{|\chi_t(\alpha)-1|^2}{t^2}
=\frac{2\bigl(1-\cos(t h(\alpha))\bigr)}{t^2}.
\tag{3}
\]

Regard `Psi_h(alpha)` as a positive element of `C_b((0,1])`. Then:

1. `Psi_h:Gamma->C_b((0,1])_+` is translation-invariant and conditionally negative in the pointwise C*-order;
2. for every fixed interior parameter `t>0`, the scalar CND function `alpha -> Psi_h(alpha)(t)` has **zero** Levy--Khinchin quadratic part;
3. nevertheless
   \[
   \boxed{\|\Psi_h(\alpha)\|_\infty=h(\alpha)^2;}
   \tag{4}
   \]
4. if
   \[
   B_h:=C^*\bigl(1,\{\Psi_h(\alpha):\alpha\in\Gamma\}\bigr)
   \subset C_b((0,1]),
   \tag{5}
   \]
   then every element of `B_h` has a limit at `t=0`, and
   \[
   \varepsilon_0(f):=\lim_{t\downarrow0}f(t)
   \tag{6}
   \]
   is a **single fixed character/state** of `B_h` satisfying
   \[
   \boxed{\varepsilon_0(\Psi_h(\alpha))
   =\|\Psi_h(\alpha)\|_\infty
   =h(\alpha)^2.}
   \tag{7}
   \]

Thus an apparently singular infinite-dimensional readout can recover a quadratic displacement even though every fixed interior scalar channel has no quadratic drift. But it does so only because the coherent family itself compactifies by a boundary state whose value is already the square of the generating homomorphism.

For the prime-exponent displacement group

\[
\Gamma=\bigoplus_p\mathbb Z e_p,
\qquad
L(\alpha)=\sum_p\alpha_p\log p,
\tag{8}
\]

taking `h=L` gives

\[
\varepsilon_0(\Psi_L(\alpha))=L(\alpha)^2.
\tag{9}
\]

This does **not** manufacture the arithmetic log-square from an oscillatory positive geometry. The one-parameter character family was generated by `L` before positivity was read out, and its canonical boundary state recovers exactly that pre-existing quadratic direction.

**Classification:** `EXACT-DERIVED + STATIONARY-CND + INFINITE-DIMENSIONAL-COMMUTATIVE-CSTAR + SINGULAR-BOUNDARY-TANGENT + ZERO-INTERIOR-QUADRATIC-PART + FIXED-BOUNDARY-STATE-RECOVERY + MATCHED-CONTROL + DECISIVE-NEGATIVE-FOR-COHERENT-CHARACTER-TANGENT-ESCAPE + NOT-WEIL-POSITIVITY`.

## 1. Every interior channel is pure oscillatory negative type

For fixed `t>0`, `chi_t` is a unitary character. Hence

\[
\alpha\longmapsto 1-\operatorname{Re}\chi_t(\alpha)
\tag{10}
\]

is conditionally negative definite. Multiplication by the positive scalar `2/t^2` preserves conditional negative type, so (3) is scalar CND at every `t`.

Because order in `C_b((0,1])` is pointwise, the same statement simultaneously gives operator-order conditional negativity:

\[
\sum_{i,j}\overline{c_i}c_j
\Psi_h(\alpha_i-\alpha_j)\preceq0
\quad\text{whenever }\sum_i c_i=0.
\tag{11}
\]

At any fixed `t`, however, the function is bounded in the group-dilation variable. Indeed

\[
0\le \Psi_h(m\alpha)(t)\le\frac4{t^2},
\tag{12}
\]

so its quadratic Levy--Khinchin component is

\[
q_t(\alpha)
=\lim_{m\to\infty}
\frac{\Psi_h(m\alpha)(t)}{m^2}
=0.
\tag{13}
\]

This is exactly why the construction initially looks like an escape from `WP-341`: no individual interior scalar probe contains Euclidean drift.

## 2. The singular normalization recovers the tangent square exactly

Rewrite (3) as

\[
\Psi_h(\alpha)(t)
=4\frac{\sin^2(t h(\alpha)/2)}{t^2}.
\tag{14}
\]

The elementary inequality `|sin x|<=|x|` gives

\[
0\le \Psi_h(\alpha)(t)\le h(\alpha)^2
\qquad(t>0).
\tag{15}
\]

On the other hand,

\[
\lim_{t\downarrow0}\Psi_h(\alpha)(t)=h(\alpha)^2.
\tag{16}
\]

Therefore the supremum over the open parameter interval reaches its value as a boundary limit and (4) follows.

The important feature is the order of limits. For every fixed `t>0`, dilation in `m` gives the zero quadratic part (13). If the character parameter tends to zero first, the normalized finite difference converges to the square of the infinitesimal generator:

\[
\lim_{t\downarrow0}
\frac{|e^{it h(\alpha)}-1|^2}{t^2}
=h(\alpha)^2.
\tag{17}
\]

So the apparent new quadratic growth is a **character tangent**, not growth synthesized by the oscillatory Levy--Khintchine sector.

## 3. The generated source algebra already contains the boundary readout

One might object that evaluation at `t=0` is not a state on the full ambient algebra `C_b((0,1])`, because an arbitrary bounded continuous function on `(0,1]` need not have a boundary limit. That objection disappears on the algebra actually generated by the proposed source observables.

Each generator `Psi_h(alpha)` extends continuously to `[0,1]` by assigning the boundary value `h(alpha)^2`. Every unital *-polynomial in finitely many generators therefore has a boundary limit. Uniform limits preserve boundary limits: if `f_n` converge uniformly on `(0,1]` and each `lim_{t->0} f_n(t)` exists, then the boundary values form a Cauchy sequence and the uniform limit has the corresponding boundary limit.

Consequently every `f in B_h` extends continuously to `t=0`. The map (6) is then a unital *-homomorphism

\[
\varepsilon_0:B_h\to\mathbb C,
\tag{18}
\]

hence a positive norm-one functional. Applying it to the transport gives

\[
\varepsilon_0(\Psi_h(\alpha))=h(\alpha)^2.
\tag{19}
\]

Together with (4), this proves (7).

The distinction from `WP-343` is useful. No global domination theorem for every positive functional on an infinite-dimensional algebra is being claimed. Instead, this particular coherent singular construction carries its own fixed boundary state. The nonlinear operator-norm readout coincides with that fixed state **on the entire transport family being used**.

## 4. Specialization to the arithmetic logarithm is target preload, not source discovery

Prime Lattice gives the canonical exponent displacement group, and unique factorization gives the homomorphism `L` in (8). Substituting `h=L` into (2) produces

\[
\chi_t(\alpha)
=\exp\!\left(it\sum_p\alpha_p\log p\right).
\tag{20}
\]

The resulting positive CND family satisfies

\[
\|\Psi_L(\alpha)\|_\infty
=\varepsilon_0(\Psi_L(\alpha))
=\left(\sum_p\alpha_p\log p\right)^2.
\tag{21}
\]

Thus it certainly supplies the quadratic logarithmic transport scale required by the `WP-338`--`WP-341` defect analysis. But the arithmetic direction entered at the first step, as the infinitesimal generator of the character path. The fixed boundary scalarization then merely squares it.

This is the same substantive failure mode identified by `WP-341`, now exposed inside a singular infinite-dimensional realization: successful quadratic control is not evidence that oscillatory channels generated the arithmetic coupling. The relevant quadratic covector was encoded before the positivity theorem was applied.

## 5. Matched controls remove arithmetic selectivity completely

Let `omega_p` be arbitrary real generator weights and define

\[
h_\omega(\alpha)=\sum_p\alpha_p\omega_p.
\tag{22}
\]

Repeating the construction verbatim gives

\[
\Psi_\omega(\alpha)(t)
=\frac{|e^{it h_\omega(\alpha)}-1|^2}{t^2}
\tag{23}
\]

and

\[
\|\Psi_\omega(\alpha)\|_\infty
=\varepsilon_0(\Psi_\omega(\alpha))
=h_\omega(\alpha)^2.
\tag{24}
\]

No step uses primality, Euler products, the Gamma factor, the polar terms, or any global Riemann-specific relation. The construction can encode **any** chosen linear functional on the free abelian exponent lattice just as effectively as it encodes `log p`.

Therefore the positive character-tangent mechanism fails the matched-control gate as an explanation of Weil positivity. To become arithmetic, a source theorem would first have to select `omega_p=log p` for an independent reason; once that is done, the present geometry contributes no further explanation of the critical quadratic direction.

## 6. Aggressive falsification and exact boundary

This finding does not close every singular or infinite-dimensional operator-valued escape left by `WP-343`.

A family with **no common boundary compactification** may evade the argument. If the positive source observables do not generate a C*-algebra on which the singular limit is one fixed state, a separate analysis is required.

A genuinely **operator-level noncommutative** sign theorem also remains open. Here the coefficient algebra is commutative and the decisive scalar quantity is already visible through a character.

A **nonstationary/basepoint-dependent** geometry remains open. The present transport depends only on the group displacement and inherits all stationary rigidity away from the singular parameter boundary.

A source-derived singular limit whose tangent is not specified by a preselected homomorphism remains open. The negative conclusion here is specifically that a normalized one-parameter character tangent cannot be credited with discovering the quadratic direction that generated the character family itself.

Finally, nothing in (3)--(24) supplies the archimedean Gamma contribution, polar counterterms, or the full Weil explicit-formula pairing. Even the arithmetic specialization only reconstructs the `L^2` transport scale used to control a UCP variance defect; it does not produce the destination Weil sign.

## 7. Prior-art and novelty audit

Schoenberg's correspondence between unitary/positive-definite data and conditionally negative type is classical. The abelian Levy--Khintchine decomposition and the separation between quadratic and character-integral parts are standard; Berg--Christensen--Ressel give a systematic treatment. The fact that a continuous character path has a quadratic infinitesimal chord length is elementary Hilbert geometry, and boundary evaluation on a uniformly closed algebra of functions with a common continuous extension is elementary commutative C*-algebra theory.

No novelty is claimed for any of those ingredients. The branch-specific contribution is the **falsification of the most direct singular escape left by `WP-343`**:

- every interior character channel is pure oscillatory CND and has zero quadratic dilation part;
- the normalized infinite-dimensional family nevertheless has exact quadratic operator norm;
- that norm is not a new nonlinear sign mechanism on the source family, because one fixed boundary state on the generated C*-algebra returns the same value;
- the boundary value is exactly the square of the homomorphism that generated the character family;
- arbitrary-weight controls reproduce the construction identically.

So the apparent noncommutation of the `t->0` and group-dilation limits is real, but it does not create arithmetic geometry. It exposes where the quadratic direction was stored.

## Representation audit

The statement is intrinsic to the pair `(Gamma,h)`. Changing generators of `Gamma` changes the coordinate expression of `h` but not the character path `alpha -> exp(it h(alpha))` or the boundary value `h(alpha)^2`.

A linear reparameterization `t -> ct` rescales the infinitesimal generator and the quadratic boundary value by the expected constant factor; it cannot create a new direction. The singular denominator `t^2` is also substantive: it is exactly the second-order normalization required to retain a nonzero character tangent. Choosing a different normalization after inspecting the desired target would be a regulator choice, not an independent geometric theorem.

For the arithmetic specialization, the nontrivial input is the selection of the logarithmic homomorphism `L`. The positivity and boundary-state arguments do not select it. That separation is invariant under any coordinate representation of the exponent lattice.

## Consequence for the Weil-positivity search

The open boundary after `WP-343` can be narrowed further. A surviving infinite-dimensional/singular stationary route cannot merely take a coherent family of oscillatory character costs, divide by the square of a parameter, and use a supremum or endpoint tangent to recover quadratic growth. On the C*-algebra generated by those observables, the endpoint is already one fixed positive scalarization and returns the square of the preselected generator.

For Weil positivity, a genuinely new mechanism must therefore do more: produce a singular or operator-level positive structure whose decisive readout does **not** reduce on the source-generated algebra to a fixed boundary state carrying a preloaded arithmetic covector, or abandon stationary character-tangent geometry altogether. It must still explain the finite-prime/archimedean/polar assembly and prove the final sign independently of RH.
