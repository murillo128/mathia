# PC-128 — vertexwise resultant Hessian is the bipartite inverse-square chord Laplacian

**Status:** `EXACT-DERIVED` + `LITERATURE+DERIVED` + `PRIOR-ART-REDIRECTION` + `DECISIVE-NEGATIVE` for treating finite vertex-dependent differential response of a two-shell resultant as a new mechanism distinct from the already studied chord-operator branch.

PC-126/PC-127 close finite global-projective deformations of a shell and their finite logarithmic differential response, while deliberately leaving genuinely vertex-dependent deformations outside the obstruction. The most direct enlargement is to let every vertex of both finite shells move independently and differentiate the full collision resultant on that configuration space. That enlargement is genuinely high-dimensional and retains every pairwise shell interaction, but its Hessian is not a new operator: on the unit circle it is exactly the weighted graph Laplacian with inverse-square chord weights. Higher derivatives remain sums of single-edge tensors.

Thus the finite vertex-dependent resultant branch does not evade the earlier chord analysis by passing to a larger deformation space. It lands directly on it.

## 1. Full vertexwise collision product

Let `A={alpha_1,...,alpha_r}` and `B={beta_1,...,beta_s}` be two disjoint finite point sets in `C^*`. For Prime Circle take

\[
A=P_m^*,\qquad B=P_n^*,\qquad m\ne n,
\]

so the two primitive shells are disjoint. Give every vertex an independent logarithmic multiplier,

\[
x_i=\alpha_i e^{u_i},\qquad y_j=\beta_j e^{v_j}.
\]

The monic polynomials with these moving roots have collision resultant, up to the fixed conventional sign,

\[
\boxed{
\mathcal R(u,v)=\prod_{i=1}^r\prod_{j=1}^s(x_i-y_j).
}
\]

Choose a local branch away from collisions and write

\[
\mathcal S(u,v)=\log \mathcal R(u,v)
=\sum_{i,j}\log(x_i-y_j).
\]

This is the full finite vertex-coordinate enlargement of the PC-126/127 resultant: no common `PGL_2` motion is imposed and the deformation space has dimension `r+s` before quotienting the common scale/rotation direction.

A first exact control is already strong. If the `B` shell is fixed (`v_j=0`) while the vertices of `A` move independently, then

\[
\boxed{
\mathcal R(u,0)
=\prod_{i=1}^r \Phi_n(\alpha_i e^{u_i})
}
\]

for `B=P_n^*`. Hence the one-shell vertexwise deformation is completely separable: all mixed derivatives between distinct `u_i` vanish, and every coordinate divisor is the cyclotomic collision set

\[
e^{u_i}=\beta/\alpha_i,\qquad \beta\in P_n^*.
\]

Any coupling in a one-shell deformation must therefore be inserted through a chosen relation among the `u_i`; it is not generated by the scalar resultant itself.

## 2. The two-shell Hessian is a weighted complete-bipartite Laplacian

For one pair `(i,j)` put

\[
w_{ij}:=\frac{x_i y_j}{(x_i-y_j)^2}.
\]

Direct differentiation gives

\[
\frac{\partial^2}{\partial u_i^2}\log(x_i-y_j)=-w_{ij},
\qquad
\frac{\partial^2}{\partial v_j^2}\log(x_i-y_j)=-w_{ij},
\]

and

\[
\boxed{
\frac{\partial^2}{\partial u_i\partial v_j}\log(x_i-y_j)=w_{ij}.
}
\]

There are no second derivatives coupling two different `A` vertices or two different `B` vertices. Therefore, if `W=(w_{ij})`,

\[
\boxed{
D^2\mathcal S=
\begin{pmatrix}
-\operatorname{diag}(W\mathbf 1)&W\\
W^T&-\operatorname{diag}(W^T\mathbf 1)
\end{pmatrix}.
}
\]

This is, up to the displayed sign convention, precisely the weighted graph Laplacian of the complete bipartite graph `K_{r,s}`. The common vector `(1,...,1;1,...,1)` is the expected null direction because multiplying every vertex by the same factor changes `log R` only by a linear term.

The important point is structural: allowing all vertices to move independently does create a full high-dimensional response matrix, but the matrix is generated edge-by-edge by the original pairwise collision factors. There is no new many-body Hessian term.

## 3. On the circle the weights are exactly inverse-square chords

Return to the intrinsic unit-circle geometry and parameterize the actual vertices by angles,

\[
x_i=e^{i\theta_i},\qquad y_j=e^{i\phi_j}.
\]

For the real logarithmic interaction

\[
E(\theta,\phi)
:=\log|\mathcal R|
=\sum_{i,j}\log|e^{i\theta_i}-e^{i\phi_j}|,
\]

we have

\[
\frac{d^2}{d\delta^2}
\log|e^{i\delta}-1|
=-\frac1{4\sin^2(\delta/2)}.
\]

Since

\[
|e^{i\theta_i}-e^{i\phi_j}|^2
=4\sin^2\frac{\theta_i-\phi_j}{2},
\]

set

\[
\boxed{
c_{ij}:=
\frac1{|x_i-y_j|^2}
=\frac1{4\sin^2((\theta_i-\phi_j)/2)}.
}
\]

Then

\[
\boxed{
-D^2E=
L_{A,B}:=
\begin{pmatrix}
\operatorname{diag}(C\mathbf 1)&-C\\
-C^T&\operatorname{diag}(C^T\mathbf 1)
\end{pmatrix},
\qquad C=(c_{ij}).
}
\]

So the vertexwise Hessian of the shell resultant is **exactly the inverse-square chord Laplacian** on the complete bipartite interaction graph between the two shells. Because all `c_{ij}>0` for disjoint finite shells, `K_{r,s}` is connected and

\[
\boxed{\operatorname{rank}L_{A,B}=r+s-1.}
\]

Thus this is not a low-rank collapse. It is a maximal-rank response modulo the unavoidable common-rotation mode. The negative conclusion is different: the response is not a new resultant-specific operator at all; it is the same `1/chord^2` geometry already isolated in the PC-032--PC-047 operator branch, now appearing as the exact second variation of the pairwise logarithmic resultant energy.

## 4. Higher differential response still has only edge memory

The absence of new many-body structure is not special to the Hessian. Write

\[
\delta_{ij}:=u_i-v_j,
\qquad
b_{ij}:=e_i-e_{r+j}.
\]

Apart from a term linear in the `v_j`, each edge contribution is a one-variable function of `delta_ij`. Hence for every `k>=2`,

\[
\boxed{
D^k\mathcal S
=
\sum_{i,j}
 f_{ij}^{(k)}(\delta_{ij})
 b_{ij}^{\otimes k}
}
\]

for the elementary one-edge function

\[
f_{ij}(\delta)=\log(\alpha_i e^\delta-\beta_j).
\]

Every finite differential tensor is therefore a sum of tensors supported on individual edges of the complete bipartite collision graph. Differentiation can alter the edge weight but cannot create an irreducible interaction involving two different collision edges.

This is the vertex-coordinate analogue of PC-127's hyperplane-master-function formula. The larger parameter space removes the finite-dimensional `PGL_2` restriction, but it does not remove the arrangement/master-function structure.

## 5. Relation to the existing chord branch

PC-032 introduced the canonical full-polygon inverse-square chord Laplacian and gave its explicit regular-polygon spectrum. PC-033/PC-044 and the subsequent old/new analysis studied what survives when that kernel is compressed to primitive birth vertices and divisor-defined sectors. PC-047 corrected an overstrong low-rank interpretation and showed that old/new cotangent coupling can have maximal possible rank.

PC-128 supplies an exact bridge in the other direction:

\[
\boxed{
\text{pairwise shell resultant}
\xrightarrow{\text{full vertexwise second variation}}
\text{bipartite }1/\text{chord}^2\text{ Laplacian}.
}
\]

Therefore a spectral feature extracted from this Hessian must be evaluated as part of the chord-operator program, not counted as an independent success of a resultant-deformation program. In particular, the fact that the Hessian is full rank does not itself create a new spectral parameter, functional equation, gamma factor, or critical-line selector.

For roots-of-unity shells the entries `c_ij` are cyclotomic trigonometric values, and when the two shells are embedded in their common `L=lcm(m,n)` polygon they are restrictions of the same universal `csc^2(pi k/L)` kernel. The arithmetic question is therefore entirely in how exact-order subsets select and assemble those already-known chord weights.

## 6. Prior art and novelty audit

No theorem-level novelty is claimed for the differential identities.

- PC-126/PC-127 already place products of pairwise collision factors and their logarithmic derivatives in classical resultant / hyperplane-arrangement master-function theory. Varchenko's arrangement/Gaudin work is the relevant prior-art boundary for interpreting Hessians of such master functions as a new spectral mechanism.
- PC-032 already records Calogero--Perelomov as the classical anchor for the `csc^{-2}` regular-polygon matrix family. The appearance of inverse-square trigonometric interactions from second derivatives of logarithmic sine/Vandermonde potentials belongs to the same classical Calogero--Sutherland neighborhood.
- The factorization and Hessian formulas above hold for arbitrary disjoint finite point clouds on the circle. Primality enters only through choosing the particular exact-order root subsets. A matched nonarithmetic configuration has the identical differential mechanism.

Directed literature checks around resultants/discriminants, arrangement master functions and their Hessians, and trigonometric inverse-square interaction matrices found only these classical neighboring structures. The durable contribution here is the **branch identification**: the explicit vertex-dependent boundary left by PC-127 maps exactly into the already existing inverse-square chord branch rather than producing a separate finite operator mechanism.

## 7. Boundary and research consequence

The result rules out the following as an independent route:

\[
\boxed{
\text{finite two-shell resultant}
\to
\text{independent vertex coordinates}
\to
\text{finite differential response}
\to
\text{new resultant-specific RH operator}.
}
\]

It does **not** prove that every spectrum of the bipartite exact-order chord blocks is trivial; those blocks belong to the chord-operator branch and may still require their own arithmetic analysis. It also does not rule out:

- a genuinely nonlinear evolution in which the deformation law is itself forced by Prime-Circle geometry and cannot be reduced to finite differential tensors of the collision product;
- noncommutative cross-level transport carrying ordered memory beyond the scalar resultant;
- an infinite cross-level limit whose convergence or renormalization creates new analytic structure;
- the nonlinear Fuchsian uniformization/monodromy branch of PC-017.

The practical boundary is now sharper. Merely enlarging the PC-126/127 deformation space from one global projective motion to independent finite vertex motions does not create a new family of local response operators: at second order it reproduces the inverse-square chord Laplacian exactly, and at all finite orders it remains edge-additive master-function data. Any surviving deformation-based mechanism must introduce structure beyond finite differential extraction of the pairwise collision resultant.
