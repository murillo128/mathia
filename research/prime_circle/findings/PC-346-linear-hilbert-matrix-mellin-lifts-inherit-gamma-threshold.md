# PC-346 — linear Hilbert/matrix Mellin lifts inherit the sharp Gamma threshold

**Status:** `EXACT-DERIVED` + `DECISIVE-NEGATIVE` for linear Hilbert- or matrix-valued lifts of the full-shell residual Mellin readout classified in PC-345.

PC-345 leaves matrix-valued/noncommuting carriers among the possible ways to escape the scalar residual Mellin classification. There is an important distinction: merely allowing the residual selector to take values in a Hilbert space or matrix algebra does **not** activate noncommutativity when the shell kernel is still scalar and the readout is linear. In that regime the complete shell transform is exactly the scalar transform tensored with the identity.

Consequently the `pi/2` Gamma-strip threshold of PC-345 survives unchanged for arbitrary separable Hilbert targets. At and above the critical width the vector-valued transform is injective; below it the kernel is precisely the Hilbert amplification of the scalar kernel and is infinite-dimensional. Finite matrix-valued selectors are an immediate corollary. Genuine matrix escape therefore requires multiplication, commutators, ordering, shell-dependent matrix symbols, or another nonseparable operation **before** the scalar Mellin integration.

## 1. Hilbert-valued full-shell residual response

Fix

\[
\sigma>0,\qquad \beta:=1-\sigma,
\]

and retain the exact shell factor from PC-345,

\[
A_n(t)
=\sum_{d\mid n}\mu(n/d)d^{\beta-it}.
\tag{1}
\]

Let `H` be a separable complex Hilbert space and, for `b>0`, define

\[
\mathcal H_b(H)
:=\left\{S:\mathbb R\to H\text{ strongly measurable}: 
\int_{\mathbb R}e^{2b|t|}\|S(t)\|_H^2\,dt<\infty\right\}.
\tag{2}
\]

Cauchy--Schwarz gives

\[
\int_{\mathbb R}\|S(t)\|_H\,dt
\le
\left(\int_{\mathbb R}e^{2b|t|}\|S(t)\|_H^2dt\right)^{1/2}
\left(\int_{\mathbb R}e^{-2b|t|}dt\right)^{1/2},
\tag{3}
\]

so `S` is Bochner integrable. Since `A_n` is a finite bounded exponential sum, every vector shell response

\[
\mathcal L_S(n)
:=\int_{\mathbb R}S(t)A_n(t)\,dt
\in H
\qquad(n>1)
\tag{4}
\]

is absolutely well defined.

This is exactly the linear Hilbert-valued lift of the residual scalar layer `S=U_sigma T` in PC-345. No new shell-dependent symbol has been inserted: `A_n(t)` remains scalar.

## 2. The critical and supercritical widths remain injective

Assume

\[
\mathcal L_S(n)=0
\qquad\text{for every }n>1.
\tag{5}
\]

Choose a countable orthonormal basis `(e_j)` of the closed separable subspace generated by the essential range of `S`, and set

\[
s_j(t):=\langle S(t),e_j\rangle.
\tag{6}
\]

Each coordinate satisfies

\[
e^{b|t|}s_j(t)\in L^2(\mathbb R)
\tag{7}
\]

and, by bounded linearity of the coordinate functional through the Bochner integral,

\[
0
=\langle\mathcal L_S(n),e_j\rangle
=\int_{\mathbb R}s_j(t)A_n(t)\,dt
\qquad(n>1).
\tag{8}
\]

For `b>=pi/2`, PC-345 applies to every scalar coordinate and gives

\[
s_j=0\quad\text{a.e. for every }j.
\tag{9}
\]

A countable union of the coordinate null sets is still null, hence all coordinates of `S(t)` vanish simultaneously almost everywhere. Therefore

\[
\boxed{
\ker \mathcal L^{H}_{\sigma,b}=\{0\}
\qquad
(\sigma>0,\ b\ge\pi/2).
}
\tag{10}
\]

No finite-dimensionality assumption on `H` was used.

## 3. Below `pi/2` the vector kernel is exactly the scalar kernel amplified by `H`

Let

\[
K_{\sigma,b}
:=\left\{s\in\mathcal H_b(\mathbb C):
\int_{\mathbb R}s(t)A_n(t)dt=0\ \forall n>1\right\}.
\tag{11}
\]

Every shell functional in (11) is bounded on the weighted `L^2` space, because

\[
\left|\int s(t)A_n(t)dt\right|
\le
\|e^{b|t|}s\|_2\,
\|e^{-b|t|}A_n\|_2.
\tag{12}
\]

Thus `K_{sigma,b}` is closed. Under the canonical Hilbert identification

\[
\mathcal H_b(H)
\cong
\mathcal H_b(\mathbb C)\widehat\otimes H,
\tag{13}
\]

the coordinate argument above gives the exact kernel identity

\[
\boxed{
\ker\mathcal L^{H}_{\sigma,b}
=
K_{\sigma,b}\widehat\otimes H.
}
\tag{14}
\]

Indeed, membership in the left side is equivalent to every scalar coordinate lying in `K_{sigma,b}`; conversely any Hilbert-summable family of scalar kernel coordinates has zero vector response.

PC-345 proves that

\[
\dim K_{\sigma,b}=\infty
\qquad
(\sigma>0,\ 0<b<\pi/2).
\tag{15}
\]

Hence for every nonzero Hilbert target,

\[
\boxed{
\dim\ker\mathcal L^{H}_{\sigma,b}=\infty
\qquad
(\sigma>0,\ 0<b<\pi/2).
}
\tag{16}
\]

The sharp threshold is therefore unchanged by arbitrary separable Hilbert amplification:

\[
\boxed{
\begin{array}{ll}
b\ge\pi/2:& \ker\mathcal L^{H}_{\sigma,b}=\{0\},\\[1mm]
0<b<\pi/2:& \ker\mathcal L^{H}_{\sigma,b}=K_{\sigma,b}\widehat\otimes H\text{ and is infinite-dimensional.}
\end{array}}
\tag{17}
\]

## 4. Matrix noncommutativity is dormant under a scalar linear shell kernel

Take

\[
H=M_d(\mathbb C)
\]

with the Hilbert--Schmidt inner product. Equation (17) applies for every finite `d`. The matrices `S(t_1)` and `S(t_2)` may fail to commute for almost every pair of frequencies, but the response still has the form

\[
\mathcal L_S(n)
=\int_{\mathbb R} A_n(t)S(t)\,dt.
\tag{18}
\]

Because `A_n(t)` is scalar, no product of matrix values at different frequencies and no commutator is ever formed. Entrywise,

\[
[\mathcal L_S(n)]_{jk}
=\int_{\mathbb R}A_n(t)S_{jk}(t)dt.
\tag{19}
\]

Thus matrix noncommutativity is algebraically invisible to this readout. Increasing the matrix size, allowing a continuously rotating eigenspace, or choosing pairwise noncommuting values of `S(t)` does not create a new shell carrier as long as the final operation remains the scalar-kernel linear integral (18).

The same statement holds for operator-valued profiles in any separable Hilbert class where the chosen operator norm is represented by a Hilbert norm, for example Hilbert--Schmidt operators. No claim is made here for arbitrary Banach-valued operator classes.

## 5. What this closes and what it does not

This result closes the direct continuation

\[
\text{full-shell scalar residual Mellin transform}
\longrightarrow
\text{Hilbert/matrix-valued residual selector}
\longrightarrow
\text{new nullspace or critical-line mechanism}.
\tag{20}
\]

It does **not** close matrix constructions in which noncommutativity is actually used before integration. In particular, the theorem does not address:

- shell-dependent matrix kernels `A_n(t)` replaced by intrinsic matrix symbols;
- products such as `S(t_1)S(t_2)`, commutators, ordered exponentials, or nonlinear functional calculus before shell evaluation;
- genuinely coupled cross-shell/cross-level operators that cannot be written as independent scalar shell integrals;
- non-Hilbert operator topologies whose geometry changes the analytic class rather than merely amplifying it.

The distinction is structural. A matrix label is not enough; the source geometry must force an operation that cannot be diagonalized coordinatewise through the scalar shell kernel.

The functional-analytic ingredients are standard: Bochner integration, separable Hilbert coordinate decompositions, and tensor amplification of scalar bounded functionals. Vector-valued Hardy and Paley--Wiener theory provides a broader classical setting, but it is not load-bearing here because the proof reduces coordinatewise to the already persisted scalar theorem PC-345.

A directed prior-art check for vector/operator-valued Hardy spaces, Paley--Wiener theory on strips, logarithmic uniqueness sets, and operator-valued Mellin transforms found the expected classical vector-valued analytic frameworks, not an independent prime-circle or RH mechanism corresponding to (17). No historical novelty is claimed for the Hilbert-space extension itself.

The durable line-local content is the **boundary classification**: an escape explicitly left open after the scalar theorem is not obtained merely by replacing a scalar residual profile by an arbitrary separable Hilbert- or finite-matrix-valued one. The full-shell Prime-Circle divisor algebra still acts through one scalar family `A_n(t)`, so the vector transform is only an amplification of the scalar transform.

PC-346 concerns the complete full-shell Mellin family after the exact PC-179/PC-345 reduction and allows an arbitrary separable Hilbert target.

## 7. Consequence for the Prime-Circle frontier

The final sentence of PC-345 can now be sharpened. **Matrix-valued is not, by itself, an escape from the scalar Mellin no-go.** If shell dependence remains scalar and the readout remains linear, every matrix component sees exactly the same `pi/2` threshold and exactly the same subcritical scalar ghost space.

Any surviving matrix/noncommutative route must therefore engage its noncommutativity before scalar Mellin reduction: a geometry-forced shell-dependent matrix symbol, a nonlinear product/commutator/ordering operation, or a genuinely cross-shell/cross-level construction. The other surviving classes from PC-345 -- shell-dependent operators and nonlinear observables -- remain untouched.

There is still no new RH criterion here. The theorem is a no-go boundary result showing that a seemingly broader target space does not add arithmetic or zero-sensitive information to the existing full-shell linear Mellin carrier.
