## 1. Exact reflection of the mechanical boundary words

Use the PC-258 boundary indicator, for `a in {p,r}`,

\[
b_a(u)
=
\left\lfloor\frac{a(u+1)}q\right\rfloor
-
\left\lfloor\frac{au}q\right\rfloor,
\qquad 0\le u\le q-2.
\tag{7}
\]

For every interior index `1<=u<=q-2`, both `au/q` and `a(u+1)/q` are nonintegral because `gcd(a,q)=1`. Put

\[
u^\vee=q-1-u.
\tag{8}
\]

Then

\[
\begin{aligned}
b_a(u^\vee)
&=
\left\lfloor a-\frac{au}{q}\right\rfloor
-
\left\lfloor a-\frac{a(u+1)}q\right\rfloor\\
&=
\left(a-1-\left\lfloor\frac{au}q\right\rfloor\right)
-
\left(a-1-\left\lfloor\frac{a(u+1)}q\right\rfloor\right)\\
&=b_a(u).
\end{aligned}
\tag{9}
\]

Hence `u` is a double-boundary collision cell exactly when `u^vee` is.

For a collision define, as in PC-258,

\[
i_u=\left\lfloor\frac{p(u+1)}q\right\rfloor,
\qquad
j_u=\left\lfloor\frac{r(u+1)}q\right\rfloor.
\tag{10}
\]

Because `b_p(u)=b_r(u)=1`,

\[
\left\lfloor\frac{pu}q\right\rfloor=i_u-1,
\qquad
\left\lfloor\frac{ru}q\right\rfloor=j_u-1.
\tag{11}
\]

Therefore

\[
\boxed{
 i_{u^\vee}=p-i_u,
\qquad
 j_{u^\vee}=r-j_u.
}
\tag{12}
\]

The involution reverses the strict ordering of collision cells. If

\[
u_1<\cdots<u_k,
\]

then

\[
\boxed{
 u_{k+1-a}=q-1-u_a,
\quad
 i_{k+1-a}=p-i_a,
\quad
 j_{k+1-a}=r-j_a.
}
\tag{13}
\]

There is no fixed collision. The only possible fixed upper cell is

\[
u=\frac{q-1}{2}.
\]

For odd `a<q`, writing `a=2h+1` gives

\[
\left\lfloor\frac{a(q+1)}{2q}\right\rfloor
=
\left\lfloor\frac{a(q-1)}{2q}\right\rfloor=h,
\tag{14}
\]

so `b_a((q-1)/2)=0`. Hence

\[
\boxed{k\text{ is even}.}
\tag{15}
\]

This argument in fact needs only the corresponding odd coprimality hypotheses, not primality itself.
