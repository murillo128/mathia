# PC-187 — primitive-shell weighted refinement holonomy is cyclotomic

**Status:** `EXACT-DERIVED` + `CLASSICAL-IDENTITY` + `DECISIVE-NEGATIVE` for the most direct source-native **nonlinear/ordered radial escape** left open by PC-186. Attaching the actual primitive-shell cyclotomic multiplier to refinement dilation produces a genuinely nonzero order defect at some composite levels, but the defect is the antisymmetrization of an explicit cyclotomic coboundary. Its logarithm is a finite integer combination of existing shell fields, its radial flux has zero total mass, and its Mellin transform again contains the same universal `Gamma(s) zeta(s)` carrier classified in PC-179.

This does not classify every nonlinear or shell-dependent coupling. It closes the canonical finite weighted-composition transport built only from the primitive-shell multiplier and the source refinement map.

## 1. Source-native weighted refinement transport

For `n>1`, let

\[
F_n(x)=\log\Phi_n(e^{-x}),
\qquad
\rho_n(x)=-F_n'(x),
\qquad x>0,
\]

and let

\[
(U_a f)(x)=f(ax).
\]

PC-186 classified the linear refinement calculus generated by these dilations and the exact cyclotomic child-shell identities. The first ordered nonlinear extension requiring no new kernel is to retain the shell itself as a multiplicative weight:

\[
\boxed{
W_n:=M_{\Phi_n(e^{-x})}U_n.
}
\tag{1}
\]

Writing `z=e^{-x}` and using `U_mM_g=M_{g(mx)}U_m`,

\[
W_mW_n
=M_{\Phi_m(z)\Phi_n(z^m)}U_{mn},
\qquad
W_nW_m
=M_{\Phi_n(z)\Phi_m(z^n)}U_{mn}.
\tag{2}
\]

Hence the relative ordered holonomy is the multiplication operator

\[
\boxed{
W_mW_n(W_nW_m)^{-1}=M_{\mathscr H_{m,n}(z)},
}
\tag{3}
\]

where

\[
\boxed{
\mathscr H_{m,n}(z)
=
\frac{\Phi_m(z)\Phi_n(z^m)}
{\Phi_n(z)\Phi_m(z^n)}.
}
\tag{4}
\]

The order defect is real: for example,

\[
\mathscr H_{2,3}=1,
\qquad
\mathscr H_{4,3}=\Phi_6,
\qquad
\mathscr H_{6,5}=\Phi_{10}\Phi_{15}.
\tag{5}
\]

Thus PC-186's flatness does not extend blindly to shell-dependent weighted products. The question is whether this first nonzero holonomy is a new arithmetic carrier.

## 2. Exact cyclotomic factorization

A root `u` of order `k` is a root of `Phi_n(z^m)` exactly when `u^m` has order `n`, equivalently

\[
\frac{k}{\gcd(k,m)}=n.
\]

Therefore

\[
\boxed{
\Phi_n(z^m)
=
\prod_{\substack{k\mid mn\\k/\gcd(k,m)=n}}
\Phi_k(z).
}
\tag{6}
\]

Substituting into (4) gives

\[
\boxed{
\mathscr H_{m,n}(z)
=
\prod_{k\mid mn}\Phi_k(z)^{E_k(m,n)},
}
\tag{7}
\]

with

\[
\boxed{
E_k(m,n)
=
\mathbf 1_{k=m}-\mathbf 1_{k=n}
+
\mathbf 1_{k/\gcd(k,m)=n}
-
\mathbf 1_{k/\gcd(k,n)=m}.
}
\tag{8}
\]

So every finite holonomy is a rational monomial in ordinary cyclotomic polynomials. It has no zero or pole in `|z|<1`; all complex zeros and poles are root-of-unity torsion on `|z|=1`.

For coprime `m,n`, (6) simplifies to

\[
\Phi_n(z^m)=\prod_{d\mid m}\Phi_{nd}(z),
\]

and hence

\[
\boxed{
\mathscr H_{m,n}(z)
=
\frac{\displaystyle\prod_{\substack{d\mid m\\d>1}}\Phi_{nd}(z)}
{\displaystyle\prod_{\substack{e\mid n\\e>1}}\Phi_{me}(z)}.
}
\tag{9}
\]

Two immediate controls are

\[
\boxed{\mathscr H_{p,q}=1\quad(p\ne q\text{ primes})}
\tag{10}
\]

and, for a prime power against a distinct prime,

\[
\boxed{
\mathscr H_{p^a,q}(z)
=
\prod_{j=1}^{a-1}\Phi_{q p^j}(z).
}
\tag{11}
\]

Thus distinct prime directions remain flat at first depth; nonzero order dependence begins only after one step already carries nontrivial divisor depth.

## 3. The cocycle class is trivial

Normalize a two-step product against the canonical endpoint transporter `W_{mn}`:

\[
W_mW_n=M_{c(m,n)}W_{mn},
\]

where

\[
\boxed{
c(m,n;z)
=
\frac{\Phi_m(z)\Phi_n(z^m)}{\Phi_{mn}(z)}.
}
\tag{12}
\]

If `w_n(z)=Phi_n(z)` and `alpha_m f(z)=f(z^m)`, then

\[
\boxed{
c(m,n)=w_m\,\alpha_m(w_n)\,w_{mn}^{-1}.}
\tag{13}
\]

This is the multiplicative coboundary of the shell-weight cochain `w`. Associativity gives

\[
\boxed{
c(m,n)c(mn,r)
=\alpha_m(c(n,r))c(m,nr).}
\tag{14}
\]

The ordered square is its antisymmetrization:

\[
\boxed{
\mathscr H_{m,n}=\frac{c(m,n)}{c(n,m)}.
}
\tag{15}
\]

Equivalently, removing the shell weight from each generator gives `M_{Phi_n}^{-1}W_n=U_n`, and the bare refinement generators commute. This does **not** erase the nonzero profile (4); equations (7)--(11) classify it even when retained. It does show that the weighted-composition construction supplies no nontrivial cocycle class beyond the cyclotomic shell weights used to define it.

This is analogous to the pure-gauge warning in PC-087, but the present object is different: here the surviving order defect is not zero; it is exactly a finite cyclotomic monomial.

## 4. Log-holonomy and boundary mass

Define

\[
h_{m,n}(x)=\log\mathscr H_{m,n}(e^{-x}).
\]

Directly from (4),

\[
\boxed{
h_{m,n}
=(\alpha_m-I)F_n-(\alpha_n-I)F_m.}
\tag{16}
\]

Using (7),

\[
\boxed{
h_{m,n}(x)=\sum_{k\mid mn}E_k(m,n)F_k(x).}
\tag{17}
\]

Thus this ordered nonlinear field never leaves the finite span of existing cyclotomic shell potentials.

Both radial endpoints are trivial. Since `Phi_k(0)=1` for `k>1`,

\[
\lim_{x\to\infty}h_{m,n}(x)=0.
\]

At the common vertex the same two endpoint factors occur in numerator and denominator of (4), so

\[
\boxed{
\lim_{x\to0+}\mathscr H_{m,n}(e^{-x})=1,
\qquad
\lim_{x\to0+}h_{m,n}(x)=0.
}
\tag{18}
\]

Therefore the order defect creates no second von-Mangoldt endpoint anomaly. If one complexifies `z=e^{-w}`, its finite divisor lifts only to arithmetic imaginary lattices with `Re(w)=0`; translating those to `Re(w)=1/2` would insert the critical line by coordinate choice, as in the cyclotomic spectralization no-go of PC-125.

## 5. Holonomy flux has zero mass and the same Mellin carrier

Set

\[
\kappa_{m,n}(x)=-h_{m,n}'(x),
\qquad
(\beta_a g)(x)=a g(ax).
\]

Then

\[
\boxed{
\kappa_{m,n}
=(\beta_m-I)\rho_n-(\beta_n-I)\rho_m
=
\sum_{k\mid mn}E_k(m,n)\rho_k.
}
\tag{19}
\]

Equation (18) gives the exact zero-mass identity

\[
\boxed{
\int_0^\infty\kappa_{m,n}(x)\,dx=0.
}
\tag{20}
\]

For `Re(s)>1`, Mellin covariance and PC-179 yield

\[
\mathcal M\kappa_{m,n}(s)
=(m^{1-s}-1)\mathcal R_n(s)
-(n^{1-s}-1)\mathcal R_m(s),
\tag{21}
\]

with

\[
\mathcal R_k(s)
=-\Gamma(s)\zeta(s)
 k^{1-s}\prod_{p\mid k}(1-p^{s-1}).
\]

Hence

\[
\boxed{
\mathcal M\kappa_{m,n}(s)
=-\Gamma(s)\zeta(s)Q_{m,n}(s),
}
\tag{22}
\]

where

\[
\boxed{
\begin{aligned}
Q_{m,n}(s)
={}&(m^{1-s}-1)n^{1-s}\prod_{p\mid n}(1-p^{s-1})\\
&-(n^{1-s}-1)m^{1-s}\prod_{p\mid m}(1-p^{s-1}).
\end{aligned}
}
\tag{23}
\]

`Q_{m,n}` is a finite exponential polynomial. Thus every Riemann zero appearing in the Mellin transform of the ordered holonomy is inherited through the same universal `zeta(s)` factor already present in one shell. The extra finite factor neither supplies the completed gamma symmetry nor derives a critical line.

The smallest nontrivial example is decisive:

\[
\mathscr H_{4,3}=\Phi_6,
\qquad
h_{4,3}=F_6,
\qquad
\kappa_{4,3}=\rho_6.
\tag{24}
\]

A genuinely noncommuting two-step weighted transport can therefore collapse exactly to one ordinary composite shell before Mellinization.

## 6. Prior-art and novelty audit

No theorem-level novelty is claimed for the ingredients. The factorization (6) is the standard exact-order decomposition of the cyclotomic composition `Phi_n(z^m)`. PC-125 already places finite cyclotomic spectral divisors and scaled cyclotomic resultants on the classical side, and PC-186 places the dilation/multiplication refinement architecture against the standard crossed-product/Bost--Connes boundary. Equation (22) is the classical Ramanujan/Lambert Mellin carrier already audited in PC-179.

The durable contribution is the **Prime-Circle scope classification**: the first canonical shell-dependent ordered product that genuinely escapes PC-186's linear flatness is noncommutative, but its complete finite holonomy remains cyclotomic, cohomologically generated by a coboundary, endpoint-neutral, and Mellin-classical. A prior-art search found no basis for treating this exact quotient as an independent RH mechanism; the explicit reduction, rather than absence of literature, is the negative evidence.

## 7. Boundary and research consequence

PC-187 rules out the finite-level route

\[
\boxed{
\text{primitive-shell multiplier}
\to
\text{shell-dependent radial dilation}
\to
\text{ordered two-step holonomy}
\to
\text{new RH-relevant mixed-prime curvature}.
}
\]

It does **not** classify a second independent source field, matrix-valued transports whose noncommuting eigenspaces come from chord/angular/old-new geometry, nonlinear couplings outside finite cyclotomic products and ratios, growing-level limits with genuinely new convergence/renormalization, or the global uniformization/accessory-parameter sector.

For the accepted signed-radial-flux direction, the boundary is now sharper: making the canonical radial refinement shell-dependent and order-sensitive is not enough. A surviving candidate must identify where an additional geometry-forced carrier enters before the cyclotomic coboundary reduction.
