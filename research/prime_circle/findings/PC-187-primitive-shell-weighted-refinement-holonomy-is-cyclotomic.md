# PC-187 — primitive-shell weighted refinement holonomy is cyclotomic

**Status:** `EXACT-DERIVED` + `CLASSICAL-IDENTITY` + `DECISIVE-NEGATIVE` for the most direct source-native **nonlinear/ordered radial escape** left open by PC-186: attach the actual primitive-shell cyclotomic multiplier to the refinement dilation, compose two such shell-dependent transports before scalarization, and use their order defect as a candidate mixed-prime holonomy. The order defect can be nonzero, so this is strictly beyond the flat linear prime-difference calculus of PC-186. However, its complete finite-level holonomy is an explicit cyclotomic coboundary. Its logarithm is a finite integer combination of existing cyclotomic shell fields, its radial flux has zero total mass, and Mellinization again carries the same universal `Gamma(s) zeta(s)` factor already classified in PC-179.

This closes a concrete part of the accepted signed-radial-flux frontier without asserting that every nonlinear or shell-dependent coupling is trivial. A surviving radial construction must introduce a second source-forced carrier, a genuinely non-coboundary interaction, a non-cyclotomic growing-level limit, or additional angular/old-new geometry before the weighted dilation algebra is formed.

## 1. The first shell-dependent ordered transport

For `n>1` put

\[
F_n(x)=\log \Phi_n(e^{-x}),
\qquad
\rho_n(x)=-F_n'(x),
\qquad x>0.
\]

Let

\[
(U_a f)(x)=f(ax)
\]

be the bare radial refinement dilation, and let `M_g` denote multiplication by a radial function `g`. PC-186 studied the source-native linear child-shell law generated by the commuting dilations `U_a` and the finite differences `alpha_a-I`. The simplest way to move beyond that linear category without choosing a new kernel is to keep the primitive-shell field itself as a multiplicative weight during transport:

\[
\boxed{
W_n:=M_{\Phi_n(e^{-x})}U_n.
}
\tag{1}
\]

This is intrinsic to the same Prime-Circle radial data: the weight is exactly the primitive-shell cyclotomic product and the composition map is exactly the refinement `x -> nx`.

Since

\[
U_m M_g=M_{g(mx)}U_m,
\]

two ordered steps give

\[
\boxed{
W_mW_n
=
M_{\Phi_m(z)\Phi_n(z^m)}U_{mn},
\qquad z=e^{-x},
}
\tag{2}
\]

whereas

\[
\boxed{
W_nW_m
=
M_{\Phi_n(z)\Phi_m(z^n)}U_{mn}.
}
\tag{3}
\]

Thus the two paths have the same endpoint dilation but need not have the same shell weight.

Because every `Phi_k(z)` is positive and nonzero for `0<z<1`, the relative two-step holonomy is well-defined there:

\[
\boxed{
W_mW_n(W_nW_m)^{-1}
=M_{\mathscr H_{m,n}(z)},
}
\tag{4}
\]

with

\[
\boxed{
\mathscr H_{m,n}(z)
=
\frac{\Phi_m(z)\Phi_n(z^m)}
{\Phi_n(z)\Phi_m(z^n)}.
}
\tag{5}
\]

This is a genuine ordered effect. For example,

\[
\mathscr H_{2,3}=1,
\qquad
\mathscr H_{4,3}=\Phi_6,
\qquad
\mathscr H_{6,5}=\Phi_{10}\Phi_{15}.
\tag{6}
\]

So the source-native nonlinear weighted transport is **not** globally flat. The question is whether the nonzero holonomy is a new carrier. It is not.

## 2. Every finite holonomy is an explicit cyclotomic monomial

The required composition factorization follows directly from root orders. A root `u` of order `k` is a root of `Phi_n(z^m)` exactly when `u^m` has order `n`, that is,

\[
\frac{k}{\gcd(k,m)}=n.
\]

Therefore

\[
\boxed{
\Phi_n(z^m)
=
\prod_{\substack{k\mid mn\\k/\gcd(k,m)=n}}
\Phi_k(z).
}
\tag{7}
\]

Substitution into (5) gives the complete factorization

\[
\boxed{
\mathscr H_{m,n}(z)
=
\prod_{k\mid mn}\Phi_k(z)^{E_k(m,n)},
}
\tag{8}
\]

where

\[
\boxed{
E_k(m,n)
=
\mathbf 1_{k=m}-\mathbf 1_{k=n}
+
\mathbf 1_{k/\gcd(k,m)=n}
-
\mathbf 1_{k/\gcd(k,n)=m}.
}
\tag{9}
\]

The exponents are integers in `{-2,-1,0,1,2}`. Thus the full order defect is a finite rational monomial in ordinary cyclotomic polynomials. It has no zeros or poles in the open unit disk; every complex zero or pole lies at finite root-of-unity torsion on `|z|=1`.

For coprime `m,n`, (7) simplifies to

\[
\Phi_n(z^m)=\prod_{d\mid m}\Phi_{nd}(z),
\]

and hence

\[
\boxed{
\mathscr H_{m,n}(z)
=
\frac{\displaystyle\prod_{\substack{d\mid m\\d>1}}\Phi_{nd}(z)}
{\displaystyle\prod_{\substack{e\mid n\\e>1}}\Phi_{me}(z)}.
}
\tag{10}
\]

This immediately explains the strongest flat control. If `p,q` are distinct primes, both products in (10) consist only of `Phi_{pq}`, so

\[
\boxed{
\mathscr H_{p,q}(z)=1.
}
\tag{11}
\]

Nonzero holonomy first appears only when at least one ordered step already carries nontrivial divisor structure. For a prime power against a distinct prime,

\[
\boxed{
\mathscr H_{p^a,q}(z)
=
\prod_{j=1}^{a-1}\Phi_{q p^j}(z),
\qquad p\ne q.
}
\tag{12}
\]

Equation (6) is the first instance `p=2,a=2,q=3`.

## 3. The apparent operator cocycle is an exact coboundary

The cyclotomic classification has an operator-level explanation. Normalize the two-step product relative to the canonical endpoint transporter `W_{mn}`:

\[
W_mW_n=M_{c(m,n)}W_{mn},
\]

where

\[
\boxed{
c(m,n;z)
=
\frac{\Phi_m(z)\Phi_n(z^m)}{\Phi_{mn}(z)}.
}
\tag{13}
\]

If `w_n(z)=Phi_n(z)`, then

\[
\boxed{
c(m,n)=w_m\,\alpha_m(w_n)\,w_{mn}^{-1},
}
\tag{14}
\]

with `alpha_m f(z)=f(z^m)`. This is exactly the multiplicative coboundary of the shell-weight cochain `w_n`. Associativity gives the corresponding twisted cocycle identity

\[
\boxed{
c(m,n)c(mn,r)
=
\alpha_m(c(n,r))c(m,nr).
}
\tag{15}
\]

The ordered square is only the antisymmetrization of this coboundary:

\[
\boxed{
\mathscr H_{m,n}=rac{c(m,n)}{c(n,m)}.
}
\tag{16}
\]

Equivalently, removing the shell weight from each generator sends

\[
M_{\Phi_n}^{-1}W_n=U_n,
\]

and the remaining refinement generators commute exactly. This does **not** say that the nonzero profile (5) should be discarded: equations (8)--(12) classify it even when it is retained. It says that the weighted-composition defect carries no nontrivial cocycle class beyond the shell weights from which it was constructed.

This is the radial analogue of the general warning already encountered in PC-087: an order-dependent coefficient created by transporting a canonical product through shell-dependent coordinates must be checked for exact coboundary structure before it is interpreted as new curvature or holonomy.

## 4. The logarithmic holonomy is only a finite shell combination

Define the real radial log-holonomy

\[
h_{m,n}(x)
:=\log \mathscr H_{m,n}(e^{-x}).
\]

Directly from (5),

\[
\boxed{
h_{m,n}
=(\alpha_m-I)F_n-(\alpha_n-I)F_m.
}
\tag{17}
\]

Using (8), the same object is

\[
\boxed{
h_{m,n}(x)
=
\sum_{k\mid mn}E_k(m,n)F_k(x).
}
\tag{18}
\]

Thus the first nonlinear ordered transport left open by PC-186 does produce a nonzero field, but that field never leaves the finite linear span of already existing cyclotomic shell potentials.

Both radial endpoints are trivial. Since `Phi_k(0)=1` for every `k>1`,

\[
\lim_{x\to\infty}h_{m,n}(x)=0.
\]

At the common vertex the numerator and denominator of (5) contain the same two endpoint values, so

\[
\boxed{
\lim_{x\to0+}\mathscr H_{m,n}(e^{-x})=1,
\qquad
\lim_{x\to0+}h_{m,n}(x)=0.
}
\tag{19}
\]

Consequently this order defect does not create a second von-Mangoldt endpoint anomaly.

If one complexifies the radial coordinate by writing `z=e^{-w}`, every zero or pole of (8) lifts from a root of unity to an arithmetic imaginary lattice with `Re(w)=0`. Moving that divisor to `Re(w)=1/2` would again be a coordinate shift imposed by hand, exactly as in the finite cyclotomic spectralization boundary of PC-125.

## 5. Its signed flux has zero mass and Mellinizes to the same zeta carrier

Differentiate (17) and define

\[
\kappa_{m,n}(x):=-h_{m,n}'(x).
\]

With the flux dilation

\[
(\beta_a g)(x)=a g(ax),
\]

one obtains

\[
\boxed{
\kappa_{m,n}
=(\beta_m-I)\rho_n-(\beta_n-I)\rho_m
=
\sum_{k\mid mn}E_k(m,n)\rho_k.
}
\tag{20}
\]

Because (19) and the exterior endpoint both vanish,

\[
\boxed{
\int_0^\infty\kappa_{m,n}(x)\,dx=0
}
\tag{21}
\]

for every `m,n>1`. Thus the canonical ordered holonomy supplies interior sign structure but no net prime-power selector.

For `Re(s)>1`, Mellin covariance and PC-179 give

\[
\mathcal M\kappa_{m,n}(s)
=
(m^{1-s}-1)\mathcal R_n(s)
-
(n^{1-s}-1)\mathcal R_m(s),
\tag{22}
\]

where

\[
\mathcal R_k(s)
=-\Gamma(s)\zeta(s)
\,k^{1-s}\prod_{p\mid k}(1-p^{s-1}).
\]

Therefore

\[
\boxed{
\mathcal M\kappa_{m,n}(s)
=-\Gamma(s)\zeta(s)\,Q_{m,n}(s),
}
\tag{23}
\]

with the finite exponential polynomial

\[
\boxed{
\begin{aligned}
Q_{m,n}(s)
={}&(m^{1-s}-1)
 n^{1-s}\prod_{p\mid n}(1-p^{s-1})\\
&-(n^{1-s}-1)
 m^{1-s}\prod_{p\mid m}(1-p^{s-1}).
\end{aligned}
}
\tag{24}
\]

Equivalently, by (20), `Q_{m,n}` is the finite integer combination of the shell Euler factors indexed by `E_k(m,n)`.

Thus every Riemann zero appearing in the Mellin transform of the nonlinear ordered holonomy is again inherited through the same universal scalar `zeta(s)` already present in a single shell. The extra factor is a finite exponential polynomial determined by `m,n`; it contributes only an additional elementary divisor and supplies neither the gamma completion nor a source-derived `s <-> 1-s` symmetry.

The smallest nontrivial control makes the collapse explicit. From `mathscr H_{4,3}=Phi_6`,

\[
h_{4,3}=F_6,
\qquad
\kappa_{4,3}=\rho_6.
\tag{25}
\]

So a genuinely noncommuting two-step weighted transport can reduce **exactly to one ordinary composite shell** before Mellinization.

## 6. Prior-art and novelty audit

No theorem-level novelty is claimed for the ingredients.

- Factorization (7) is the standard root-order decomposition of the cyclotomic composition `Phi_n(z^m)`; it is equivalent to the classical factorization of roots of unity by exact order. The related scaled/resultant cyclotomic spectralizations are already placed on the classical side by PC-125, which records Apostol's 1975 scaled-resultant theorem.
- Weighted composition operators, semigroup cocycles/semicocycles, and dilation-multiplication crossed products are standard operator-theoretic constructions. A directed check of the modern weighted-composition-semigroup literature finds this architecture to be established, not a new spectral mechanism. PC-186 had already placed the bare dilation-multiplication realization against the Bost--Connes/crossed-product novelty boundary.
- The Mellin factorization (23) is not a new zeta representation. It follows from the classical Ramanujan/Lambert transform already audited in PC-179.

The durable contribution is therefore a **Prime-Circle-specific obstruction**: the first canonical shell-dependent ordered operator product that genuinely escapes the linear flatness theorem of PC-186 does become noncommutative, but its entire finite holonomy is still a cyclotomic coboundary and its radial analytic content remains in the same finite shell/Mellin algebra.

Directed novelty searches did not locate a result using the exact quotient (5) as an RH mechanism. That absence is not used as evidence of novelty; the explicit reduction above is instead evidence that this route remains classical.

## 7. Boundary and research consequence

PC-187 rules out treating the following chain as a new Prime-Circle RH mechanism at finite level:

\[
\boxed{
\text{primitive-shell cyclotomic weight}
\to
\text{shell-dependent radial dilation}
\to
\text{ordered two-step holonomy}
\to
\text{new mixed-prime curvature / zeta spectrum}.
}
\]

The negative result is deliberately narrow. It does **not** classify:

- a second independent source field not generated by the same `F_n` family;
- matrix-valued shell-dependent transports whose noncommuting eigenspaces come from angular, chord, or old-new geometry;
- nonlinear couplings not expressible as finite products/ratios of the cyclotomic shell multipliers;
- growing-level or infinite products whose convergence/renormalization introduces analytic structure not present in a finite cyclotomic monomial;
- the nonlinear global uniformization/accessory-parameter sector.

For the accepted signed-radial-flux direction, the consequence is sharper than PC-186. **Merely making the canonical radial refinement transport shell-dependent and order-sensitive is not enough.** The first such ordered construction has nonzero finite holonomy, but that holonomy is only finite cyclotomic shell algebra with zero endpoint mass. A surviving candidate must demonstrate where an additional geometry-forced carrier enters before this coboundary reduction.
