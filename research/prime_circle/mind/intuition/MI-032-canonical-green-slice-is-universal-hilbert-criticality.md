# MI-032 — Canonical Green slicing has universal Hilbert core and classical one-channel relative edge zeros

**Evidence level:** exact/classical-mechanism synthesis from [PC-316](../../findings/PC-316-cross-level-poisson-products-generate-mordell-tornheim-packets.md), [PC-319](../../findings/PC-319-small-mordell-tornheim-coupling-preserves-off-critical-zeros.md)--[PC-321](../../findings/PC-321-large-mordell-tornheim-exponent-is-zero-free-on-right-polyhalfplane.md), and [PC-322](../../findings/PC-322-canonical-green-slice-is-classical-hilbert-criticality.md)--[PC-324](../../findings/PC-324-one-residue-green-controls-have-classical-hilbert-edge-zeros.md).

The canonical cross-level field of PC-316 contains a continuous additive exponent `u` through `(k+l)^(-u)`. PC-319--PC-321 show that its two easy limits fail oppositely: off-critical zeros persist near `u=0`, while sufficiently large `Re u` isolates the unique lowest output mode and removes zeros from the right polyhalf-plane.

PC-322 identifies a non-fitted intermediate value. Ordinary downstream Green inversion forces `u=1`, where `K_1(k,l)=1/(k+l)` is exactly the classical Hilbert kernel. This is the real `ell^2` transition: `0<u<1` is unbounded, `u=1` bounded noncompact, and `u>1` Hilbert--Schmidt. The accompanying vector threshold `Re s=1/2` occurs for every nonzero periodic source, so the critical axis is matched-control universal.

PC-323 asks whether retaining the **full cross-level operator** instead of one matrix coefficient restores arithmetic structure. For bounded periodic sources `a,b`, residue grouping gives

`X_(a,b)=A_(a,b) tensor H_1 + S`,  with `S` trace class,

and the finite channel matrix is rank one:

`A_(a,b)=L^(-1) a_L b_L^T`.

Its only nonzero singular value is `c_(a,b)=sqrt(mu_a mu_b)`, the product of the two RMS source norms. The canonical self-adjoint dilation therefore has essential spectrum

`[-pi c_(a,b), pi c_(a,b)]`

with one positive and one negative Hilbert absolutely-continuous branch. Detailed source structure can only enter through the trace-class relative defect.

PC-324 shows that even the most immediate relative spectral signal is not source-selective. For a one-residue periodic control, the residue decomposition has one nonzero block

`X=(AB/L) H_alpha`,  `alpha=(rho+sigma)/L`.

When `0<alpha<1/2`, the classical generalized-Hilbert eigenvector `u_n=(alpha)_n/n!` lies in `ell^2` and satisfies

`H_alpha u = (pi/sin(pi alpha)) u`.

Thus the self-adjoint dilation has discrete outliers

`lambda_±=±pi c/sin(pi alpha)`

outside the universal Hilbert band, and these are zeros of the PC-323 perturbation determinant. Their scale-free location depends only on the residue offset `alpha`; matched amplitudes can even preserve the canonical continuous band while retaining these classical outliers. Finite-section edge determinant anomalies in the same regime are likewise generalized-Hilbert phenomena.

The reusable distinction is therefore four-stage. Canonicality can select `u=1`; Hilbert geometry can select a `1/2` boundary; the full operator can retain only a universal one-band continuous core; and **off-band zeros of the relative determinant can still be generated by a single non-arithmetic residue channel**. None of these selects Riemann zeros.

Source specificity, if any, must now be demonstrated in genuinely multi-residue relative data: interference among several residue blocks, a scattering/spectral-shift relation absent from one-channel generalized Hilbert controls, or another invariant whose hypotheses exclude the classical edge mechanism. Only after that matched-control separation is proved does a zero-sensitive destination theorem become meaningful.

**Boundary.** PC-324 does not classify the canonical multi-residue discrete spectrum, embedded spectrum, resonances, full scattering matrix or spectral-shift function. It proves only that existence/location of simple off-band relative-determinant zeros is not an arithmetic discriminator by itself. A surviving multi-residue invariant still requires its own source-selectivity and RH bridge.
