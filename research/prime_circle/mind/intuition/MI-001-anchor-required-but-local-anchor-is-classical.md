# MI-001 — Anchoring is necessary, but finite cotangent memory still collapses to endpoint algebra

**Evidence level:** supported by exact and literature-backed structural reductions

## Core intuition

Breaking rotational symmetry by naming vertices or retaining old/new structure is necessary to avoid the coarsest Prime-Circle quotients, but neither rank, finite nonlinear depth, nor finite branching is evidence of new arithmetic information. For the intrinsic cotangent propagator, a large class of finite shell networks now closes under explicit endpoint reductions. The first genuinely unresolved cotangent information layer begins only after finite forest/displacement closure fails.

## Strongest justified principle

The earlier one-shell evidence already separated information capacity from information novelty. Pointed local spectra of a translation-invariant shell are derivative data of the full-shell characteristic polynomial; inverse-square divisor refinement is path independent; square-free metric and chiral blocks reduce to finite character packages; and high-rank old/new cotangent carriers can still carry only this classicalized data. Rank therefore does not certify a new arithmetic channel.

PC-087--PC-089 closed the first nonlinear escapes: intrinsic sector multiplication produces a coboundary carry phase, the cotangent Leibniz defect is Hochschild-exact, and one intermediate exact-order shell reduces to direct endpoint cotangent data, cyclotomic endpoint potentials, and a separable term.

PC-090--PC-095 extend that closure substantially. Reflection kills every odd fully contracted cotangent shell word. Complete exact-order shells make every remaining finite fully contracted scalar word Galois-rational. More importantly, arbitrary diagonal weights on intermediate shells do not rescue an interior tensor: the exact weighted two-hop identity keeps every finite serial path inside an endpoint-displacement algebra generated by direct cotangent blocks, endpoint profiles, rank-one terms, and return diagonals. Hermite's classical cotangent product identity eliminates arbitrary-valence hidden vertices, so finite acyclic multileg networks with pairwise-disjoint shell sets reduce to an endpoint forest algebra; for two exposed legs, off-path repeated shells may be absorbed into scalar messages as long as the exposed serial path satisfies the disjointness gate.

Thus **adding more finite shell memories, arbitrary shell-local weights, or finite tree branching does not by itself leave the endpoint/classical quotient**.

## What remains possible

The finite cotangent boundary is now specific. Repeated exact-order shells on a serial exposed path, coincidence strata, cycles, repeated-edge powers, and other constructions for which the rational cotangent partial-fraction elimination no longer applies remain open. So do genuinely different intrinsic operators/tensors, infinite-depth limits, the higher Hardy/Hankel trace algebra, and global uniformization/monodromy.

A surviving finite cotangent candidate must first prove that it lies outside the displacement/forest closure and then pass a matched non-prime/refinement control at that same interaction layer. Merely obtaining a nonzero rational scalar or a complicated endpoint profile is not enough.

## Status / novelty

The reductions use persisted exact findings; the multileg star identity is classical Hermite prior art. The synthesis is a supported boundary for finite cotangent-memory mechanisms, not a theorem about all nonlinear Prime-Circle constructions.

## Falsification criterion

Exhibit a finite serial or acyclic cotangent-shell network satisfying the hypotheses of PC-092/PC-094/PC-095 whose contracted observable contains an irreducible hidden-shell tensor not representable in the stated endpoint algebra. A positive advance should instead identify the first canonical cyclic/repeated-shell or different-operator construction that provably escapes those closures and survives matched controls.

## Lean-formalizable core

- Reflection parity of cotangent words.
- Galois invariance of complete-shell scalar contractions.
- Weighted two-hop endpoint-displacement identity.
- Hermite arbitrary-valence star reduction.
- Inductive elimination of finite shell trees.
