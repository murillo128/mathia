# Prime-circle research lines

This file holds the current mathematical questions suggested by the durable prime-circle intuitions. It is not a roadmap, task queue, status page, or history.

## Add a destination theorem that survives the autocorrelation quotient and matched controls

**Linked intuitions:** `MI-012-finite-scalar-cross-shell-fusion-is-closed-under-classical-packet-algebra` through `MI-039-green-hardy-band-control-is-short-interval-variance-in-fourier-coordinates`.

PC-295--PC-334 close the main scalar one-level, finite-Fourier, multivariable-radial and canonical Green routes as independent RH mechanisms. Mesh-scale recovery is a cyclic decoder, finite packet fusion remains classical Dirichlet data, multivariable lifts either decode the source or inherit ordinary analytic behavior, and the Green lift factors through universal Hilbert structure plus source autocorrelation. Its multiscale magnitude branch is equivalent to classical short-interval variance and admits an exact binary complement matched control.

A substantive continuation must therefore retain information lost by magnitude/autocorrelation quotienting — for example genuinely nonseparable phase coupling — or use a source amplitude/normalization the complement control cannot match, and then prove an independent zero-sensitive destination theorem. More spectral richness or source recovery is not enough.

## Treat scalar Mellin interpolation as an analytic-domain, growth and observation-family classification

**Linked intuitions:** `MI-040-endpoint-mellin-singularities-form-a-classical-von-mangoldt-jet` through `MI-044-full-shell-finite-measure-nullspace-is-only-the-universal-zeta-factor`.

PC-335--PC-341 progressively classify scalar semiprime-null Mellin selectors. Exact mixed-semiprime nulls force zeros at the prime logarithms. On a horizontal strip `S_a`, those points are a uniqueness set for bounded-characteristic functions exactly when `a>=pi/2`; at the native Gamma half-width `pi/2`, the selector collapses to the von Mangoldt endpoint, while every narrower strip admits a nonzero bounded Blaschke survivor.

PC-342 identifies the full-plane escape cost. Entire continuation alone does not restore uniqueness: any nonzero entire function vanishing at all but finitely many prime logarithms must have infinite order, because its zero count grows like `pi(e^r)~e^r/r`. Finite-order entire, Cartwright and exponential-type repairs are therefore excluded. At the same time, Weierstrass products with the prime-log zeros do exist, and reality/evenness/nonnegativity can be imposed, so arbitrary entire continuation still leaves survivors.

PC-343 closes a different loophole by strengthening the **observation family**, not the function class. If a finite Mellin-frequency measure annihilates every shell, divisor inversion upgrades the prime-log interpolation problem to zeros at every integer logarithm `log m`. Gamma decay gives only polynomial norm blow-up as the native strip boundary is approached, whereas a nonzero analytic function with all integer-log zeros would require `exp(c/delta)` blow-up. Hence the interpolation transform vanishes identically. Fourier uniqueness then leaves exactly the common zeta-factor kernel: for `sigma!=1`, the measure is supported on ordinates where `zeta(sigma+it)=0`; at `sigma=1` the kernel is trivial. In particular the finite-measure representation of the full Mangoldt shell response is uniquely `c delta_0`.

The analytic boundary is therefore three-part. Domain width and growth class govern what semiprime nulls alone can exclude, while the amount of shell data can change the zero-set geometry completely. Prime-log zeros permit narrow-strip or infinite-order survivors; all integer-log zeros are too dense for the boundary growth of any finite Mellin measure. But the resulting full-shell nullspace still contains only the **already explicit universal zeta zeros**, so this is a closure theorem for the representation, not a new zero-selection mechanism.

A proposed scalar escape must now say which information it removes from one of these gates. Infinite-order or otherwise uncontrolled semiprime interpolation is not enough if the full shell family is still available through a finite measure. To escape PC-343 one must leave the finite-measure/full-shell setting — for example through a genuinely different functional class, shell-dependent/nonlinear coupling or cross-shell geometry — and then prove that the surviving structure is independently zero-selective rather than another reformulation of the common zeta factor.

## Demand a zero-sensitive destination theorem before interpreting source distinguishability

Prime Circle now exhibits many ways to retain or even reconstruct source structure without selecting the Riemann divisor: cyclic decoding, multivariable source tensors, universal Hilbert criticality, trace-class relative spectra, autocorrelation energy, broad scalar analytic continuation and infinite-order entire prime-log zero carriers. PC-343 adds the opposite warning: a sufficiently complete scalar observation family can become rigid, yet its exact residual kernel may still be nothing more than the universal zeta factor already present in every shell.

The next proposal should state the source-sensitive zero/sign statement first and identify what extra information survives the relevant matched-control/no-go boundary. Source distinguishability, large analytic domain, very fast growth, sign-indefinite weighting, full-shell injectivity modulo known zeros or a hard band estimate count only after the surviving invariant is both control-resistant and independently coupled to the Riemann zero restriction.
