## Treat scalar Mellin interpolation as an analytic-domain-and-growth classification

**Linked intuitions:** `MI-040-endpoint-mellin-singularities-form-a-classical-von-mangoldt-jet` through `MI-043-prime-log-zero-sets-separate-strip-uniqueness-from-entire-growth`.

PC-335--PC-341 progressively classify scalar semiprime-null Mellin selectors. Exact mixed-semiprime nulls force zeros at the prime logarithms. On a horizontal strip `S_a`, those points are a uniqueness set for bounded-characteristic functions exactly when `a>=pi/2`; at the native Gamma half-width `pi/2`, the selector collapses to the von Mangoldt endpoint, while every narrower strip admits a nonzero bounded Blaschke survivor.

PC-342 now identifies the full-plane escape cost. Entire continuation alone does not restore uniqueness: any nonzero entire function vanishing at all but finitely many prime logarithms must have **infinite order**, because its zero count grows like `pi(e^r)~e^r/r`. Finite-order entire, Cartwright and exponential-type repairs are therefore excluded. At the same time, Weierstrass products with the prime-log zeros do exist, and reality/evenness/nonnegativity can be imposed, so arbitrary entire continuation still leaves survivors.

The analytic boundary is therefore not one-dimensional. Domain width and growth class trade against one another. The full native strip plus bounded characteristic is rigid; a narrower strip can support bounded survivors; the whole plane can support survivors only by paying infinite growth. A proposed scalar escape must state exactly which analytic class it controls and which additional semiprime/source constraints remain after the zero-set condition. Merely saying that the interpolation function is entire or globally continued is no longer informative enough.
