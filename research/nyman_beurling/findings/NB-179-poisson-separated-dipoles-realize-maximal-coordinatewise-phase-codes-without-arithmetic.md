**Date:** 2026-09-17  
**Status:** `DERIVED + MATCHED-CONTROL + CAPPED-TRANSPORT + COORDINATEWISE-DUAL + HADAMARD-CODE + NB-178-STRESS-TEST`.

`NB-178` identifies a viable escape from the jointly Hilbert compactness ceiling of `NB-177`: if individually capped-transport-contractive scalar probes produce an `N x N` response matrix with singular values on the `sqrt N` scale, then the approximate source complexity `mathfrak L_T(epsilon)` grows linearly in `N`. The open question there is whether such a dense phase code can arise from source-natural prime phases.

Before treating a successful code as arithmetic evidence, one must test whether the same response can already be generated by the bare capped-Poisson geometry. It can. A one-dimensional interval containing `2N` points separated by one Poisson width supports `N` disjoint signed dipoles and scalar capped-Lipschitz probes whose response matrix is **exactly a Hadamard matrix**, with no Euler product, prime frequencies, zeta values or Nyman structure involved.

More strongly, for this matched synthetic range the `NB-174` approximate source complexity can be computed exactly:

\[
\boxed{
\mathfrak L^{\mathrm{pack}}_{a,q,X}(\epsilon)
=
N(X-\epsilon)_+^2.
}
\]

Thus the coordinatewise nuclear certificate of `NB-178` is sharp on a purely geometric packing model. The result does not weaken `NB-174`, whose complexity is only a necessary resource for logarithmic Euler rescue. It sharpens the representation boundary of `NB-178`: **Hadamard-scale coordinatewise response by arbitrary capped-Lipschitz probes is not itself an arithmetic signature.** Any source-specific use must restrict how probes/templates arise or survive a matched-control comparison that excludes this Poisson-width packing mechanism.

## Claim

Fix `B>0`, `q>0`, `X>0` and `0<a<=1`. Let `N` be a power of two satisfying

\[
(2N-1)a\le 2B.
\tag{1}
\]

Then there exist `N` zero-mass finite signed measures

\[
\nu_1,\ldots,\nu_N
\]

supported on `[-B,B]` and `N` scalar linear probes

\[
\ell_1,\ldots,\ell_N
\]

such that:

1. every template has normalized capped-Poisson amplitude exactly `X`,

\[
\mathsf D_a(\nu_i)=qX;
\tag{2}
\]

2. every probe is coordinatewise contractive for the `NB-174`/`NB-178` norm,

\[
|\ell_k(\sigma)|
\le
\frac{\mathsf D_a(\sigma)}q
\tag{3}
\]

for every zero-mass finite signed measure `sigma` supported on `[-B,B]`;

3. their response matrix is

\[
\boxed{
A_{ik}:=\ell_k(\nu_i)=X(H_N)_{ik},
}
\tag{4}
\]

where `H_N` is the Sylvester Hadamard matrix, so

\[
AA^{\mathsf T}=X^2NI_N
\tag{5}
\]

and every singular value of `A` equals `X sqrt N`.

Let an adaptive family `t -> nu_t` have realized range exactly

\[
\mathcal R^{\mathrm{pack}}:=\{\nu_1,\ldots,\nu_N\}
\]

and let `mathfrak L^{pack}_{a,q,X}(epsilon)` denote its `NB-174` approximate linear source complexity. Then for every `epsilon>=0`,

\[
\boxed{
\mathfrak L^{\mathrm{pack}}_{a,q,X}(\epsilon)
=
N(X-\epsilon)_+^2.
}
\tag{6}
\]

In particular,

\[
\boxed{
\mathfrak L^{\mathrm{pack}}_{a,q,X}(0)=NX^2,
}
\tag{7}
\]

and `NB-178` certifies the exact value rather than merely a lower-order fraction of it.

Since a power of two can be chosen with

\[
N\asymp_B a^{-1}
\]

whenever `a` is sufficiently small, the bare one-dimensional capped-Poisson geometry already supports matched-control families with

\[
\boxed{
\mathfrak L^{\mathrm{pack}}_{a,q,X}(\epsilon)
\asymp_B
\frac{(X-\epsilon)_+^2}{a}.
}
\tag{8}
\]

No arithmetic input enters any of these statements.

## Construction

Choose `2N` points at exact Poisson-width spacing,

\[
y_j=-B+(j-1)a,
\qquad 1\le j\le 2N.
\tag{9}
\]

Condition (1) keeps all of them inside `[-B,B]`. For each row `i`, define the signed dipole

\[
\nu_i
:=
qX\bigl(\delta_{y_{2i}}-\delta_{y_{2i-1}}\bigr).
\tag{10}
\]

Its positive and negative Jordan parts each have mass `qX`, and their only coupling moves that mass by distance exactly `a`. Hence the capped cost

\[
d_a(u,v)=\min\left\{1,\frac{|u-v|}{a}\right\}
\]

is exactly one on the dipole endpoints, proving (2).

Now take the Sylvester Hadamard matrix `H_N`, available for every power of two and satisfying

\[
H_NH_N^{\mathsf T}=NI_N.
\tag{11}
\]

For each column `k`, prescribe values on the packed nodes by

\[
f_k(y_{2i})
=\frac12(H_N)_{ik},
\qquad
f_k(y_{2i-1})
=-\frac12(H_N)_{ik}.
\tag{12}
\]

Extend `f_k` linearly between consecutive nodes and constantly outside `[y_1,y_{2N}]`. Every nodal value lies in `[-1/2,1/2]`; across one spacing interval the endpoint difference is at most one. Therefore

\[
\|f_k\|_{\mathrm{osc}}\le1,
\qquad
\operatorname{Lip}(f_k)\le\frac1a.
\tag{13}
\]

Consequently, for all `u,v in [-B,B]`,

\[
|f_k(u)-f_k(v)|
\le
\min\left\{1,\frac{|u-v|}{a}\right\}
=d_a(u,v).
\tag{14}
\]

Define

\[
\ell_k(\sigma)
:=
\frac1q\int f_k\,d\sigma.
\tag{15}
\]

For any Jordan coupling `pi` between `sigma^+` and `sigma^-`, zero total mass gives

\[
\left|\int f_k\,d\sigma\right|
=
\left|\iint(f_k(u)-f_k(v))\,d\pi(u,v)\right|
\le
\iint d_a(u,v)\,d\pi(u,v).
\]

Taking the infimum over couplings proves (3). Finally, (10), (12) and (15) give

\[
\ell_k(\nu_i)
=
X\left(f_k(y_{2i})-f_k(y_{2i-1})\right)
=X(H_N)_{ik},
\]

which proves (4)--(5).

The construction is deliberately elementary. One may view (14) as a finite scalar Lipschitz-extension phenomenon, but no extension theorem is required: the piecewise-linear formula supplies the probes explicitly.

## Exact approximate complexity of the packed range

The lower bound is immediate from `NB-178`. Here `K=N`, all singular values of `A` equal `X sqrt N`, and hence

\[
\|A\|_*=X N^{3/2}.
\]

Substituting this into the coordinatewise certificate gives

\[
\mathfrak L^{\mathrm{pack}}_{a,q,X}(\epsilon)
\ge
\frac{
\left(XN^{3/2}-\epsilon N^{3/2}\right)_+^2
}{N^2}
=
N(X-\epsilon)_+^2.
\tag{16}
\]

The matching upper bound has no spectral input. Put

\[
\tau_i
:=
q\bigl(\delta_{y_{2i}}-\delta_{y_{2i-1}}\bigr),
\qquad
\mathsf D_a(\tau_i)=q.
\tag{17}
\]

If `0<=epsilon<X`, represent each range element as

\[
\nu_i
=(X-\epsilon)\tau_i+r_i,
\qquad
r_i:=\epsilon\tau_i.
\tag{18}
\]

The residual has capped transport `q epsilon`. Using the `N` normalized atoms `tau_i`, each coefficient row is one-hot with squared `ell^2` norm `(X-epsilon)^2`. Therefore the `NB-174` definition gives

\[
\mathfrak L^{\mathrm{pack}}_{a,q,X}(\epsilon)
\le
N(X-\epsilon)^2.
\tag{19}
\]

If `epsilon>=X`, put the whole template into the residual and use zero stationary coefficient energy, giving complexity zero. Combining with (16) proves (6).

Thus the phase-code witness is not merely feasible in the ambient geometry: on this family it is **optimal for the exact conditioning-weighted complexity currency introduced in `NB-174`**.

## Poisson-width packing supplies the entire code dimension

The only dimension limit in the construction is spatial packing at the source resolution. The interval has length `2B`, and each dipole consumes two nodes whose mutual and cross-dipole spacing is at least one Poisson width. Condition (1) therefore permits

\[
N\le \frac{B}{a}+\frac12.
\tag{20}
\]

Conversely, if `B/a` is large, choose the largest power of two below the right side of (20). It differs by at most a factor of two from that packing count. This yields (8).

The conclusion is representation-sensitive in exactly the way required by the research protocol. The `ell^infinity` probe architecture of `NB-178` can read one independent sign bit per Poisson-separated dipole and can reuse all such bits across Hadamard columns. This requires no prime phases. It is the generic coding capacity of a capped metric space containing a large equilateral subset.

By contrast, the canonical Euler witness of `NB-176/177` is jointly Hilbert contractive and cannot spend an independent unit of squared dual energy on every such code column. There is therefore no contradiction with the compactness ceiling of `NB-177`: the present construction escapes precisely by allowing the total joint `ell^2` probe budget to grow like `N`, which is the tariff already exposed in `NB-178`.

## Consequence for the arithmetic phase-code frontier

`NB-178` correctly identifies Hadamard-scale nuclear growth as sufficient to certify large `mathfrak L_T(epsilon)`. `NB-179` shows that the converse interpretation must be handled carefully: **observing such growth for arbitrary coordinatewise capped-Lipschitz probes does not show coherent prime-phase complexity.** The same matrix can be manufactured by a source-free matched control whose only structure is `a_T`-scale spatial separation.

This distinction matters especially at the positive source tolerance of `NB-174`. Scaling the dipoles by `X` makes the code amplitude `X`, so the certificate remains active whenever `X>epsilon`. In the high-ordinate regime where the meaningful tolerance is `epsilon_T` of order `log log T`, the synthetic construction can therefore remain fully visible whenever the template amplitude exceeds that resolution; nothing specifically arithmetic is needed to make its coordinatewise complexity large.

What remains source-specific is harder and better posed. A useful successor to `NB-178` must either:

- restrict the probes to a uniformly defined arithmetic class, for example probes obtained from a declared prime/Euler phase mechanism with its own complexity budget; or
- show that the **actual realized Nyman template range**, unlike the packed dipole control, cannot contain enough Poisson-separated signed directions to support the required dense code; or
- demonstrate a phase-code effect that persists after matching the capped-transport packing geometry in a non-arithmetic control.

These are alternatives for future derivation, not claims established here. The present finding only proves that the unrestricted coordinatewise witness class is too expressive to make Hadamard response itself an arithmetic discriminator.

## Self-adversarial audit

The construction does **not** produce logarithmic Euler rescue. `NB-174` gives a necessary complexity condition for positive-density rescue, not a sufficient one. A matched control may have enormous `mathfrak L_T(epsilon)` while its stationary responses are arithmetically useless. Thus (6) does not weaken the source-persistence obstruction; it only blocks one possible interpretation of a large dual certificate.

The templates are deliberately synthetic dipoles. No claim is made that natural Nyman--Beurling samplers contain them, approximate them, or can choose their signs independently. Proving such a statement would be new source-side input and is exactly what remains open.

The code dimension is limited by `a`-scale packing. At fixed positive `a` and fixed `B`, the construction has bounded `N`. Growth appears only as the Poisson width shrinks. This is consistent with the source geometry: the capped metric itself gains more distinguishable spatial cells as `a->0`.

The power-of-two restriction is inessential to the asymptotic conclusion because Sylvester matrices exist for every `N=2^m`. No Hadamard-conjecture assumption is used. A different bounded orthogonal code could remove even this sparse size restriction, but it is unnecessary here.

The factor `X` is genuine amplitude, not free probe rescaling. Every probe remains unit contractive in the normalized capped-transport dual, while each template has primal norm exactly `X`. If `X<=epsilon`, the exact complexity correctly collapses to zero because the whole range fits inside the allowed residual ball.

Finally, the argument depends only on the metric `d_a` and zero-mass signed transport. It would apply to any problem using the same bounded-Lipschitz quotient. That genericity is the point: the new information is a **matched-control falsification of arithmetic interpretation**, not a claim that the finite metric construction itself is novel functional analysis.
