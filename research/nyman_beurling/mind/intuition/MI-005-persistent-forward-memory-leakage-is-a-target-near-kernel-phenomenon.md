# MI-005 — Stable tails are global continuation phenomena constrained by source branching, not one-cell memory phenomena

**Evidence level:** supported by the causal/stable-tail theorems NB-063--NB-066, finite Schur characterization NB-067, boundary-chain control NB-068, and its source-specific exclusion by integer-dilation branching in NB-069; no bounded certificate for the actual Nyman source is yet proved.

NB-066--NB-067 show that a hypothetical persistent Nyman target is a global continuation problem. Its finite traces are natural, but the least compatible future norm diverges; finite normalized Schur complements converge to that continuation cost and therefore provide a source-only certificate.

NB-068 proves that the canonical one-cell memory map is not a substitute. A nearest-neighbor scalar chain can have `Gamma_R=0` at every step and still carry a one-dimensional stable boundary mode whose continuation constants and every finite Schur certificate diverge. Local causal bandwidth and vanishing one-step memory do not determine the tail.

NB-069 sharpens the matched-control boundary. The actual Nyman innovations satisfy an exact integer-dilation branching law: a coarse innovation is mapped isometrically to the normalized sum of a consecutive finer block. On Gram matrices this becomes a block-renormalization identity at every iterated dilation scale.

That extra source covariance kills the NB-068 chain. For uniformly bounded innovations, exact branching plus fixed finite Gram bandwidth forces all off-diagonal Gram entries to vanish. The tridiagonal nonorthogonal boundary chain is therefore not an admissible source-matched obstruction. The lesson is not that the stable tail has disappeared; it is that any surviving mechanism must be genuinely nonlocal or scale-growing while respecting the branch identities.

The reusable distinction is now four-way: **one-cell memory can vanish, global continuation can still be expensive, source branching can exclude cheap boundary controls, and the finite Schur geometry remains the place where the surviving global cost is measured**. A useful next theorem should combine the branching renormalization with the generalized-eigenvalue certificates rather than sharpen local leakage.

**Boundary.** NB-069 excludes bounded finite-band nonorthogonal controls under uniform norm bounds. It does not prove the actual Nyman stable tail is zero, bound the Schur certificates, or exclude long-range/scale-growing Gram mechanisms.
