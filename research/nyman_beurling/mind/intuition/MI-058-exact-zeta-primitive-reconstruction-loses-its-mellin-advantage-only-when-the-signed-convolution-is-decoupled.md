# MI-058 — Exact zeta-primitive reconstruction can be soft-localized into an entire source pairing before the Mellin advantage is lost

**Evidence level:** exact synthesis from [NB-218](../../findings/NB-218-exact-zeta-primitive-convolution-isolates-mellin-tariff.md) through [NB-220](../../findings/NB-220-gaussian-vertical-windows-give-entire-source-continuation.md), refining the absolute reconstruction obstruction in [NB-217](../../findings/NB-217-reciprocal-log-support-mass-prices-two-sided-mellin-reconstruction.md).

Let `sigma>1`, let `h` be a smooth logarithmic source shell supported away from `u=0`, and define the `j`-fold vertical primitive and its matched reconstruction kernel. Fourier inversion gives an exact signed convolution for the Euler shell. The factors `(log n)^j` and `(log n)^(-j)` cancel coefficient by coefficient **inside the convolution**, and every finite polynomial jet of the primitive is annihilated because the shell kernel vanishes to all moments at the origin.

NB-218 therefore separates the exact algebra from the absolute reconstruction tariff. The lower bound `||K_j||_1/|M_psi(h)|>=2pi/J_j(E)` applies when kernel and primitive are decoupled by absolute values; it is not an algebraic multiplier in the signed identity. For a moving shell `h(u)=phi(u-X)`, the source is a carrier-frequency Fourier coefficient of the zeta primitive, so a pointwise primitive envelope is not the native quantity.

NB-219 shows that the full vertical line can be localized without first destroying this structure. A compact smooth cutoff in the vertical variable transfers back to convolution with a Schwartz approximate identity in the logarithmic source coordinate, producing `O_A(V^-A)` source error on the natural `1+` line and preserving finite-jet annihilation to superalgebraic accuracy. Its only remaining source-side weakness is that exact compact vertical support creates noncompact Schwartz tails whose Euler series need not converge absolutely to the left of one.

NB-220 removes that weakness by changing the localization class rather than estimating the tail harder. A Gaussian-type soft vertical window has a Gaussian dual source profile. For any prescribed algebraic accuracy, its order can be fixed so that the localized moving shell differs from the original by `O_B(X^-B)`, while the modified Euler source series converges absolutely and locally uniformly for **every** complex `s`. The localized source pairing therefore has an entire source-defined continuation. Finite-jet annihilation remains Gaussian-small.

This changes the live bottleneck a second time. The infinite vertical tail does not need to be priced by `int |K P_j|`, and the dual source tail no longer obstructs continuation across `Re(s)=1`. Both losses can be removed **before** estimating the primitive by choosing a localization whose source pullback is negligible and entire.

The remaining obstruction is analytic identification rather than source convergence: one must relate the entire source-defined continuation back to the zeta-primitive representation and zero-free-region data after crossing `Re(s)=1`. Entire continuation of the Euler-side object does not by itself justify deforming a primitive contour through the pole/branch structure or prevent remote zeta singularities and horizontal pieces from reintroducing a global/absolute tariff.

The reusable lesson is that **proof-interface losses should be attacked at the representation level before destructive inequalities or continuation arguments are applied**. A global acquisition domain can be softened so that its dual source perturbation is both negligible and analytically better behaved. Once that is done, the true cost is the theorem that identifies the continued source object with the intended analytic observable in the destination region.

**Boundary.** NB-220 does not provide a Vinogradov--Korobov saving, a justified left-of-one primitive contour identity, a Nyman-distance improvement or the destination coupling from near-optimal approximants to this source coefficient. It proves that source localization and source continuation themselves need not pay those costs. The unresolved object is the entire soft-localized source coefficient tied back to zeta-primitive data across `Re(s)=1`.
