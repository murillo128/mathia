# MC-313 — Generalized Griesmer collapses at the source-code frontier, while generic rate-one-half codes match its coarse hierarchy

**Status:** `EXACT-DERIVED` · `LITERATURE+DERIVED` · `FRONTIER-REFINEMENT` · `NEGATIVE/OBSTRUCTION` · `CLASSICAL-MECHANISM` · `PRIOR-ART-AUDITED` · `NO-NOVELTY-CLAIM` · `NON-RH`.

## Claim

Continue the fixed-representative source-incidence code of `MC-312`. Thus

\[
C_A\le \mathbf F_2^n,
\qquad \dim C_A=R,
\]

is the full-rank binary code generated by the incidence rows of the chosen lower-prime representatives, every coordinate corresponds to an actual source prime, and

\[
Z:=\max U
\]

is the largest source prime in the common package. Let `d_t=d_t(C_A)` be the `t`-th generalized Hamming weight.

Before applying any generic coding upper bound, the source-cut argument of `MC-308` already gives the sharper direct inequality

\[
\boxed{
 d_t\log Z
 \ge
 \left(1-(2+o(1))\frac{R+1}{2^t}\right)\log y-O(1)
}
\tag{1}
\]

whenever the displayed exponent is positive. Indeed, take a `t`-dimensional subcode with support `J` of size `d_t`; `MC-308` gives `t_J\ge t`, `h_J\le R+1`, and therefore a source-product lower bound, while `P_J\le Z^{d_t}`.

The source-code pressure in `(1)` has an exact classical coding interpretation. For an erasure set `E\subseteq[n]`, write

\[
C(E):=\{c\in C_A:\operatorname{supp}(c)\subseteq E\}.
\tag{2}
\]

Then for every integer `s`,

\[
\boxed{
 d_t>s
 \iff
 \dim C(E)\le t-1\quad\text{for every }|E|\le s.
}
\tag{3}
\]

After erasing `E`, every compatible received word has a candidate list that is either empty or a coset of `C(E)`. Hence `(3)` is exactly the statement that `C_A` is adversarially erasure-list-decodable from `s` erasures with list size at most `2^{t-1}`.

This translation exposes two facts that sharply narrow the live route after `MC-312`.

First, replacing generalized Singleton by the classical **generalized Griesmer bound does not improve the source redundancy conclusion in the relevant regime**. For a binary `[n,R]` code the generalized Griesmer bound is

\[
 n\ge
 d_t+
 \sum_{i=1}^{R-t}
 \left\lceil
 \frac{d_t}{2^i(2^t-1)}
 \right\rceil.
\tag{4}
\]

If

\[
1\le d_t<2^t-1,
\tag{5}
\]

then every summand in `(4)` equals `1`, so `(4)` collapses **exactly** to

\[
\boxed{n\ge d_t+R-t,}
\tag{6}
\]

which is precisely generalized Singleton. In particular, with the `MC-312` choice

\[
t_R=\left\lceil2\log_2(R+1)\right\rceil,
\tag{7}
\]

one has `2^{t_R}-1\ge(R+1)^2-1`. Therefore for every candidate family with `n=O(R)`, necessarily `d_{t_R}\le n<2^{t_R}-1` for large `R`, and generalized Griesmer gives **no additional bit of redundancy** beyond `MC-312`.

Second, the asymptotic hierarchy forced at the natural source scale is not exotic from the viewpoint of generic binary codes. For all sufficiently large `R` there exists a full-length binary `[2R,R]` code `C` such that simultaneously for every

\[
t_R\le t\le R/2
\]

one has

\[
\boxed{
 d_t(C)>
 R-\left\lceil\frac{4R}{t}\right\rceil.
}
\tag{8}
\]

Thus at `t=t_R`,

\[
d_{t_R}(C)=R-O\!\left(\frac{R}{\log R}\right)=(1-o(1))R.
\tag{9}
\]

So the coarse `MC-312` conclusion `n\ge2R-o(R)` at source scale `Z\le y^{(1+o(1))/R}` is compatible with ordinary rate-one-half binary code geometry. The source-incidence route has reached a genuine boundary: **generic generalized-weight geometry can accommodate the required linear redundancy and near-half erasure resilience.** Any further coercion must use arithmetic realizability of the incidence columns, a quantitatively sharper second-order source-scale budget, several generalized weights jointly, or another structure absent from a generic binary code.

This is not an arithmetic construction of the endpoint representation, and no estimate for `M(x)` follows.

## 1. The source-product theorem directly lower-bounds the weight hierarchy

Choose a `t`-dimensional subcode

\[
D\le C_A
\]

with

\[
|\operatorname{supp}(D)|=d_t,
\qquad J:=\operatorname{supp}(D).
\]

The argument of `MC-312` identifies this support as a source cut for which the source-cut rank loss of `MC-308` satisfies

\[
t_J\ge t,
\]

while the quotient-simplex size always satisfies

\[
h_J\le R+1.
\]

Therefore `MC-308` yields

\[
P_J
\ge
 y^{1-(2+o(1))(R+1)/2^t}e^{-O(1)}.
\tag{10}
\]

Every coordinate in `J` is an actual source prime at most `Z`, so

\[
P_J\le Z^{|J|}=Z^{d_t}.
\tag{11}
\]

Combining `(10)` and `(11)` proves `(1)`.

This formulation separates the two ingredients that `MC-312` subsequently combined: arithmetic gives a **lower bound on `d_t log Z`**, while coding theory determines how large `d_t` can be forced from the ambient length `n`. It is therefore legitimate to ask whether a stronger classical bound on `d_t` versus `(n,R)` closes the remaining redundancy escape.

## 2. Generalized Griesmer is identically Singleton in the live regime

Helleseth, Kløve and Ytrehus proved a generalized Griesmer bound for higher support weights; a current geometric formulation is Theorem 1 of Kurz, Landjev and Rousseva. For an `[n,k,d_r]^{(r)}_q` code it states

\[
n\ge d_r+\sum_{i=1}^{k-r}
\left\lceil\frac{d_r}{q^i v_r}\right\rceil,
\qquad
v_r=\frac{q^r-1}{q-1}.
\tag{12}
\]

Taking `q=2`, `k=R`, and `r=t` gives `(4)` because `v_t=2^t-1`.

Under `(5)`, for every `i\ge1`,

\[
0<\frac{d_t}{2^i(2^t-1)}<1,
\]

so all `R-t` ceilings are exactly one. This proves `(6)` with no asymptotic loss.

The collapse is especially decisive at `(7)`. Any attempt to prove that the source package must have `n=cR+o(R)` with a larger constant `c`, while keeping the same `t_R`, remains entirely inside `d_{t_R}=O(R)\ll2^{t_R}`. The generalized Griesmer correction terms therefore cannot even start to distinguish such a candidate from the generalized Singleton envelope.

This kills a natural next refinement of `MC-312`: **the missing charge cannot come merely from swapping in generalized Griesmer at the same generalized weight.**

## 3. Generalized weights are exactly adversarial erasure-list dimensions

Fix an erasure set `E`. If two codewords agree outside `E`, their difference is supported in `E`; conversely, adding any word of `C(E)` preserves all unerased coordinates. Hence the set of codewords compatible with a fixed unerased pattern is either empty or an affine coset of `C(E)`, and its size is

\[
2^{\dim C(E)}.
\tag{13}
\]

By definition, `d_t\le s` exactly when some `t`-dimensional subcode is supported on some set of at most `s` coordinates, equivalently when there is an `E` with `|E|\le s` and `\dim C(E)\ge t`. Negating this gives `(3)`.

This connection is classical. Guruswami's work on list decoding from erasures explicitly identifies the earlier generalized-Hamming-weight bounds with adversarial erasure list decoding and shows that, as the allowed list size grows, achievable rates approach the erasure capacity. The present contribution is only the line-specific dictionary: `(1)` says that the arithmetic endpoint forces its **source-incidence code** toward a near-capacity erasure-list profile.

For `n\approx2R`, rate is approximately `1/2`. A generalized weight `d_t\approx R` means that after erasing almost half the source coordinates, the ambiguity space still has dimension below `t`, hence list size below `2^t`. With `t\asymp\log R`, that is only polynomial list size. This is a standard coding-theory regime, not by itself evidence of arithmetic impossibility.

## 4. A generic full-length rate-one-half control has the required coarse hierarchy

The following elementary probabilistic construction makes the previous boundary concrete and prevents the line from attributing arithmetic force to generic code geometry.

Choose `C` uniformly among the `R`-dimensional subspaces of `\mathbf F_2^{2R}`. Fix `t` and `s`. The expected number of `t`-dimensional subcodes whose support is contained in some `s`-coordinate set is at most

\[
\binom{2R}{s}
{ s\brack t }_2
\frac{{ R\brack t }_2}{{ 2R\brack t }_2},
\tag{14}
\]

where `{m\brack t}_2` is the Gaussian binomial coefficient. Indeed, there are at most `\binom{2R}{s}{s\brack t}_2` candidate `t`-subspaces supported inside an `s`-set, and a fixed `t`-subspace lies in a uniformly random `R`-subspace with probability

\[
\frac{{2R-t\brack R-t}_2}{{2R\brack R}_2}
=
\frac{{R\brack t}_2}{{2R\brack t}_2}.
\tag{15}
\]

Let

\[
c_2:=\prod_{j\ge1}(1-2^{-j})>0.
\]

The product formula for Gaussian coefficients gives uniformly

\[
c_2\,2^{t(m-t)}
\le {m\brack t}_2
\le c_2^{-1}2^{t(m-t)}.
\tag{16}
\]

Using `\binom{2R}{s}\le2^{2R}`, `(14)` is at most

\[
c_2^{-3}
2^{\,2R+t(s-R)-t^2}.
\tag{17}
\]

Now take

\[
s_t=R-\left\lceil\frac{4R}{t}\right\rceil.
\tag{18}
\]

For every `t` for which `s_t\ge t`, `(17)` is at most

\[
c_2^{-3}2^{-2R-t^2}.
\tag{19}
\]

Summing over `t_R\le t\le R/2` still gives `o(1)`. A uniformly random `R`-subspace has an identically zero coordinate with probability at most

\[
2R\,
\frac{{2R-1\brack R}_2}{{2R\brack R}_2}
=
2R\frac{2^R-1}{2^{2R}-1}
=o(1).
\tag{20}
\]

Therefore with positive probability neither failure occurs: the code is full length and has no `t`-subcode supported on `s_t` coordinates for any `t_R\le t\le R/2`. This proves `(8)` simultaneously.

This is only a **matched coding control**. Its nonzero columns are abstract binary incidence vectors; nothing here proves they can arise from actual lower-prime Legendre representatives with the required endpoint values and source products. That missing arithmetic realizability is precisely what the control isolates.

## 5. Prior art and novelty boundary

The coding ingredients are classical or explicit recent restatements:

- Helleseth, Kløve and Ytrehus, *Generalized Hamming weights of linear codes*, IEEE Transactions on Information Theory **38** (1992), 1133–1140, DOI `10.1109/18.135655`, develops higher support weights and generalized Griesmer-type bounds.
- Venkatesan Guruswami, *List decoding from erasures: bounds and code constructions*, IEEE Transactions on Information Theory **49** (2003), 2826–2833, DOI `10.1109/TIT.2003.815776`, makes the generalized-weight / erasure-list-decoding connection explicit and studies the rate/list-size tradeoff.
- Sascha Kurz, Ivan Landjev and Assia Rousseva, *Optimal codes and arcs for the generalized Hamming weights*, arXiv:2601.00250 (2026), Theorem 1, states `(12)` in the exact notation used here and attributes the generalized Griesmer result to the earlier literature.
- Ding, Jin and Xing, *Erasure List-Decodable Codes From Random and Algebraic Geometry Codes*, IEEE Transactions on Information Theory **60** (2014), 3889–3894, DOI `10.1109/TIT.2014.2314468`, proves that random linear codes attain the optimal erasure rate/fraction tradeoff away from capacity with list size `2^{O(1/\epsilon)}`.

A targeted literature check on 15 September 2026 found the generalized-weight, generalized-Griesmer, and erasure-list-decoding theories above, but no source coupling them to the specific lower-prime Legendre source-incidence representation used in `MC-307`–`MC-312`. **No standalone novelty claim is made.** The durable delta is the exact arithmetic-to-coding reduction `(1)`, the exact collapse `(5)`–`(6)` at the current scale, and the full-length generic-code control `(8)` showing which part of the source-redundancy escape is not arithmetically coercive by coding geometry alone.

## Boundaries and falsification tests

- **The random code is not an arithmetic realization.** It matches only the binary representation-code geometry. Its columns are not asserted to be attainable as lower-prime Legendre incidence vectors for the endpoint shell.
- **The result does not prove that `n=2R` is attainable by the source system.** It proves that ordinary binary coding constraints cannot rule out that scale at the coarse generalized-weight level.
- **Generalized Griesmer is killed only in the stated regime.** Once `d_t\ge2^t-1`, its extra ceilings can exceed one. At `t_R\asymp2\log R`, every `n=O(R)` candidate lies below that threshold, which is exactly the current redundancy regime.
- **The generic control gives a second-order deficit.** At `t_R`, `(8)` gives `R-d_t=O(R/\log R)`, not `O(1)`. A source-scale theorem precise enough to demand `d_{t_R}=R-o(R/\log R)` would therefore exceed this particular control and could reopen a coding obstruction.
- **The `o(1)` source-scale allowance matters.** The current `Z\le y^{(1+o(1))/R}` specialization permits relative slack of order `1/\log R`; such slack is large enough at the level of orders to coexist with `(9)`. An exact or much sharper source-prime cap could change the conclusion.
- **One generalized weight is not the whole hierarchy.** The control `(8)` handles a broad range simultaneously, but arithmetic may impose relations among all weights, column multiplicities, source-prime sizes, and representative products that random codes do not satisfy.
- **No RH or Mertens estimate follows.** This is a negative structural result about the representation-code branch of the localized endpoint program.

## Consequence for the research line

`MC-312` showed that a fixed endpoint representation must pay either source-coordinate redundancy or a larger individual source scale. The present finding says that the first escape is **not chargeable by the obvious next layer of generic coding theory**: generalized Griesmer reduces exactly to Singleton throughout the linear-length regime, and a full-length generic `[2R,R]` code can simultaneously have `d_t=(1-o(1))R` from logarithmic `t` upward.

The live target should therefore move from scalar code bounds to the arithmetic realization problem. A useful next theorem must exploit a property that a random binary code does not possess: for example, the fact that every column is attached to a concrete lower prime, that source supports represent quadratic characters on one common prime shell, that source-prime products carry analytic cost, or that the entire weight hierarchy must coexist with those product labels. Equivalently, one can sharpen the second-order budget enough that the `O(R/\log R)` generic erasure-list slack becomes visible. Replacing Singleton by another generic one-weight bound at the same scale is no longer a live route.
