# MC-314 — Second-order source-scale slack is exactly the generalized-weight defect currency

**Status:** `EXACT-DERIVED` · `LITERATURE+DERIVED` · `FRONTIER-REFINEMENT` · `NEGATIVE/OBSTRUCTION` · `PRIOR-ART-AUDITED` · `NO-NOVELTY-CLAIM` · `NON-RH`.

## Claim

Continue the reciprocal endpoint source-incidence code of `MC-312`–`MC-313`. Thus

\[
C_A\le \mathbf F_2^n,
\qquad \dim C_A=R,
\]

is generated by a fixed common package of lower-prime representatives, every source coordinate is an actual lower prime, and

\[
Z:=\max U
\]

is the largest source prime used by the package. Let `d_t=d_t(C_A)` be the generalized Hamming weights. The direct arithmetic source-cut inequality from `MC-313` is

\[
 d_t\log Z
 \ge
 \left(1-(2+o(1))\frac{R+1}{2^t}\right)\log y-O(1).
\tag{1}
\]

Take

\[
t_R:=\left\lceil2\log_2(R+1)\right\rceil,
\tag{2}
\]

and suppose `R\to\infty`, `R=o(\log y)`, while the common source package satisfies the sharpened natural-scale cap

\[
\boxed{
\log Z\le \frac{1+\eta_R}{R}\log y,
\qquad \eta_R\ge0,
\qquad \eta_R=o(1).
}
\tag{3}
\]

Then `(1)` gives the quantitative defect law

\[
\boxed{
R-d_{t_R}
\le
\frac{R\eta_R}{1+\eta_R}+2+o(1).
}
\tag{4}
\]

Consequently generalized Singleton yields

\[
\boxed{
n
\ge
2R-t_R-rac{R\eta_R}{1+\eta_R}-2-o(1).
}
\tag{5}
\]

The point is not another first-order `n\ge2R-o(R)` statement. Equation `(4)` identifies the **second-order source-scale slack** as the exact currency visible to the current one-weight coding reduction: a relative inflation `\eta_R` of the largest allowed source prime becomes an additive generalized-weight defect of order `R\eta_R`.

Two regimes are especially diagnostic.

### Exact natural source scale

If

\[
Z\le y^{1/R},
\tag{6}
\]

then `\eta_R=0`, so the integrality of `d_{t_R}` gives, for all sufficiently large parameters,

\[
\boxed{d_{t_R}\ge R-2}
\tag{7}
\]

and therefore

\[
\boxed{n\ge2R-t_R-2.}
\tag{8}
\]

If in addition `n=2R`, the erasure-list dictionary of `MC-313` turns `(7)` into a near-capacity statement. Every erasure set of size at most `R-3` leaves ambiguity dimension at most `t_R-1`, hence list size below

\[
2^{t_R-1}<(R+1)^2.
\tag{9}
\]

The code rate is `1/2`, while the erased fraction is

\[
\frac{R-3}{2R}
=\frac12-\frac{3}{2R}.
\tag{10}
\]

Thus a rate-one-half source code at exact natural source scale would have to be adversarially erasure-list-decodable with polynomial list size at a gap only

\[
\boxed{\frac{3}{2R}}
\tag{11}
\]

below the erasure-capacity boundary.

### Threshold for escaping the current random-code control

`MC-313` constructed a generic full-length `[2R,R]` binary matched control with

\[
d_{t_R}\ge R-O\!\left(\frac{R}{\log R}\right).
\tag{12}
\]

Equation `(4)` shows exactly how much sharper the source-prime scale would need to become before the arithmetic lower bound exits that **particular guaranteed control scale**. If

\[
\boxed{\eta_R=o(1/\log R),}
\tag{13}
\]

then

\[
R-d_{t_R}=o\!\left(\frac{R}{\log R}\right),
\tag{14}
\]

so the source theorem demands a generalized-weight profile strictly sharper, at the level of orders, than the profile certified for the random control in `MC-313`.

This does not prove that generic or explicit binary codes cannot satisfy `(14)`, and it does not prove that the arithmetic source package obeys `(3)` with `(13)`. It localizes the next useful theorem surface: **first-order natural-scale information `Z\le y^{(1+o(1))/R}` is too coarse; the current coding route only becomes genuinely more coercive once source-scale inflation is controlled on the `o(1/\log R)` relative scale, or through some independent arithmetic restriction on the joint weight hierarchy.**

No estimate for `M(x)` follows.

## 1. Derivation of the defect law

By `(2)`,

\[
2^{t_R}\ge(R+1)^2,
\]

so

\[
\frac{R+1}{2^{t_R}}\le\frac1{R+1}.
\tag{15}
\]

Substituting `t=t_R` into `(1)` gives

\[
d_{t_R}\log Z
\ge
\left(1-\frac{2+o(1)}{R+1}\right)\log y-O(1).
\tag{16}
\]

Using `(3)` on the left and dividing by `\log y` yields

\[
d_{t_R}\frac{1+\eta_R}{R}
\ge
1-\frac{2+o(1)}{R+1}-O\!\left(\frac1{\log y}\right).
\tag{17}
\]

Therefore

\[
d_{t_R}
\ge
\frac{R}{1+\eta_R}
\left(
1-\frac{2+o(1)}{R+1}
-O\!\left(\frac1{\log y}\right)
\right).
\tag{18}
\]

Since `R=o(\log y)`, rearranging `(18)` gives

\[
R-d_{t_R}
\le
R-\frac{R}{1+\eta_R}
+\frac{2+o(1)}{1+\eta_R}
+o(1),
\]

which is `(4)`.

Generalized Singleton says

\[
d_{t_R}\le n-R+t_R.
\tag{19}
\]

Combining `(4)` and `(19)` gives `(5)`.

For `\eta_R=0`, equation `(18)` is

\[
d_{t_R}\ge R-2-o(1).
\tag{20}
\]

Because `d_{t_R}` is integer-valued, `(7)` follows eventually. Equation `(8)` then follows from `(19)`.

## 2. Exact natural scale becomes a vanishing-gap erasure-list problem

For a coordinate set `E`, let

\[
C_A(E):=\{c\in C_A:\operatorname{supp}(c)\subseteq E\}.
\]

`MC-313` proved the exact equivalence

\[
d_t>s
\iff
\dim C_A(E)\le t-1
\quad\text{for every }|E|\le s.
\tag{21}
\]

Under `(7)`, take `s=R-3`. Then `d_{t_R}>s`, so every such erasure pattern has list size at most `2^{t_R-1}`. Since `t_R=\lceil2\log_2(R+1)\rceil`, one has

\[
t_R-1<2\log_2(R+1),
\]

which proves `(9)`.

For length `n=2R`, the source code has rate `1/2`; `(10)`–`(11)` follow immediately. Hence the exact natural source cap does not itself produce a contradiction. It converts the arithmetic endpoint into a much sharper coding target than the coarse `d_{t_R}/R\to1` statement: polynomial-list decoding from an erasure fraction approaching `1/2` at distance `O(1/R)` from capacity.

This is precisely the second-order regime hidden by the `o(1)` in the earlier source-scale formulation.

## 3. Comparison with the generic control is quantitative, not existential

The random-code construction in `MC-313` guarantees only

\[
R-d_{t_R}=O(R/\log R).
\tag{22}
\]

Equation `(4)` instead gives

\[
R-d_{t_R}\le R\eta_R+O(1)
\tag{23}
\]

throughout `\eta_R=o(1)`. Thus `(13)` is a sufficient scale at which the arithmetic requirement becomes `o(R/\log R)` and is no longer matched by the **proved guarantee** `(22)`.

This comparison must not be overstated. `MC-313` did not prove an upper bound saying that random or deterministic rate-one-half codes cannot do better than `(22)`. Therefore `(13)` does not by itself establish arithmetic impossibility, nor is it claimed to be a necessary condition for every possible coding obstruction. It identifies the resolution at which the existing matched control stops certifying compatibility.

The distinction matters operationally. Improving `(3)` only to, say,

\[
\eta_R\asymp1/\sqrt{\log R}
\]

would still leave a defect allowance much larger than `R/\log R` and would not beat the present control. Reaching `\eta_R=o(1/\log R)` would force the line to answer a genuinely sharper coding/realizability question rather than merely repeat the first-order redundancy argument.

## 4. Prior-art boundary

No new coding theorem is claimed. The generalized-weight/erasure-list equivalence used in `(21)` is classical and already anchored by MC-S50 (Guruswami, 2003). The generalized Singleton/Griesmer framework is anchored by the sources audited in `MC-313`, including MC-S51. MC-S52 records that random linear codes achieve the optimal erasure rate/fraction tradeoff at a **fixed positive gap** from capacity with bounded list size depending on that gap.

The regime exposed by `(9)`–`(11)` is different: the gap to capacity is `\asymp1/R` while the allowed list is polynomial in `R`. The fixed-gap result in MC-S52 cannot be converted into this statement by simply substituting a varying gap into constants proved only for a fixed parameter. A targeted literature check on 15 September 2026 of the generalized-Hamming-weight and erasure-list sources already attached to this frontier did not provide a theorem settling this exact growing-parameter regime. This is not a bibliographic-completeness claim.

Accordingly the durable Mathia result is not a coding novelty claim. It is the exact arithmetic bookkeeping `(4)`: the unresolved relative source-scale error `\eta_R` maps linearly to the generalized-weight defect `R-d_{t_R}`, and the exact natural scale maps the endpoint to the vanishing-gap erasure-list boundary `(11)`.

## Boundaries and falsification tests

- **The source cap is an additional hypothesis.** Existing findings do not prove `(3)` with `\eta_R=o(1/\log R)`, much less `\eta_R=0`. The result says what such a theorem would buy.
- **The fixed-representative package remains load-bearing.** `n`, `Z`, and `C_A` depend on the chosen common representatives. The inequalities apply to every fixed package satisfying the stated cap, but no canonical or optimal package is assumed.
- **The `o(1)` in `(1)` is harmless only in the stated regime.** The assumption `R=o(\log y)` removes the additive `O(R/\log y)` term after division. The inherited asymptotic error in the coefficient contributes only `o(1)` to `(4)` because `(R+1)/2^{t_R}=O(1/R)`.
- **Exact natural scale does not contradict coding capacity.** Equation `(11)` is a near-capacity requirement, not an impossibility theorem. A stronger coding bound or an arithmetic restriction on realizable columns is still needed.
- **MC-S52 does not supply a vanishing-gap theorem here.** Its fixed-parameter random-code statement is used only as a prior-art boundary, not extrapolated to `\epsilon\asymp1/R`.
- **Beating the MC-313 control is not the same as proving no binary control exists.** Equation `(13)` exits one proved matched-control scale; it does not classify optimal rate-one-half generalized-weight hierarchies.
- **No prime-shell occupancy theorem is obtained.** The result does not show that actual shell primes realize or fail to realize the endpoint cells.
- **No RH or Mertens estimate follows.** The result refines the necessary source-incidence geometry inside the localized endpoint program.

## Consequence for the research line

`MC-313` left two apparently different escapes: sharpen the source-prime scale, or find arithmetic structure beyond generic code geometry. Equation `(4)` shows that these are coupled rather than independent. A sharper source cap determines exactly how close the generalized weight must move toward `R`, and therefore exactly how close the associated erasure-list problem moves toward capacity.

The first useful source-scale target is no longer the qualitative statement `Z\le y^{(1+o(1))/R}`. At the current coding frontier, a theorem with relative slack `o(1/\log R)` is the scale that forces a generalized-weight defect smaller than the `O(R/\log R)` matched-control guarantee. The exact cap `Z\le y^{1/R}` would force `d_{t_R}\ge R-2` and expose the much sharper `O(1/R)` capacity-gap problem.

Thus the next productive question is precise: either derive this second-order control on actual lower-prime source representatives, or prove a realizability/joint-hierarchy obstruction strong enough to rule out the near-capacity source code directly. Further first-order manipulations of `n\sim2R`, `d_{t_R}\sim R`, or generic Singleton/Griesmer bounds will not change the frontier.
