# MC-296 — Endpoint defect partitions force almost-total Page source-cost inflation

**Status:** `EXACT-DERIVED` · `LITERATURE+DERIVED` · `FRONTIER-REFINEMENT` · `CLASSICAL-MECHANISM` · `PRIOR-ART-AUDITED` · `NO-NOVELTY-CLAIM` · `NON-RH`.

## Claim

Continue the localized Legendre-shell notation and Page source cost from `MC-293`–`MC-295`. Let

\[
\mathcal R_y
=\{r:y<r\le2y,\ r\text{ prime},\ r\equiv1\pmod4\},
\qquad N=|\mathcal R_y|,
\tag{1}
\]

let `H` be the binary span generated by the occupied lower-prime Legendre sign cells, and for `\lambda\in H^*` write

\[
x_\lambda
=\frac1N\sum_{r\in\mathcal R_y}(-1)^{\lambda(s(r))},
\qquad
 d_\lambda=\frac{1+x_\lambda}{2}.
\tag{2}
\]

Thus the preferred value is `-1`, and the defect set of `\lambda` is

\[
D_\lambda
:=\{r\in\mathcal R_y:(-1)^{\lambda(s(r))}=+1\},
\qquad
\frac{|D_\lambda|}{N}=d_\lambda.
\tag{3}
\]

Let `Q(lambda)` be the minimum lower-prime product source cost from `MC-293`. After choosing the same sufficiently small absolute `\kappa>0`, put

\[
D_y
=\exp\!\left(\kappa\frac{\log y}{\log\log y}\right).
\tag{4}
\]

`MC-293` gives `\varepsilon_y=O((\log y)^{-2})` and at most one nonzero Page-exceptional shell functional `\lambda_*` such that

\[
Q(\lambda)\le D_y,
\qquad
\lambda\ne0,\lambda_*
\quad\Longrightarrow\quad
|x_\lambda|\le\varepsilon_y.
\tag{5}
\]

Now let

\[
\lambda_1,\ldots,\lambda_R\in H^*
\tag{6}
\]

be linearly independent, and suppose their defect sets form an **exact endpoint partition** of the shell:

\[
\mathcal R_y
=D_1\sqcup\cdots\sqcup D_R,
\qquad
D_i:=D_{\lambda_i},
\qquad
d_i:=|D_i|/N>0.
\tag{7}
\]

Hence

\[
\sum_{i=1}^R d_i=1.
\tag{8}
\]

For `I\subseteq[R]` define

\[
\lambda_I:=\sum_{i\in I}\lambda_i,
\qquad
d(I):=\sum_{i\in I}d_i.
\tag{9}
\]

Then the whole Fourier profile of the selected span is forced by the partition weights:

\[
\boxed{
 x_{\lambda_I}
 =(-1)^{|I|}\bigl(1-2d(I)\bigr).
}
\tag{10}
\]

Consequently every nonempty subset `I` satisfying

\[
\left|d(I)-\frac12\right|>\frac{\varepsilon_y}{2}
\tag{11}
\]

obeys

\[
\boxed{
Q(\lambda_I)>D_y
}
\tag{12}
\]

except for at most one subset, namely the unique subset (if any) whose functional equals `\lambda_*`.

This already upgrades the source-cost conclusion from the **basis directions** in `MC-293`–`MC-294` to the **entire subset-sum spectrum** generated by an endpoint-saturating family.

There is a robust counting consequence. Assume additionally that

\[
d_{\min}:=\min_i d_i>\varepsilon_y.
\tag{13}
\]

Then the family of low-source-cost, nonexceptional subset sums is an antichain in the Boolean lattice. Therefore Sperner's theorem gives

\[
\boxed{
\#\{\lambda\in L\setminus\{0\}:Q(\lambda)\le D_y\}
\le
\binom{R}{\lfloor R/2\rfloor}+1,
}
\tag{14}
\]

where

\[
L=\langle\lambda_1,\ldots,\lambda_R\rangle
\cong\mathbf F_2^R,
\tag{15}
\]

and the `+1` pays for the possible Page-exceptional functional. Equivalently,

\[
\boxed{
\#\{\lambda\in L\setminus\{0\}:Q(\lambda)>D_y\}
\ge
2^R-inom{R}{\lfloor R/2\rfloor}-2.
}
\tag{16}
\]

Since

\[
\binom{R}{\lfloor R/2\rfloor}
=2^R\sqrt{\frac{2}{\pi R}}\,(1+o(1)),
\tag{17}
\]

an endpoint partition with `d_min>epsilon_y` forces

\[
\boxed{
1-O(R^{-1/2})
}
\tag{18}
\]

of the complete nonzero selected Fourier subspace to lie **above** the Page source-cost threshold.

The reciprocal-defect extremizer of `MC-295` is sharper still. If

\[
d_1=\cdots=d_R=\frac1R
\tag{19}
\]

and

\[
R=o((\log y)^2),
\tag{20}
\]

then eventually `epsilon_y<1/R`. Formula `(10)` becomes

\[
 x_{\lambda_I}
 =(-1)^{|I|}\left(1-\frac{2|I|}{R}\right).
\tag{21}
\]

Hence:

- if `R` is odd, **every** nonzero element of `L` has source cost `>D_y`, except possibly the single Page-exceptional functional;
- if `R` is even, every nonzero element outside the middle Hamming layer `|I|=R/2` has source cost `>D_y`, again except possibly one Page-exceptional functional.

For even `R`, exactly the parity used by the live `k=1` model in `MC-295`, this gives

\[
\boxed{
\#\{\lambda\in L\setminus\{0\}:Q(\lambda)>D_y\}
\ge
2^R-inom{R}{R/2}-2.
}
\tag{22}
\]

Thus the fixed-weight finite model from `MC-295` is not yet a source-cost-matched arithmetic control. Page theory says that any actual Legendre-shell realization of its one-defect endpoint behavior would have to place **almost its entire `R`-dimensional Fourier subspace**, not merely the `R` chosen generators, beyond the quasi-subpower source-cost scale `(4)`.

This is a genuine source-cost/multiplicity restriction of the kind left open after `MC-295`, but it is not a contradiction. A high-source-cost subspace of this size is not excluded by any theorem used here. No estimate for `M(x)` follows.

## 1. Endpoint partition gives the complete selected Fourier spectrum

Fix `I\subseteq[R]`, put `j=|I|`, and consider a shell prime `r`. By `(7)` there is exactly one index `z=z(r)` for which `r\in D_z`. Therefore

\[
(-1)^{\lambda_i(s(r))}
=\begin{cases}
+1,&i=z,\\
-1,&i\ne z.
\end{cases}
\tag{23}
\]

If `z\notin I`, all `j` selected signs are `-1`, so

\[
(-1)^{\lambda_I(s(r))}=(-1)^j.
\tag{24}
\]

If `z\in I`, exactly one selected sign is changed from `-1` to `+1`, so

\[
(-1)^{\lambda_I(s(r))}=(-1)^{j-1}.
\tag{25}
\]

The shell proportion with `z\in I` is exactly

\[
\sum_{i\in I}|D_i|/N=d(I).
\tag{26}
\]

Averaging `(24)`–`(25)` proves

\[
x_{\lambda_I}
=(-1)^j(1-d(I))+(-1)^{j-1}d(I)
=(-1)^j(1-2d(I)),
\]

which is `(10)`.

For equal defects `d_i=1/R`, `(10)` is precisely the `k=1` Krawtchouk multiplier already displayed abstractly in `MC-295`. The present point is that no flatness assumption on unused coordinates and no abstract Hamming-sphere model is needed: **the endpoint partition itself forces this spectrum on `L`**.

## 2. Page balance converts Fourier bias into source-cost exclusion

Because the `lambda_i` are linearly independent, the map

\[
I\longmapsto\lambda_I
\tag{27}
\]

is injective, and every nonempty `I` gives a nonzero shell functional.

Suppose `(11)` holds. Equation `(10)` gives

\[
|x_{\lambda_I}|
=|1-2d(I)|
>\varepsilon_y.
\tag{28}
\]

If `Q(lambda_I)<=D_y`, the Page dichotomy `(5)` therefore forces

\[
\lambda_I=\lambda_*.
\tag{29}
\]

Injectivity of `(27)` means that at most one subset can satisfy `(29)`. This proves `(12)`.

This is stronger than the short-relation conclusion in `MC-294` in one precise direction. `MC-294` used `|I|<=t` and a union bound to show that a short quotient relation cannot land inside a uniformly Page-cheap subspace. Under the endpoint partition, `(10)` knows the bias of **every** subset sum, including combinations with `|I|` of order `R`. The only potentially cheap nonexceptional combinations are those whose accumulated defect mass lies inside the narrow half-mass window `(11)`.

## 3. The half-mass window is an antichain when every defect exceeds the Page error

Let

\[
\mathcal F
:=
\left\{
I\subseteq[R]:
\left|d(I)-\frac12\right|\le\frac{\varepsilon_y}{2}
\right\}.
\tag{30}
\]

Assume `(13)`. If `I\subsetneq J`, then

\[
d(J)-d(I)
=\sum_{j\in J\setminus I}d_j
\ge d_{\min}
>\varepsilon_y.
\tag{31}
\]

But two numbers both belonging to the interval

\[
\left[\frac{1-\varepsilon_y}{2},
      \frac{1+\varepsilon_y}{2}\right]
\tag{32}
\]

can differ by at most `\varepsilon_y`. Therefore no two distinct members of `F` are comparable by inclusion. In other words, `F` is an antichain.

Sperner's theorem now gives

\[
|\mathcal F|
\le
\binom{R}{\lfloor R/2\rfloor}.
\tag{33}
\]

Every low-cost nonzero nonexceptional functional in `L` comes from an `I\in\mathcal F` by Sections 1–2. The possible exceptional functional contributes at most one further subset. This proves `(14)` and `(16)`.

The argument is deliberately elementary. A Littlewood–Offord concentration theorem can also control weighted subset sums near half mass under different hypotheses, but no such machinery is needed in the reciprocal-defect regime: the Page window is narrower than every individual defect, so ordinary Sperner width is already decisive.

## 4. Reciprocal defects leave only the middle Hamming layer

Under `(19)`,

\[
d(I)=|I|/R.
\tag{34}
\]

Condition `(20)` and `epsilon_y=O((log y)^-2)` imply

\[
\varepsilon_yR=o(1),
\tag{35}
\]

so eventually `epsilon_y<1/R`.

If `R` is odd, every integer `j` satisfies

\[
\left|1-\frac{2j}{R}\right|\ge\frac1R>\varepsilon_y.
\tag{36}
\]

Thus every nonzero subset sum is Page-forced above `D_y`, except possibly the unique exceptional mode.

If `R` is even, the only `j` with

\[
\left|1-\frac{2j}{R}\right|\le\varepsilon_y
\tag{37}
\]

is `j=R/2`. There are exactly `binom(R,R/2)` such subsets. All other nonempty subsets are forced high-cost, with at most one Page exception, proving `(22)`.

At the live scale `R\asymp\log\log y` suggested by the endpoint finite-structural frontier, `(20)` holds overwhelmingly. The middle-layer fraction is only `Theta(R^-1/2)`. Thus an arithmetic realization of the `MC-295` endpoint cannot be made source-cost-compatible by declaring only the chosen basis vectors expensive; almost every noncentral linear combination must be expensive as well.

## 5. Prior art and novelty boundary

The analytic input is entirely classical and already audited in `MC-293`: Landau–Page uniqueness and the prime-number theorem for nonexceptional real characters, in the growing-level form used there from Imre Ruzsa and Tom Sanders, *Difference sets and the primes*, Acta Arithmetica **131** (2008), arXiv `0710.0644`, Corollary 4.3 and Theorem 4.5. No new exceptional-zero theorem is claimed.

The finite-set input is Sperner's classical theorem: Emanuel Sperner, *Ein Satz über Untermengen einer endlichen Menge*, Mathematische Zeitschrift **27** (1928), 544–548, DOI `10.1007/BF01171114`. It states that an antichain of subsets of an `R`-element set has cardinality at most the middle binomial coefficient. Equation `(33)` is a direct application.

The equal-defect Fourier multiplier `(21)` is the degree-one Krawtchouk profile of the Hamming sphere, already treated as classical prior art in `MC-295`. A targeted literature search on 14 September 2026 found the Page/exceptional-character and Sperner/Boolean-lattice mechanisms separately, but no source asserting the Mathia-specific source-cost conclusion `(14)`–`(22)`. **No standalone novelty claim is made**: the durable delta is the exact composition of previously audited arithmetic balance with the endpoint defect-partition geometry.

## Boundaries and falsification tests

- **Exact endpoint partition is load-bearing.** Equation `(10)` uses that every shell point has exactly one defect. If defects overlap or leave a positive common preferred-sign cell, the spectrum acquires extra joint-intersection terms and the theorem does not apply unchanged.
- **The minimum-defect condition is quantitative.** The antichain bound `(14)` needs `d_min>epsilon_y`. Without it, nested subsets can both remain inside the Page half-mass window. The direct exclusion `(12)` remains valid without `(13)`.
- **Independence is load-bearing.** It makes the subset-sum map injective and ensures the Page exception can account for at most one subset. A dependent selected family may have many subsets representing the same shell functional.
- **One Page exception is retained honestly.** Nothing here removes a Landau–Siegel exceptional mode. It costs the explicit `+1` in `(14)` and the `-1` in the high-cost count.
- **Source cost is not quotient dimension.** Equations `(14)`–`(22)` force many individual functionals above `D_y`; they do not by themselves prove that those functionals require many independent high-cost source coordinates or that the ambient high-cost quotient is too small.
- **No arithmetic realization is asserted.** The theorem is conditional on an actual Legendre shell exhibiting the endpoint defect partition. It sharpens the cost that such a realization must pay; it does not construct or rule one out.
- **No critical-strip input is imported.** The only zero information is the unconditional Landau–Page exceptional-character dichotomy already used in `MC-293`. No zero-free continuation of `1/zeta(s)` near `Re(s)=1/2`, GRH, or Mertens bound enters.

## Consequence for the research line

`MC-295` showed that finite Fourier, entropy, participation, common-cell, and quotient-girth constraints admit a clean one-defect extremizer, leaving the possibility that the actual shell simply escapes into a sufficiently large high-source-cost quotient. The present finding makes that escape substantially more expensive: **at endpoint saturation, almost the whole selected Fourier subspace must be high source cost**, not merely the selected generators or a Hamming-separated quotient basis.

This still leaves a coherent escape, but it identifies a sharper next arithmetic target. A closing theorem now needs information about the **multiplicity/distribution of high-source-cost shell functionals** or a source-side structural restriction showing that an `R`-dimensional endpoint family cannot place `2^R-O(2^R/\sqrt R)` distinct subset sums beyond the Page threshold. Alternatively, an approximate-partition stability theorem strong enough to preserve `(10)` up to an error below the Page window could transfer the same pressure away from exact endpoint saturation. Further generic entropy or coding inequalities that ignore source-cost multiplicity will not address this new constraint.
