# Möbius-cancellation research lines

This file holds the current mathematical questions suggested by the durable Möbius-cancellation intuitions. It is not a roadmap, task queue, status page, or history.

## Convert forced source-incidence cost into arithmetic endpoint coercivity beyond generic code geometry

**Linked intuitions:** `MI-013-bost-connes-regularity-needs-an-intermediate-transverse-category` through `MI-037-source-incidence-cost-is-a-redundancy-scale-tradeoff`.

MC-293--MC-306 move from individual character cost through family energy, multiquadratic packaging, common radical and quotient occupancy, and show that the previous full-family scalar capacities can be simultaneously saturated by a matched disjoint-singleton control.

MC-307 forces complexity to survive every relevant target-coordinate projection. MC-308 dualizes this to source-prime cuts. MC-309 then uses Landau--Page to show that moderate-rank low-product quotients must have at least half occupancy apart from at most one exceptional frequency. MC-310 turns reciprocal equal-mass Page-cheap closure into the exact rank ceiling `t<=nu_2(R)` (or `nu_2(R)+1` with the Page exception), and MC-311 uses Bose--Burton to force at least `2^(R-nu_2(R))-O(1)` Page-expensive directions.

MC-312 resolves the first source-sharing question. Fix any common lower-prime representatives for the `R` endpoint generators, let `n` be the number of distinct source primes used and `Z` the largest. Generalized Hamming supports plus the MC-308 source-cut theorem give, for `t~2 log_2 R`,

`(n-R+O(log R)) log Z >= (1-o(1)) log y`.

MC-313 sharpens the hierarchy itself:

`d_t log Z >= (1-(2+o(1))(R+1)/2^t) log y - O(1)`.

It also identifies its exact coding boundary. At `t_R=ceil(2 log_2(R+1))`, generalized Griesmer is identically generalized Singleton throughout the `n=O(R)` regime, and generic full-length `[2R,R]` binary codes can simultaneously satisfy `d_t>R-O(R/t)` for `t_R<=t<=R/2`. Thus the current near-half erasure-list/generalized-weight demand is compatible with ordinary rate-one-half code geometry.

The live theorem is therefore no longer to strengthen the **generic** coding bound at the same scale. It must show that the arithmetic incidence columns cannot realize the generic control, derive a second-order source-scale restriction sharp enough to beat the `O(R/log R)` slack, force an incompatible joint generalized-weight profile, or identify another arithmetic source constraint. Either branch of the redundancy/scale tradeoff still has to be charged to the Möbius endpoint, but generic linear-code geometry alone cannot supply that charge.

## Keep target projection, source-cut quotienting, cheap-subspace closure, expensive-set density and arithmetic representation support distinct

MC-307 asks what remains when endpoint coordinates are deleted. MC-308 asks what remains when source coordinates are deleted and their span is quotiented out. MC-309 gives a Fourier occupancy floor for low-cost source cuts. MC-310 imposes a separate linear-closure condition on Page-cheap frequencies. MC-311 converts the absence of large cheap flats into a lower bound for the **number** of expensive directions. MC-312 turns generalized Hamming support into a prime-product cost, and MC-313 identifies that same hierarchy with adversarial erasure-list ambiguity.

These resources are not interchangeable. Half occupancy of a quotient does not imply a large cheap subspace; many cheap points need not close linearly; a large expensive complement need not have additive source costs; a large common source radical can be assembled either from many moderate coordinates or a few large ones; and a strong generic erasure-list profile need not be arithmetically realizable by lower-prime Legendre columns. Any closing argument must state which quotient/subspace is used, what representative package is fixed, how its source supports overlap, what largest-prime scale is allowed, and which **arithmetic realizability constraint** distinguishes it from a generic binary code.

## Preserve matched controls, now through the hereditary erasure-list profile

The exchangeable controls of MC-295/MC-298 show that low-order combinatorial regularity can coexist with forbidden parity. MC-306 proves aggregate capacities noncoercive; MC-307--MC-310 add hereditary projection/quotient and linear-subspace audits; MC-311 adds expensive-set density. MC-312 rules out an invertible re-encoding on only `R` equal-scale source coordinates, because generalized Singleton exposes a small-support subcode that must carry almost a shell-sized prime product.

MC-313 supplies the next matched control: a generic full-length rate-one-half binary code can satisfy the required generalized-weight hierarchy to the current coarse precision. A surviving arithmetic obstruction must therefore match the hereditary code profile **and then use structure generic codes do not have**. Replacing Singleton by generalized Griesmer, recounting expensive modes, or treating near-half erasure resilience as intrinsically arithmetic is obsolete. The next control/obstruction pair should focus on realizable Legendre-incidence columns, sharper source-prime scale, or genuinely joint hierarchy constraints.
