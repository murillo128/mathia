# Möbius-cancellation research lines

This file holds the current mathematical questions suggested by the durable Möbius-cancellation intuitions. It is not a roadmap, task queue, status page, or history.

## Improve or explain the linear-in-rank exact-endpoint source tariff

**Linked intuitions:** `MI-013-bost-connes-regularity-needs-an-intermediate-transverse-category` through `MI-067-exact-endpoints-force-superpolynomial-common-source-cost`.

MC-366--MC-376 separate exact-real source leakage, finite-resolution quotienting, average shell stability and the geometry of a hypothetical exact endpoint. MC-377 proves that every exact endpoint source package must escape every fixed-power common-radical regime: `log P/log y -> infinity`.

MC-378--MC-380 then make the escape quantitative. They combine a large source-character subspace, smooth-modulus character cancellation, endpoint-specific rough-squarefree terminal blocks and the observation that tiny source primes can be packed into an early exact factor rather than deleted.

MC-381 removes the remaining artificial rank loss. Under a trial bound `P<=y^A`, killing only source primes above one fixed shell power costs `O(A)` dimensions, not `O(A^2)`, and the frame contradiction needs only a fixed positive fraction of the `R` endpoint dimensions to survive. Consequently an exact endpoint cannot satisfy the trial bound whenever `A<=c_0 R` and `2^(C A) log log y=o(log y)`, and therefore

`log P/log y >= c min{R, log log y}`

for an absolute nonoptimized `c>0`.

The current frontier is no longer whether the rank-side source cost is merely superpolynomial: it is already **linear in the number of independent endpoint defect cells** until the analytic `log log y` ceiling takes over. A useful continuation should identify which remaining loss is intrinsic. Can the terminal differencing/character-sum architecture raise the `log log y` ceiling, improve the absolute linear constant, or replace common-radical size by a destination quantity closer to Möbius cancellation? Any improvement must use a genuinely new source-specific saving rather than reintroducing pruning losses already removed by MC-380--MC-381.

## Keep resolution, source incidence, conductor, common-radical cost and bias amplitude distinct

The current resource ledger separates exact-real subset-sum conditioning, finite-resolution quotienting, `l1` worst-case shell displacement, `l2` average dephasing stability, source-incidence balance, incidence-signature delocalization, package conductor, minimum primitive conductor, common-radical size and endpoint bias amplitude. These are not interchangeable.

MC-381 adds a particularly useful rank lesson: an analytic contradiction driven by exponentially many rows need not preserve `R-o(R)` source dimensions. If a fixed positive fraction remains, the exponential frame can still dominate polynomial and `2^(O(A))` losses. Thus codimension should be priced against the **actual amount of surviving combinatorial mass the terminal argument needs**, not against a default near-full-rank standard.

None of these source-cost bounds imply Möbius cancellation or establish an optimal source tariff. The endpoint argument must still specify which physical quotient is observed and how its source-cost obstruction reaches a destination quantity relevant to `M(x)`.

## Repair probabilistic comparators only after exact-stratum and algebraic-collapse gates

Probabilistic proxies remain secondary until their conditioning is arithmetically consistent and their observables survive exact multiplicative simplification. A model that becomes degenerate after conditioning on an exact arithmetic stratum, or whose auxiliary statistic collapses algebraically to `M(x)`, has not created an independent cancellation mechanism.

The source-cost results add another control: a plausible endpoint comparator must not hide the exact architecture inside a common source package whose cost violates MC-377--MC-381. Conditional finite-power models may still diagnose which modes or amplitudes would become expensive, but they cannot be used as evidence that an exact endpoint can actually inhabit that source regime.
