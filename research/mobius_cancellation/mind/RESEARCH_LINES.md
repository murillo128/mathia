## Improve the linear-in-rank exact-endpoint source tariff only by separating combinatorial and analytic ceilings

**Linked intuitions:** `MI-013-bost-connes-regularity-needs-an-intermediate-transverse-category` through `MI-068-iterated-q-vdc-has-an-intrinsic-loglog-source-horizon`.

MC-366--MC-376 separate exact-real source leakage, finite-resolution quotienting, average shell stability and the geometry of a hypothetical exact endpoint. MC-377 proves that every exact endpoint source package must escape every fixed-power common-radical regime: `log P/log y -> infinity`.

MC-378--MC-381 make the escape quantitative. Tiny source primes can be packed into an early exact factor rather than deleted, only source primes above one fixed shell power need to be removed, and the terminal frame contradiction needs only a fixed positive fraction of the endpoint dimensions. Consequently the common-source obstruction is already linear in rank until the analytic ceiling takes over:

`log P/log y >= c min{R, log log y}`.

MC-382 identifies the status of that `log log y` ceiling. In the present iterated q-van der Corput architecture, a source modulus `q=y^a` requires differencing depth at least `a-2-o(1)`, while even an ideal square-root terminal estimate leaves a saving exponent only of order `2^(-a+O(1))`. The frame argument needs that exponent times `log y` to diverge. Hence repacking factors or recovering more source rank inside the same architecture cannot push the supported source exponent beyond `a=O(log log y)` except by constants.

The live frontier is therefore split cleanly. The absolute constant in the linear-in-`R` regime may still be sharpened within the current architecture. **Beating the `log log y` horizon requires a qualitatively different analytic input**: a terminal estimate whose saving does not halve at every required factor, a collective/multilinear estimate that sees several source factors at once, or a different source-to-destination mechanism that avoids the q-vdC depth cascade.

## Keep resolution, source incidence, conductor, common-radical cost, differencing depth and bias amplitude distinct

The current resource ledger separates exact-real subset-sum conditioning, finite-resolution quotienting, `l1` worst-case shell displacement, `l2` average dephasing stability, source-incidence balance, incidence-signature delocalization, package conductor, minimum primitive conductor, common-radical size, q-vdC factor depth, terminal saving exponent and endpoint bias amplitude. These are not interchangeable.

MC-381 shows that an analytic contradiction driven by exponentially many rows need not preserve `R-o(R)` source dimensions: a fixed positive fraction can suffice. MC-382 supplies the complementary warning. Once the source exponent itself forces linearly many differencing stages, eliminating rank waste does not move the analytic horizon if every stage exponentially dilutes the final saving.

None of these source-cost bounds imply Möbius cancellation or establish an optimal source tariff. The endpoint argument must still specify which physical quotient is observed and how its source-cost obstruction reaches a destination quantity relevant to `M(x)`.

## Repair probabilistic comparators only after exact-stratum and algebraic-collapse gates

Probabilistic proxies remain secondary until their conditioning is arithmetically consistent and their observables survive exact multiplicative simplification. A model that becomes degenerate after conditioning on an exact arithmetic stratum, or whose auxiliary statistic collapses algebraically to `M(x)`, has not created an independent cancellation mechanism.

The source-cost results add another control: a plausible endpoint comparator must not hide the exact architecture inside a common source package whose cost violates MC-377--MC-381. MC-382 further says that failure of the present q-vdC terminal route beyond the log-log horizon is a method boundary, not evidence that the underlying source regime is impossible. Conditional finite-power models may still diagnose which modes or amplitudes become expensive, but they cannot be promoted to endpoint evidence merely because the current terminal estimate stops resolving them.
