# Möbius-cancellation research lines

This file holds the current mathematical questions suggested by the durable Möbius-cancellation intuitions. It is not a roadmap, task queue, status page, or history.

## Find shell rigidity beyond bounded-order Legendre pseudorandomness, or cancel the exact rough Möbius coset

**Linked intuitions:** `MI-013-bost-connes-regularity-needs-an-intermediate-transverse-category`, `MI-014-centered-parity-and-zero-mode-are-separate-currencies`, `MI-015-sign-support-covariance-gives-a-conditioned-quadratic-bridge`, `MI-016-source-aligned-shifts-face-a-defect-or-mertens-dichotomy`, `MI-017-first-shell-crt-common-mode-is-a-source-coupled-energy-coordinate`, `MI-018-nonnegative-transference-does-not-create-fixed-power-sign-balance`, `MI-019-shell-square-blindness-is-a-cross-prime-common-quotient-problem`.

MC-238--MC-246 reduce complete blindness to one rough Möbius coset and the quotient `Q=G/H`. MC-247--MC-251 translate support, prime-power torsion and shell occupancy into coding constraints, but the generic fixed-low-order rank deficit stays sublinear. MC-252 then shows that quadratic reciprocity alone supplies no missing rigidity: once column primes may leave `(y,2y]`, every finite binary matrix can be realized by genuine Legendre symbols.

MC-253 tests the first genuinely shell-local analytic resource. Heath-Brown's quadratic large sieve implies that almost every fixed-size XOR of actual shell columns is asymptotically balanced; in particular almost every column and pair looks pseudorandom at fixed parity order. But an explicit Walsh-character matrix with `N~k` has the same qualitative fixed-order balance, exact pairwise half-distance, and only rank `log_2 k`. Bounded-order shell pseudorandomness is therefore still rank-blind.

The live quadratic theorem must cross a stronger boundary: control parity products at order `t=t(y)` high enough to see possible blind relations, derive a shell-specific algebraic/analytic restriction that rules out low-dimensional spans without reducing to fixed moments, or bypass generation and prove signed cancellation for the exact rough Möbius coset. Higher-primary Kummer structure remains a separate possible source of rigidity.

## Keep localization, parity order, code rank and signed amplitude separate

MC-252 says residue-symbol arithmetic without localization is universal enough to model arbitrary codes. MC-253 says localization does create real fixed-order Fourier structure, but that structure is compatible with logarithmic rank. A useful invariant must therefore fail both controls: arbitrary separated-prime Legendre realizations **and** low-rank shell-like Walsh pseudorandomness. Pairwise near-orthogonality, fixed-order moment balance, generic code distance and signed Möbius cancellation are distinct currencies.
