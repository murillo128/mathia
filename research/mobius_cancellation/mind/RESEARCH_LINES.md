This file holds the current mathematical questions suggested by the durable Möbius-cancellation intuitions. It is not a roadmap, task queue, status page, or history.

## Exploit tight shell localization or cancel the exact rough Möbius coset

**Linked intuitions:** `MI-013-bost-connes-regularity-needs-an-intermediate-transverse-category`, `MI-014-centered-parity-and-zero-mode-are-separate-currencies`, `MI-015-sign-support-covariance-gives-a-conditioned-quadratic-bridge`, `MI-016-source-aligned-shifts-face-a-defect-or-mertens-dichotomy`, `MI-017-first-shell-crt-common-mode-is-a-source-coupled-energy-coordinate`, `MI-018-nonnegative-transference-does-not-create-fixed-power-sign-balance`, `MI-019-shell-square-blindness-is-a-cross-prime-common-quotient-problem`.

MC-238--MC-246 reduce the complete blind source to one rough Möbius coset and identify the quotient `Q=G/H`. MC-247--MC-251 couple witness support, prime-power torsion order, order-compatible shell occupancy and primary multiplicity, ending with q-ary Hamming sphere packing. The resulting generic fixed-low-order rank deficit grows but remains sublinear relative to the compatible shell.

MC-252 now rules out the simplest claim that quadratic reciprocity itself supplies the missing rigidity. If the column primes are allowed to escape the active shell, every finite binary matrix is realizable exactly as a lower-prime/upper-prime Legendre matrix by CRT, reciprocity and Dirichlet. Consequently every binary code of codimension at most `pi(y)` can occur as a separated-prime quadratic blind sector.

The live quadratic theorem must therefore use structure destroyed by that realization: above all the simultaneous localization `r in (y,2y]`, or another quantitative coupling between the lower-prime rows and the moving shell columns. Generic residue-symbol algebra, reciprocity identities, or another abstract coding inequality cannot distinguish the actual shell code from the separated-prime universal control. Higher-primary Kummer structure remains a separate possibility, as does bypassing generation and proving fixed-power signed cancellation for the exact rough Möbius coset / complete-annihilator aggregate.

## Keep support, torsion order, shell occupancy, code-family deficit, reciprocity algebra, localization and signed amplitude separate

MC-252 does not realize arbitrary codes inside `(y,2y]`; its CRT modulus is exponentially larger than the shell scale. That failure is the point. A useful new invariant must fail on the separated-prime Legendre realization while holding for the tightly localized shell. Future work should not count “arithmetic matrix” or “quadratic reciprocity” as such an invariant unless the argument genuinely consumes localization or another simultaneous source constraint.
