# Möbius-cancellation research lines

This file holds the current mathematical lines of investigation suggested by the durable Möbius-cancellation intuitions. It is not a roadmap, task queue, status page, or history.

## Recover first-absolute excursion from information that survives exact divisor-topology controls

**Linked intuitions:** `MI-004-mean-absolute-cancellation-needs-excursion-coupled-information`, `MI-012-checkpoint-rh-completeness-does-not-remove-source-information-burden`.

The endpoint is already sharp: square-root-scale first-absolute Mertens control on any unbounded checkpoint sequence is RH-complete. The source problem is therefore to derive that endpoint from information which actually retains excursion geometry.

MC-122--MC-132 close scalar local feedback, fixed finite memory, modular/product-state histograms, coarse time bins, fixed finite-horizon path types, arbitrary periodic clocks, and fixed or controlled-growing polynomial timestamp moments. MC-133 then tests a genuinely Möbius-specific representation rather than a generic matched word: Björner's divisibility complex. Its alternating Betti sum is exactly the terminal odd dyadic Möbius annulus, while its unsigned Betti mass is linear. MC-134 closes the obvious inter-scale repair at the level of ordinary one-parameter persistent homology: every reduced bar is exactly `[m,2m)` for an odd squarefree `m`, so all homological transport dies within one dyadic step and the signed live-bar count is still the same Mertens burden.

The surviving carrier must therefore preserve order or arithmetic relations not already determined by finite/quasi-polynomial summaries or the ordinary divisor-filtration barcode: a raw ordered occurrence process, a nonflattenable nested/multiscale relation, chain-level or labelled divisor structure, a genuinely different filtration, an adaptive/nonpolynomial statistic with a justified information budget, or another Möbius-specific constraint whose estimate is demonstrably cheaper than controlling `M` itself.

## Treat finite-state vocabulary growth as closed until it changes the order topology

Adding context length, modular height, finitely many future steps, periodic phases, or finitely/moderately many polynomial timestamp moments enlarges the state description but still admits exact macro-cycle controls. A proposed local enrichment should first be tested for whether it factors through a finite product-state/path-type summary before any cancellation meaning is assigned to it.

## Treat static homology and ordinary one-parameter divisor persistence as classified representations

MC-133--MC-134 show that exact divisor structure does not help merely by changing language. Static reduced homology repackages the signed target as the parity imbalance of two linear-size Betti masses, and the full ordinary persistence module is the explicit dyadic barcode `[m,2m)`. Long-lived homology, Betti magnitude, persistence lifetime, or any statistic determined by that barcode does not independently control Mertens cancellation.

A topological continuation must use structure not determined by the barcode and must prove a quantitative implication to first-absolute excursion that is weaker to establish than the endpoint itself. Merely retaining all birth times is not compression: those births already encode odd squarefree support and factor-count parity.

## Require the source theorem to be Möbius-specific where generic controls fail, but not merely target-equivalent

The generic matched controls do not satisfy Möbius multiplicativity, square-free support, prime values, or divisor identities, so exact arithmetic remains a legitimate escape. MC-133--MC-134 add the converse warning: a representation can be fully Möbius-specific and still carry the hard sign information in an equivalent form.

A positive theorem must identify an arithmetic relation that both forbids the order rearrangements used by the generic controls and yields an independently controlled quantity whose cost is strictly below the Mertens endpoint.

## Keep endpoint sparsity separate from source information

Dense checkpoint coverage is not the missing theorem. Once actual Möbius reaches the square-root first-absolute bound on an unbounded sequence, the endpoint implication is already available. Additional scale density matters only if it is part of a source mechanism that produces the bound.
