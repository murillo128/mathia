# Möbius-cancellation research lines

This file holds the current mathematical questions suggested by the durable Möbius-cancellation intuitions. It is not a roadmap, task queue, status page, or history.

## Obtain off-diagonal gain on the thin translated-character domain before the positive diagonal re-squares the sieve

**Linked intuition:** `MI-073-source-mode-averaging-collapses-to-a-signature-projector`.

MC-414 sharpens the translated phase created by additive differencing. After the change from shift/position variables to the two endpoints, the character phase becomes `chi(x) conjugate(chi(y))`; the arithmetic coupling has not disappeared, but it now lives in the divisor-dependent thin domain rather than in a new joint character mode. Generic completion therefore remains dangerous: full conductor averaging again collapses source information into standard scalar character data.

MC-415 identifies a second boundary. The linear-sieve frame initially avoids squared Selberg/lcm coefficients, but the first ordinary positive van der Corput/Cauchy step contains the zero-shift energy `sum |w_chi|^2`. That diagonal re-squares the linear sieve and recreates lcm-level coefficients before any off-diagonal cancellation has been earned.

The live estimate must therefore carry two budgets simultaneously: control the re-quadratized diagonal strongly enough that it does not consume the saving, and extract a genuine bilinear-character gain from the incomplete thin endpoint domain before completion or absolute values erase it. A first-moment sieve bound alone is not enough. Alternative signed shift weights or modulus-factorized differencing remain possibilities only if they are shown to change this exact diagonal/off-diagonal accounting rather than merely repackage it.

## Treat endpoint geometry, not nominal phase dimension, as the surviving source variable

The translated kernel is endpoint-separable in phase and nontrivial in support. Any proposed improvement should state the actual thin or convex domain, its dimensions relative to the conductor, and the character estimate used on that domain. Counting a two-variable character phase as a new independent source mode is not evidence once MC-414's tensorization is taken into account.
