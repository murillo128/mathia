MC-260 shows that the complementary support-sensitive route currently misses from the opposite side. For the Mathia shell this excludes `Q~R` throughout the canonical range and allows `Q~R^2` only for `c>1/4`, exactly where elementary support already reaches the square-root target. The hard regime `0<c<1/4` therefore sits between two existing theories: **KMT has the right modulus regime but a dense residual scale; sparse BDH has the right support scale but the wrong modulus regime.**

MC-261 resolves what the other logical exit `H=G` actually asks. For

`R=prod_(y<r<=2y) r`, `G=(Z/RZ)^*`, `H=<p mod R:p<=y>`,

the image of all `y`-smooth positive integers modulo `R` is exactly `H`. Thus `H=G` if and only if every reduced residue class modulo `R` has a `y`-smooth representative. Since `log R=y+o(y)`, the shell requires all-class generation by primes only up to `(1+o(1)) log R`.

That cutoff is far beyond what the currently audited generic theorems provide. Fixed-`A` smooth-number equidistribution allows moduli at most polynomial in the smoothness cutoff, while the shell has `R=exp((1+o(1))y)`; all-class products-of-primes and smooth-representative results likewise use prime factors at a fixed positive power of the modulus. The modulus itself is exceptionally smooth, but that is not the missing resource: the generator cutoff is exponentially shorter.

The live endpoint is therefore genuinely bifurcated. Either exploit the special contiguous shell to prove **logarithmic-scale simultaneous generation**, or control the single blind pretender / prove support-sensitive signed cancellation at the actual fixed or sub-square-root source modulus. Neither conductor descent, generic smoothness, polynomial-scale all-class generation nor a sparse theorem in the wrong modulus range resolves the source problem.
