# MI-019 — Shell-square blindness is a primary code problem whose generic deficits remain sublinear

**Evidence level:** proved for the shell-square full-annihilator geometry through MC-251. MC-247 supplies the conditional GRH/ERH support instance, while MC-248--MC-251 give deterministic implications from a stated witness/support bound. No full generation or fixed-power signed cancellation is proved.

MC-238--MC-246 identify smooth-dilation blindness with the annihilator of the subgroup `H` generated by small primes and invert the complete blind family to one rough Möbius multiplicative coset `-H`. The structural object is the quotient `Q=G/H`; blind index and coset density cancel exactly.

MC-247--MC-250 progressively couple active support, prime-power torsion order, shell occupancy and primary multiplicity. At level `d=ell^a`, the order-`ell` shadow is an `F_ell` code on shell primes `r=1 mod d`, with dimension `m_(ell,a)` and minimum distance at least the universal support floor `D_y`. Singleton gives the occupancy-slack bound `m_(ell,a)<=n_d-D_y+1`.

MC-251 sharpens the weak fixed-low-order regime by packing the whole code family at once. With `t_y=floor((D_y-1)/2)`, the exact q-ary Hamming bound is

`ell^(m_(ell,a)) V_ell(n_d,t_y) <= ell^(n_d)`,

so `n_d-m_(ell,a) >= log_ell V_ell(n_d,t_y)`. In a wide compatible shell this is `Omega(D_y log_ell(n_d/D_y))`, not merely `D_y-1`. At the Brun--Titchmarsh shell scale the unconditional fixed-order deficit rises to `Omega(log y log log y)`; under the ERH support floor it rises to `Omega(sqrt(y))`.

This is a real family-size squeeze but still not quotient collapse. For fixed low `ell^a`, the compatible shell has size about `y/log y`, so even the strengthened generic deficit is `o(n_d)`. An exponentially large low-order blind family remains compatible with generic coding theory.

The residual target is therefore more precise: exploit **arithmetic dependence beyond minimum distance**—reciprocity, residue-symbol column relations, generalized weights/distance profiles tied to the arithmetic matrix, or another simultaneous constraint—or bypass generation and control the signed rough Möbius coset directly. Merely improving a single-character support floor helps only if it becomes a positive fraction of the compatible shell.

**Boundary.** MC-251 is classical sphere packing applied to the arithmetic primary codes exposed by MC-250. It does not prove `Q=1`, estimate the rough-coset signed amplitude, or make the fixed-low-order deficit linear in shell size.
