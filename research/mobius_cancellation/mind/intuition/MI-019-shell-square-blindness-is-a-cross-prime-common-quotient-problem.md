# MI-019 — Shell-square blindness needs quantitative localization information beyond every fixed parity order

**Evidence level:** proved for the shell-square full-annihilator geometry through MC-253. MC-247 supplies the conditional GRH/ERH support instance; MC-248--MC-251 give deterministic coding consequences from stated support bounds; MC-252 is an exact separated-prime universality obstruction; MC-253 gives an unconditional fixed-order shell parity law and an exact low-rank matched control. No full shell generation, quotient collapse, or fixed-power signed cancellation is proved.

MC-238--MC-246 identify smooth-dilation blindness with the annihilator of the subgroup `H` generated by small primes and invert the complete blind family to one rough Möbius multiplicative coset. The structural object is the quotient `Q=G/H`; blind index and coset density cancel exactly.

MC-247--MC-251 couple active support, prime-power torsion order, shell occupancy and primary multiplicity. At level `d=ell^a`, the order-`ell` shadow is an `F_ell` code on compatible shell primes. Generic sphere-packing pressure improves the deficit but still permits a near-full-dimensional blind family.

MC-252 shows that bare quadratic-residue algebra cannot close the gap. Without the short moving shell, any finite binary matrix can be realized exactly as a lower-prime/upper-prime Legendre matrix. The missing resource therefore had to involve simultaneous localization or another coupling between lower rows and shell columns.

MC-253 proves that localization does produce genuine extra information: for every fixed parity order `t`, Heath-Brown's quadratic large sieve makes almost every `t`-column XOR asymptotically balanced over the lower-prime rows. Yet that entire information class is rank-blind. A Walsh-character matrix with `N~k` columns has exact pairwise half-distance and fixed-order normalized parity-bias mean square `O_t(1/k)`, while its binary rank is only `log_2 k`.

The missing quadratic resource is therefore more specific than shell pseudorandomness. It must see additive relations whose order grows with the shell, prove a direct shell-specific obstruction to low-dimensional column spans, or avoid rank generation entirely and control the exact rough Möbius coset by signed cancellation. Fixed-order large-sieve moments, pairwise distances and ordinary reciprocity identities cannot supply the needed quotient collapse by themselves.

**Boundary.** MC-253 is an average fixed-`t` theorem and gives no uniform control as `t` grows. The Walsh matrix is a matched information control, not a claim that the actual Legendre shell has logarithmic rank. Higher-primary residue/Kummer structure and direct signed control remain open. The durable conclusion is that any proposed shell invariant must distinguish the true shell from both separated-prime universality and low-rank bounded-order pseudorandom controls.
