# MI-019 — Shell-square blindness is a primary code problem whose missing rigidity is quantitative shell localization

**Evidence level:** proved for the shell-square full-annihilator geometry through MC-252. MC-247 supplies the conditional GRH/ERH support instance; MC-248--MC-251 give deterministic coding consequences from stated support bounds; MC-252 is an exact separated-prime universality obstruction. No full shell generation, quotient collapse, or fixed-power signed cancellation is proved.

MC-238--MC-246 identify smooth-dilation blindness with the annihilator of the subgroup `H` generated by small primes and invert the complete blind family to one rough Möbius multiplicative coset `-H`. The structural object is the quotient `Q=G/H`; blind index and coset density cancel exactly.

MC-247--MC-251 couple active support, prime-power torsion order, shell occupancy and primary multiplicity. At level `d=ell^a`, the order-`ell` shadow is an `F_ell` code on shell primes `r=1 mod d`, with minimum distance at least the universal support floor `D_y`. Sphere packing strengthens the Singleton deficit to

`n_d-m_(ell,a) >= log_ell V_ell(n_d,floor((D_y-1)/2))`,

but for fixed low order the compatible shell has size about `y/log y`, so the resulting generic deficit remains `o(n_d)`. A near-full-dimensional blind family is still compatible with generic coding theory.

MC-252 tests whether quadratic-residue arithmetic alone closes that gap. It does not. Once the tight column localization is removed, any finite binary matrix can be realized exactly as

`A_(p,r)=(1-(p/r))/2`

with row primes `p<=y` and arbitrarily large distinct column primes `r>y`. Hence every binary code of codimension at most `pi(y)` occurs as a genuine separated-prime Legendre blind sector. Quadratic reciprocity, CRT and primality therefore impose no useful rank/distance-profile rigidity by themselves.

The missing quadratic resource is now precise: **the same column primes must realize their complete lower-prime sign patterns while remaining in the short moving shell `(y,2y]`**. Any useful arithmetic dependence theorem must exploit that simultaneous size constraint, a shell-tied cross-column relation, or another source coupling absent from the separated-prime realization. If a proposed invariant survives arbitrary separated-prime Legendre realizations, it cannot by itself distinguish the Mathia shell from a generic code.

Higher-primary residue/Kummer structure is not ruled out by the quadratic theorem, and direct signed control of the rough Möbius coset remains an independent escape.

**Boundary.** MC-252 is deliberately nonquantitative in the column-prime sizes. It does not realize arbitrary codes in `(y,2y]`, estimate the actual blind quotient, or bound `M(X)`. Its durable content is that “use reciprocity” must now mean reciprocity plus localization or another quantitative simultaneous constraint, not residue-symbol algebra alone.
