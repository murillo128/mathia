# MI-019 — Shell-square blindness reduces to one rough Möbius coset; generic witness exponents cannot determine the quotient

**Evidence level:** proved for the shell-square full-annihilator geometry through MC-246; MC-247 gives the GRH/ERH `A=2` witness instance and MC-248 proves the deterministic fixed-`A>1` exponent barrier. No full generation or fixed-power signed cancellation is proved.

MC-238--MC-243 identify smooth-dilation blindness with the annihilator of the subgroup `H` generated by the small primes modulo the shell-square modulus. MC-244--MC-246 invert first the quadratic and then the complete blind family. Finite-group orthogonality turns the whole complete-annihilator contribution into one rough Möbius multiplicative coset `-H`; blind index and coset density cancel exactly.

This makes the true structural object the quotient `G/H`. Quadratic full rank sees only its elementary `2`-quotient: it says `[G:H]` is odd, not that `H=G`. Higher-order blind characters can therefore survive after every quadratic blind mode has vanished.

MC-247 uses the classical GRH/ERH proper-subgroup witness scale `O(log^2 q)` to force every nonprincipal blind character to involve `>>sqrt(y)/log y` shell primes. MC-248 abstracts the calculation. If a generic witness theorem has scale `W(q) <= C (log q)^A`, then blindness below `y` and the active conductor bound imply `k >> y^(1/A)/log y`.

For every fixed `A>1`, this is `o(n)` relative to shell dimension `n asymp y/log y`. Abstract binary linear codes with the same minimum-distance scale can still have parity-check rank only `O(y^(1/A))=o(n)`. Therefore no fixed superlinear log-conductor witness exponent can force full generation merely by excluding low-support relations.

The transition `A=1` only removes that power deficit. Linear-scale minimum distance can still coexist with a nontrivial kernel, so support alone remains insufficient. A uniform generic all-moduli `O(log q)` theorem is also impossible already in the quadratic prime-modulus subfamily, where classical lower bounds force least nonresidues above `log p` by an unbounded factor along infinitely many primes. This does not rule out stronger results specialized to the moving shell moduli; it says the needed gain must be **shell-specific simultaneous arithmetic**, not generic witness sharpening.

The two exact exits remain: prove `H=G` using simultaneous relations among the shell generators, or prove fixed-power signed cancellation of the one source-selected rough Möbius coset `-H` / complete-annihilator aggregate.

**Boundary.** The symbolic witness theorem in MC-248 is a scale classifier unless a specific literature theorem supplies it. MC-247's `A=2` instance is conditional. The coding construction is a matched information control, not an arithmetic blind code. None of these bounds estimates `[G:H]` or the signed rough-coset amplitude.
