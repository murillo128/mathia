# MI-019 — Shell-square blindness is a bipartite cross-prime problem invisible to several global quadratic summaries

**Evidence level:** proved for the shell-square full-annihilator geometry through MC-254. MC-247 supplies the conditional GRH/ERH support instance; MC-248--MC-251 give deterministic coding consequences from stated support bounds; MC-252 is an exact separated-prime universality obstruction; MC-253 gives an unconditional fixed-order shell parity law and an exact low-rank matched control; MC-254 gives an exact Rédei cross-block identification and a genuine-prime maximal-full-rank/low-cross-rank control. No full shell generation, quotient collapse, or fixed-power signed cancellation is proved.

MC-238--MC-246 identify smooth-dilation blindness with the annihilator of the subgroup `H` generated by small primes and invert the complete blind family to one rough Möbius multiplicative coset. The structural object is the quotient `Q=G/H`; blind index and coset density cancel exactly.

MC-247--MC-251 couple active support, prime-power torsion order, shell occupancy and primary multiplicity. At quadratic level the order-two shadow is an `F_2` code whose rows are lower primes and whose columns are shell primes. Generic coding pressure improves the deficit but does not force full generation.

MC-252 shows that bare quadratic-residue algebra cannot close the gap: without the short moving shell, arbitrary finite binary cross-prime matrices can be realized by genuine Legendre symbols. MC-253 shows that localization does create real information, since every fixed-order XOR of actual shell columns is asymptotically balanced for almost all column subsets. But a Walsh-character control has the same bounded-order balance and pairwise half-distance with only logarithmic rank. Fixed-order shell pseudorandomness is therefore rank-blind.

MC-254 closes a different apparent escape. For odd primes the shell matrix is literally a rectangular off-diagonal block `A` of the classical Rédei matrix. Nevertheless the full Rédei rank/corank sees the wrong kernel. If

`R = [[C,A],[A^T,E]]`,

then a shell-supported vector belongs to `ker R` only when it lies in `ker A ∩ ker E`. The shell-shell block can therefore eliminate every full-kernel witness while `ker A` remains large. This is not only abstract linear algebra: genuine primes `q_i=1 mod 4` can realize a path-Laplacian Rédei matrix of maximal rank `n-1` while a prescribed cut has cross-block rank exactly one. Thus even zero narrow class-group `4`-rank does not force the lower/shell Legendre block to generate.

The missing quadratic resource is consequently **bipartite and localized**. It must constrain `A` itself, control the action of the shell-shell block on `ker A`, use higher Rédei/Kummer data in a way that provably sees the lower/shell interaction, or bypass rank generation and estimate the exact rough Möbius coset by signed cancellation. Scalar full-matrix rank, ordinary `4`-rank, fixed-order parity balance, pairwise distance, and reciprocity identities all discard information that the destination needs.

**Boundary.** The MC-254 prime construction is deliberately nonlocal: CRT/Dirichlet realizes the matrix only by allowing the primes to separate arbitrarily, so it does not reproduce the actual fixed lower-prime set with columns constrained to `(y,2y]`. The Walsh and path-Laplacian families are matched controls, not claims about the true shell. Higher Rédei symbols, `8`-rank/governing-field information, higher-primary Kummer structure, growing-order shell estimates and direct signed control remain open precisely when they retain localization-sensitive cross-block information.
