# MI-019 — Shell-square blindness is a coding-rank problem after minimum-support growth is paid

**Evidence level:** proved for the shell-square subgroup geometry through MC-243; no fixed-power Möbius cancellation, annihilator triviality, full-rank theorem, or growing-support Fourier-decay theorem follows.

MC-238 identifies smooth-dilation blindness with the annihilator of the subgroup generated by primes up to `y`, equivalently the kernel over `F_2` of the Legendre-symbol matrix `A`. MC-239 shows that the whole prime-square congruence kernel is already generated and that every individual shell-prime factor is generated asymptotically. MC-240--MC-242 then force every surviving nonprincipal blind character to involve at least

`(1/log 2-o(1)) log log y`

shell primes.

MC-243 makes the remaining information loss explicit. Because the blind sector is literally the binary linear code `K_y(S)=ker A`, the MC-242 support floor is its minimum distance. Hamming sphere packing therefore converts it into the unconditional rank bound

`R_y(S) >= (1/(2(log 2)^2)-o(1)) log y log log y`

for the active first-shell scaling `n asymp y/log y` whenever the kernel is nontrivial; a trivial kernel already has full rank.

But minimum distance is the wrong statistic for deciding kernel dimension. Classical linear Gilbert--Varshamov controls exhibit abstract binary codes with the same double-logarithmic minimum distance and redundancy only `O(log y log log y)`, hence dimension `n-o(n)`. Even a one-dimensional kernel may have its only nonzero word supported on all `n` coordinates. Thus **large blind support does not imply few blind modes or annihilator triviality**.

This sharpens the previous collective-mode picture. The support theorem has not merely failed to reach the right numerical scale; it has compressed away the invariant now needed. Full quadratic generation is a rank/kernel-dimension statement, whereas MC-242 controls only one extremal codeword statistic. A useful next theorem must exploit arithmetic structure of the Legendre matrix to control rank or dependencies, count the surviving characters directly, or bypass dimension by proving that every surviving mode couples too weakly to the actual Möbius progression vector.

The reusable separation is: **support size, blind-sector dimension, arithmetic rank, Fourier decay, and signed source amplitude are different currencies**. Passing from one to another requires an explicit theorem; generic coding theory shows there is no implication from minimum support alone strong enough to close the current gap.

**Boundary.** MC-243 does not assert that the actual Legendre kernel is large or random-like. The Gilbert--Varshamov comparison is only an information-theoretic matched control showing what the minimum-support datum cannot force. The rank lower bound is real for the arithmetic matrix but remains `o(n)` and gives no Möbius cancellation estimate.
