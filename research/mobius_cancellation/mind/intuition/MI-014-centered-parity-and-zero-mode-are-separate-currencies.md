# MI-014 — The rough zero mode is protected from canonical transverse rearrangements

**Evidence level:** exact centered/zero-mode decomposition and representation-theoretic no-go results through MC-194

## Core intuition

The uncentered rough Möbius problem contains two different currencies: centered parity fluctuations and a principal scalar mean. The newer evidence shows that this is not merely a bookkeeping split. Across the canonical primorial symmetries tested so far, the principal mode is representation-theoretically protected from the transverse sectors.

## Strongest justified principle

MC-185 separates centered variance from the rough zero mode, while MC-186--MC-187 show that current classical cancellation makes the latter only subpower-small. MC-188 shows that smooth arithmetic-progression dispersion acts transversely and leaves the principal obligation behind. MC-190--MC-191 make this exact for unit-group-equivariant quadratic statistics and nested primorial transport: character sectors stay diagonal.

MC-192--MC-193 test the natural additive escape. Primitive additive shells are Gauss-weighted copies of coarse multiplicative character sectors, with the zero mode reappearing as a Ramanujan-sum component. MC-194 closes the residual shell-multiplicity loophole: the additive transform of one unit-supported source occupies a multiplicity-free invariant image, so all ambient copies of one character are rigidly tied to a single source Fourier coefficient.

## Program consequence

Do not expect transverse equidistribution, canonical CRT transport, or additive shell mixing to lend a fixed power to the principal mean. Either prove fixed-power cancellation for the rough zero mode directly, or identify a source-forced non-equivariant/non-diagonal relation whose action on the principal sector can be verified explicitly.

## Counterevidence / boundary

The no-go results cover canonical equivariant linear/Hermitian-quadratic transport and the full additive image of a single residue vector. They do not rule out genuinely nonlinear arithmetic identities, operations using extra source data, or cross-scale structures outside that representation category.

## Epistemic status
