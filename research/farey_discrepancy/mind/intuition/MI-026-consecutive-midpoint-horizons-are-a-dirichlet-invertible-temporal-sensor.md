# MI-026 — Midpoint temporal redundancy is relative to the admissible source class

**Evidence level:** exact synthesis from [FD-166](../../findings/FD-166-unbounded-complete-field-horizons-force-the-permanent-mobius-source.md), [FD-167](../../findings/FD-167-full-field-l2-inversion-has-uniform-square-root-prefix-conditioning.md), [FD-168](../../findings/FD-168-prefix-mobius-rows-give-coordinate-minimal-stable-partial-farey-sampling.md), [FD-169](../../findings/FD-169-unrestricted-mixed-measurements-collapse-to-target-rank.md), [FD-170](../../findings/FD-170-midpoint-horizon-path-is-a-dirichlet-invertible-temporal-sensor.md), [FD-171](../../findings/FD-171-midpoint-temporal-sensing-has-zero-exact-redundancy.md), [FD-172](../../findings/FD-172-dyadic-midpoint-sensing-rigidifies-bounded-squarefree-multiplicative-sources.md), and [FD-173](../../findings/FD-173-prime-power-annulus-hitting-exactly-classifies-sparse-midpoint-target-rigidity.md).

A Farey observation can be spatially tiny and still source-complete if the observation operator changes with horizon. FD-170 fixes the spatial point at `1/2` and records only the horizon path `P_a(H)=D_{H,a}(1/2)`. Its first difference is

`P_a(H)-P_a(H-1)=-(1/2)(u*a)(H)`,

with `u` the indicator of odd integers. Since the Dirichlet inverse of `u` is `mu` on odd divisors and zero on even divisors, every formal source coefficient is recovered by an explicit triangular divisor inversion when every horizon is observed.

FD-171 proves this temporal family has **zero exact redundancy over the unrestricted normalized formal source class**. In the invertible coordinate `b=u*(a-mu)`, the midpoint error at horizon `H` is a cumulative prefix sum of `b`. Omitting one horizon `k` leaves the pulse pair `b=e_k-e_(k+1)` invisible at every observed horizon, and pulling it back through `u^{-1}=mu_odd` gives a fixed integer-valued permanent source perturbation. On a finite prefix `2,...,K`, any selected horizon set `S` has exact row rank `|S|` and kernel dimension `K-1-|S|`.

FD-172 shows why that rank statement is not an intrinsic information lower bound once the admissible source fibre changes. Restrict to multiplicative squarefree-supported sources with `-1<=a(p)<=1`. For odd squarefree `m`, the transformed coefficient

`F(m)=(u*a)(m)=prod_(p|m)(1+a(p))`

is nonnegative. The dyadic midpoint error decomposes into nonnegative annular contributions, so a prime defect cannot be hidden by the signed pulse cancellation used in FD-171. Exact agreement with Möbius at `H=2,4,8,...` forces `a=mu`, and small dyadic errors bound each prime defect by the same error scale.

FD-173 identifies the exact sparse-horizon condition inside that same source class. For an observed set `mathcal H`, exact Möbius target-rigidity holds iff every odd prime-power orbit intersects the annulus union `U(mathcal H)=union_(H in mathcal H)(H/2,H]`: for every odd prime `p`, some `p^j` lies in an observed annulus. Exact zero error kills every nonnegative transformed coefficient in each observed annulus, while a missed complete prime-power orbit gives an explicit permanent source perturbation invisible at all observed horizons. The same hitting condition retains the uniform prime-defect stability modulus.

This classification shows that bounded multiplicative-gap coverage is not the right invariant. Every fixed integer geometric ladder `H={B^k:k>=1}`, including `B>2`, is target-rigid even though its annuli leave large multiplicative gaps: powers of each prime recur through the logarithmic observation window. What becomes expensive is **finite-scale certification**. For `B>2`, the first detected power of a given prime can occur far above the prime itself, so exact infinite-horizon identifiability need not provide a useful uniform source-scale-to-horizon bound.

The two regimes are therefore not contradictory. FD-171 is an ambient linear recovery theorem; FD-172--FD-173 are one-target rigidity theorems inside a nonlinear arithmetic cone. A temporal row can be linearly indispensable over arbitrary formal perturbations yet globally unnecessary for testing one distinguished target when source constraints turn surviving defects into positive mass repeated along arithmetic orbits.

The reusable lesson is that observation rank and redundancy must be computed *after* the source class, target notion and observation horizon geometry are fixed. In the restricted multiplicative cone, the correct sparse-sensing object is not the row count or even coverage of source locations, but whether the observation windows intersect every orbit on which a local source defect is forced to reappear.

**Boundary.** FD-173 still uses multiplicativity, squarefree support and the one-target Möbius comparison; it does not prove pairwise injectivity among arbitrary admissible sources or the RH-critical Franel--Landau estimate. The exact infinite-horizon sparse classification is closed in this class. The live acquisition question is quantitative: which horizon families hit every relevant prime-power orbit by a controlled height as the source scale grows, and how far can the multiplicative/positivity architecture be weakened without restoring signed null directions?
