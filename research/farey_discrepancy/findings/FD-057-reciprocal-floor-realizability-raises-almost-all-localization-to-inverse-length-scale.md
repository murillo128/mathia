# FD-057 — reciprocal-floor realizability raises almost-all localization to inverse-length scale

**Status:** `EXACT-DERIVED + SOURCE-SPECIFIC + RECIPROCAL-FLOOR-SAMPLING + ADAPTIVE-HOST-SPARSITY + ALMOST-ALL-MOBIUS + EXCEPTIONAL-SET-LOCALIZATION + ZERO-FRONTIER + NEGATIVE/ROUTE-RESTRICTION + JOINT-NONSQUAREFREE-OCCUPATION`.

`FD-056` compares a global almost-all short-interval exceptional set against the full additive transfer corridor around a zero-frontier shell spike. If

\[
A_X:=|\mathcal H(X)|=X^{\Theta+o(1)},
\qquad \frac12<\Theta<1,
\]

and the admissible transfer radius is

\[
R_X=A_XL_X,
\qquad L_X=X^{o(1)},
\]

then that corridor contains `X^(Theta+o(1))` integer starting points. A global exceptional estimate of the schematic form

\[
|\mathcal E_X|\ll X R_X^{-c+o(1)}
\]

can therefore beat the **whole corridor** by cardinality once

\[
c>\frac{1-\Theta}{\Theta}.
\]

That comparison is deliberately optimistic: the Farey/Jordan transfer cannot choose an arbitrary point of the corridor. Its source endpoint has to be generated by the reciprocal-floor map attached to an integer host row and a nearby nonsquarefree row. Keeping that realizability condition changes the counting scale.

There is an explicit family of admissible first-layer transfers with source starts

\[
\boxed{
\mathscr S_X
:=
\left\{
\left\lfloor\frac{qX}{q+2}\right\rfloor:
Q_X\le q\le2Q_X,
\ q\equiv2\pmod4,
\ q\ \text{squarefree}
\right\},
}
\tag{1}
\]

where

\[
Q_X:=\left\lfloor\frac{X}{R_X}\right\rfloor.
\tag{2}
\]

For all sufficiently large zero-frontier spikes,

\[
\boxed{
|\mathscr S_X|\asymp \frac{X}{R_X}
=X^{1-\Theta+o(1)}.
}
\tag{3}
\]

Every element of `mathscr S_X` lies inside the `FD-056` corridor, and its interval length is comparable with `R_X`. Thus the actual host-generated sample has reciprocal cardinality `X/R_X`, not corridor cardinality `R_X`. Since `Theta>1/2`,

\[
\boxed{
\frac{R_X}{X/R_X}
=\frac{R_X^2}{X}
=X^{2\Theta-1+o(1)}\longrightarrow\infty.
}
\tag{4}
\]

The distinction is polynomial.

Consequently, even under the deliberately stronger oracle in which **one common exceptional set** controls every interval length represented by (1), a cardinality-only argument can force one good realizable start from a bound

\[
|\mathcal E_X|\ll X R_X^{-c+o(1)}
\]

only at the inverse-length exponent

\[
\boxed{c>1.}
\tag{5}
\]

More precisely, `c>1` makes the exceptional budget `o(X/R_X)` and therefore forces a good member of (1), while `c<1` leaves enough cardinality for the exceptional set to cover the entire realizable sample. The endpoint `c=1` is constant- and subpower-sensitive and is not decided by exponent bookkeeping alone.

This sharpens `FD-056`: its threshold `(1-Theta)/Theta` is the best-case cost of pretending that every point in the additive corridor is selectable. Once the reciprocal-floor host geometry is retained, the relevant cardinality scale drops by the factor `R_X^2/X`, and the exponent threshold rises to the inverse-length scale `c=1`, independently of the zero-frontier value `Theta>1/2`.

## 1. The adaptive transfer samples a sparse reciprocal-floor set

The additive twin mechanism of `FD-054` starts from a squarefree row `q` at physical horizon

\[
T=qX
\]

and moves to a nearby nonsquarefree row. For rows

\[
q\equiv2\pmod4
\]

that nearest witness is exactly

\[
q^*=q+2,
\]

which is divisible by four. The source value sampled by the witness is

\[
x_q
:=
\left\lfloor\frac{T}{q+2}\right\rfloor
=
\left\lfloor\frac{qX}{q+2}\right\rfloor.
\tag{6}
\]

Because `X` is an integer,

\[
\boxed{
X-x_q
=
\left\lceil\frac{2X}{q+2}\right\rceil.
}
\tag{7}
\]

Take `q` in `[Q_X,2Q_X]`, with `Q_X=floor(X/R_X)`. Since `R_X=o(X)`, one has `Q_X->infinity`, and (7) gives uniformly

\[
\boxed{
(1+o(1))R_X
\le X-x_q
\le(2+o(1))R_X.
}
\tag{8}
\]

Hence every such witness asks for cancellation on an interval of the same power scale as the `FD-056` transfer radius. These are not arbitrary starts in `[X-CR_X,X]`; they are values of one monotone reciprocal-floor map.

The congruence restriction is compatible with squarefree hosts. Writing `q=2m`, the conditions `q squarefree` and `q=2 mod 4` are equivalent to `m` being odd and squarefree. The standard squarefree-density argument therefore gives

\[
\#\{Q_X\le q\le2Q_X:q\equiv2\pmod4,\ q\ \text{squarefree}\}
\asymp Q_X.
\tag{9}
\]

Only a positive-density lower bound is needed here; no short-interval squarefree theorem is involved because the host interval has fixed relative length.

It remains to check that different hosts really provide different source starts. If `q_1<q_2` both satisfy `q_i=2 mod 4`, then `q_2-q_1>=4` and

\[
\frac{2X}{q_1+2}-\frac{2X}{q_2+2}
=
\frac{2X(q_2-q_1)}{(q_1+2)(q_2+2)}.
\tag{10}
\]

For `q_i<=2Q_X`, the right side is

\[
\gg \frac{X}{Q_X^2}
\asymp \frac{R_X^2}{X}.
\tag{11}
\]

Along a zero-frontier spike `R_X=X^(Theta+o(1))` with `Theta>1/2`, expression (11) tends to infinity. Thus the ceilings in (7) are eventually strictly distinct on this congruence class. Combining this with (9) proves (3).

The same exponent survives any subpower enlargement of the host or witness family. If `q` is allowed to range through an `X^{o(1)}` multiplicative band around `X/R_X` and a nearby row `q+d` is required to keep the quotient displacement `O(R_X)`, then

\[
d\ll \frac{R_Xq}{X}=X^{o(1)},
\]

so the number of admissible pairs `(q,d)` remains at most

\[
\frac{X}{R_X}X^{o(1)}
=X^{1-\Theta+o(1)}.
\tag{12}
\]

Thus (3) is not an artifact of choosing the particular increment `d=2`; it exhibits the correct power cardinality of the local reciprocal-floor channel.

## 2. Cardinality-only localization now has an inverse-length threshold

To isolate the localization issue from every other analytic loss, grant an oracle stronger than the available almost-all theorems. Assume that there is a **single** exceptional set `mathcal E_X` of starts such that every interval represented by the admissible family (1), despite its varying length in the band (8), has the needed Möbius/source cancellation whenever its start is outside `mathcal E_X`.

Suppose only that

\[
|\mathcal E_X|
\ll X R_X^{-c+o(1)}.
\tag{13}
\]

By (3), cardinality alone certainly forces a nonexceptional realizable start if

\[
X R_X^{-c+o(1)}
=o\!\left(\frac{X}{R_X}\right),
\]

which is exactly

\[
R_X^{1-c+o(1)}\to0.
\tag{14}
\]

Every fixed `c>1` satisfies (14). Conversely, if `c<1`, then the permitted exceptional budget is larger than the whole set `mathscr S_X` by a power of `R_X`; a set obeying the global cardinality bound can therefore contain all realizable starts. No conclusion is possible from cardinality alone. At `c=1`, the two sides have the same principal order and constants or additional structure become decisive.

This proves the exponent threshold (5). It should be read as a statement about what **global counting by itself** can certify. It is not a claim that an exceptional set from a particular theorem actually concentrates on `mathscr S_X`.

The common-exception-set assumption makes the obstruction stronger, not weaker. Existing almost-all estimates are normally stated at a specified interval length or scale; different lengths may have different bad starts. If one has to union exceptional sets over many represented lengths, the localization burden can only increase. Equation (5) therefore remains a best-case necessary benchmark for any route that refuses to use structure of the host-generated set beyond its size.

## 3. Why the 2026 almost-all theorem is even farther from the adaptive sample

`FD-056` records the 2026 theorem of Matomäki--Radziwiłł--Shao--Tao--Teräväinen: for the Möbius function at lengths `H>=X^(1/3+epsilon)`, arbitrary fixed logarithmic cancellation is available outside a global exceptional set of size

\[
O_{K,\varepsilon}\!\left(\frac{X}{(\log X)^K}\right).
\tag{15}
\]

On a zero-frontier spike with `Theta>1/2`, every length in (8) lies safely above the one-third power threshold. The cancellation strength is therefore not the issue. But relative to the realizable sample,

\[
\frac{X(\log X)^{-K}}
{X/R_X}
=
\frac{R_X}{(\log X)^K}
=
X^{\Theta+o(1)}(\log X)^{-K}
\longrightarrow\infty
\tag{16}
\]

for every fixed `K`.

Thus the published global exceptional budget can contain the **entire reciprocal-floor sample** many times over. This is a stronger mismatch than the corridor comparison in `FD-056`, where the denominator was `R_X`; here the denominator is only `X/R_X`.

The same warning applies to schematic power-saving exceptional bounds with `c<=1`. Even if their cancellation error were ideal and even if one granted a common bad set across the whole length band, their cardinality alone does not force contact with a good host-generated start. An almost-all theorem useful here must therefore carry more than a global measure estimate: it needs local density or avoidance information relative to the reciprocal-floor sample, or an exceptional budget genuinely below inverse length.

## 4. Relation to the live joint-occupation route

This result does not move a shell spike to a new nonsquarefree row and does not prove a lower bound for `U_(H,D)/E_(H,D)`. It instead sharpens the obstruction identified in `FD-056` to one of the most natural attempts to do so below the `FD-055` all-interval range.

The surviving analytic targets are now more specific. A theorem uniform for **all** intervals in the near-critical range would bypass exceptional localization entirely. An almost-all theorem could also work if it controls the exceptional set *inside the sparse reciprocal-floor image* or proves that these starts avoid the bad set for arithmetic reasons. Finally, a genuinely inverse-length exceptional estimate, with effective strength beyond the `c=1` boundary and sufficient cancellation error, would beat the sample by cardinality alone.

What no longer looks sufficient is a generic density-zero statement, an arbitrary logarithmic exceptional saving, or even a power-saving exceptional law with exponent below one. The Farey/Jordan geometry consumes almost all of the ambient freedom before the short-interval theorem is invoked.

The conclusion is compatible with `FD-054` and `FD-055`. Above the deterministic threshold, or in the all-interval range where source cancellation is known uniformly, one can select the required host directly and no exceptional-set hitting problem arises. `FD-057` concerns only the attempted replacement of that uniform input by global almost-all information in the low-row adaptive regime.

## 5. Prior-art and falsification boundary

The load-bearing external comparison remains Theorem 1.1(i) of Matomäki, Radziwiłł, Shao, Tao and Teräväinen, *Higher uniformity of arithmetic functions in short intervals II. Almost all intervals*, Inventiones Mathematicae **244** (2026), 967--1091, already anchored in `SOURCES.md` by `FD-056`. A targeted search around Möbius cancellation on prescribed sparse starting sets, reciprocal/floor-selected starts, and adaptive short intervals did not locate a theorem matching the present host-generated sampling problem. No broad novelty is claimed for reciprocal-floor monotonicity, squarefree density, or the elementary counting argument itself, and no new external theorem is needed, so `SOURCES.md` remains unchanged.

The decisive checks are explicit. The spike exponent `Theta>1/2` is needed for `R_X^2/X->infinity`, which makes the chosen reciprocal-floor starts distinct. The host interval in (9) has fixed relative width, so only ordinary squarefree density is used. The threshold `c>1` is an exponent-level cardinality statement under an intentionally favorable common-exception-set oracle; the endpoint `c=1` is not settled. Most importantly, the finding must not be cited as showing that the actual exceptional set contains the adaptive sample, as ruling out structural avoidance, as proving positive nonsquarefree occupation, or as improving a Möbius short-interval theorem. Its exact contribution is the realizability correction from corridor size `R_X` to adaptive sample size `X/R_X`, and the resulting inverse-length localization threshold.
