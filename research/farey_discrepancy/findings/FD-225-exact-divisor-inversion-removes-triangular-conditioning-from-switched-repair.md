## Claim

The exponential `17^J` triangular-conditioning loss in FD-222--FD-223 is not intrinsic to the divisor-reservoir geometry. The complete reservoir response matrix has an exact arithmetic inverse, and using all divisor reservoirs rather than one pivot per switched row makes the entire sampled integer-multiple grid essentially constant.

Retain the periodic scheduler

\[
q_t=\begin{cases}
0,&t\equiv0\pmod3,\\
3,&t\equiv1,2\pmod3,
\end{cases}
\qquad
q(n)=q_{\lfloor\log_2 n\rfloor},
\]

with

\[
\mathcal C_q^X(n)=(T-I)^{q+1}X(n),
\qquad (TF)(n)=F(2n),
\]

and put

\[
\Phi(x)=\frac{(\log x)^{3/5}}{(\log\log x)^{1/5}}.
\]

Fix `0<beta<1`. There is a constant `kappa_beta>0` such that, for all sufficiently large integers `N` and every

\[
1\le J\le \kappa_\beta\Phi(N),
\]

there is one deterministic sequence

\[
\xi_n^{(N)}\in\{-1,0,1\},
\qquad
(\xi_n^{(N)})^2=\mu(n)^2,
\qquad
\xi_1^{(N)}=1,
\]

satisfying globally

\[
\boxed{
\xi_{pn}^{(N)}=-\xi_n^{(N)}
\quad(p\le\beta N,\ p\nmid n).
}
\]

Let

\[
e_j=j+q(2^jN)+1,
\qquad
E=\max_{0\le j<J}e_j,
\qquad
D=2^E,
\]

so `2^J<=D<=8*2^J`, and write

\[
X_N(x)=\sum_{n\le x}\xi_n^{(N)}.
\]

Then the source can be chosen so that for one integer

\[
A\asymp_\beta\frac{N}{D\log N}
\]

one has the stronger full-grid flattening

\[
\boxed{
X_N(mN)=2A+\varepsilon_m,
\qquad
|\varepsilon_m|\le1
\quad(1\le m\le D).
}
\]

Consequently every scheduled observation in the block is uniformly bounded,

\[
\boxed{
\max_{0\le j<J}
\left|
\mathcal C_{q(2^jN)}^{X_N}(2^jN)
\right|
\le16,
}
\]

while

\[
\boxed{
X_N(N)=2A+O(1)
\asymp_\beta\frac{N}{D\log N}
=N^{1-o(1)}.
}
\]

Thus FD-223 can be strengthened from a subpower observation bound `O(D)` to an absolute `O(1)` bound on the same Vinogradov--Korobov-scale horizon range. More importantly, the proof no longer inverts the `J x J` triangular switched-response matrix at all. Its `17^J` condition estimate was an artifact of the pivot-only repair, not a structural capacity obstruction.

## 1. The complete divisor-reservoir response operator

Use exactly the floor-stable reservoirs of FD-223. Thus

\[
h=
\min\left\{
\frac{1-\beta}{2},
\frac{1}{2(D+1)}
\right\},
\qquad
I_d=((d-h)N,dN),
\quad1\le d\le D.
\]

For sufficiently large `N`, every reservoir lies above `beta N`, the intervals are disjoint, and every core-prime flip `r in I_d` has the exact response

\[
\Delta X_N(mN)
=
2M\!\left(\left\lfloor\frac md\right\rfloor\right)
\qquad(1\le m\le D).
\tag{1}
\]

The same selected-Euler source representation as FD-222--FD-223 is being used here: start with physical core signs, flip only squarefree core primes above the locked cutoff, and extend each core sign through the exact Euler cube generated by primes at most `beta N`. Since `D=N^{o(1)}`, eventually every quotient in (1) has all of its prime factors below the locked cutoff, so (1) is an exact source-side identity, not a transform-space surrogate.

For an integer vector `c=(c_1,...,c_D)`, define the unscaled response operator

\[
(\mathscr A c)(m)
=
\sum_{d\le m}
c_dM\!\left(\left\lfloor\frac md\right\rfloor\right),
\qquad1\le m\le D.
\tag{2}
\]

One prime flip contributes twice this kernel. FD-005 used the special identity

\[
\sum_{d\le m}M\!\left(\left\lfloor\frac md\right\rfloor\right)=1,
\]

which says simply that `\mathscr A 1=1`. The full operator is just as explicit.

## 2. Exact inverse by one ordinary difference and one divisor sum

Let `y(0)=0`. Then

\[
\boxed{
\mathscr A c=y
\quad\Longleftrightarrow\quad
c(n)=\sum_{d\mid n}\bigl(y(d)-y(d-1)\bigr)
\quad(1\le n\le D).
}
\tag{3}
\]

Indeed, expanding the Mertens kernel gives

\[
(\mathscr A c)(m)
=
\sum_{d\le m}c_d
\sum_{a\le m/d}\mu(a)
=
\sum_{k\le m}(c*\mu)(k).
\tag{4}
\]

Taking an ordinary first difference in `m` yields

\[
y(m)-y(m-1)=(c*\mu)(m).
\]

Dirichlet-convolving with the constant-one function and using `\mu*1=\varepsilon` gives (3). Conversely, reversing those two steps proves that every integer target vector `y` is attained by an integer reservoir-count vector `c`.

This is a unimodular arithmetic inversion of the **full** divisor-response table. There is no exponential forward-substitution factor. Quantitatively,

\[
|c(n)|
\le
\tau(n)
\max_{d\le n}|y(d)-y(d-1)|.
\tag{5}
\]

The standard elementary divisor bound `max_{n<=D} tau(n)=D^{o(1)}` is sufficient below; no sharp divisor estimate is needed.

## 3. Flatten the whole grid instead of cancelling switched rows one at a time

Choose, for every `1<=m<=D`, an integer

\[
y(m)=\operatorname{nint}\!\left(-\frac{M(mN)}2\right),
\tag{6}
\]

where `nint` denotes any nearest integer, and put `y(0)=0`. Then

\[
\varepsilon_m:=M(mN)+2y(m)
\]

is an integer with

\[
|\varepsilon_m|\le1.
\tag{7}
\]

Let `c` be the exact inverse (3). Independently choose a positive common occupancy

\[
A=
\left\lfloor
a_\beta\frac{N}{D\log N}
\right\rfloor
\tag{8}
\]

with `a_beta>0` sufficiently small. In reservoir `I_d`, flip exactly

\[
A+c(d)
\tag{9}
\]

core primes. The next section verifies that these counts are nonnegative and remain within the available prime capacity.

Assuming that capacity check for the moment, equations (1)--(3) and `\mathscr A1=1` give, for every `m<=D`,

\[
\begin{aligned}
X_N(mN)
&=M(mN)
+2\sum_{d\le m}(A+c(d))
M\!\left(\left\lfloor\frac md\right\rfloor\right)\\
&=M(mN)+2A+2y(m)\\
&=2A+\varepsilon_m.
\end{aligned}
\tag{10}
\]

This flattens **every integer-multiple sample** through `DN`, not merely the dyadic points entering the switched rows.

Every `\mathcal C_q=(T-I)^{q+1}` has coefficient sum zero, so the common `2A` disappears. For the scheduler `q in {0,3}`, the coefficient `l^1` norm is at most

\[
2^{q+1}\le16.
\]

All samples used by a row lie among `mN` with `m<=D`. Equation (7) therefore gives the claimed uniform observation bound `<=16`.

At the first prefix,

\[
X_N(N)=2A+\varepsilon_1,
\]

so the large defect is retained automatically; no separate argument excluding pivot reservoirs below `N` is needed.

## 4. The inverse correction fits the same Vinogradov--Korobov reservoirs

It remains to show that `c(d)` is much smaller than the common occupancy (8). Use the same unconditional Mertens estimate already anchored in `SOURCES.md` for FD-223: after weakening constants uniformly over `N<=x<=DN`,

\[
|M(x)|
\le
C_M x\log x\,e^{-c'_M\Phi(N)}.
\tag{11}
\]

For `J<=kappa_beta Phi(N)`, one has `D=N^{o(1)}` and `log(DN)=(1+o(1))log N`. From (6), uniformly for `d<=D`,

\[
|y(d)-y(d-1)|
\ll
DN\log N\,e^{-c'_M\Phi(N)}+1.
\tag{12}
\]

Let

\[
T(D)=\max_{n\le D}\tau(n)=D^{o(1)}.
\]

Equations (5), (8), and (12) imply

\[
\frac{\max_{d\le D}|c(d)|}{A}
\ll_\beta
D^2T(D)(\log N)^2e^{-c'_M\Phi(N)}
+
\frac{DT(D)\log N}{N}.
\tag{13}
\]

Since `log D<=kappa_beta(log 2)Phi(N)+O(1)` and `log T(D)=o(log D)`, the right-hand side tends to zero once `kappa_beta` is chosen small enough that

\[
2\kappa_\beta\log2<c'_M
\tag{14}
\]

with a fixed margin.

The prime-capacity estimate from FD-223 is unchanged. Its Vinogradov--Korobov prime-number-theorem remainder gives uniformly

\[
|I_d\cap\mathbb P|
\gg_\beta
\frac{N}{D\log N}
\tag{15}
\]

provided, after another fixed weakening of constants,

\[
2\kappa_\beta\log2<c'_\vartheta.
\tag{16}
\]

Choose `kappa_beta` satisfying (14)--(16), then choose `a_beta` in (8) below the uniform capacity constant in (15). Equation (13) gives `|c(d)|=o(A)`, so eventually every count (9) lies, for example, between `A/2` and `3A/2` and therefore inside its reservoir.

This completes the construction. Notice what has disappeared from the budget: there is no factor `17^J`, no `J x J` inverse norm, and no row-ordering argument. The remaining stretched-logarithmic restriction comes from resolving the shrinking floor-stable prime reservoirs and from making the physical Mertens baseline small enough for the full-grid correction to fit.

## 5. Boundary and consequence

FD-223 had two visibly exponential-in-`J` ingredients: `D asymp 2^J`, which is geometric and comes from the deepest sampled multiplier, and the additional crude triangular conditioning factor `17^J`. FD-225 removes the second one completely. The divisor-response family itself has an exact integer inverse whose cost is only the divisor multiplicity `D^{o(1)}` after the unavoidable scale factor already present in the target data.

Therefore a loss of algebraic rank or exponential pivot conditioning cannot be the intrinsic obstruction sought after FD-224. Within the current floor-stable construction, the surviving quantitative pressure is instead

\[
D^2D^{o(1)}e^{-c\Phi(N)},
\]

coming from reservoir width and unconditional prime/Mertens remainders. This still certifies only `J=O(Phi(N))`; the result does **not** claim blindness beyond Vinogradov--Korobov depth, nor does it show that the remaining `D^2` budget is sharp.

The representation boundary of FD-224 is unchanged. The exact Euler cutoff remains the fixed absolute cutoff `beta N<N`, so relative multiplicative fidelity decays along the dyadic block. Exhaustive or cofinal exact Euler coverage still identifies the source with Möbius rather than producing a stronger relaxed-source countermodel.

No new external theorem is introduced. The analytic inputs are exactly the Mertens and prime-number-theorem bounds already anchored for FD-223. Formula (3) is elementary Möbius/Dirichlet inversion and is not claimed as new general mathematics; the repository-specific result is its use to replace the switched pivot repair by an exact full-grid divisor-reservoir repair.

The next meaningful negative test is therefore sharper than “improve the triangular matrix conditioning”: that issue is closed. To move the base-anchored blind block beyond the present `Phi(N)` range one must improve or bypass the shrinking floor-cell prime reservoirs, avoid paying for the physical Mertens baseline in the same way, or prove an intrinsic capacity obstruction that persists even when the full divisor response is inverted exactly.
