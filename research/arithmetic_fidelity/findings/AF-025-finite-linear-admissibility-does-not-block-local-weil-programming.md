# AF-025 — Finite linear admissibility constraints do not block local Weil programming when they can be corrected off the response footprint

**Status:** `EXACT-DERIVED`, `LITERATURE+DERIVED`, `NEGATIVE/OBSTRUCTION`

## Claim

Fix `A>0`, a locally finite generalized-prime background `B`, and distinct visible generator logarithms

\[
0<c_1<\cdots<c_N<A
\]

satisfying the nonresonance hypothesis of AF-024:

\[
mc_j\neq c_k
\]

for all `j,k` and integers `m\ge2` with `mc_j<A`.

Choose sufficiently small pairwise disjoint intervals `U_j\ni c_j` and vary only these generators,

\[
Q_\ell
=B\sqcup\{e^{\ell_1},\ldots,e^{\ell_N}\},
\qquad
\ell=(\ell_1,\ldots,\ell_N)\in U_1\times\cdots\times U_N.
\]

For `F\in C_c^\infty(0,A)`, let

\[
W_{Q_\ell}(F)
=
\sum_{q\in Q_\ell}\sum_{m\ge1}
(\log q)e^{-m\log q/2}F(m\log q).
\]

Then the following hold.

1. **The whole local experiment has an infinite-dimensional invisible correction space.** The neighborhoods `U_j` may be chosen so that there is a nonempty open interval
   \[
   J\Subset(0,A)
   \]
   disjoint from every prime-power log that occurs for any `Q_\ell` in the local chamber. Consequently every
   \[
   k\in C_c^\infty(J)
   \]
   satisfies
   \[
   \boxed{
   W_{Q_\ell}(k)=0
   \qquad
   \text{for every }\ell\in U_1\times\cdots\times U_N.
   }
   \]
   Thus adding `k` changes neither the absolute retained value nor any derivative, fiber, or higher-order singular geometry of the local source map.

2. **Finite linear admissibility has an exact quotient obstruction.** Let
   \[
   E=C_c^\infty(0,A)
   \]
   and let
   \[
   \mathcal M:E\to \mathcal Y,
   \qquad
   \mathcal M(F)(\ell)=W_{Q_\ell}(F),
   \]
   where `\mathcal Y=\operatorname{im}\mathcal M` is the vector space of local measurement functions actually generated by tests. Put
   \[
   K=\ker\mathcal M.
   \]
   For any linear constraint map
   \[
   L:E\to\mathbb R^r
   \]
   define
   \[
   C=L(K)\subseteq\mathbb R^r.
   \]
   Then there is a canonical linear map
   \[
   \boxed{
   \Omega:\mathcal Y\to\mathbb R^r/C,
   \qquad
   \Omega(\mathcal M(F))=L(F)+C.
   }
   \]
   It is well defined, and for every target constraint vector `b\in\mathbb R^r`,
   \[
   \boxed{
   \mathcal M\bigl(L^{-1}(b)\bigr)
   =
   \{y\in\mathcal Y:\Omega(y)=b+C\}.
   }
   \]
   In particular,
   \[
   \boxed{
   L(K)=\mathbb R^r
   \Longrightarrow
   \mathcal M\bigl(L^{-1}(b)\bigr)=\mathcal Y
   \quad\text{for every }b.
   }
   \]
   Such constraints impose **no restriction at all** on the local Weil experiment.

3. **Any finite family of ordinary moment constraints can be repaired invisibly.** For
   \[
   L_k(F)=\int_0^A x^{k-1}F(x)\,dx,
   \qquad 1\le k\le r,
   \]
   one has
   \[
   L\bigl(C_c^\infty(J)\bigr)=\mathbb R^r.
   \]
   Hence arbitrary prescribed values of the first `r` moments can be imposed without changing `W_{Q_\ell}(F)` for a single point of the local chamber.

4. **Evenness and finite origin normalization do not cure AF-024 source tuning.** Under the common symmetric-test convention, any positive-side test supported away from zero has a smooth even extension to `(-A,A)` with exactly the same positive-log prime-power samples. In particular, the nonnegative quadratic isolator of AF-024 extends to an even nonnegative test. One may then add an even nonnegative bump supported in a sufficiently small neighborhood of `0`, below the smallest generator log occurring in the local chamber, and normalize for example
   \[
   F(0)=1
   \]
   without changing any prime-power sample. Therefore **evenness + pointwise nonnegativity + a finite normalization at the origin still permit source-tuned singular isolation of an arbitrary finite nonresonant generator block**.

5. For a rational-prime center `c_j=\log p_j`, the nonresonance hypothesis is automatic. Thus finite linear normalizations, finitely many moment conditions, evenness, pointwise nonnegativity, and a basic origin normalization are not by themselves enough to make a finite-test singularity rational-prime-specific.

The decisive distinction is not whether an admissibility condition is source-independent. It is whether the condition actually couples to the local response quotient. A constraint that can be repaired inside the exact measurement kernel is mathematically invisible to the source-identification problem.

## Construction of an exact response-invisible correction interval

Let

\[
S_B
=
\{m\log q:\ q\in B,\ m\ge1,\ m\log q<A\}.
\]

Because `B` is locally finite, only finitely many background generators lie below `e^A`, and each contributes only finitely many multiples below `A`. Hence `S_B` is finite.

For the selected moving generators, define the local prime-power footprint

\[
D_U
=
\bigcup_{j=1}^N
\bigcup_{m\ge1\,:\,mU_j\cap(0,A)\neq\varnothing}
\bigl(mU_j\cap(0,A)\bigr).
\]

Only finitely many integers `m` occur. Since the centers `c_j` are positive and finite in number, the intervals `U_j` can be shrunk so that the total length of this finite union is arbitrarily small. The fixed set `S_B` has zero length. Therefore one may reserve an open interval

\[
J\Subset(0,A)\setminus\overline{(D_U\cup S_B)}.
\]

Now take `k\in C_c^\infty(J)`. Every positive prime-power log of every `Q_\ell` in the chamber lies in `D_U\cup S_B`, so every summand samples `k` at a point outside its support. Hence

\[
W_{Q_\ell}(k)=0
\]

for every local source `\ell`.

This is stronger than the kernel used implicitly in AF-024. The correction does not merely leave the selected one-generator germs unchanged; it leaves the **entire exact local Weil measurement function**, including its background offset, unchanged.

The interval `J` is not canonical and need not be. Its role is adversarial: it exhibits unused test-function freedom that a proposed finite admissibility condition must eliminate if that condition is supposed to explain local source fidelity.

## Exact quotient criterion for finite linear constraints

Let

\[
\mathcal M:E\to\mathcal Y
\]

be any linear measurement map and `K=\ker\mathcal M`. Let `L:E\to\mathbb R^r` be linear and put `C=L(K)`.

If

\[
\mathcal M(F)=\mathcal M(F'),
\]

then `F-F'\in K`, so

\[
L(F)-L(F')\in C.
\]

Therefore the coset

\[
L(F)+C
\]

depends only on the measurement `\mathcal M(F)`, which proves that `\Omega` is well defined.

Fix `b\in\mathbb R^r`. If `F\in L^{-1}(b)`, then

\[
\Omega(\mathcal M(F))=b+C.
\]

Conversely, suppose `y=\mathcal M(F_0)` and

\[
\Omega(y)=b+C.
\]

Then

\[
b-L(F_0)\in C=L(K),
\]

so there is `k\in K` with

\[
L(k)=b-L(F_0).
\]

Thus

\[
F=F_0+k
\]

satisfies simultaneously

\[
\mathcal M(F)=y,
\qquad
L(F)=b.
\]

Hence

\[
\mathcal M(L^{-1}(b))
=
\Omega^{-1}(b+C).
\]

For homogeneous constraints,

\[
\mathcal M(\ker L)=\ker\Omega.
\]

The only part of a finite linear admissibility condition that can affect the local measurement class is therefore the quotient

\[
\boxed{
\mathbb R^r/L(K).
}
\]

If every constraint direction can be changed inside the measurement kernel, that quotient is zero and the admissibility condition is completely irrelevant to the retained experiment.

This is the finite-linear analogue of the line's broader fidelity principle: a downstream condition matters only through what survives after quotienting by directions already invisible to the measurement.

## Finite moments are exactly correctable off the arithmetic footprint

Take the correction interval `J` above and impose the first `r` ordinary moments

\[
L_k(F)=\int_0^A x^{k-1}F(x)\,dx.
\]

Choose distinct points

\[
y_1,\ldots,y_r\in J.
\]

For each `s`, choose a nonnegative unit-mass bump `\psi_s^{(\varepsilon)}` supported in a small interval around `y_s`, with the supports still contained in `J`. As `\varepsilon\to0`,

\[
M_{ks}(\varepsilon)
=
\int_0^A x^{k-1}\psi_s^{(\varepsilon)}(x)\,dx
\longrightarrow
 y_s^{k-1}.
\]

The limiting matrix

\[
[y_s^{k-1}]_{k,s=1}^r
\]

is an ordinary Vandermonde matrix and is invertible because the `y_s` are distinct. Therefore `M(\varepsilon)` is invertible for all sufficiently small `\varepsilon`.

Given any desired correction vector `a\in\mathbb R^r`, solve

\[
M(\varepsilon)\alpha=a
\]

and set

\[
k=\sum_{s=1}^r\alpha_s\psi_s^{(\varepsilon)}.
\]

Then `k\in C_c^\infty(J)\subset K` and

\[
L(k)=a.
\]

Thus

\[
L(K)=\mathbb R^r.
\]

The same argument applies to many other finite families of linear test constraints whenever their restrictions to a reserved correction interval are linearly independent. The precise criterion is not that they are called moments, normalizations, or orthogonality conditions; it is the surjectivity of their restriction to the measurement kernel.

Compactly supported smooth kernels satisfying prescribed finite moment conditions are standard in harmonic analysis and function-space theory. For example, V. S. Rychkov, **“Intrinsic characterizations of distribution spaces on domains,”** *Studia Mathematica* 127 (1998), 277–298, DOI `10.4064/sm-127-3-277-298`, uses compactly supported smooth kernels with moment conditions in the analysis of Besov and Triebel--Lizorkin spaces. That literature is neighboring prior art for the availability of moment-corrected smooth kernels; the exact response-kernel specialization above is derived directly.

## Evenness, nonnegativity, and origin normalization still allow singular isolation

AF-024 constructs, for any finite visible nonresonant block, a nonnegative test

\[
F_+\in C_c^\infty(0,A)
\]

whose local response satisfies

\[
W_{Q_\ell}(F_+)-W_{Q_c}(F_+)
=
\sum_{j=1}^N(\ell_j-c_j)^2.
\]

Because `F_+` has compact support strictly inside `(0,A)`, it vanishes on a neighborhood of `0`. Define the even extension

\[
F_{\mathrm{ev}}(x)=F_+(|x|).
\]

It belongs to `C_c^\infty(-A,A)`, is even and nonnegative, and has exactly the same values at every positive prime-power log. Under a symmetric prime-side convention using

\[
F(x)+F(-x),
\]

the response is simply multiplied by the known factor `2`, so the isolated fiber is unchanged.

Now let

\[
\lambda_*
=
\inf\{\log q:\ q\in Q_\ell,\ \ell\text{ in the chosen local chamber}\}.
\]

After shrinking the chamber, local finiteness and the fact that all generators exceed `1` give

\[
\lambda_*>0.
\]

Choose an even nonnegative cutoff `\chi_0` with

\[
\operatorname{supp}\chi_0
\subset(-\lambda_*/2,\lambda_*/2),
\qquad
\chi_0(0)=1.
\]

No positive prime-power log enters this support, so

\[
W_{Q_\ell}(\chi_0)=0
\]

throughout the chamber. Therefore

\[
F=F_{\mathrm{ev}}+\chi_0
\]

is even, nonnegative, satisfies `F(0)=1`, and retains exactly the same source-isolating quadratic response.

More generally, after dropping pointwise nonnegativity one can prescribe any finite compatible even jet at the origin by multiplying a finite even Taylor polynomial by such a cutoff. Those jet normalizations are likewise invisible to the local prime-power experiment.

This proves that several superficially natural restrictions do not address AF-024's objection. They constrain the test, but they do not constrain the part of the test seen by the local arithmetic source.

## Prior art and novelty assessment

The abstract mathematics is classical.

- The quotient map `\Omega` is elementary linear algebra: it is the induced map obtained after quotienting the admissibility target by the image of the measurement kernel. No novelty is claimed for this factorization.
- Smooth bump localization, finite interpolation, and correction on disjoint supports are standard `C_c^\infty` techniques.
- Finite moment conditions on compactly supported smooth kernels are standard in harmonic analysis; Rychkov's 1998 paper above is one representative published source.
- AF-024 already establishes arbitrary local smooth-germ programming for the unconstrained prime-power Weil response. AF-025 does not claim a second interpolation theorem; it identifies exactly which additional finite linear restrictions survive quotienting by response-invisible test directions.

A targeted literature search did not locate a Beurling-prime or Weil-explicit-formula theorem phrased as this exact correction-kernel criterion. That absence is not treated as proof of novelty. The Arithmetic Fidelity contribution is the category audit: **finite source-independent linear conditions matter only through their quotient by the exact local measurement kernel, and common finite moment/normalization constraints can be repaired entirely off the arithmetic response footprint.**

The explicit even/nonnegative/origin-normalized singular isolator is likewise an elementary consequence of AF-024 plus support separation, not a claim that evenness or positivity theory is new.

## Boundaries and failure modes

- The quotient theorem applies to linear admissibility conditions. Convex cones and nonlinear constraints such as Fourier positivity, positive definiteness, norm inequalities, monotonicity, or operator-realizability require a separate exact audit.
- The moment-correction construction generally uses signed linear combinations of bumps. It does not preserve pointwise nonnegativity or positive definiteness while imposing arbitrary moment vectors.
- The explicit even/nonnegative example handles evenness, pointwise nonnegativity, and a simple origin normalization simultaneously, but it does **not** establish Fourier positivity or positive definiteness.
- A fixed finite-dimensional test family is not a finite-codimensional perturbation of `C_c^\infty`; it may genuinely shrink the local response image and must be analyzed directly.
- Infinite families of linear constraints can eliminate the reserved correction freedom. Paley--Wiener, analyticity, transform relations, and other global closure conditions may couple values on every open region and are not covered by the finite-constraint result.
- The correction interval is local to a fixed bounded support horizon and a fixed finite deformation chamber. This finding does not produce one globally invisible interval for all generators or all support scales.
- The generalized-prime background is assumed locally finite so that its prime-power support below `A` is finite. More general weighted local factors or accumulation of generator logs require a separate support audit.
- None of these statements imply anything about zero locations, multiplicity, simplicity, or RH.

## Decisive audit test

When a finite-test route proposes an admissibility condition as the reason its singular source geometry is intrinsic:

1. write the exact local measurement map `\mathcal M` for the declared source/control class;
2. compute or exhibit a useful subspace of `K=\ker\mathcal M`;
3. for every finite linear normalization `L`, compute `L(K)` rather than merely listing the constraint;
4. if `L(K)=\mathbb R^r`, remove `L` from the claimed source-identification mechanism because it does not change the local measurement image at all;
5. if `L(K)` is proper, identify the residual quotient `\mathbb R^r/L(K)` and state exactly which local response directions it forbids;
6. for cones or nonlinear/global admissibility, replace the linear argument by the appropriate exact tangent/cone/global analysis instead of extrapolating AF-025;
7. only if the true admissible category eliminates source-tuned local programming should a singular rational-prime point be interpreted as potentially intrinsic.

The relevant gate is therefore

\[
\boxed{
\text{admissibility constraint}
\quad\longrightarrow\quad
\text{nontrivial quotient after the exact measurement kernel?}
}
\]

not merely whether the constraint sounds natural or is chosen independently of the primes.

## Consequence for the line

AF-024 moved the finite-Weil-test frontier from regular versus singular geometry to the source-tuning freedom of the admissible test class. AF-025 removes another large class of apparent escapes.

**Finite source-independent linear restrictions are not enough when they can be corrected in response-invisible regions.** In particular, finitely many ordinary moments and many finite normalizations do not restrict the local Weil experiment at all, while evenness, pointwise nonnegativity, and a basic origin normalization still allow the explicit quadratic singular isolator.

The next genuinely different frontier is therefore formed by admissibility conditions that cannot be repaired off the arithmetic footprint: Fourier-positive or positive-definite cones, Paley--Wiener/analytic transform classes, fixed low-dimensional families, and operator- or geometry-generated test spaces. Those categories must be audited on their own terms rather than treated as cosmetic restrictions of `C_c^\infty`.
