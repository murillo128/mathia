# AF-375 — Sampling difference subgroup classifies separable determinant gauges

## Status

`EXACT-DERIVED` · `LITERATURE+DERIVED` · `GAUGE-CLASSIFICATION` · `TOTAL-POSITIVITY` · `SAMPLING` · `NO-NOVELTY-CLAIM`

## Claim

Let `E\subset\mathbb R` be a nonempty row-sampling set and let

\[
H_E:=\langle E-E\rangle
\]

be the additive subgroup generated by all row differences. Consider a positive continuous multiplicative gauge `p:\mathbb R\to(0,\infty)` with the property that on the sampled translation kernel it separates into positive row and column factors,

\[
p(u-x)=r(u)c(x),\qquad u\in E,\ x\in\mathbb R.
\tag{1}
\]

Then multiplication `f\mapsto pf` preserves the sign and zero pattern of every Toeplitz minor whose row locations lie in `E`, because every such determinant is multiplied by a positive product of row and column factors.

The exact freedom in `(1)` is controlled by `H_E`. There is a positive character `\chi:H_E\to(0,\infty)` such that

\[
p(t+h)=\chi(h)p(t),\qquad t\in\mathbb R,\ h\in H_E.
\tag{2}
\]

Conversely, `(2)` implies `(1)`. Continuity then gives a complete trichotomy:

1. if `H_E={0}` (equivalently, `E` is a singleton), every positive continuous `p` is invisible in this separable sense;
2. if `H_E=a\mathbb Z` for some `a>0`, then
   \[
   p(t)=e^{\lambda t}q(t)
   \tag{3}
   \]
   for some `\lambda\in\mathbb R` and some positive continuous `a`-periodic `q`;
3. if `H_E` is dense in `\mathbb R`, then
   \[
   p(t)=C e^{\lambda t}
   \tag{4}
   \]
   for constants `C>0` and `\lambda\in\mathbb R`.

Thus the non-universal periodic alias exposed in AF-374 is present exactly when the sampling difference subgroup is discrete. Once the row geometry generates a dense subgroup, every continuous separable multiplicative ambiguity collapses to the global exponential tilt already invisible to the *full* translation-minor family.

This is a gauge-elimination theorem, not a determining-set theorem. Dense `H_E` removes this exact multiplicative alias but does not prove that `E`-Pólya-frequency implies full Pólya-frequency; non-separable false-positive fibers may still remain.

## Exact derivation

Assume `(1)` and choose `u_0\in E`. For any `u,v\in E`, set `h=u-v`. Since `x` ranges over all real numbers, `t=v-x` also ranges over all real numbers, and

\[
\frac{p(t+h)}{p(t)}
=
\frac{p(u-x)}{p(v-x)}
=
\frac{r(u)}{r(v)}.
\tag{5}
\]

The ratio is independent of `t`. Therefore each generator `h\in E-E` acts on `p` by multiplication by a positive constant. Products and inverses extend these constants uniquely to a group homomorphism

\[
\chi:H_E\to(0,\infty)
\]

satisfying `(2)`.

Conversely, if `(2)` holds, choose `u_0\in E`. Since `u-u_0\in H_E`,

\[
p(u-x)=\chi(u-u_0)p(u_0-x).
\]

Hence `(1)` holds with

\[
r(u)=\chi(u-u_0),\qquad c(x)=p(u_0-x).
\]

For a sampled `k\times k` minor this gives

\[
\det\bigl[(pf)(u_i-x_j)\bigr]
=
\left(\prod_{i=1}^k r(u_i)\right)
\left(\prod_{j=1}^k c(x_j)\right)
\det\bigl[f(u_i-x_j)\bigr].
\tag{6}
\]

All prefactors are positive, so signs and zeros are preserved at every determinant order.

It remains to classify continuous solutions of `(2)`. Write `\alpha(h)=\log\chi(h)`. Then `\alpha` is additive on `H_E`.

If `H_E=a\mathbb Z`, set `\lambda=\alpha(a)/a` and define

\[
q(t)=e^{-\lambda t}p(t).
\]

Equation `(2)` gives `q(t+a)=q(t)`, which proves `(3)`.

If `H_E` is dense, continuity of `p` forces continuity of `\chi` at zero: whenever `h_n\in H_E` and `h_n\to0`,

\[
\chi(h_n)=\frac{p(t+h_n)}{p(t)}\to1.
\]

Therefore `\alpha` is a continuous additive character on the dense subgroup `H_E`, so `\alpha(h)=\lambda h` there for some `\lambda\in\mathbb R`. The function `q(t)=e^{-\lambda t}p(t)` is continuous and invariant under the dense subgroup `H_E`; hence it is constant. This proves `(4)`.

Finally, every additive subgroup of `\mathbb R` is either dense or, if nonzero and nondense, cyclic of the form `a\mathbb Z`. This gives the stated trichotomy.

## Phase arithmetic

The classification turns the qualitative suggestion at the end of AF-374 into an exact commensurability test.

For one lattice `E=a\mathbb Z`,

\[
H_E=a\mathbb Z,
\]

so the hidden continuous separable gauges are exactly exponential tilts times positive `a`-periodic functions. AF-374 used the bounded periodic subfamily because it preserves the Gaussian-decay source class and provides explicit non-PF controls.

Now add a second phase of the same mesh,

\[
E=a\mathbb Z\cup(\tau+a\mathbb Z).
\tag{7}
\]

Then

\[
H_E=a\mathbb Z+\tau\mathbb Z.
\tag{8}
\]

If `\tau/a=m/n\in\mathbb Q` in lowest terms, `(8)` equals `(a/n)\mathbb Z`. The extra phase only refines the hidden periodicity: a positive `(a/n)`-periodic factor remains invisible.

If `\tau/a\notin\mathbb Q`, `(8)` is dense in `\mathbb R`, so every continuous separable gauge has the form `C e^{\lambda t}`. Thus **one incommensurate lattice phase is enough to kill every nonconstant periodic multiplicative alias of AF-374**, modulo the universal exponential tilt.

The same conclusion holds whenever `H_E` is dense, independently of how that density is generated.

## Relation to Ganzburg determining sets

AF-373 records two classical sufficient geometries from Ganzburg for an exponentially decaying `E`-Pólya-frequency function to be fully Pólya-frequency: an `E` with a finite accumulation point, or an appropriate symmetric unbounded sequence with sub-square-root growth.

Both geometries necessarily have dense difference subgroup.

If `E` has an accumulation point, `E-E` contains nonzero differences tending to zero. Hence `H_E` cannot be a nonzero discrete subgroup `a\mathbb Z`; it is dense.

For the symmetric increasing sequence `u_s` in Ganzburg's second theorem, a discrete difference subgroup would force the sequence into a translate of a fixed lattice (up to a fixed finite-index rescaling), which makes the `s`-th positive sample grow at least linearly in `s`. That contradicts `u_s=o(\sqrt{s})`. Hence its difference subgroup is also dense.

This provides a structural explanation for one necessary feature shared by Ganzburg's determining geometries: they leave no nonconstant continuous periodic separable gauge. But the implication is one-way. Dense `H_E` is only a gauge-elimination condition and is substantially weaker than Ganzburg's determining hypotheses.

In particular, the two-phase set `(7)` with irrational `\tau/a` has dense `H_E` but is still a discrete set with linear counting growth. Ganzburg's two sufficient determining theorems quoted in AF-373 do not settle whether this two-phase geometry is itself determining on the exponentially decaying source class.

## Fidelity interpretation

For this determinant observation, the relevant geometric invariant is not simply the density or cardinality of the sampling set. It is first the additive relation group generated by **row differences**.

The quotient mechanism is exact:

- a discrete difference group leaves a periodic degree of freedom after the universal exponential tilt is removed;
- a dense difference group destroys that continuous periodic degree of freedom;
- neither conclusion decides whether other, non-separable aliases remain.

This separates two questions that AF-374 left coupled: "does extra sampling destroy the known gauge?" and "does extra sampling make the target recoverable?" The first is now answered exactly by `H_E`; the second still requires a determining-set theorem for the declared source class.

The universal factor `e^{\lambda t}` should not be mistaken for the AF-374 defect. It already factorizes for arbitrary real row locations,

\[
e^{\lambda(u-x)}=e^{\lambda u}e^{-\lambda x},
\]

so full translation total positivity itself cannot detect it. Whether a particular source class admits such tilts is a separate admissibility question.

## Riemann specialization

If an RH-facing total-positivity reduction samples all determinant orders on arithmetic row sets, the first exact gauge audit is now algebraic: compute `H_E=\langle E-E\rangle`.

A single lattice, or any finite collection of commensurate phases, leaves a nonconstant continuous periodic multiplicative gauge unless the source class independently forbids it. By contrast, adding a phase incommensurate with the lattice spacing removes this particular ambiguity modulo the universal exponential tilt.

That is only a necessary representation-level improvement. It does not establish positivity of the sampled minors, does not show that the sampled family determines full Pólya-frequency structure, and does not constrain zeta zeros. A genuine arithmetic reduction still needs a theorem that the chosen source class has no remaining target-changing fiber after the gauge has been removed.

No novelty is claimed for them, for incommensurable-period uniqueness, or for Ganzburg's theorems.

A focused literature search did not identify a standard theorem phrased as the `H_E` classification of separable multiplicative gauges for `E`-Pólya-frequency determinant observations. The durable contribution claimed here is therefore limited to the **derived audit mechanism**: the sampling difference subgroup exactly determines whether the AF-374 periodic gauge survives, and it exposes a sharp rational-versus-irrational phase transition. No claim is made that this organization is a new mathematical theory.

## Decisive audit rule

For any proposal to repair fixed-lattice total-positivity fidelity by adding row samples, compute

\[
H_E=\langle E-E\rangle
\]

before attempting a difficult determining-set proof.

If `H_E=a\mathbb Z`, the repair has not removed the AF-374 mechanism: exponential tilts times positive `a`-periodic gauges remain separably invisible. If `H_E` is dense, that exact obstruction is gone modulo the universal exponential tilt, but the burden then shifts to proving that no non-separable target-changing aliases survive in the declared source class.
