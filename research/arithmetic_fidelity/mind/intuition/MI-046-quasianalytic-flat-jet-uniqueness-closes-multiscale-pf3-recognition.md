# MI-046 — Quasianalytic flat-jet uniqueness closes multiscale `PF_3` recognition

**Evidence level:** exact/literature-backed synthesis from [AF-385](../../findings/AF-385-sampled-solid-minor-hierarchy-certifies-continuum-fixed-order-total-nonnegativity.md), [AF-389](../../findings/AF-389-multiscale-solid-pf3-excludes-all-finite-order-boundary-contact.md), and [AF-390](../../findings/AF-390-quasianalytic-curvature-closes-multiscale-pf3-recognition.md).

For a positive smooth profile `f`, write `q=-(log f)''`. If the same profile has nonnegative solid Toeplitz minors of orders two and three on meshes `h_n -> 0`, AF-389 already forces `q>=0` and makes every zero of `q` infinitely flat. The multiscale observation has therefore recovered the entire finite jet of the only remaining lower-order boundary defect; what is missing is a rule saying whether that flat jet can belong to a nonzero admissible source.

AF-390 identifies that missing resource exactly for this proof architecture. Assume the source class has flat-zero unique continuation for `q`: if `q^(m)(x_0)=0` for every `m`, then `q≡0`. Then the sampled hierarchy leaves only two branches. Either `q>0` everywhere, so every sampled order-two minor is strict and AF-385 upgrades the solid order-three generators to all continuum order-three placements, or `q≡0`, so `f=e^(ax+b)` and the translation kernel is rank one and totally nonnegative at every order. Hence the shrinking-mesh solid certificate is equivalent to continuum `TN_3` inside that source class.

The conceptual point is that **regularity becomes useful only after the observation has recovered the right local invariant**. Quasianalyticity does not manufacture positivity and is not a generic replacement for missing data. The determinant hierarchy first forces the complete flat jet; the source category then turns that recovered jet into a global dichotomy. Real analyticity is one sufficient category, but the actual resource is quasianalytic flat-jet uniqueness for `q`, including suitable Denjoy--Carleman classes.

This also separates source rigidity from target reconstruction. The observation need not identify `f`; it only has to recover enough boundary information that the admissible source fibre becomes target-pure. The useful chain is therefore: compressed compatible observations recover a complete local jet, source-class rigidity collapses the residual fibre, and the existing recognition theorem transports the surviving branch to the target property.

**Boundary.** Flat-zero unique continuation is sufficient here, not claimed necessary. In the unrestricted `C^infinity` category an infinitely-flat nonnegative `q` may exist, and AF-390 does not decide whether such a profile can satisfy the full shrinking solid hierarchy while retaining a negative non-solid continuum `3x3` minor. Nor does any of this supply the sampled generator signs from a Riemann-associated source or imply RH.
