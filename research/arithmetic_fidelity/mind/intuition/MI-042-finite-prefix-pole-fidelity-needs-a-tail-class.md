# MI-042 — Fixed-source fidelity is governed by completable secants, source topology, and output packing

**Evidence level:** exact synthesis from AF-449, the correction in [AF-451](../../findings/AF-451-common-backgrounds-transport-radon-collisions-across-source-law-fibers.md), the conditioning identity in [AF-452](../../findings/AF-452-difference-norm-conditioning-descends-to-completed-source-law-secants.md), the topology obstruction in [AF-453](../../findings/AF-453-weakly-collapsing-secants-force-zero-total-variation-conditioning.md), and the discrete-output capacity theorem [AF-454](../../findings/AF-454-bounded-finite-observations-cannot-be-tv-coercive-on-infinite-discrete-alphabets.md).

AF-451 corrects the residual-circuit picture: cancelling common mass from two equal-observation measures exposes a Radon core, but the core need not itself carry the prescribed source-law barycenter. A core is relevant to a fixed source law only when a common positive background and mixing weight complete both Jordan sides into admissible sources without violating the atom budget. AF-452 then identifies the inverse lower Lipschitz modulus, for difference-homogeneous source metrics, with the minimum observation gain on the normalized carrier of those completable secants.

AF-453 adds a topological gate. If the admissible fiber contains secants `mu_n-nu_n` that converge weakly to zero while their total-variation norm stays bounded below, every finite continuous observation has vanishing normalized TV gain. Moving atoms in a non-discrete source-law level set are the canonical witness.

AF-454 closes the naive discrete-source escape. For distinct one-atom sources on an infinite alphabet `A`, `kappa_A^TV(Phi) = (1/2) inf_{x != y} d(Phi(x),Phi(y))`; positive TV conditioning is therefore equivalent to a uniformly discrete output image. If `Phi(A)` is totally bounded, the margin is zero. In particular, any bounded `d`-dimensional observation has zero uniform TV margin on an infinite alphabet, and on `N` atoms inside an output ball of radius `R` the margin is at most `R/(N^(1/d)-1)`. Common-background completion preserves this normalized ratio.

Hence source discreteness is only one gate. Uniform TV fidelity on an infinite discrete source additionally requires the retained representation itself to be non-precompact on that source class—for example through unbounded finite-dimensional amplitude or a bounded infinite-dimensional uniformly separated image—or else the source class must be finite or the metric weakened. Exact injectivity remains strictly weaker than stable physical inversion.

**Boundary.** AF-454 is a representation-capacity obstruction, not positive arithmetic evidence. It does not prove a lower gain for any arithmetic observation family, nor does it say which weaker source metric is physically correct. The remaining problem is to declare the physical source class, topology and output resource, then estimate the observation gain on the corresponding completed secant carrier.
