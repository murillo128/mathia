# MI-043 — Support-scale interaction components bound effective relational arity

**Evidence level:** exact synthesis from [AF-372](../../findings/AF-372-finite-order-total-positivity-does-not-determine-laguerre-polya.md), [AF-376](../../findings/AF-376-uniform-separation-defeats-e-polya-frequency-determination.md), [AF-377](../../findings/AF-377-bounded-support-interaction-components-hide-finite-order-aliases.md), the coordinate-transport boundary [AF-378](../../findings/AF-378-order-reparameterization-preserves-sampling-fibres-but-not-translation-geometry.md), the one-sided determining regime [AF-379](../../findings/AF-379-vanishing-row-mesh-determines-continuous-translation-total-positivity.md), and the two-sided determining refinement [AF-381](../../findings/AF-381-prime-ratio-minors-determine-translation-total-nonnegativity.md).

Nominal access to determinants of every order does not imply genuinely unbounded relational information. For a compact/local translation kernel with support width `w`, the relevant object is the graph `G_w(E)` on the sampled row set: two rows are adjacent only when their translates can interact inside that support scale. If every connected component has at most `r` vertices, every sampled Toeplitz matrix permutes into blocks of size at most `r`, so all determinants of arbitrary nominal order are decided by minors of order at most `r`.

AF-377 makes this exact and removes a tempting repair of AF-376. Positive minimum spacing is sufficient to hide compact-support false positives, but its failure is not sufficient to restore determination. One can have `inf |u-v|=0` while `G_w(E)` remains a disjoint union of pairs. A compactly supported `PF_2` function that is not `PF_3` then passes every sampled determinant order even though it is not globally Pólya-frequency.

AF-379 gives the complementary sufficient regime. For a continuous translation kernel, normalize a sampled row tuple by subtracting its first row. If the resulting finite row patterns are dense in the full ordered difference cone at every determinant order needed by the target, continuity transports every sampled determinant inequality to every missing row configuration. An increasing unbounded sampling sequence with consecutive mesh tending to zero forces this pattern density at all finite orders. Thus unbounded interaction is only an intermediate geometric resource; **dense normalized finite-pattern closure is a direct determining resource**.

AF-381 shows that this remains true after the observation is compressed further. When both rows and columns are restricted to the same sampled set, the determining object is the joint normalized configuration consisting of row offsets and column offsets relative to one common row origin. Vanishing tail mesh lets one translate any finite union of target row/column points far enough into a fine tail and approximate them simultaneously, so the joint pattern set is dense. The same topological mechanism therefore upgrades row-only determination to full `E x E` determination.

The arithmetic specialization is sharper than an arithmetic-looking presentation suggests. For `E={log p}`, the prime number theorem gives `log p_(n+1)-log p_n -> 0`; hence both prime-log row sampling and fully prime-ratio sampling `f(log(p/q))` determine continuous translation total positivity. AF-381 even gives finite prime-ratio witnesses for any fixed negative target minor once a local modulus of continuity is supplied. Yet this extra arithmetic indexing adds no source discrimination: closure reconstructs the entire real translation target from the prime-ratio grid.

AF-378 supplies the representation boundary needed to use both the obstruction and the determining theorems correctly. A nonlinear order reparameterization can make the displayed set have shrinking gaps, but if the original kernel is transported with the coordinates then all sampled determinant values and false-positive fibres are unchanged. The apparent Euclidean support graph or mesh in the new coordinate is not the intrinsic geometry of that transported experiment. If one instead declares a fresh difference kernel in the new coordinate, one has changed the source category. For the whole translation-kernel class, only positive affine reparameterizations preserve the difference-only geometry.

The reusable hierarchy is therefore: dense generated differences may kill a separable gauge; unbounded intrinsic support-scale components prevent the bounded-block alias mechanism; dense normalized finite row patterns determine one-sided sampled translation minors; dense **joint** normalized row/column patterns determine fully sampled translation minors. Vanishing gaps matter only when they are intrinsic and assemble into translated copies of arbitrary finite configurations, not when they merely occur somewhere or are manufactured by redrawing coordinates.

For sampled positivity arguments the audit should ask, in order: what source relation and localization scale are intrinsic; whether a coordinate change transports that source model or replaces it; what interaction graph that model induces on the actual rows; whether higher-order interactions genuinely grow; whether normalized finite row patterns or joint row/column patterns are dense enough to give determination; and, if they are, where any claimed arithmetic selectivity survives after closure. A proof that checks only `inf gap=0`, dense `H_E`, or nominal all-order access can still be effectively finite-order; a proof that reaches joint pattern closure has solved the sampling-fidelity problem even for a fully arithmetic-looking grid, but not the arithmetic provenance of the inequalities.

**Falsification criterion.** For a proposed sampled all-order certificate, either construct an admissible compact/local source scale `w` whose intrinsic interaction graph has uniformly bounded components and a corresponding `PF_r` but non-PF kernel, or test the stronger determining condition directly by computing the closure of the relevant normalized finite pattern space. For two-sided sampling the latter must include both row and column offsets modulo their common translation. Bounded interaction proves finite effective arity; dense pattern closure, when the profile is continuous, rules out that sampling alias mechanism completely. Any coordinate escape must additionally preserve the declared source category rather than merely reimpose new translation geometry.
