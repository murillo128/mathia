# Arithmetic-fidelity research lines

This file holds the current mathematical questions suggested by the durable arithmetic-fidelity intuitions. It is not a roadmap, task queue, status page, or history.

## Derive the admissible provenance code before demanding scalable recovery

**Linked intuitions:** `MI-001-fidelity-is-quotient-relative`, `MI-015-whole-experiment-fidelity-needs-a-common-recovery-profile`, `MI-016-shtarkov-rays-separate-radial-reset-from-full-experiment-loss`, and `MI-017-exact-sufficiency-geometry-does-not-fix-approximate-recovery-scale`.

AF-160 separates Shtarkov source complexity from the convex-hull penalty of a recoverable barycentric reference. AF-161--AF-163 then show that composition depends on provenance: free Cartesian recombination is exponentially expensive, one shared identity stays bounded, and blockwise shared identity scales exactly with the number of independently recombinable blocks.

AF-164 identifies the more intrinsic object. An arbitrary provenance constraint is a codebook of admissible identity words. Its normalized Shtarkov mass is exactly whole-word MAP success; pairwise Hellinger overlap gives a sufficient collective-separation test, while the one-use channel capacity gives a necessary asymptotic rate gate. The source question is therefore to derive the **actual admissible provenance code and its overlap/rate geometry**, not to impose a worst-case tensor or block model by default.

## Declare the endpoint quotient before charging provenance loss

AF-165 shows that whole-provenance recovery can be much stronger than the downstream theorem needs. For an endpoint map `f_n`, the exact envelope mass is the Bayes success probability for the quotient variable `f_n(A)`, the overlap budget counts only cross-endpoint pairs, and the capacity obstruction applies to endpoint entropy rather than hidden-source cardinality.

A recovery no-go is therefore relevant only after the destination equivalence relation is declared. Distinctions inside one endpoint fiber are destination-null and should not be charged as lost fidelity. Conversely, a proposed arithmetic endpoint must state which provenance alternatives it genuinely separates before a local collision is treated as an obstruction.

## Match reference complexity, provenance geometry, and destination loss in one composition law

Reference choice, admissible source identities, and endpoint loss are separate axes. A useful theorem should select a recoverable reference, quantify its likelihood/Shtarkov cost, derive the intrinsic provenance composition law, and evaluate only the quotient consumed by the endpoint.

If full-family recovery is stronger than the destination needs, narrow the recovered witness class rather than interpreting exponential codebook complexity as unavoidable information loss. If the endpoint really does distinguish exponentially many admissible identities, then the channel/overlap geometry must carry that load; representation changes alone cannot remove it.

## Classify retained interaction support before proposing repair

Linear span, sigma-algebra, interaction depth, family recovery, center reset, radial conflict, tangential likelihood-ray loss, endpoint observability, reference complexity, provenance code geometry, and endpoint quotient complexity are distinct information layers. Repairs should target the first layer that fails instead of treating one center, divergence, aggregate geometry, or generic tensor product as a complete fidelity metric.
