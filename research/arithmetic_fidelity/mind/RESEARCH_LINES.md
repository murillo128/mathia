# Arithmetic-fidelity research lines

This file holds the current mathematical questions suggested by the durable arithmetic-fidelity intuitions. It is not a roadmap, task queue, status page, or history.

## Price retained information jointly with the admissible source class

**Linked intuitions:** `MI-001-fidelity-is-quotient-relative`, `MI-004-prime-specificity-depends-on-the-retained-analytic-layer`, `MI-018-signed-complexity-only-transfers-through-sign-regular-observations`, `MI-041-one-riesz-order-crosses-conditioning-without-moving-the-zero-discriminator`, `MI-042-finite-prefix-pole-fidelity-needs-a-tail-class`.

The fidelity results separate exact discriminator survival from finite observation, source freedom, conditioning and source-category rigidity. Recovering `zeta` inside a rigid source class can identify the analytic object without selecting its nontrivial zeros, while small observations can become complete only after the admissible source fibre has already been restricted enough. Any useful compression must therefore state the source class and retained analytic layer before counting coordinates.

## Match physical locality to source-density and sparse-sampling scales

**Linked intuitions:** `MI-043-support-scale-interaction-components-bound-effective-relational-arity` through `MI-049-physical-locality-walls-have-source-dependent-index-depth`.

AF-387--AF-394 identify the smooth order-three translation-kernel structure. For a positive `C^4` profile, the local analytic `TN_3` condition is controlled by logarithmic curvature `q=-(log f)''`; under the shrinking solid hierarchy the remaining global datum is connectedness of `{q>0}`. AF-395--AF-399 then show that a fixed successor stencil can miss that global topology and that physical logarithmic reach, not raw successor count, is the invariant resource.

AF-400 proves that ordinary regular variation is insufficient when the physical wall itself shrinks. The source-density theorem must operate at the same scale as the detector. AF-401 supplies an all-prime-start conversion from uniform short-interval PNT: for `h_N=p_N^(-beta)` with `beta<13/30`, `B_N(h_N)~N h_N` for every sufficiently large prime index.

AF-402 adds a distinct density-one route. An ambient short-interval failure persists over nearby starts, while Brun--Titchmarsh limits how many prime starts can occupy those persistence regions. This inertia-plus-packing mechanism transfers an almost-all ambient PNT to relative density one of prime starts. With the current input it yields `B_N(p_N^(-beta))~N p_N^(-beta)` for relative density one of prime indices throughout every fixed `beta<13/15`.

The live question is therefore no longer simply how many successors a detector uses. A proposed arithmetic relation must declare its **physical wall**, whether it needs every prime start or only a density-one family, and the source theorem that controls exactly that sampling regime. The current `13/30` all-start and `13/15` density-one boundaries are technology boundaries, not intrinsic `PF_3` constants. If a route needs a thinner wall, it must supply stronger uniform source information, a sharper exceptional-set transfer, or a different representation whose physical locality is not priced by raw successor breadth.

A separate structural frontier remains whether higher determinant orders admit a similarly sharp split between local analytic conditions and a finite global/topological residue.

## Separate source identification from zero selection

Hamburger-type rigidity can identify the zeta source without forcing RH. Future fidelity arguments must keep source identification, stable recovery, source-specific relational structure and zero selection as separate gates. The same discipline applies to conditional prime-phase incidence programs: exact algebraic incidence is weaker than a stable source theorem excluding the relevant fibre.

For every proposed destination theorem state separately the observed data, admissible source/tail class, retained analytic layer, relation order, intrinsic physical source coordinate, sampling set, same-scale density theorem, exceptional-set transfer if needed, conditioning, residual gauge and final zero/sign discriminator. A source-coordinate count has mathematical meaning only after those choices are fixed.
