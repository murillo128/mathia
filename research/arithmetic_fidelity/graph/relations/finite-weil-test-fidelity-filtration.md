# Weil-test fidelity separates scale horizon, test resolution, and admissible-class rigidity

[[research/arithmetic_fidelity/findings/AF-020-full-weil-test-family-is-norm-faithful-fixed-support-is-finite-scale|AF-020]] separates the support horizon from information completeness: the full compactly supported Weil-test family determines the weighted prime-power measure, while fixed support sees only the finite arithmetic horizon below `e^A`.

[[research/arithmetic_fidelity/findings/AF-021-finite-test-families-have-large-moment-fibers|AF-021]]--[[research/arithmetic_fidelity/findings/AF-023-regular-weil-test-points-have-positive-dimensional-beurling-fibers|AF-023]] isolate the independent finite-dimensional resolution loss. More source degrees of freedom than retained test values give exact generalized-prime collision fibers at regular points.

[[research/arithmetic_fidelity/findings/AF-024-unconstrained-weil-tests-program-local-separable-geometry|AF-024]]--[[research/arithmetic_fidelity/findings/AF-027-double-positive-compact-tests-retain-full-dimensional-finite-weil-jet-freedom|AF-027]] show that singular source tuning and familiar finite admissibility constraints do not automatically restore rational-prime specificity: unconstrained tests can program local response germs, finite linear constraints can be repaired invisibly, and Fourier or double positivity still leaves full-dimensional finite Weil-jet freedom.

The infinite-family boundary is now explicit. [[research/arithmetic_fidelity/findings/AF-028-accumulating-double-positive-tests-are-finite-scale-norm-faithful|AF-028]] constructs an accumulating family inside the same double-positive compact test class that is determining for finite signed measures on every fixed visible interval. [[research/arithmetic_fidelity/findings/AF-029-lattice-modulation-tests-have-sharp-cosine-alias-horizon|AF-029]] shows that replacing finite accumulation by lattice frequencies gives an exact cosine quotient, with a sharp faithfulness threshold `hB <= pi`. [[research/arithmetic_fidelity/findings/AF-030-linear-test-fidelity-is-closed-span-density|AF-030]] gives the general linear criterion: the exact fibers are the annihilator of the closed linear span of the retained tests, and full signed-measure fidelity occurs exactly when that span is dense in `C(X)`.

The source-backed filtration is therefore fourfold: **support controls visible arithmetic scale; finite test dimension controls local resolution; infinite sampling geometry controls whether the retained linear span becomes determining; and arithmetic specificity still depends on an admissible source/test category fixed independently of the target.** Point-separation, generated-algebra density, positivity, or a source-tuned singular isolator are not substitutes for the actual linear-span/fiber calculation.
