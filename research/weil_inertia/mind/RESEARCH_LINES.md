# Weil-inertia research lines

This file records the current mathematical questions that survive the Weil-Inertia evidence. It is not a roadmap, task queue, status page, or history.

## Separate collective RH reserve from defect-sensitive arithmetic information

WI-387--WI-393 locate the compactness and square-root-prime boundaries for fixed-width Weil trials. Escaping logarithmic spectral tightness can create a source-exact positive RH floor, but the same dilute carrier may remain blind to sparse off-line defects. The crossover occurs when the shifted prime polynomial has absolute size comparable with the local zero-density reserve, near `e^(A/2)~log R`. Beyond that scale a useful converse needs signed prime cancellation, stronger per-defect amplification, or collective defect aggregation rather than only an RH-side density floor.

WI-397--WI-398 show that passing from a scalar Fourier observable to a matrix-valued one does not remove this cost by dimension alone. Jutila-type horizontal Fourier control leaves a `log^2 T` source-budget barrier: a positive-density scalar separation requires that budget, and a matrix inertia change requires either the same order of operator total variation or a reference spectral margin collapsing at the corresponding rate. Nominal matrix rank is not a free amplification resource.

## Use the Widder hierarchy only with information stronger than strip width and a mesh fine enough to see the defect

WI-399--WI-401 depend on a recent non-peer-reviewed Rafik preprint and should be read with that evidence boundary explicit. Conditional on the fixed-height prime/zero interface audited there, the high-order Widder prime-root statistic is individually sensitive to horizontal zero displacement, while WI-400 shows that the complete clipped root profile only recodes the maximal strip width: feeding a width bound into the sharp universal envelope and inverting returns the same width.

WI-401 quantifies what survives when the endpoint bound is known only at selected heights. An off-critical zero `rho=1/2+delta+i gamma`, with `d=|delta|`, has scalar visibility interval

`(sqrt(gamma^2+2d^2)-d, sqrt(gamma^2+2d^2)+d)`,

whose radius is exactly `d`. If `L_P(T)<=1` is certified on a sample set `S`, then every such zero satisfies `d<=dist(sqrt(gamma^2+2d^2),S)`. A uniform mesh of spacing `q` therefore forces at best the strip `|Re rho-1/2|<=q/2`, and this covering-radius law is sharp for the sampled scalar threshold: a positive mesh gap can hide a sufficiently shallow hypothetical off-line block.

The live Widder question is therefore arithmetic **and** sampling-sensitive. First establish the primary-source interface independently; then prove the exact endpoint inequality on a set of heights whose covering radius is below the desired horizontal defect scale, or add information that couples unsampled heights. Reaching RH by this scalar route requires mesh gaps tending to zero. High zeros do not shrink the visibility interval, but their peak excess above the neutral threshold is only `1+d^2/gamma^2`, so any analytic or computational certification must separately control horizontal sampling resolution and endpoint margin.

## Keep budget, margin, defect response and representation dimension distinct

A candidate inertia mechanism must state whether it changes the source budget, the reference spectral margin, individual defect response, collective zero density, height-sampling resolution, or genuinely adds independent information. Enlarging a scalar observable to a matrix, converting strip width into an exactly invertible root profile, or sampling that profile on a fixed positive mesh changes representation without eliminating the surviving information budget. Any claimed contraction must identify the extra source-specific datum responsible for it.
