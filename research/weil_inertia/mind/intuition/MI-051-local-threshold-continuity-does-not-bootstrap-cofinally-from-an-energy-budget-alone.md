# MI-051 — Local threshold continuity does not bootstrap cofinally from scalar energy, graph norm or abstract zero-mode control

**Evidence level:** exact synthesis from [WI-357](../../findings/WI-357-null-equation-gives-threshold-continuity-on-the-ground-state-class.md), [WI-358](../../findings/WI-358-log-energy-budget-does-not-give-cofinal-threshold-continuity.md), and [WI-359](../../findings/WI-359-source-norm-graph-control-still-cannot-make-prime-thresholds-cofinal.md).

WI-357 establishes the correct local topology at a prime-power activation threshold. On actual normalized null states, Suzuki's null equation bounds logarithmic energy, and bounded logarithmic energy gives an inverse-logarithmic modulus for the autocorrelations entering the finite source ledger. A newly activated prime channel is therefore form-small on the selected state even though it jumps in ambient operator norm.

WI-358 shows why this cannot be promoted to a global threshold-by-threshold argument using the energy budget alone. There are normalized tests with the allowed logarithmic-energy scale for which an already-present source autocorrelation changes by order one between consecutive thresholds. The witnesses are not null states, so they do not contradict WI-357; they show that the scalar budget class itself has no cofinal modulus strong enough to carry positivity indefinitely.

WI-359 strengthens the comparison and still finds the same boundary. The same threshold-resolving oscillations have principal graph cost only `||T_0u_j||=O(a_j)`. Moreover they can be made **exact zero modes** of rank-at-most-two bounded self-adjoint perturbations whose norm lies inside the natural scalar coefficientwise envelope obtained from Suzuki's arithmetic remainder. That envelope is exponentially larger, `U(a)>=(4+o(1))e^a`, so generic graph control plus an abstract zero-mode equation leaves ample room for the bad threshold motion.

The distinction is therefore structural. **Local continuity is selected by the actual source equation; cofinal control must use source structure that is lost under scalar compression.** Replacing the real `K_a` by its norm, or the real null state by the class of zero modes of arbitrary perturbations with the same bound, discards precisely the coupling that could make successive thresholds coherent.

A global first-crossing exclusion must consequently exploit something specific to the true arithmetic perturbation: relations among the von-Mangoldt translation channels, the archimedean kernel, signed-source identities, firstness, or a coercive reserve tied to those channels. Improving a generic continuity theorem on an energy/graph ball cannot cross the WI-358/WI-359 boundary.

**Boundary.** WI-359's rank-two perturbations are comparison operators, not Suzuki's actual `K_a`, and the witnesses are not constructed as true first-crossing states. The result does not refute WI-357 or show that actual null states jump. It rules out only cofinal arguments whose retained information reduces to scalar energy/graph regularity, an abstract zero-mode equation and a scalar perturbation-norm envelope.
