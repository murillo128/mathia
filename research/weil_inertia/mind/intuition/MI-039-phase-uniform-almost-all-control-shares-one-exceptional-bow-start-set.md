# MI-039 — Phase-uniform exceptional starts are regime-dependent; below theta=3/16 the obstruction is the norm

**Evidence level:** exact/literature synthesis from [WI-327](../../findings/WI-327-signed-source-subtraction-kills-generic-cubic-resonance-but-not-exceptional-bows.md) through [WI-331](../../findings/WI-331-all-interval-nilsequence-control-removes-distinguished-start-exceptionalism-below-theta-3-16.md).

WI-328 identifies the first source length where varying height across a surviving bow can produce order-one phase motion: `J asymp X^(1-2 theta)`. WI-329 shows that the matching modern almost-all theorem is uniform over the relevant bounded-complexity polynomial phase family, so within that theorem's regime one common exceptional set of starts survives all bow heights. Phase diversity alone does not create source-start diversity.

WI-331 sharpens the quantifier boundary using the older all-interval nilsequence theorem. Its threshold `J >= X^(5/8+epsilon)` is met by the natural bow length whenever fixed `theta<3/16`. In that range the signed `Lambda-Lambda_X^sharp` nilsequence bound holds for **every** start `M~X` and uniformly for the relevant heights `|U|<=C X^2`. The distinguished-start exceptionalism is therefore absent below `theta=3/16`.

This splits the surviving bow regime into two qualitatively different arithmetic bottlenecks. For `0<theta<3/16`, the problem is no longer how to remove an exceptional start: all-start linear-amplitude cancellation is already available. The obstruction is that this pointwise bound is too weak in norm after squaring to supply the diagonal-scale `L^2` variance required by the exact WI-195 covariance. For `3/16 <= theta <= 3943/12011`, the stronger all-start theorem no longer reaches the natural source length, so the common exceptional-start issue remains alongside the variance gap.

The reusable lesson is that **quantifier and norm must be audited separately**. Upgrading almost-all control to all-start control can close the location problem without coming close to the covariance scale needed by the destination. Conversely, adding more phases at one start cannot repair a quantifier gap when the theorem is already uniform over those phases.

**Boundary.** WI-331 does not provide the WI-195 diagonal-scale `L^2` estimate, exclude off-line zeros, or settle the intermediate exponent range. The `theta=3/16` threshold is the reach of the cited all-interval theorem at the natural bow scale, not a claimed intrinsic RH barrier. Above it, source-start exceptionalism may still matter; below it, the live obstruction is the stronger variance/norm requirement.
