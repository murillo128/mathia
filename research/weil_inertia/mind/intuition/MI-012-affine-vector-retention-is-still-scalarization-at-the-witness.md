# MI-012 — Affine vector retention is still scalarization at the periodic witness

**Evidence level:** exact route-specific obstruction through WI-177

## Core intuition

Keeping several local coordinates does not by itself preserve non-scalar information. If the global theorem ultimately consumes a finite-dimensional additive state only through affine linear functionals, support functions, or positive LP/conic dual combinations, every final certificate is again one scalar question about an invariant average. A deterministic periodic source witness can answer all of those questions simultaneously.

For the current Weil-inertia assembly, the period-33 Montgomery--Taylor witness supplies exactly such a rotation vector. A useful vector escape must therefore retain a genuinely joint constraint that is not equivalent to valid affine taxes on the same witness class, or introduce source information that makes the witness inadmissible.

## Strongest justified principle

WI-177 allows an arbitrary translation-covariant local observable `U(B)` in any finite-dimensional real vector space. For every affine channel `ell_theta`, the universal local floor and the global tax are both tested on the same phase-averaged witness vector `bar U`. The local credit `ell_theta(bar U)` and global cost cancel, leaving every valid directional density bound below the certified period-33 density; in the standard nonnegative-floor regime the same uniform `0.673604` ceiling survives.

The result is pointwise in the dual direction, so optimizing a support function after retaining the whole vector does not help. Finite positive combinations of local affine certificates reduce by weak duality to one averaged affine functional and inherit the same witness. The obstruction is independent of the dimension of `U` and of the nonlinear way a block produces that vector.

## What remains possible

A genuinely nonlinear joint admissible set can escape if it excludes the period-33 rotation point for source-specific reasons not expressible as affine taxes valid on that class. Coupling several profiles through an exact arithmetic relation, using information from the exceptional indefinite block, or proving a zeta-specific spacing/correlation/multiplicity restriction can also break the witness hypothesis.

The distinction is not “scalar versus vector storage.” It is **whether joint source information survives the final dual consumption**.

## Status / novelty

Rotation sets, support functions, ergodic optimization, and LP/conic duality are classical. The durable line-specific synthesis is the witness test: an additive vector remains informationally scalar if every theorem-level use of it factors through affine functionals on a deterministic source class containing the certified period-33 orbit.

## Falsification criterion

Give a vector-valued assembly satisfying WI-177's affine hypotheses whose optimized final bound crosses the witness ceiling, invalidate the common phase-average/tax evaluation on the period-33 source, or exhibit a source-forced joint constraint that excludes the witness while not reducing to an affine tax already covered by the theorem.
