# MI-025 — Gamma-pole self-consistency forces a global L1 mass floor

**Evidence level:** exact source-local rigidity from [WI-296](../../findings/WI-296-gamma-pole-self-consistency-forces-an-l1-mass-floor.md), sharpening the support-only bathtub bound in [WI-295](../../findings/WI-295-exact-gamma-bathtub-forces-positive-support-and-separated-mass-budgets.md)

For a normalized one-signed first-crossing null mode `v>=0` under complete prime-power screening, let

`M=||v||_1`, `s=M^2`.

WI-295 bounded the gamma energy using the support measure. WI-296 keeps the actual Fourier cap `|vhat(z)|<=M` in the same exact bathtub profile `H`. Compact support prevents equality with the saturated frequency box, so

`G(v)>H(s)`.

The positive pole factorization acts on the same mass:

`P_a(v)=2 L_-(v)L_+(v) >= 2 M^2=2s`.

Since complete screening gives the null identity `G(v)+P_a(v)=0`, the same vector must satisfy

`H(s)+2s<0`.

If `sigma_* = inf{u>0 : H(u)+2u<0}`, then every hypothetical candidate obeys the strict chain

`mu_* < sigma_* < ||v||_1^2 <= |{v>0}| <= log 2`,

and `P_a(v)>2 sigma_*`. Thus complete one-signed screening forces not only positive support measure but a **global positive L1 mass budget generated by gamma/pole self-consistency**.

This sharpens the remaining escape. Remote components may still carry arbitrarily small individual mass while most of the forced global `L^1` mass sits in a bounded core, so the theorem does not yet contradict many-component screening. The live issue is spatial distribution: combine the global mass floor with the exponentially decaying separated-mass tariff of WI-295 and `L^2` normalization strongly enough to prevent indefinitely weak remote satellites.

**Boundary.** `sigma_*` is defined by the exact bathtub profile; numerical values are orientation only. The result applies to the one-signed, completely screened branch and does not cover sign-changing modes, incomplete screening, or unrestricted supported spectral relaxation.
