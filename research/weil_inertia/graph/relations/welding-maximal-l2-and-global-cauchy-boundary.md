# Welding boundary: maximal interval control versus forbidden global Cauchy

[[research/weil_inertia/findings/WI-041-mrt-endpoint-stability-gives-maximal-interval-l2|WI-041]] sharpens the source-side welding analysis by showing that movable interval endpoints can be absorbed into a maximal-interval `L^2` estimate in the Matomäki–Radziwiłł–Tao long-shift regime. The remaining loss is concentrated in sparse-coefficient / residue-class aggregation rather than endpoint motion itself.

[[research/weil_inertia/findings/WI-042-public-band-ledger-is-the-forbidden-family-cauchy-route|WI-042]] then audits the public executable band ledger and shows that it uses the across-family/global Cauchy–Schwarz route that the printed argument explicitly excludes because of its Poisson-floor cost.

The supported boundary is:

```text
moving interval selector
    -> maximal MRT L2 control removes endpoint obstruction
    -> remaining outer aggregation is load-bearing
    -> public ledger uses forbidden across-family Cauchy
```

WI-042 does not refute the Yang–Yang one-sided fourth-moment candidate. It closes only the repair route that treats the current public global-cell ledger, or standard MRT/BDH applied after that global square, as the missing theorem bridge.
