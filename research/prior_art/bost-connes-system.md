# Bost-Connes system

## What it is

An arithmetic quantum statistical mechanical system in which the Riemann zeta function occurs as thermodynamic counting data and its pole corresponds to a phase transition in the equilibrium-state structure. The retained analysis also records an arithmetic symmetry acting on the low-temperature phases.

## Relation to RH / Mathia research

For Mathia this is a concrete bridge from zeta to operator-algebraic dynamics and symmetry. It is relevant as an established realization of arithmetic information, not as a zero criterion.

## Known scope and limits

Encoding zeta as a partition function does not locate its nontrivial zeros and does not prove RH. This note does not merge the system with Connes's separate adele-class trace program merely because both use noncommutative geometry.
